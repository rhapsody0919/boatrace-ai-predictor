# SNS PDCA の基準値と必要件数（2026-10-12）

spec の「統計検証」節の根拠。読み取りのみ（GA4・YouTube Analytics・sns_drafts）。

## 再実行

```bash
node scripts/analysis/sns-pdca-baseline/ga4-sns-inflow.js --from=2026-08-15 --to=2026-10-11
node scripts/analysis/sns-pdca-baseline/youtube-shorts-metrics.js --since=2026-08-01 --to=2026-10-11
node scripts/analysis/sns-pdca-baseline/power.js --ga4=data/analysis/sns-pdca-baseline/ga4-2026-08-15_2026-10-11.json --youtube=data/analysis/sns-pdca-baseline/youtube-2026-08-01_2026-10-11.json
```

worktree で動かすときは `GOOGLE_SERVICE_ACCOUNT_KEY_PATH` に本体の `credentials/google-service-account.json` を渡す。結果は `data/analysis/sns-pdca-baseline/`（youtube-*.json）。ga4-*.json・power-2026-10-12.json（GA4 の実数を含む）は hq へ移した（2026-11-06）。

## 前提

- 投稿は 9/15 から止まっている（sns_drafts の最終投稿は X 9/14、YouTube 9/15）。「投稿したときの基準値」は投稿期 8/29〜9/15（X 51件、YouTube 35本）を使う
- GA4 は www.boat-ai.jp だけ。流入元は完全一致のリスト（X: t.co・x.com・twitter.com・x、YouTube: youtube.com 等）。正規表現 `t\.co` は chatgpt.com にも当たるため使わない
- GA4 は Cookie に同意した人だけ（src/utils/analytics.js）。数は下限
- ユーザー数は日ごとの totalUsers の和

## 基準値

### サイト流入（GA4）

X・YouTube 由来の人/日、自然検索の対照、ソナーのタブを開いた人の実数は hq へ移した（2026-11-06 オーナー決定）。SNS 由来の流入は1日1人前後で、週ごとの判定には足りない。

### YouTube Shorts（youtube-2026-08-01_2026-10-11.json）

日付は太平洋時間（YouTube Analytics の日）。2日の窓は PT の投稿日＋翌日。

| 指標 | 値 |
|---|---|
| アップロード / 再生のある動画 | 41本 / 35本（6本は再生0） |
| views 中央値 / p25 / p75 / 最大 / 合計（投稿日〜10/11、再生のある35本） | 248 / 168 / 460 / 1,190 / 13,575 |
| 投稿日と翌日の2日に出た再生の割合 | 99.2% |
| 2日で100回以上（フィードに乗った）割合（分母はアップロード41本） | 65.9%（27本） |
| 2日で30回以上の割合（分母はアップロード41本） | 70.7%（29本） |
| 2日の engagedViews/views（2日で30回以上の29本） | 平均0.126（SD 0.069） |
| 2日の平均視聴率（同、100%超の外れ値を除く28本） | 56.4%（SD 13.8） |

- Shorts の再生に対し、YouTube 由来のサイトユーザーはごくわずか（実数は hq）。Shorts の再生画面からは外部へリンクできない（2023-08-31 以降）

## 必要件数（power-2026-10-12.json#perArm、版ごと、検出力0.8・両側α=0.05）

| 指標（基準値） | +20% | +50% | +100% |
|---|---|---|---|
| X 由来ユーザー/日（基準値は hq、過分散1.68） | 654日 | 119日 | 36日 |
| 同 /週 | 94週 | 17週 | 6週 |
| SNS 由来ソナー利用/日（仮置き0.25、ポアソン） | 1,727日 | 314日 | 95日 |
| YouTube views（対数 SD 1.72） | 1,402本 | 284本 | 97本 |
| YouTube engagedViews（対数 SD 1.31） | 813本 | 165本 | 57本 |
| engagedViews/views（0.126、SD 0.069）を**投稿本数**で | 167本 | 27本 | 8本 |
| 平均視聴率（56.4%、SD 13.8）を投稿本数で | +5pt で170本 | +10pt で43本 | — |
| フィードに乗った率（65.9%） | 177本 | 18本（ほぼ全部が乗る水準） | — |

- 率の指標は2日で30回以上の動画でしか計算しない。30回以上になるかは版の効果を受けるので、必要件数は「30回以上の本数」を投稿本数に換算した（÷0.707）。換算前の値は JSON の `engagedRatioVideos`・`averageViewPercentageVideos`
- 日替わりで2つの版を交互に出すなら、合計の日数は2倍。engagedViews/views が1.5倍なら版ごと27本で約8週、平均視聴率 +10pt なら版ごと43本で約12週

## 言えること・言えないこと

- **サイト流入とソナー利用は、週ごとには判定できない**。流入が2倍になっても版ごとに6週（交互なら12週）要る。+20% は事実上判定できない
- **YouTube はサイト流入で判定しない**。動画の中の指標（engagedViews/views・平均視聴率・フィードに乗った率）を版の判定に使う。engagedViews/views が1.5倍になれば版ごとに27本（1日1本の交互で約8週）で判定できる。小さい改善（+20%）はどの指標でも1年以上かかり、判定できない
- **週ごとの「守り」は基準値1点と比べない**。1週間7本では、効果が無くても半分ほどの週で基準値を下回る。直近4週の分布の下側10%を下回ったときだけ「悪化」とする
- **X の1投稿ごとの指標（表示・リンクのクリック）は未取得**。ばらつきが分からないので必要件数は出せない。X API の取り込みが始まって4週たまったら出し直す
- ソナー利用の基準値は4日で1人からの仮置き。4週たまったらやり直す

## 交絡と抑え方

| 要因 | 状況 | 抑え方 |
|---|---|---|
| 曜日 | 自然検索の曜日差 約±12% | 版を曜日で入れ替える |
| チャンネル全体の勢い | 9/6 に1000回以上が3本、9/16 以降は1日0〜11回 | 前後比較をしない。日替わりで交互に出す |
| 投稿を止めていた影響 | 止まった後も X 由来が0.39人/日残る | 再開直後の2週は基準値の取り直しにあてる |
| SG・G1 の開催日 | 未検証 | 開催日の印を付けて、版の間で数をそろえる |
| ブログ公開・検索の変動 | 10/12 にブログ3本公開 | SNS は流入元で絞る。サイト全体と自然検索を対照に並べる |
| Cookie 同意 | 同意しない人は数えられない | GA4 の数は下限として扱う |
| オーナーが手で出す投稿 | t.co の流入に混ざる | 型の投稿には utm_content を付け、UTM 無しの t.co と分けて数える |
| 再生数の窓 | YouTube Analytics は太平洋時間の日単位 | 投稿日を PT で数える（UTC で数えると41本中21本で1日ずれる。2026-10-12 の design-reviewer の指摘で直した）。2日で99%出るので日単位の窓でよい |
