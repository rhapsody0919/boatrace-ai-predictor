```bash

node scripts/analysis/sns-pdca-baseline/youtube-shorts-metrics.js --since=2026-08-01 --to=2026-10-11
```

worktree で動かすときは `GOOGLE_SERVICE_ACCOUNT_KEY_PATH` に本体の `credentials/google-service-account.json` を渡す。結果は `data/analysis/sns-pdca-baseline/`（ga4-*.json・youtube-*.json・power-2026-10-12.json）。

## 前提

- 投稿は 9/15 から止まっている（sns_drafts の最終投稿は X 9/14、YouTube 9/15）。「投稿したときの基準値」は投稿期 8/29〜9/15（X 51件、YouTube 35本）を使う
- GA4 は www.boat-ai.jp だけ。流入元は完全一致のリスト（X: t.co・x.com・twitter.com・x、YouTube: youtube.com 等）。正規表現 `t\.co` は chatgpt.com にも当たるため使わない
- GA4 は Cookie に同意した人だけ（src/utils/analytics.js）。数は下限
- ユーザー数は日ごとの totalUsers の和

## 言えること・言えないこと

- **サイト流入とソナー利用は、週ごとには判定できない**。流入が2倍になっても版ごとに6週（交互なら12週）要る。+20% は事実上判定できない
- **YouTube はサイト流入で判定しない**。動画の中の指標（engagedViews/views・平均視聴率・フィードに乗った率）を版の判定に使う。engagedViews/views が1.5倍になれば版ごとに19本（1日1本の交互で約5〜6週）で判定できる
- **X の1投稿ごとの指標（表示・リンクのクリック）は未取得**。ばらつきが分からないので必要件数は出せない。X API の取り込みが始まって4週たまったら出し直す
- ソナー利用の基準値は4日で1人からの仮置き。4週たまったらやり直す

## 交絡と抑え方

| 要因 | 状況 | 抑え方 |
|---|---|---|
| 曜日 | 自然検索の曜日差 約±12% | 版を曜日で入れ替える |
| チャンネル全体の勢い | 9/6 に1000回以上が3本、9/16 以降は1日0〜11回 | 前後比較をしない。日替わりで交互に出す |
| 投稿を止めていた影響 | 止まった後も X 由来が0.39人/日残る | 再開直後の2週は基準値の取り直しにあてる |
| SG・G1 の開催日 | 未検証 | 開催日の印を付けて、版の間で数をそろえる |
| ブログ公開・検索の変動 | 10/12 にブログ3本公開 | SNS は流入元で絞る。サイト全体と自然検索を対照に並べる |
| Cookie 同意 | 同意しない人は数えられない | GA4 の数は下限として扱う |
| オーナーが手で出す投稿 | t.co の流入に混ざる | 型の投稿には utm_content を付け、UTM 無しの t.co と分けて数える |
| 再生数の窓 | YouTube Analytics は日単位 | 投稿の時刻をそろえる。2日で99%出るので日単位の窓でよい |
