# 1号艇の選手別の回収率は、20〜45走で「言えること」になるか

全貌動画の場面3③（1号艇の選手の、1号艇での過去180日の単勝・複勝回収率）を残すかの判断材料（BOA-913、2026-10-20、data-scientist）。

## 方法

- 式: 払戻の合計 ÷（走の数 × 100円）。画面の `getRacerBoatReturnRate` と同じで、不成立（`race_status='no_race'`）だけを除く
- 母集団: race_entries の `boat_number=1` × race_results（読み取りのみ、匿名キー）
- 直近180日（2026-04-22〜10-19）: 1号艇が20〜45走の選手617人の分布と、ブートストラップ（2000回、乱数の種を固定）の95%区間
- 時期を分けた再現性: 前半 2025-12-01〜2026-05-31 で20〜45走、後半 2026-06-01〜10-19 で15走以上の496人。前半の値で後半を当てられるか（Spearman の順位相関）

## 結果

| 項目 | 値 |
|---|---|
| 1号艇全体（180日、28,282走・1,539人） | 1着率54.6%・単勝回収率90.2%・複勝回収率92.9% |
| 1走あたりの払戻の標準偏差 | 単勝115円・複勝99円 |
| 95%区間の半分の幅（20・30・45走） | 単勝 ±50・±41・±34pt、複勝 ±43・±35・±29pt |
| 20〜45走の選手で、単勝の区間が100%を含む割合 | 85.3% |
| 前半→後半の順位相関 | 単勝回収率 0.055・複勝回収率 0.033・1着率 0.449・2連率 0.315 |
| 前半の単勝回収率100%以上／未満で分けた後半の平均 | 89.7% ／ 90.1%（差なし） |
| 前半の1着率で中央値の上／下に分けた後半の1着率 | 71.7% ／ 60.7%（11pt の差が残る） |

4レースの1号艇の選手（窓の終わりを10/19に固定）は、4人とも単勝の区間が90%と100%の両方を含む。

## 言えること・言えないこと

- 言える: 20〜45走の回収率は、選手の差を示さない（時期をまたぐと残らない）。1着率・2連率は残る
- 言える: 回収率は「1着率 × 払戻（人気）」で、「1号艇は信頼できる？」の答えに筋が合わない
- 言えない: 100走以上の選手の回収率が残るか。会場・級別に分けた再現性
