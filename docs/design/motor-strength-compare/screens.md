# モーターの強さをひと目で比べる（screens）

spec: [spec.md](./spec.md)（BOA-428）。子1（6艇の比較）と子3（会場モーターランキング）の2画面。

## 影響する画面

| 画面 | URL | 変更 | 役割 |
|---|---|---|---|
| レース詳細「モータ情報」タブ | `/race/:raceId`（タブ「モータ情報」） | 既存の6艇表を改修（子1） | 出走6基の公式2連率を横棒で比べ、各行に「会場内◯位／◯機中」を添える |
| 分析ツール「モーター調子」タブ | `/winning-technique?tab=motor` | 子1と同じ部品なので同時に変わる | レースを選んだときの6艇表が、レース詳細と同じ見た目になる |
| 分析ツール「モーターランキング」タブ（新規） | `/winning-technique?tab=motorranking` | 新しいタブ（子3） | 会場を選ぶと、その会場の全モーター（約60基）を順位・機番・2連率（横棒）・優出・優勝・前検・今節使用者で並べる |

## 画面の構成（ワイヤーフレーム）

### 子1: モータ情報タブの6艇表（375px）

```
モーター調子（このレースの6基）            [期間: 90日 ▼]
┌──┬──────┬────┬──────────────────────┬────────┐
│枠│選手  │機番│公式2連率（節時点）    │会場内順位│
├──┼──────┼────┼──────────────────────┼────────┤
│1 │西村拓也│69 │████████████▌    35.7% │20位/60 │
│2 │下條雄太郎│22│█████████████   36.2% │17位/60 │
│…                                                   │
│6 │峰竜太 │44 │██████████████▉  40.0% │ 7位/60 │ ← 最大を全長
└──┴──────┴────┴──────────────────────┴────────┘
 ※会場内順位は会場サイトの2連率（9/30時点）で数えた順位
 ※モーターの2連率には、乗った選手の実力も混ざります
 （既存の列: 3連率・前検・機力指数・優出・優勝 は右へ。横スクロール）
```

- 2連率のセルに横棒を重ねる（数字は棒の右端）。6基の最大の値を全長にする
- 会場内順位は2連率の列のすぐ右（今の「2連率より左に列を足さない」方針を守る）
- 同じ値は「17位タイ」

### 子3: 分析ツール「モーターランキング」タブ（375px）

```

出典: 児島 公式サイトのモーター成績（2026/9/30時点）
┌───┬────┬──────────────────┬───┬───┬─────┬────────┐
│順位│機番│2連率 ▼            │優出│優勝│前検  │今節使用者│
├───┼────┼──────────────────┼───┼───┼─────┼────────┤
│ 1 │ 55 │████████████ 47.9 │ 6 │ 2 │6.79 │磯部 誠 │
│ 2 │ 20 │███████████▊ 47.2 │ 7 │ 0 │6.70 │桐生 順平│
│ …                                                         │
│17 │ 16 │█████████  36.1   │ 4 │ 0 │6.87 │渡邉 優美│ ← 同率は同じ順位
│17 │ 22 │█████████  36.1   │ 6 │ 0 │6.80 │下條雄太郎│
│ …                                                         │
│60 │ 70 │████▋     18.6    │ 1 │ 0 │  -  │   -    │ ← 今節使われていない
└───┴────┴──────────────────┴───┴───┴─────┴────────┘
 機番・2連率・優勝・前検の見出しを押すと並べ替え（前検は速い順）
 ※モーターの2連率には、乗った選手の実力も混ざります
```

- 初期は2連率の降順。表の中だけ横スクロール（375pxで「順位・機番・2連率」が最初の画面に入る）
- 今節使用者は選手ページへのリンク（`translate="no"`）
- 機番は既存のドリルダウン（`?tab=motor&motor=N`）へのリンク
- データの無い会場（戸田・浜名湖・宮島）: 出典の行を「BOATRACE 公式の出走表（今節使用中のモーターのみ）」に替え、優出・優勝は「-」

## コンポーネント

| コンポーネント | 新規/拡張 | 内容 |
|---|---|---|
| `MotorConditionChart.jsx`（6艇表） | 拡張 | 公式2連率の列を横棒つきにし、会場内順位の列を足す。会場内順位は `getVenueMotorRanking` を6基分まとめて引く（下記） |
| `RateBar`（新規、`src/components/common/`） | 新規 | セルの中に横棒と数字を出す小さな部品。値・最大値・色（トークン名）を受け取る。子1・子3の両方で使う。基本情報タブの勝率バー（`.rbit-bar-track`）とは見た目が違う（あちらは行全体の帯）ので、置き換えはしない |
| `VenueMotorRanking.jsx`（新規、`src/components/analysis/`） | 新規 | 子3のタブ本体。会場の選択は既存の `useVenueRaceSelector`、横スクロールの手がかりは `useHorizontalScrollHint`、順位は `competitionRank` |
| `WinningTechniqueAnalysis.jsx` | 拡張 | タブ `motorranking` を足す（`TAB_KEYS`・`analysisPage.info`・4言語） |
| `supabaseDataService` | 拡張 | 子1: 6基分の会場内順位をまとめて返す関数（`getVenueMotorRanking` の会場全体の結果を1回だけ取り、6基分を引く）。子3: 会場の全モーターの一覧（`venue_motor_stats` の最新スナップショット＋`motor_pretest_stats`＋使用者） |

- `App.jsx` と `RaceDetail.jsx` の両方に同じ UI が要る箇所は無い（6艇表は `MotorConditionChart` の1か所）
- 新しいクラス名は部品に固有にする（`.rate-bar-*`、`.vmr-*`。`.claude/rules/component-reuse.md`「CSS」）

## デザイントークン

- 文字色・背景: 意味トークン（`--text-primary` / `--text-secondary` / `--surface-card` / `--surface-page`）。ダークモードで反転する
- 横棒の色: **未確定**。「レース詳細UI統一レーン」が決める色分けの共通ルールに合わせる（spec の未確定事項）。モックは中立の色（`--text-secondary` の薄い塗り）で描く
- 新規 CSS が要るもの: 横棒のトラックと塗り（幅を % で指定）、ランキング表の列幅。余白・文字サイズはトークンで足りる

## 文言（ja。4言語に足す）

- 列見出し: 「公式2連率（節時点）」（既存キー）、「会場内順位」、「順位」「機番」「2連率」「優出」「優勝」「前検」「今節使用者」
- 順位の表記: 「17位／60機中」「17位タイ」（既存の `venueRankBadgeTied` に合わせる）
- 出典: 「出典: {{venue}} 公式サイトのモーター成績（{{date}}時点）」
- 注記: 「モーターの2連率には、乗った選手の実力も混ざります」
