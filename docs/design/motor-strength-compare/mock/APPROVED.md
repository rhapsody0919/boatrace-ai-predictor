# 承認済みモック（BOA-428 モーターの強さをひと目で比べる）

- 承認日: 2026-10-02（オーケストレーター経由のユーザー回答）
- 画像: [mock-375.png](./mock-375.png)・[mock-1440.png](./mock-1440.png)（データは本番の実データ。児島 2026-09-30 7R の6基、児島の全60基の 9/30 時点）

## 承認の要点

- (a) 棒（BOATRACE 公式の2連率）と会場内順位（会場公式サイトの2連率）の出どころが違う点は、注記で書く形でよい
- (b) 棒の色は、レース詳細UI統一レーンのルールに合わせる。棒・線は艇色のまま、良し悪しは値ラベルで示す（最良は金枠＋太字。同じ値の最良は全部光らせる）
- (c) 見た目・列の並び・注記の文言は、モックのままでよい

## 承認の範囲

- 子1: レース詳細「モータ情報」タブの6艇表（`MotorConditionChart.jsx`）。分析ツールの「モーター調子」タブも同じ部品。列の並びは「枠・選手・機番・公式2連率の棒・会場内順位」を左に置き、既存の列を右に続ける
- 子3: 分析ツールの新しいタブ「モーターランキング」（`VenueMotorRanking.jsx`）
