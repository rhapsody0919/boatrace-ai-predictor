# race-ai-copy 仕様書

## 種別
UI機能（画面・コンポーネントが関わる）

## 対応Linearチケット
[BOA-194](https://linear.app/boat-ai/issue/BOA-194/レースデータプロンプトをコピーして外部aichatgptgemini等で予想できる機能) — レースデータ+プロンプトをコピーして外部AI（ChatGPT/Gemini等）で予想できる機能

## 背景
「レースごとの各データとプロンプトをコピペできたら嬉しいはず」というユーザー発案（2026-08-16）。自前のAIツール（ChatGPT/Gemini等）にboatAIのデータを読み込ませて独自に予想したいユーザー層向けの機能。

## 機能要件

### 必須（P0）

| # | 要件 | 受入基準 |
|---|------|---------|
| 1 | データ出走表（6艇×11指標: 全国勝率・当地勝率・モーター2連率・調子・平均ST・ST安定度・展示ST・展示タイム・コース別勝率・決まり手・単勝回収率）をMarkdown表形式でクリップボードにコピーする | ボタンクリック後、`navigator.clipboard`にMarkdown表形式のテキストが格納され、任意のテキストエディタにペーストして表として読める状態になっている |
| 2 | 分析依頼の定型プロンプトを3パターン（単勝予想用・3連単予想用・3連複予想用）から選択し、データ出走表と併せてコピーする | ユーザーが3パターンのいずれかを選択した状態でコピーすると、選択した券種向けの依頼文＋データ出走表がまとめてコピーされる |
| 3 | コピーボタンを (a) 予想パネル内（SNSシェアボタン付近） (b) データ出走表コンポーネント付近 の両方に設置する | 両方の設置箇所からコピー操作が開始できる |
| 4 | コピー成功時にトースト通知等の視覚的フィードバックを表示する | コピー実行後、1〜2秒程度「コピーしました」等の通知が表示され自動的に消える |
| 5 | 結果未確定のレースでのみボタンを表示する（展開予測の表示条件と同じロジック） | 結果確定済みレースの詳細ページではコピーボタンが表示されない |
| 6 | コピーするテキストの言語は、サイトの現在の表示言語（ja/en/zh-TW/ko）に合わせる | `/en/race/...`等の言語別URLでコピーすると、プロンプト文言・出走表の項目名（見出し）が対応言語で出力される |
| 7 | コピーボタンに常時軽いパルス/バウンスアニメーションを付け、「あなたのAIに聞ける！」風の短いキャッチコピーを併記して新機能であることを視覚的に訴求する | ボタンが静止画像ではなく周期的なアニメーションを伴って表示され、近接する位置に説明バッジ・吹き出し等でキャッチコピーが表示される。訪問者が偶然見つけるのではなく能動的に気づける状態になっている |

## スコープ

### やること
- 上記機能要件の実装
- ja/en/zh-TW/koの4言語対応（プロンプト文言・出走表の項目名見出し）

### やらないこと
- 外部AI APIとの自動連携（ChatGPT/Gemini等のAPIを直接呼び出す実装は行わない。クリップボードコピーのみ）
- 複数レースの一括コピー（1レース単位のみ）
- コピー履歴・お気に入り機能

## 非機能要件
- モバイル対応必須（iOS Safariを含む主要ブラウザでclipboard APIが正常動作すること。実装後Playwrightで動作確認する）
- それ以外の特別な数値要件なし

## 制約・前提
- 新規のSupabaseクエリ・RPCは不要。既存の`RaceDetail.jsx`が保持する`prediction`オブジェクト（データ出走表11指標は`DataRaceTable`/`raceIndicators.jsx`が既に構築済み）から出力用テキストを組み立てる
- クリップボードコピー機能・トースト通知コンポーネントは現状ゼロから新規実装が必要（既存の`utils/share.js`のテキスト生成関数群がテンプレートリテラルによる文字列組み立ての参考実装として使える。SNSシェア機能`SocialShareButtons.jsx`は外部リンクを開くのみでクリップボードは扱っていないため、コピーAPI部分は新規実装）
- 展開予測（1マーク展開予測）・イン崩れ指数はコピー対象に含めない（データ出走表のみ）
- 用語ルール（「競艇」使用禁止、`docs/reference/i18n-glossary.md`準拠の多言語訳語）を、生成するプロンプト文言・UI表示テキストに適用する
- ディスクレイマー: 新規追加不要。サイト全体の既存の「AI予測は結果を保証しない」旨の注意書きで対応する
- `Header`等の共通コンポーネント・既存の予想パネル/データ出走表の表示ロジック自体は変更しない（コピー機能の追加のみ）
