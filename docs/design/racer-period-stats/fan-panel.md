# 選手ページの公式成績の見せ方（ファン4人の議論、GS00）

2026-10-28 に `discussion-panel` で議論した記録。ファン役は同じモデルのロールプレイなので、ここでの結論は仮説にすぎない。検証は、ファン評価ループ・オーナーが Preview を見ること・公開後の数字で行う。

前提とした材料は次のとおり。
- data-scientist の言える範囲（`analysis/display-scope.md`）
- `docs/knowledge/fan-reactions.md`・`user-insights.md`。特に user-insights の 2026-09-14「数値の表はグラフにする、厳密さは補助」と、fan-reactions の「6コースは横棒で縦に並べ、値を常に出す」

## 決めたいこと
1. 2つの表をどこに置くか
2. 期別の表の列と並び
3. コース別の表の列（何を主にするか）
4. 375px での見せ方
5. 枠番別との混同を防ぐ書き方

## 4人の意見

**20代男性**
- 選手名で検索して来たら、まず「どのくらい強いか」を見たい
- 置き場所は、プロフィールの直後に勝率の折れ線と最新の期の数字。今節のモーターより上
- 期は新しいものを上に。15期全部を並べられると長いので、残りは畳んでいい

**20代女性**
- コース別は表より横棒のほうがぱっと分かる
- 1〜6コースの2連対率を棒で並べ、横に進入の数を書いてほしい
- 少ない走数のコースを数字だけで見せられると、「6コース 0%」が実力に見えて誤解する。「参考」の印は小さくていいので付けてほしい

**30代男性**
- 艇国で見ていたのは、期別の勝率・2連率・優出・優勝の表と、コース別の進入回数・1着率・2連率・平均ST
- 表は省かないでほしい。スマホでは横にずらしてでも全部の列を見たい
- 級は数字の右端でいい。左から「期・勝率・2連率…」と読み、勝率が最初に目に入るほうがいい
- 枠番別とコース別は今まで混ざっていた。見出しで「公式・進入」と「当サイト・枠番」をはっきり分けてほしい

**30代女性**
- 折れ線の縦軸を狭くされると、小さな上下が大きく見えて「落ちてる」と読んでしまう。軸は少し広めにしてほしい
- 「公式の値は4月まで」という注意は1行あれば十分。長い説明は表の下でいい
- 優勝の回数は数字だけで、優勝したレースの一覧は別に欲しい（今回の範囲外）

## 割れた点
- **置き場所**
  - 20代男性と30代男性は「プロフィールの直後」
  - 20代女性は「今節のモーターを先に」。今節を見に来る人もいるため
  - → 結論は「プロフィールの直後」。検索で来る人の目的は成績で、今節は2つ目の目的と見た
- **コース別の主**
  - 20代女性は棒
  - 30代男性は表
  - → 結論は両方。棒（2連対率・進入の数）を先に置き、全部の列の表をその下に置く
- **期別の表の長さ**
  - 30代男性は全部を見せたい
  - 20代男性は畳みたい
  - → 結論は、直近4期（2年）を見せ、残りは「それより前の N 期を見る」で開く。開く前も中身はページの中にあり、検索エンジンに読まれる

## 結論（実装したもの）
1. 置き場所はプロフィールの直後。見出しは「{選手名}の公式成績（期別・進入コース別）」
2. 期別
   - 勝率（公式）の折れ線を15期分。縦軸は値の幅より上下に1点ずつ広げる
   - その下に表を置く。列は「期（集計期間）・勝率・2連対率・3連対率・出走・1着・優出・優勝・平均ST・この期で決まった級（適用の期間）」
   - 新しい期を上にし、直近4期を出して残りは畳む
3. コース別（直近3期の合算）
   - 2連対率の横棒（0〜100%）に、値と進入の数を常に出す
   - その下に表を置く。列は「コース・進入・1着率・2連対率・3連対率・平均ST」
   - 10走未満は率を出さない。10〜29走は「参考」と付ける。進入0は「進入なし」
4. 375px では、表を横にずらす。棒は縦に6本並べる
5. 混同を防ぐ書き方
   - コース別の見出しは「進入コース別成績（公式・期間）」。注記に「実際に何コースに入ったかで分けた公式の成績」と書く
   - 枠番別の見出しは「枠番別成績（当サイト集計・2025年12月以降・全会場計）」。注記に「何号艇で出たかで分けた成績」と書く
   - 古い注記「前づけは区別できない」は消した。今のデータと合わないため

## 知見ノートに足す行
- fan-reactions.md: 選手ページの公式成績は、プロフィールの直後に置く（検索で来る人の目的は成績）。期別は勝率の折れ線＋新しい期が上の表で、直近4期を出し残りは畳む。コース別は2連対率の横棒（値・進入数を常に出す）＋全列の表で、級の列は右端（2026-10-28、ファン役、docs/design/racer-period-stats/fan-panel.md）
- fan-reactions.md: 推移の折れ線の縦軸を値の幅いっぱいにすると、小さな上下が「落ちた」と読まれる。上下に余白を取る（2026-10-28、ファン役、同上）
