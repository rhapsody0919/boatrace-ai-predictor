# FT01 準優・優勝戦の注意度 × 1号艇の展示タイム順位

hq の依頼（FT01 優勝戦の思考の投稿の較正、2026-10-25）。準優勝戦・優勝戦で、イン崩れ注意度（gapband-r-v1）の3段と1号艇の展示タイム順位の3段を掛けたとき、1号艇が1着を逃した率を見る。

- スクリプト: `scripts/analysis/ft01-wall-grid/wall-grid.js`
- 結果: `data/analysis/ft01-wall-grid/wall-grid.json`（全セル・期間別・感度）、`data/analysis/ft01-wall-grid/wall-grid.csv`（全セル）

## 結論

- 準優・優勝戦の1号艇の非1着は、展示タイム順位が下がるほど高い。1〜2位 25.1%・3〜4位 31.5%・5〜6位 35.4%
- ラウンド（準優・優勝戦）と注意度の段をそろえても順位の傾きは残る（Mantel z=5.33）。期間の前後半（〜2026-02 z=2.76、2026-03〜 z=4.82）とも同じ向き
- 注意度35%未満（低い段）でも、展示5〜6位の1号艇は非1着 33.5%（n=445）で、1〜2位の 24.4%（n=2,308）より高い
- 注意度55%以上（崩れ注意の段）は17か月で6Rだけ（全部優勝戦、準優は0R）。準優・優勝戦では崩れ注意の段は実質出ない

## 母集団

- 期間: 2025-06-01〜2026-10-24（実データの最初と最後の日も同じ）
- 〜2025-12-02 は kb_archive_races・kb_archive_boats（stage が「準優勝戦」「優勝戦」、has_result）、2025-12-03〜 は本体（race_conditions.race_stage が「準優勝戦」「優勝戦」の完全一致）
- 使ったレース 4,191R（長期 1,472R・本体 2,719R）。そのうち注意度の累積件数が100未満（sparse）の25Rを除いた **4,166R** を表に使う
- 除いたもの: 返還艇あり（長期 90R、本体 race_status=partial_refund 101R）、本体の結果なし 22R。不成立（race_status='no_race'）・中止（is_cancelled、races.cancellation_status）も除く。is_no_race は使わない（BOA-1107）

## 定義

- **注意度（gapband-r-v1）**: 勝率差 = round(1号艇の全国勝率×100) − round(2〜6号艇の最高×100)。帯 = clamp(floor(差/50), −8, 6)。率 = in_caution_gap_band_daily の (ラウンド, 帯) の、レース日より前の日までの累積 non_win / n（朝の生成と同じ）。pct = (200k + n) div (2n)
- **段**: 低い <35、互角 35〜55未満、崩れ注意 >=55。累積 n<100 のセルは出さない（sparse）
- **展示タイム順位**: exhibition_time の6艇の昇順。同タイムは小さい方の順位をそろって取る（method=min。例 6.70・6.70 → ともに1位）。6艇そろわないレースは除く。3段 1〜2位・3〜4位・5〜6位
- **艇番版**: 艇番1の艇。**実進入版**: 実進入1コースの艇（本体 race_results.actual_course_N、長期 kb_archive_boats.course）。注意度はどちらも1号艇の勝率差で決まる同じ値
- 区間は Wilson の95%区間。順位の傾きは、層（ラウンド×段）の中で順位3段に得点1・2・3を付けた Mantel の傾向検定

### 実進入版・感度

- 実進入版の全段: 1〜2位 24.7%・3〜4位 31.2%・5〜6位 35.8%、Mantel z=5.70。実進入1コースが1号艇でないのは 4,166R中30R
- 艇番版との差はセルごとに最大1.5pt（準優の35〜55%・5〜6位、n=30）。件数100以上のセルでは最大1.1pt（優勝戦の35%未満・5〜6位、n=136）
- 1号艇が展示タイムで他艇と同タイムのレースは 969R（4,191R の23%）。同タイムを大きい方の順位に寄せても（method=max）Mantel z=5.45 で向きは同じ（JSON の sensitivityTieMax）

## 言える範囲

- 準優・優勝戦の1号艇は、展示タイム順位が下位ほど1着を逃しやすい。注意度の段とラウンドをそろえても、期間を前後に分けても同じ向き
- 注意度35%未満の1号艇でも、展示5〜6位なら非1着は3割を超える（33.5%）
- 準優・優勝戦の表示で崩れ注意（55%以上）の段はほぼ出ない

## 言えないこと

- 展示タイム順位が1着を逃す原因か。モーター・選手の力・気象などの交絡は確かめていない
- 崩れ注意の段（55%以上）の中の順位の差。6Rしかない
- 準優と優勝戦の差。区間が重なっており、差の検定はしていない
- 互角の段（35〜55%）の5〜6位の値（51.0%）は n=49 で区間が広い（37.5〜64.4%）。数字を出すなら件数少なめと添える

## 再実行の手順

本番 DB への接続は読み取り専用のロール claude_ro（`SUPABASE_RO_DB_URL`、`scripts/lib/roQuery.js` の checkRoUrl で確かめる）。READ ONLY のトランザクションで読み、最後に ROLLBACK する。

```bash
node --env-file=.env.local scripts/analysis/ft01-wall-grid/wall-grid.js --to 2026-10-24
```

出力先は `--out`（既定 `data/analysis/ft01-wall-grid`）。
