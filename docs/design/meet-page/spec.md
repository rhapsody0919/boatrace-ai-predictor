# 節ページ（SG/G1/G2 の全選手得点率ランキング・準優ボーダー・勝ち上がり）spec

種別: UI機能
対応Linearチケット: [BOA-292](https://linear.app/boat-ai/issue/BOA-292)（親）/ [BOA-682](https://linear.app/boat-ai/issue/BOA-682)（節ページ本体）/ [BOA-683](https://linear.app/boat-ai/issue/BOA-683)（導線）/ [BOA-684](https://linear.app/boat-ai/issue/BOA-684)（公式の得点率早見との照合、画面なし）
目標: SG 第73回ボートレースダービー（尼崎、2026-10-27〜11-01）。集客レーンのダービー記事（10/20ごろ公開）が節ページへ直接リンクするため、**10/20までに本番公開**する。

## 背景・目的

BOA-292 は「SG/G1 限定ページ（ピットレポート・得点率一覧・得点率早見表）が未対応」として起票された。2026-10-02 に公式サイトと既存実装を突き合わせた結果:

| 公式ページ | 公式で出る条件（2026-10-02 実測） | 当サービスの現状 |
|---|---|---|
| ピットレポート `race/pitreport` | SG全レース、G1・G2の7R以降（最終日は12Rのみ） | 取得・表示済み（BOA-611。直前情報タブ） |
| 得点率一覧 `race/pointrank` | SG/G1の4日目以降に表が出る。一般戦はページはあるが「データはありません」 | 取得済み（`racer_series_points`、22:00 JST）。今節タブが予選後に使う |
| 得点率早見 `race/pointchart` | 予選中の当日だけ表が出る。過去日・予選後は「データはありません」。一般戦は「不正なURL」 | 未取得。自社計算の早見が今節タブにある。照合は BOA-684 |

足りないのは**節（開催）単位で全選手を見る場所**。今節タブは表示中のレースの6艇だけを出す。ファンが SG/G1 で一番知りたい「誰が準優に乗るか」「推しが今何位か」「あと何点要るか」を、レースを1つずつ開かずに見られる場所が無い。

ユーザー決定（2026-10-02、オーケストレーター経由）:
- 案A: 節ページを新設する。載せるのは ①全選手の得点率ランキング＋準優ボーダー線＋残り走数・必要得点、②準優・優勝戦のメンバー。対象 SG/G1/G2。翻訳対象。ピットレポートの節横断は後回し
- 導線: トップの SG 帯の遷移先は会場ページのまま。会場ページ上部に「今節の得点率ランキング」カード、レース詳細の今節タブに「全選手を見る」リンク。ダービー記事からは節ページへ直接リンク

## 機能要件

### FR-1 節ページ（BOA-682）P0

URL: `/venue/{会場コード}/meet/{節の初日 YYYY-MM-DD}`（例 `/venue/13/meet/2026-10-27`）。言語プレフィックス付き（`/en/venue/13/meet/2026-10-27` 等）も同じ形。**節が終わっても同じ URL で残す**。

#### FR-1.1 節の見出し P0
- 会場名・節タイトル・グレード・開催期間（初日〜最終日）・今日が何日目か・節の段階（予選中／予選終了／準優勝戦の日／優勝戦の日／節終了）
- 受入基準: 児島 2026-09-28 の節を開くと「児島」「児島キングカップ開設７４周年記念競走」「G1」「9/28〜10/3」が出る

#### FR-1.2 全選手の得点率ランキング P0
- 行: 節に出場した全選手（約48〜52人）。列: 順位・登録番号/級別・選手名・得点率・走数・着順の並び（今節タブと同じ表記。公式の着順文字列の全角空白は日の区切りではなく「走らなかった枠」なので、日ごとに区切って出さない。`seriesPoints.js` の `officialSeriesScore` のコメント参照）
- 並びと値は今節タブと同じ計算（`getMeetScoreboard` → `buildMeetRanking`）。予選終了後は公式の得点率一覧の値（`officialByRacer`）
- 順位から外れる選手（途中帰郷・賞典除外・F）は表の末尾に、理由つきで出す（今節タブと同じ扱い）
- 受入基準: 児島 2026-09-28 の節（予選終了後）で、46人に順位が付き、1位が藤原啓史朗 8.67、18位が西山貴浩 5.50、順位外6人（賞典除外2・途中帰郷4）が末尾に出る（公式 pointrank と一致）

#### FR-1.3 準優ボーダー線 P0
- 準優の枠（`semifinalSlots`、既定18、男女Ｗ開催は12）の位置に線を引き、ボーダーの得点率を見出しに出す（「準優の目安 18位 5.50」）
- 予選中は「目安」（推定）と明記する。予選終了後は確定の枠として出す
- 受入基準: 児島の節で18位と19位の間に線が出る

#### FR-1.4 残り走数・必要得点（勝負駆け）P0
- 予選中だけ、各選手の残り予選走数と、ボーダーに届くのに要る点（`pointsNeededForBorder`）を出す。必要点を着順の目安で言い換える（例「残り1走で2着以内」）
- ボーダー際の選手（必要点が残りの走で届く範囲で、枠の内外±数人）を絞り込めるようにする（「勝負駆け」フィルター）
- 予選終了後は出さない
- 受入基準: 予選中の節で、残り走数0の選手には必要得点を出さない。計算は今節タブの必要得点と同じ値になる

#### FR-1.5 勝ち上がり（準優・優勝戦メンバー）P1
- 準優勝戦の番組が出たら、準優の各レース（レース番号・6艇の枠と選手名・結果が出ていれば着順）を出す。優勝戦の番組が出たら優勝戦の6艇（結果が出ていれば着順）
- 各レースはレース詳細へリンクする
- 番組がまだのときは「準優勝戦の番組は予選終了後に発表」等の案内
- 受入基準: 児島 2026-10-02（5日目）に開くと、10R・11R・12R の準優3レース・18人が出る。18人は FR-1.2 の1〜18位と一致する

#### FR-1.6 開幕前・データなし P0
- 節の初日より前、または出走表が無い日に開いても壊れない。「{日付}開幕。得点率は初日のレース後から出ます」と出す
- `race_series` に節の行が無くても壊れない（節タイトル・期間が分からないときは出さない、または出走表から分かる範囲で出す）
- 受入基準: `/venue/13/meet/2026-10-27` を 2026-10-20 に開くと開幕前の案内が出る（エラーにならない）

#### FR-1.7 SEO P0
- title: `{会場}競艇 {節タイトル} 得点率ランキング・準優ボーダー | 龍神レーダー`（メタ情報の「競艇」は code-style 例外1の暫定措置。コミット・PRに明記）。description も節タイトル・会場名・「得点率」「準優 ボーダー」を含める。画面内の見出しは「ボートレース」表記
- 構造化データ: 既存の Breadcrumb コンポーネントで BreadcrumbList（トップ > 会場 > 節）
- sitemap: SG/G1/G2 の節の URL を追加し、lastmod は節の最終日（BOA-599 / PR #1011 の方針）
- canonical は自分自身の URL

### FR-2 導線（BOA-683）

- FR-2.1 P0 会場ページ（`/venue/{code}`）の上部に「今節の得点率ランキング」カード。表示するのは、その日の開催が SG/G1/G2 のときだけ。カードは上位数人＋ボーダーの得点率を出し、節ページへリンクする
- FR-2.2 P0 レース詳細の今節タブに「全選手を見る」リンク（SG/G1/G2 の節のときだけ）
- FR-2.3 トップの SG 帯の遷移先は変えない（会場ページのまま。集客レーンの持ち物）

## スコープ

やる:
- 節ページ（FR-1）と、会場ページ・今節タブからの導線（FR-2）
- 4言語の i18n キー（翻訳対象）
- sitemap への追加

やらない:
- ピットレポートの節横断（後回し、別チケット）
- 公式の得点率早見（pointchart）の取り込み・画面表示（BOA-684 で照合のみ）
- G3・一般戦の節ページ（一般戦はボーダー推定の誤差が大きい実測がある。対象拡大は公開後の判断）
- 節の一覧ページ（過去のSG一覧等）
- 得点率の計算方法の変更（今節タブと同じ関数を使う）
- 非JSクローラー向けの静的スナップショット（必要なら別チケット）

## 非機能要件

- 375 / 768 / 1024 / 1440 / 1920px で横スクロールなし（`e2e/layout.spec.js`）。375px で52行の表が読めること（列を絞る・横スクロールでなく折り返し）
- 取得クエリは今節タブと同じ本数に抑える（`getMeetScoreboard` を節単位のキーで使い回す）。出走表の1000行上限に注意（既存コメントのとおり 10日×12R×6艇=720行）
- 色分けは承認済みの共通ルール（`docs/design/race-detail-ui-unify/spec.md`）: 最良1つ（同値は全部）を金枠＋太字、基準との差は緑/赤＋↑↓・＋−、向きの無い値は無色、グラフは艇色
- 選手名に `translate="no"`

## 制約・前提

- データ源: `race_entries`・`race_conditions`・`race_results`・`racer_series_points`・`race_series`（いずれも既存。新規スクレイプ・マイグレーションは不要の見込み。plan で確定）
- `race_series` は10月以降の行がまだ無い（2026-10-02 確認）。データ取得レーンが投入と定期取得を担当（オーケストレーター手配済み）。節ページは `race_series` が無くても壊れない作りにする
- 節の切り出し・ステージ判定・ボーダー・必要得点は既存の `getMeetScoreboard`・`seriesPoints.js` に従う（`docs/reference/racer-score-rate-rules.md`）
- 「競艇」は画面内で使わない（title・meta のみ可）
- 公式コンテンツの再表示（得点率一覧の値）は ADR-0067 の範囲。出典表記を付ける
- 投票に関する表記・AI予測のディスクレーマーは不要（予測を出さない）

## 既定値で決定した事項

| 項目 | 採用した既定値 | 根拠 |
|---|---|---|
| URL の形 | `/venue/{code}/meet/{初日}` | 節ごとに固定・節終了後も残す（集客レーン申し送り）。`/venue` は TRANSLATED_PATHS 登録済み |
| 対象グレードの判定 | その節のレースの `race_grade` が SG/G1/G2 | 公式 pointrank・ピットがある範囲。対象外のグレードの URL は「この開催は対象外」を出す（404にしない） |
| i18n 区分 | 翻訳対象 | 今節タブが翻訳対象のため揃える（ユーザー決定） |
| 予選中の値 | 自社計算、予選終了後は公式 | 今節タブと同じ（BOA-475） |
| 男女Ｗ開催 | 対象外として扱わない（節全体を1つの表＋注記） | SG/G1/G2 では男女Ｗ優勝戦の開催が無い想定。`getMeetScoreboard` は表示中レースの6艇からシリーズを決める作りで、節全体を分ける返り値を持たない。発生したら別チケット |
