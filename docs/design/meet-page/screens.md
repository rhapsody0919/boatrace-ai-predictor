## 1. 画面・コンポーネント一覧

| 画面・部品 | 新規/拡張 | 役割 |
|---|---|---|
| `src/pages/MeetPage.jsx`（＋`.css`） | 新規ページ | `/venue/:venueCode/meet/:startDate`。Header・Breadcrumb・見出し・下の3部品を並べる。title/description/canonical を設定 |
| `src/components/meet/MeetHeader.jsx` | 新規 | 会場名・節タイトル・グレードバッジ（`GRADE_CONFIG`）・期間・「N日目」・節の段階バッジ |
| `src/components/meet/MeetRankingTable.jsx` | 新規 | 全選手の得点率ランキング。準優ボーダー線、残り走数・必要得点（予選中のみ）、「勝負駆けだけ」の切り替え、順位外の選手を末尾に理由つき |
| `src/components/meet/MeetQualifiersSection.jsx` | 新規 | 準優勝戦・優勝戦の番組（レース番号・6艇・着順）。各レースはレース詳細へリンク |
| `src/components/meet/MeetRankingPreviewCard.jsx` | 新規（導線、BOA-683） | 会場ページ上部のカード。上位3人＋ボーダーの得点率＋「全選手の得点率を見る」 |
| `src/pages/VenueRaceListPage.jsx` | 拡張（BOA-683） | 当日が SG/G1/G2 のとき上部に `MeetRankingPreviewCard` を置く |
| `src/components/race/RaceMeetTab.jsx` | 拡張（BOA-683） | 表の下に「全選手を見る」リンク（SG/G1/G2 のときだけ） |
| `src/components/Breadcrumb.jsx` | 再利用 | トップ > 会場 > 節。BreadcrumbList の構造化データもここから出る |

- 計算は `seriesPoints.js`（`buildMeetRanking`・`pointsNeededForBorder`・`semifinalSlotsOf`）と `getMeetScoreboard` をそのまま使う。ページ用に計算を書き直さない
- `src/components/meet/` は新設。RaceMeetTab の6艇の表とは列・行数・並びの要件が違う（52行・ボーダー線・フィルター）ので、表は共有せず、計算関数だけを共有する
- 色・余白は `design-tokens.css` の意味トークン。順位表の帯（準優の目安内）は今節タブの左帯と同じトークンを使う
- CSS クラスは `meet-page__*`・`meet-ranking__*` 等の固有名

## 3. 状態

| 状態 | 表示 |
|---|---|
| 開幕前（今日 < 初日、または出走表なし） | 見出し（分かる範囲）＋「{初日}開幕。得点率は初日のレース後から出ます」 |
| 予選中 | ランキング（「目安」）・残り走数・必要得点・勝負駆けフィルター |
| 予選終了後 | ランキング（確定、公式値）・勝ち上がり |
| 節終了 | 同上＋優勝戦の結果 |
| 対象外グレード | 「この開催は節ページの対象外です（SG・G1・G2のみ）」＋会場ページへのリンク |
| 読み込み失敗 | `DataFetchError`（握りつぶさない） |

## 4. 色分け（共通ルール）

- 得点率1位（同値は全員）を金枠＋太字
- 必要得点は向きの無い値なので無色。届く／届かないは文言で書く（「あと6点（2着以内）」）
- 準優の目安内は今節タブと同じ左帯
