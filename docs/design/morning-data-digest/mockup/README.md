## そのままでは開けない

Design キャンバス型の独自要素（`<x-dc>`・`./support.js`・`data-dc-script`）を含むため、ブラウザで直接開いてもレイアウトは再現しない。**中身のHTML（インラインstyleの`<div>`群）を読む用途のスナップショット**として扱う。見た目を確認したいだけなら、`<x-dc>` タグと末尾の `<script type="text/x-dc">` を外せば素のHTMLとして開ける。
