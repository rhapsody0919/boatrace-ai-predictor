1. トップの「お気に入り選手の出走」

トップの会場の一覧の上に置く。☆の選手の今日の出走を締切の順に並べ、締切を過ぎたものは下へ畳む。☆の会場は区画の下に1行。

2. ☆0件のとき・☆はあるが今日の出走が無いとき

空の区画は出さない。推す案（A: 今日のSG・G1の場と、☆の会場の今日の開催）を大きく描き、もう1案（B: ☆の選手の次の出走日）は下に小さく描いた。

3. ☆のボタンの置き場所

3か所とも同じ部品。押す前は灰の☆、押した後は金の★。押せる範囲は44px。上限30に達したら追加せず、知らせを6秒出す（閉じるボタン付き）。

4. 6艇の中の並び（順位）を出すか（ファン役で割れた点）

1件の行に「思考アシストの並び（展示前） 6艇中2番目」を小さく出す案と、出さない案。行の中では印・記号にしない。出す場合は、並びが着順とどれだけ関係するかの統計検証を先に通す（未検証）。

出す案出さない案（推す）
良い点初級の人が開いた直後に6艇の中の位置をつかめる行が短い。「印・買い目を出さない」の線を越えない。上級の人の「要らない」に合う。お気に入りの選手に下位の札が付かない
悪い点順位が印の代わりに読まれやすい。お気に入りの選手に「6艇中5番目」等の札が付く。375px で1件が1行増える順位を見るのに1タップ要る
