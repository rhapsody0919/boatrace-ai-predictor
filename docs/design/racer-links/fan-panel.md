# 選手ページへのリンクをどこに付けるか（BOA-879、ファン4人の議論）

2026-10-15 オーナー依頼「数字で見る平均STの表に選手ページのSTの推移へのリンクがあれば良い」「基本情報・今節の選手名のところにも適切な場所から選手ページへのリンクがあれば良い。ファンに議論させてほしい」を受けた議論。ファン役は同じモデルのロールプレイで、結論は仮説（`.claude/skills/discussion-panel/SKILL.md`）。

## 議論の前提（事実）

- 選手ページ（`/racer/{登録番号}`）はタブの無い1枚のページ。「STの推移（2025年12月以降・最大過去2年）」は中ほどの「成績・調子」の中にあり、id（アンカー）は無い
- 龍神ソナーの「数字で見る（平均STの表）」は、列が1〜6号艇（艇番の丸だけ、選手名なし）、行が「このコース」「全体」「{会場}で」「{会場}の全選手」「今日の展示」。折りたたみの中
- 基本情報タブ: 選手名は6艇の横棒の行にだけ出る。行全体が「押すとその艇の詳細が開く」ボタン。その下の出走表には、選手名のリンクが既にある
- 今節タブ: 選手名は「6艇の今節（得点率順）」「得点率早見」「6艇の今節の推移」の各行と、選んだ1艇の詳細の上の艇の選択チップに出る。どれも「押すとその艇を選ぶ」ボタン。「順位の対象外」の行の名前は登録番号を持っていない
- 思考アシストは、艇の行は深掘りを開くボタンのまま、深掘りの見出しのフルネームをリンクにした（案B、2026-10-15 オーナー決定）

## 4人の意見

**20代男性**: 平均STの表で「4号艇の全体が .14 で速い」と見たら、次に知りたいのは「最近ずっと速いのか、たまたまか」。推移のグラフに直接飛べたら確実に押す。表の下に艇ごとに「STの推移 ›」が並んでいればいい。艇番の丸を押せるようにするのは分かりにくい。今節タブは選んだ艇の詳細に名前リンクが1つあれば十分。

**20代女性**: 名前を押したら別ページに飛ぶのと、詳細が開くのが混ざると怖い。基本情報の棒の行は今「押すと開く」で覚えているので、そのままにしてほしい。開いた中の一番上に「○○選手のページ ›」があれば迷わない。思考アシストと同じ形なのが良い。

**30代男性**: 平均STの表は、艇の列ごとに「このコース」「全体」を見比べる表。リンクは表の一番下の1行に、列とそろえて6個並べるのが表として素直。押した先がページの先頭だと、STの推移を探してスクロールすることになるので、そこへ直接飛ぶのが条件。今節は「得点率早見」の表の中に入れると表が崩れる。詳細の側でいい。出走表には既にあるので、基本情報の棒の行の中に重ねて置く必要は無い。

**30代女性**: 今節の詳細は艇の選択チップの下に1艇ぶんだけ出る。そこにリンクがあれば「選ぶ→その人のページ」が2手で済む。順位の対象外の選手は、登録番号が無いなら無理に付けなくていい。ソナーは英語などでも見られるが、選手ページは日本語だけでも、数字のページなので困らない。

## 割れた点

- 平均STの表のリンクの形: 表の最終行に6個並べる（20代男性・30代男性）か、各列の見出しの艇番の下に小さく置く（20代女性）か → 最終行に6個にまとめた。見出しに入れると表の頭が高くなり、折りたたみを開いたときに数値が下に押し出される
- 基本情報の棒の行にも直接置くか: 置かない（全員）。出走表に既にあり、行は「押すと開く」で覚えられている

## 結論（推奨）

1. **龍神ソナーの平均STの表**: 表の最終行に「STの推移」の行を足し、各艇の列に「›」のリンク（選手ページの「STの推移」へ直接飛ぶ）。選手ページの「STの推移」に id を付け、URL の `#st-trend` でそこへスクロールする
2. **基本情報タブ**: 棒の行は押すと開くボタンのまま。開いた詳細の一番上に、フルネームの「選手ページ ›」のリンクを1つ
3. **今節タブ**: 表・推移の行・選択チップは艇を選ぶボタンのまま。選んだ1艇の詳細（`rmt-card`）の一番上に、フルネームの「選手ページ ›」のリンクを1つ。「順位の対象外」の行は登録番号が無いので付けない
4. 共通: 「押すと開く・選ぶ」は変えず、開いた先・選んだ先に名前のリンクを置く（思考アシストの案Bと同じ形）。同じタブで移る

## 知見ノートに足す行

- `docs/knowledge/fan-reactions.md`: 押すと開く・選ぶ行の名前をリンクに変えると、押したときに何が起きるか分からなくなる。開いた先・選んだ先に名前のリンクを1つ置く形をファン役は選んだ（2026-10-15、ファン役、BOA-879、docs/design/racer-links/fan-panel.md）
- `docs/knowledge/fan-reactions.md`: 選手ページへのリンクは先頭に飛ぶだけだと探す手間が残る。見ていた数字（例: 平均ST）の推移の位置へ直接飛ぶことを求めた（2026-10-15、同）
