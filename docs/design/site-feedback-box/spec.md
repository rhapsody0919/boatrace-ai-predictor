# ご意見ボックス（site-feedback-box）spec

- 種別: UI機能
- 元の依頼: 利用者 2026-11-23「開発者としてどんな機能を追加すればいいか迷っている。質問箱のようにユーザーにどんな機能が欲しいか聞いたり、1から5の星の評価だったり、ユーザーの声を聞きたい。自由にコメントを書けて、そのコメントを見て次に開発するものを議論できる仕組みが欲しい」「ログインなしで気楽に書き込める」「わかりやすいところに配置」
- Linear: なし（会話での依頼で直接）
- 表の案: [db-draft.md](db-draft.md)（未審査。本番に当てるまで、画面は「送れませんでした」を出す）

## 目的

次に何を作るかを決める材料として、ファンの声（欲しい機能・使いにくいところ・データの誤り）を、ログインなし・匿名で集める。

## 今あるもの（2026-11-23 に調べた）

| 入口 | 中身 | 足りない点 |
|---|---|---|
| `/contact` | Google フォームの埋め込み（ja 専用） | フッターの一番下からしか行けない。集まった声が DB に無い |
| 龍神ソナーの「画面の中の声」（`analogy_feedback`） | 2択＋理由＋200字。レース詳細のソナーの下 | ソナーについてだけ。10/09〜10/26 の17日で14行 |

サイト全体の要望の入口・星の評価・右下の部品は無かった。

## 決めたこと

| 点 | 決定 | 理由 |
|---|---|---|
| ログイン | なし・匿名 | サイトにログインが無い。手間を足すと集まらない（ソナーの声は2タップでも17日で14行） |
| 公開 | しない。読むのは運営だけ | 公開するなら公開前の確認が要る。集めるだけなら既存の守り（CHECK・連投の制限）で足りる |
| 入口 | 右下の浮かぶボタン。フッター（お問い合わせ等の `App` のページ・会場ガイド・ガイド）にも同じパネルを開く入口 | どの画面でも同じ場所にあり、思いついた画面でそのまま書ける |
| 形 | 押すと入力パネル（600px 以下は下からのシート、それより広いと右下の小窓） | チャットの形（返事を待たせる）にしない。開発者が1人で即答できない |
| 評価 | 星 1〜5 を任意で1つ | 依頼の「1から5の星」。必須にすると自由記述が減るので任意 |
| 言語 | ja・en・zh-TW・ko | 全言語のページに出る部品なので、4言語の文を持つ |

## 機能要件

| # | 要件 | 受入基準 |
|---|---|---|
| R1 | 右下のボタン | 右端・下端から 16px。文字は「ご意見」、読み上げの名前は「ご意見・ご要望を送る」。地はカードの色、枠と文字は金（金の塗りは「選択中・最良」の意味で使っているので塗らない） |
| R2 | 読むのを邪魔しない | 下へ読み進めている間（向きが変わった位置から 8px 以上下へ、かつ先頭から 80px より下）はアイコンだけ（48px の丸）。40px 以上上へ戻すか、先頭から 40px 以内で文字が戻る |
| R3 | 既存の固定表示と重ねない | Cookie の確認が出ている間は、ボタンもフッターの入口も出さない。ブログ記事の「先頭へ戻る」が出たら、その上に 12px 空けて置く。768px 以下のレース詳細（下部ナビあり）は、ナビの上 12px にアイコンだけで置き、下へ読み進めている間は隠す。z-index は 800（メニュー・シート・下部ナビ・トーストより下） |
| R4 | 出さない画面 | `/admin/*`・`/share/*`・`/race/:id/assist`（言語の接頭辞つきも）。ボタンもフッターの入口も出さない |
| R5 | パネルの中身 | 上から、見出し・説明・内容（必須、500字まで、文字数の表示）・種類（任意の1つ: 欲しい機能／使いにくいところ／データの誤り／その他）・満足度（任意の星 1〜5）・送る・保存する物の注記 |
| R6 | 送る | 内容の前後の空白を除いて1〜500字なら送る。空で押したら送らずに「内容を書いてください」。送っている間は「送っています…」で、もう一度押しても送らない（ボタンは `aria-disabled`。`disabled` にするとフォーカスがパネルの外へ落ちる） |
| R7 | 送った後 | 見出しが「受け取りました」に替わり、お礼・返信できない断り・「もう1件書く」「閉じる」。閉じて開き直すと空から始まる |
| R8 | 送れなかったとき | 「送れませんでした。時間をおいてもう一度押してください」を出し、書いた内容・選んだ物は残す |
| R9 | 閉じ方 | ×・Esc・背景のクリック。書きかけは残る。別の画面へ移ったら閉じる（戻る→進むで開き直さない）。利用者が閉じたら開いた入口へフォーカスを戻す（画面を移って閉じたときは戻さない）。日本語の変換を取り消す Esc では閉じない |
| R10 | キーボード・読み上げ | `role="dialog"`。Tab はパネルの外へ出ない。種類・星は本物のラジオ（Tab は1か所、矢印キーで動く。選んだ物をもう一度押すと外れる）。押せる部品は 44px 以上 |
| R11 | スマホ | 指で触る端末は、開いた瞬間に入力欄へフォーカスしない（キーボードで全体が隠れない）。キーボードが出たら、その高さだけシートを持ち上げる。入力欄は 16px（iOS が拡大しない）。シートを開いている間は後ろをスクロールさせない（広い幅の小窓では止めない。スクロールバーが消えて本文が横にずれるため） |
| R12 | 送る1行 | `kind`・`comment`・`rating`・`page_type`・`lang`・`client_key`。URL（レース・選手の番号）は送らず、ページの種類だけ（`src/pure/siteFeedback.js` の `feedbackPageType`） |
| R13 | 計測 | `site_feedback_open`（`feedback_entry`: button／footer、`feedback_page_type`）、`site_feedback_send`（`feedback_kind`、`feedback_rated`、`feedback_page_type`）。GA4 は Cookie に同意した人だけなので、件数は DB の行と混ぜない |

## スコープ

やる: 上の R1〜R13、表の案、検査（`verify-site-feedback.js`）、E2E（`e2e/site-feedback.spec.js`）。

やらない（別に決める）:

- 表を本番に当てること（オーナーの承認の後、マイグレーションにして db-apply）
- プライバシーポリシーの追記（保存する物: 内容・ページの種類・ブラウザごとの識別番号。龍神ソナーの声の分も今は書かれていない）
- 集まった声を読む画面（`/admin`）と、週のまとめへの取り込み
- 投稿の公開・返信、質問箱の形（公開して答える）
- GA4 のカスタムディメンションの登録（`feedback_*`）
- ヘッダーのメニューへの入口

## 確かめていないこと

- 実機（iPhone Safari・Android Chrome）でのキーボードとシートの動き。Playwright では画面のキーボードが出ない
- AdSense の画面下の帯（アンカー広告）が下に出た回の重なり
- 集まる件数。ソナーの声の実績（17日で14行）より多いか少ないかは、出してみないと分からない
