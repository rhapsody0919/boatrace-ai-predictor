# ファンパネル: 1号艇の1コースでの まくられ・差され（spec §1.8）

`discussion-panel` の4人（20代男・20代女・30代男・30代女）。同じモデルのロールプレイなので結論は仮説。検証はオーナーのモック確認と公開後の実データで行う。

## 前提（議論の外の事実）

- オーナーの決定（2026-11-04）: 1号艇の「1コースの負けの内訳（まくられ N%・差され N%）」を、1コース30走以上の選手だけ出す。30走未満は件数だけ。色・閾値・「危ない」等の言い方なし。90日の窓は使わない。置き場所は枠別情報タブの「1コースが逃げたとき」の直前。逃がし率は出さない
- 根拠: [analysis/nigashi-makurare.md](analysis/nigashi-makurare.md)（#2243）。言えるのは「1コースの負けのうち、まくられ・差されの内訳（1コース30走以上、全選手の中での比較）」。被差しが多い1号艇は、負けたとき2号艇が勝つ側に寄る（+3.5pt［+2.1, +4.9］）。被まくられ・被差しは1コース1着率を入れた後の上積みがほぼ無い（ΔAUC +0.0002〜+0.0003）
- 率の分母は分析と同じ「1コースに進入した走」（負けた走ではない）。全選手の平均は被まくられ 16.5%・被差し 13.1%・1コース1着 53.4%（直近365日、分析の Q3）
- 期間: 6艇の表の既定「直近3期」は公式の期別成績（`racer_period_stats`）で、決まり手の内訳を持たない（列は c1_p1〜p6・F・L・K・S だけ。`docs/db-migration/083_racer_period_stats.sql`）。決まり手を持つのは当社データ（2025-12-03〜、`getRacerScopedRaceStats` の `winningTechnique`）だけ。直近3期にはそろえられない
- 同じ問いの別の数字: 超展開データ（`AttackDefenseTable`、基本情報などのタブの下の埋め込み）が1号艇の「差され・まくられ・捲差され N/M」を出している。こちらは枠番（実進入コースではない）、内訳は全期間・回数は直近365日の出走数に掛けた丸め（`src/utils/attackDefenseCells.js`）。同じ選手で値が合わない

## 論点と4人の意見

### 1. 見せ方（文字の行か、棒か）

- 20代男: 棒が欲しい。数字2つだけだと素通りする。ほかのカードは全部棒
- 20代女: 2行の文字で足りる。棒にすると長い方が「やばい」に見える。色を付けないと決めたなら棒も要らない
- 30代男: 棒にするなら全選手の平均の線が要る。線の無い棒は長いか短いか分からない
- 30代女: 文字2行に賛成。平均の線を足すと「平均より上＝危ない」と読む人が出る。オーナーが閾値の言い方を止めたのと同じ理由
- 割れた点: 棒（20代男・30代男）か文字（20代女・30代女）か。棒派の30代男も「平均の線が無いなら文字」

### 2. 文言

- 4人とも「まくられ」「差され」で通じる（超展開データの「まくられ」「差され」と同じ語）
- 30代男: 「負けの内訳」だと、負けた走の中の割合（足すと100%）に読む。分母が1コースの全走なら、そう書かないと誤読する
- 20代女: 「○走のうち△走」の形が一番分かる。%だけは要らない
- 30代女: 「1着の多さは上の1コース1着率で見てください」の「上」は、6艇の表（直近3期）を指す。期間が違うので「期間が違います」を添える
- 20代男: まくり差しも並べたい。1号艇の負けで一番いやなのはまくり差し
- 30代男: まくり差し・抜き・恵まれを入れていないことは書く。足すと100%にならない理由が分かる

### 3. 母数の出し方

- 4人とも、1コースの走数と期間（日付）を見出しの下に1回出す
- 30走未満: 20代男・30代男は「件数だけ」＝まくられ・差されの走数も出す（○走中△走）。20代女・30代女は走数（1コース18走）だけで、まくられの件数も出さない（2走・1走でも読む人は「多い」と取る）
- 割合は整数%（20代女・30代女）。30走前後で小数1桁は細かすぎる。30代男は他の表にそろえて小数1桁

### 4. 期間の既定（6艇の表は直近3期）

- 4人とも、直近3期にそろえられないなら、同じタブの1艇ずつの表の「全期間」（当社データ 2025年12月以降）と同じ期間がよい。1号艇を選べば、その表の1コースの走数と同じ数になり、照らせる
- 30代男: 直近365日（分析の主の窓）の方が「今の選手」に近い。ただし全期間の行と走数が合わなくなる
- 20代女: 期間の切り替えは要らない。上の6艇の表の「当地」に切り替えても、このカードは変えない（切り替わると思わせない書き方にする）

### 5. その他

- 30代女: 超展開データの「まくられ」と数字が違うと一番混乱する。どちらかに合わせるか、超展開データの方に「枠番で分けた別の集計」と書く必要がある
- 20代男: 2号艇の欄が無くなったなら、見出しから「2号艇」を外す

## 結論（推奨）

| 論点 | 推奨 | 割れた点 |
|---|---|---|
| 見せ方 | 文字の2行（まくられ・差され）。棒・平均の線は付けない | 棒（20代男・30代男）。30代男は平均の線とセットなら棒 |
| 文言 | 見出し「1号艇の1コースでの まくられ・差され」（wording-editor P2-1。「負け方」「負けの内訳」は全部の負けに読まれる）。主語は「今日の1号艇の選手本人が、これまで進入1コースで走った N走」。行は「34走中5走（15%）」。負けた走の中の割合ではないと注記 | — |
| 入れない決まり手 | まくり差し・抜き・恵まれは入れず、入れていないことを注記に書く | まくり差しを足す（20代男）。効き目は未検証なので出さない |

## 知見ノートに足す行

- fan-reactions.md: 決まり手の内訳を「負けの内訳」と呼ぶと、負けた走の中の割合（足して100%）に読まれる。分母が1コースの全走なら「1コースで走った N走のうち」と書く（2026-11-04、ファン役4人、docs/design/course-grid-six-boats/fan-panel-course1-loss.md）
- fan-reactions.md: 色・閾値を付けない材料に棒を付けると、長い方が悪いと読まれる（20代女・30代女）。棒にするなら平均の線が要る（30代男）。平均の線は閾値と同じく良し悪しに読まれる（2026-11-04、同）
- number-wording.md: 同じタブで期間の違う表があるとき、期間を合わせられない材料は、近い表（1艇ずつの表の「全期間」）と同じ期間にし、期間の切り替えに連動しないと書く（2026-11-04、同）
