## オーナーが決めた3点（ファンパネルで割れた点）

- 6艇の表の期間の既定: 直近3期（公式の期3つ）。当地に切り替えられる
- 今節の平均ST: 小さく出す
- データ出走表の「枠番」行: 消さずに「想定コース1着率」に差し替える（BOA-302 の食い違いを解く）

## 承認の外（モックにあっても決まっていないもの）

- 4 の値・件数の線・色（BOA-1280 の答えの後）
- モックの CSS にある差の色（`.up`・`.down`）は使わない。差に色を付けないのが承認の中身
