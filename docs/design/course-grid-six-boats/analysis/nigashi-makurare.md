# 2号艇の逃がし率・1号艇の被まくられ率の効き目（BOA-1280）

spec の §1.8「1号艇・2号艇の選手の過去」に出す値を決める前の検証。結果 JSON は `data/analysis/nigashi-makurare/`。

## 結論

| 指標 | 1号艇の勝率・級・相手の勝率をそろえた上積み | 選手差の信頼性0.5に要る進入 | 推奨 |
|---|---|---|---|
| 2号艇の逃がし率（2コース進入走のうち決まり手が逃げ） | ΔAUC +0.0002〜+0.0004（1着）。上位1/3−下位1/3 で1号艇1着 +1.4〜+2.7pt | 全選手で171走、級の中で77〜801走。直近365日の中央値は35走（信頼性約0.17） | 出さない（選手の特徴として読めない） |
| 1号艇の被まくられ率（1コース進入走のうち他艇のまくり） | 単独では ΔAUC +0.0011〜+0.0023。ただし1コース1着率を入れた後に被まくられ・被差しを足すと +0.0002〜+0.0003 | 全選手で14走、級の中で20〜89走 | 1着率の上積みとしては出す理由が無い。「負け方の内訳」として条件つきなら可 |
| 1号艇の被差し率（参考） | 単独 +0.0022〜+0.0048。1号艇が負けたとき2号艇が勝つ割合を +3.5pt［+2.1, +4.9］動かす | 全選手で24走、級の中で40〜97走 | 内訳に出すなら被まくられより根拠がある |

## 方法

- データ: 本番 DB の読み取り（claude_ro）。2019-04-01〜2025-12-02 は kb_archive、2025-12-03〜2026-11-03 は races/race_results/race_entries。1号艇が1コースのレース 413,918、うち2号艇が2コース 391,146
- 率はすべてレース日より前の走だけで作る（窓 all＝2019-04 から・365d・90d）。逃がしの数え方は 098 の `nigashi_count` と同じ（5選手で DB の `racer_course_technique_stats` と一致を確認）
- 学習 2019-04-01〜2023-12-31、検証 2024-01-01〜2026-11-03（Q1 148,317R、Q2 156,065R）
- 基準のモデル B0＝1号艇の全国勝率＋級、B1＝B0＋相手の勝率（Q1: 2号艇・3〜6号艇の最高、Q2: 2〜6号艇の最高）。足す量は 率（進入が下限未満は欠けの印）
- 区間はレース単位のブートストラップ200回。層の差は1号艇の級×勝率0.5刻みの層の中の上位1/3−下位1/3（件数の重み）
- 信頼性はモーメント法（選手間の真の分散＝観測の分散−二項の分散）。各選手の最後の出走日の前日までの値
- 事前登録のコミットはしていない（方法はスクリプトの冒頭に書いた。結果を見た後に足したのは `who-wins-when-boat1-loses.py` だけで、探索と明記）

## 言えること／言えないこと

- 言える: 「1号艇の1コースの負けのうち、まくられ・差されの内訳」（1コース30走以上、全選手の中での比較）。被差しが多い1号艇は、負けたとき2号艇が勝つ側に寄る
- 言える: 被まくられ率が高い1号艇は1着が少ない。ただしその大半は勝率・1コース1着率で既に見えている
- 言えない: 「この2号艇は逃がしやすい／逃がさない」（選手の特徴として。365d では率のぶれが真の差の2倍以上）
- 言えない: 「被まくられ20%以上は危ない」「逃がし率50%以上は鉄板」など閾値の言い方。同じ級どうしの比較（被まくられ A1・A2 は84〜89走要る）
- 言えない: 90日の窓の率（30走以上の選手がほぼ居ない）
- 未検証: 当日の3・4号艇のまくり率と組み合わせた効き目、会場別
