# GA4 に登録するカスタムディメンション（龍神ソナーの反応の計測）

イベントのパラメータは、GA4 に登録しないとレポートにも Data API にも出ない。2026-10-08 時点で登録済みは `app_language`（ユーザー範囲）だけ。登録した日より前のデータには遡らないので、早めに登録する。

## 登録する6件

すべて「範囲: イベント」。表の値をそのまま貼る。

| ディメンション名 | 範囲 | 説明 | イベント パラメータ |
|---|---|---|---|
| レース詳細のタブ | イベント | レース詳細で押した・リンクで開いたタブ（race_tab_select・race_tab_initial） | `tab_id` |
| ソナーの時点 | イベント | 龍神ソナーの時点（racecard=出走表 / exhibition=展示） | `analogy_stage` |
| ソナーのタブ | イベント | 龍神ソナーのタブ（facts / similar / scenario） | `analogy_tab` |
| ソナーの操作 | イベント | 龍神ソナーで変えた条件（stage・target・facts_boat 等） | `analogy_control` |
| ソナーからの日数 | イベント | 前回龍神ソナーを見てから何日目の再訪か（0〜7） | `analogy_days_since` |
| ソナーの評価 | イベント | 画面の中の声の1段目（useful=なった / lacking=物足りない） | `analogy_verdict` |

`race_id` は値の種類が多く、登録すると「(other)」にまとめられて使えないので登録しない。

## 手順（PC のブラウザで、6件それぞれ繰り返す）

1. https://analytics.google.com/ を開き、龍神レーダーのプロパティを選ぶ
2. 左下の歯車「管理」を押す
3. 「プロパティの設定」の中の「データの表示」→「カスタム定義」を押す
4. 「カスタム ディメンション」タブで、右上の青いボタン「カスタム ディメンションを作成」を押す
5. 右から出る入力欄に、上の表の1行を入れる
   - ディメンション名: 表の「ディメンション名」
   - 範囲: 「イベント」
   - 説明: 表の「説明」
   - イベント パラメータ: 表の「イベント パラメータ」（英字のまま。プルダウンに出ないときはそのまま入力してよい）
6. 右上の「保存」を押す
7. 6件分くり返す

## 確認

- 「カスタム定義」の一覧に6件が並び、`app_language` と合わせて7件になっていれば完了
- レポートや Data API に値が出るまで最大24〜48時間かかる
- 標準のプロパティはイベント範囲のカスタムディメンションが50件まで。今回の6件で上限の心配は無い
