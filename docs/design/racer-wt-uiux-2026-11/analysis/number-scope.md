# 分析ツールと選手ページに出す数字の言える範囲（2026-11-23、data-scientist）

UI/UX 改善（`../fan-panel.md`・`../mock/approved.md`）で画面に出す・置き直す数字の、効き目・母数・言える範囲。本番 DB には接続せず、既存の分析の結果（`data/analysis/`）とコードから判断した。

## 1. 決まり手タブの枠ごとの1着率・1着数

- 母数: `winning_technique_stats.total_races` はその枠が1着になった数で、6枠の和が会場の母数（江戸川の90日で569R）。過去90日の `race_results` から中止・不成立・1着の艇が無い・決まり手が無いレースを除く（`scripts/daily/update-winning-technique-stats.js`）。一部返還は残る。注記は「中止・不成立・決まり手の無いレースを除く」
- 会場差の信頼性（`data/analysis/ui-number-scope/waku-reliability.json`。元は `data/analysis/venue-course-win-rate/venue-course-win-rate.json` の by_waku、3か月＝2026-07-20〜10-19・24会場・444〜720R）

| 窓 | 1号艇 | 2号艇 | 3号艇 | 4号艇 | 5号艇 | 6号艇 |
|---|---|---|---|---|---|---|
| 3か月 | 0.87 | 0.65 | 0.29 | 0.42 | 0.62 | 0.32 |
| 6か月 | 0.93 | 0.76 | 0.70 | 0.71 | 0.72 | 0.45 |
| 12か月 | 0.96 | 0.83 | 0.85 | 0.79 | 0.82 | 0.71 |

- 言える範囲: 90日で会場の差を言えるのは1号艇の1着率だけ。2〜6号艇は値と件数まで、会場の順位は言わない（「1着の件数が少なく、会場の順位は期間によって変わりうる」）
- 最小の母数（二項の近似 n = z²p(1−p)/d²、会場どうしは2倍）: 1号艇（p≈0.55）で差5pt は全国と比べて約380R・会場どうし各約760R、24場を並べる（Bonferroni z=3.08）と各約1,900R
- 同じ「90日・枠ごとの1着率」は会場ページ（`outcome_distribution`、3艇完走が要る）と会場ランキング（`venues.avg_first_win_rate`、1号艇だけ）にもあり、母数が少しずつ違う。決まり手のタブでは `winning_technique_stats` の和を使い、新しい集計は作らない

## 2. 選手ページの冒頭

- 出走表の全国勝率は今期の累積で、期別（公式の期の成績）とは集計の期間が違う（`docs/design/scraping-vercel-consolidation/data-catalog.md` §2.11）
- F 数（`race_entries.f_count`）は今期の本数で 5/1・11/1 に0へ戻る。値が安定して入るのは 2026-09-21 から（`docs/design/analysis-visualization-upgrade/screens.md`「Fバッジの仕様」）
- 結論: 置き換えでなく並べる。上に「今期（YYYY/MM/DD の出走表）」、下に「前の期の公式成績（期名・集計期間・走数）」。F は今期の値。2つに矢印や「好調・不調」は付けない
- 出走表の値を使う線: その出走の日が今日と同じ期（5/1〜10/31 か 11/1〜4/30）の中だけ。期をまたいだら使わない。F は 2026-09-21 以降で NULL でないときだけ

## 3. 今日の枠の1段

- 進入コース別（公式3期）は既存の線（10走未満は出さない、10〜29走は参考）に合わせる。全選手の中で比べた信頼性0.5に要る進入数は 1コース10・2〜4コース約30・5コース42・6コース67（`docs/design/racer-period-stats/analysis/display-scope.md`）
- 当地（当サイト集計）は30走未満なら率を出さず「N走中1着M回」（`docs/knowledge/number-wording.md`）。16走で3勝の1着率の95%区間は6.6〜43.0%

## 4. 条件別の矢印と枠番別回収率

- 偶然の95%の幅（二項、全体200走、条件の走 n と それ以外の走の差）: 1着率 n=20 ±16.6pt・n=30 ±13.2pt・n=50 ±9.6pt・n=100 ±5.5pt、2連対率 n=30 ±16.2pt。式は 1.96√(p(1−p)(1/n − 1/N))
- 矢印は30走以上かつ「その条件の走」対「それ以外の走」で |z|≥1.96 のときだけ。通らない行は矢印も色も付けない
- 回収率: 1号艇の20〜45走で選手ごとの回収率の時期の前後の順位相関は0.055（`data/analysis/full-picture-boat1-return/boat1-return-rate-noise.json`）。矢印・色・順位を付けず、畳んで「参考・N走」、30走未満は「-」

## 5. 当地勝率の推移

- 着順点は6着でも1点あるので、出走して 0.00 になるのは0点の走だけのときに限る。0.00 はほぼ「当地の出走なし」で、線では欠けとして扱う
- `getRacerFormTrend` は日ごとにその日の会場の当地勝率を並べるので、会場が変わるたびに別の量になる。当地の線は外し、当地は今日の会場の値だけを出す
