   - 更新された行の win_rate が「更新日の時点のその選手の勝率」と一致する割合は 1.6%（40,575 選手日）。更新されていない行を30日後・90日後・200日後の勝率と比べた一致率 5.7%・1.8%・1.5% と同じ水準で、後の値で書き換えた形跡は無い。test 期間の月別も 0.5〜4.7%（2026-09 は更新までの日数が短く 26.7%）
   - 2026-10-06〜12 の35レースは、朝のバッチの条件（出走表の時点）と今の export から作った条件が一致（上の1）

## 言えること／言えないこと
- 言える: (15, 5) の線のまわりで、「定番」と付いた組の実際の発生率は線を明らかに下回らず、「レア」と付いた組は線を明らかに上回らない（test 2026-04〜09、28,172R）
- 言える: 同じ条件の過去レースの割合 p は全国の割合 q より結果をよく言い当てる（全小分けで Brier skill の CI が0より上）。ただし着順1点・スリットでは上積みが小さい（0.004〜0.006）
- 言えない: 境界の2つ（着順1点・進入の定番）は帯の組が600〜800と少なく、点推定は 13〜14% で線（15%）を下回る。「定番＝15%以上起きる」とまでは言えない
- 言えない: 「定番だから来る」。ラベルは線のまわりで言葉と実際が食い違わないことを確かめただけ
- 言えない: 会場ごとの食い違い（会場別は測っていない）、2026-10 以降の当てはまり
