# スリット7形×2段の全国の出現率（BOA-635 T0-2）

形に添える「全国の出現率」と、2形を AND にしたときに件数が0・ほぼ0になる組。形と段の定義は [spec.md](../spec.md)「スリットの判定」（凹みは max の定義、BOA-777）。2026-10-13 data-scientist が算出。

## 数え方
- 母集団: BOA-271 v16 の layer の行と同じ（`scripts/ml/analogy/v16_pool.py` の `layer_ok`。枠なりに限らない、全国）のうち、`st_by_course` の6コースがそろうレース。F・出遅れ・欠場の艇は ST が null になる（D-2）ので、そのレースは外れる
- 判定: コース順の本番 ST を 1/100秒の整数にして比べる。1段目は `v16_defs.slit_forms_matrix` と全行で一致することをスクリプトの中で確かめている
- データ源: 手元の export（2026-10-01 版、`export_pool.js` の CSV）。v16 の列（`kb_races.payout_3tan`、`results` の `refund_boats`・`payout_trio`・`actual_course_*`、`start_timings.finish_mark`）が無い版なので、互換の読み込みで数えた
  - 実進入: `actual_courses.csv`
  - 本体の返還: `is_flying`・`is_late_start` だけで判定
  - 「欠」: `is_absent` だけで判定
  - 形の判定は6艇の ST がそろうことが条件なので、この近似は layer_ok の境目にしか効かない
- export の欠け: 2026-02-18〜03-09 と 03-27 は本体の ST が無い（本番には今は 17,964行、約3,000Rある。後から補完された）。10/01 以降も入っていない。全期間の約1.3%。2026-04〜09 の ST の行数は本番とほぼ同じ（2026-10-13 に読み取りで照合、差は月に数行）

## 2形 AND
### 定義から0件
| 組 | 段 | 理由 |
|---|---|---|
| 内3艇そろう＋2コース凹み／カド受け凹み／イン凹み | 両方 | 内3艇の差 ≤0.02 と、隣との差 ≥0.05 が両立しない |
| 2コース凹み＋カド受け凹み、2コース凹み＋イン凹み | 両方 | 同じ2艇の差の向きが逆 |
| 横一線＋2コース凹み／カド受け凹み／イン凹み | 2段目 | 差 ≥0.08 は全体の幅 ≤0.06 を超える |
| 横一線＋ダッシュ勢先行 | 2段目 | 3艇の和の差 ≥0.24 には、どこかで差 ≥0.08 が要る |

## 言えること／言えないこと
- 言える: 全国の各形の出現率（全期間と直近6か月の差は 0.6pt 以内）。2段目で強さの効く5形が 0.41〜0.54 倍になること。0件・ほぼ0件の組
- 言えない: 会場別・層別の出現率（ここでは数えていない）。形の出現と着順の関係（ここでは測っていない。dent-max.md 等を参照）。export の欠け（約1.3%）を埋めた後の値（未検証。影響は小さいと見ている）
