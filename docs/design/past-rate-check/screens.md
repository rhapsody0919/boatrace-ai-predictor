# 過去に発生した割合を見る screens

元: [spec.md](./spec.md)。画面は確定モック（https://claude.ai/artifact/RHjYWn3GWXYUetEHf6M7aq 、Version 3）のとおり。本書はモックとの差分と、部品の分け方・操作要素だけを書く。

## 画面

### S-1 レース詳細 > AI予想タブ（既存画面の拡張）
- タブの一番上に「あなたの予想」の部品（`PastRateChecker`）を置く。既存の展開予測・イン崩れ・出現パターン、その下の BOA-271 の節（アナロジー・ファインダー）はそのまま
- 中止確定のレース、または比べる行（`rows`）が0行のレースでは出さない。スナップショットが無いレース（`snapshot: false`）でも出す。取得に失敗したときは同じ位置に `InlineFetchError`（再試行つき）
- `RaceAiPredictionTab` の早期 return（予想なし・確定後）の分岐でも出す。BOA-271 T9-1 が節の描画を分岐の外に出すので（FR-2 の作り直し後も位置は変わらない）、同じ場所の先頭に足す

### S-2 レース詳細 > 結果タブ（既存画面の拡張）
- `RaceResult` の着順・払戻の下に「振り返り」（`PastRateReview`）を足す
- 不成立のレース、比べる行が0行のレースでは出さない。スナップショットが無いレース（`snapshot: false`）でも出す。取得に失敗したときは `InlineFetchError`（再試行つき）

App.jsx 側には置かない。BOA-430 の画面（新規ルート）には同じ部品を props で絞って埋め込む（spec FR-6。BOA-430 側の作業）。

## モックとの差分（2026-10-02 オーケストレーター判断で採用。ユーザーへは事後報告）

| # | モック | 本書 | 理由 |
|---|---|---|---|
| D1 | スリットの強さ（約1/3艇身／約半艇身）を常に出す | 横一線・内3艇そろうだけを選んだときは強さを隠す | この2形は固定の線で、強さが効かない |
| D2 | 「自分で作る」は各コース「そろう→出る→凹む」。既定の「そろう」は判定では条件なし | 「指定なし→出る→凹む」の3状態。全部「指定なし」ならボタンを押せない | 「そろう」と書いて条件なしに数えると、表示と数え方が食い違う |
| D3 | 結果タブの振り返りは1件 | 保存した型をすべて型の順に。保存が無ければ決着の行だけ。当たり／外れなし | 型ごとに最新1件を保存する仕様のため |
| D4 | 分母は常に全件（例 128） | 型ごとに判定できる行だけ。除いた件数を理由つきで1行 | 決まり手・ST・実進入・払戻が無い行を「起きなかった」と数えないため |
| — | 強さの言い方の比較（案A〜C）の切り替え | 出さない。案A（艇身が主、秒数を小さく）に固定 | ユーザー確定（2026-10-01） |
| — | 結果の注記「定番は15%以上、レアは5%未満（例）」 | 「（例）」を外し、検証で採った線を出す | spec FR-3 |
| — | 例「過去128レース中」 | 層が2,000件以下なら「過去{N}レース中」、超えるなら「同じ条件の新しい2,000レース中」（2026-10-02 ユーザー承認） | FR-2 の層別化で、比べる行が層の新しい順最大2,000件になった（2026-10-02 FR-2 レーンと合意） |

## コンポーネント

新規はすべて `src/components/race/pastRate/` に置き、`src/components/race/index.js` の barrel export に `PastRateChecker`・`PastRateReview` を足す。

| コンポーネント | 新規/既存 | 役割・主要素 |
|---|---|---|
| `PastRateChecker` | 新規 | 部品の外枠。見出し「あなたの予想」、型の切り替え（tablist）、入力欄、ボタン、結果。props: `similar`・`raceId`・`deadline`・`types`・`value`/`onChange`・`persist`（spec FR-6） |
| `OrderInput` | 新規 | 着順。1着・2着・3着の3行×6艇のボタン、「流す」「やり直す」、点数の要約 |
| `Boat1Input` | 新規 | 1号艇。3つのピル |
| `TenkaiInput` | 新規 | 展開。起点の艇（6艇）と決まり手4つ |
| `SlitInput` | 新規 | スリット。7形の一覧（絵・全国の出現率）、強さ2段、「自分で作る」との切り替え |
| `SlitScene` | 新規 | 横から見たスリットの SVG（実縮尺、1艇身≒0.13秒の目盛り）。7形の絵、強さの見本、「自分で作る」の絵で共用。BOA-430 Step2 のスリットプレビューにも使える形にする（props はコース順の ST の差の配列だけ） |
| `EntryInput` | 新規 | 進入。3〜6号艇と3つのピル |
| `PayoutBandInput` | 新規 | 配当の帯。3つのピル |
| `PastRateResult` | 新規 | 結果。要約、「過去{N}レース中 {c}回（{p}%）」、ラベル、メーター、内訳、除いた件数、比べた相手の注記 |
| `PastRateReview` | 新規 | 結果タブの振り返り。保存した予想の行（型の順）と決着の行、類似レースが変わったときの注記 |
| `BoatBadge` | 既存（BOA-271 で切り出し） | 内訳の艇番表示 |
| `RaceAiPredictionTab` | 既存を拡張 | 先頭に `PastRateChecker` を足す |
| `RaceResult` | 既存を拡張 | 払戻の下に `PastRateReview` を足す |

艇の選択ボタン（6艇、公式色、`aria-pressed`）は `OrderInput`・`TenkaiInput`・`EntryInput` の3箇所で使うので、`PastRateChecker` 内の小さな部品 `BoatToggle` にまとめる（このディレクトリの外では使わないので barrel export しない）。

## データ取得

| フック | 中身 |
|---|---|
| `useAnalogySimilarRaces(raceId)`（本機能で `src/services/analogyService.js` に足す） | `get_analogy_similar_races` の返り値（層の新しい順最大2,000行と、行の外の総件数・深さ・条件・期間・スナップショット）。AI予想タブと結果タブで同じキャッシュ（`raceId` 単位、NULL・エラーは残さない） |

部品の中ではデータを取りに行かない（`similar` で受ける）。比べた相手の注記の「似ている理由」は BOA-271 FR-2 の `src/utils/analogyReason.js` で作る。

## デザイントークンと CSS
- トークンで足りる: 余白 `--space-*`、文字 `--font-size-*`、カード `--surface-card`、文字色 `--text-primary`・`--text-secondary`、境界線、ダークモードの反転
- 艇の公式色: `BOAT_COLORS`（`src/utils/colors.js`）を style / SVG の fill に渡す。CSS 変数は新設しない
- 新規 CSS が要る: 部品の枠（強調の枠線）、型のピル、艇のボタンの選択状態、メーター、スリットの絵の一覧。クラス名は `prc-` 接頭辞（`.prc-type`・`.prc-boat` 等。`verify:css-collisions`）
- 「定番」「レア」のバッジ: 定番は既存のアクセント系の意味トークン、レアは注意系の意味トークン（新しい色を作らない。トークン名は実装時に `design-tokens.css` から選ぶ）
- スリットの絵の水面・艇体の色は SVG 内の固定色（自前の背景を持つ要素なので生パレット値でよい）

## i18n
翻訳対象。文言は `src/locales/{ja,en,zh-TW,ko}/` の `aiPredictionTab.pastRate.*`（AI予想タブ）と `result.pastRate.*`（結果タブ）。決まり手4つは既存の訳語キーを使う。スリットの7形の名前・「艇身」は新しいキー。

## 画面の構造と操作要素（受け入れ E2E の前提）

| 対象 | 形 |
|---|---|
| 部品 | `<section aria-labelledby>`、見出し（h2 相当）「あなたの予想」。AI予想タブで最初の見出し |
| 型の切り替え | `role="tablist"`（`aria-label`「予想の型」）の tab 6つ。名前は「着順」「1号艇」「展開」「スリット」「進入」「配当の帯」の順。既定は「着順」 |
| 艇のボタン | `<button aria-pressed>`、`aria-label`「1号艇」〜「6号艇」。着順は行ごと（行の見出し「1着」「2着」「3着」） |
| 流す | トグルボタン（`aria-pressed`）「流す（2着・3着を複数）」 |
| やり直す | ボタン「やり直す」。着順を空にし、結果を隠す |
| 点数 | 着順の下に「1-3,4-2,3,4（4点）」の形 |
| 1号艇・配当の帯・進入の選択肢 | `<button aria-pressed>`。1号艇は「1号艇が 1着」「1号艇が 残る（3着以内）」「1号艇が 飛ぶ（4着以下）」。配当は「堅い（3連単 1,000円未満）」「中穴（1,000〜10,000円）」「万舟（10,000円以上）」。進入は「3コース以内に入る」「4コース以内に入る」「枠なりのまま」、艇は3〜6号艇（1・2号艇は disabled） |
| 展開 | 起点の艇（6艇）と決まり手「逃げ」「差し」「まくり」「まくり差し」の `aria-pressed` ボタン |
| スリットの形 | 7つの `<button aria-pressed>`。名前は「横一線」「内3艇そろう（壁）」「2コース凹み」「カド受け凹み（3コース）」「カド一撃（4コース）」「イン凹み（1コース遅れ）」「ダッシュ勢先行（外3艇）」。各ボタンに絵（`role="img"`）と「全国の15%」の形の出現率 |
| スリットの強さ | 2つの `<button aria-pressed>`。主の文言「約1/3艇身」「約半艇身」、小さく「0.05秒差」「0.08秒差」。カド一撃を選んでいるときは下に「カド一撃は約1/4艇身（0.03秒）／約1/3艇身（0.05秒）」の注記。横一線・内3艇そろうだけのときは出さない（D1） |
| 自分で作る | ボタン「自分で作る（1艇ずつ）」で切り替え。各コースのボタン `aria-label`「1コース: 指定なし」（タップで「出る」「凹む」）。戻るボタン「形から選ぶに戻る」 |
| 判定ボタン | `<button>`「過去に発生した割合を見る」。入力が足りないとき disabled |
| 結果 | `aria-live="polite"` の領域。主文は「過去1,234レース中 30回（2.4%）」または「同じ条件の新しい2,000レース中 412回（20.6%）」の形（2026-10-02 ユーザー承認）。件数が少なくても%とラベルを出す。ラベル「定番」「レア」はテキストで出す（色だけにしない）。除いた件数は理由ごとに1行（件数1以上の理由だけ）:「決まり手が分からない{k}レースを除く」（展開のみ）「スタートタイミングがそろわない{k}レースを除く」「進入が分からない{k}レースを除く」「払戻が無い{k}レースを除く」。分母0のときは主文・メーター・ラベルの代わりに「この型を判定できる類似レースがありません」 |
| 内訳 | 着順（2点以上）は「内訳: 1-3-2 9回、1-4-2 6回、… ほか」、展開は「そのとき2着に来た艇: 1号艇 12回、4号艇 9回」 |
| 振り返り（結果タブ） | 見出し（h3 相当）「振り返り」。1つのリスト（list）に、各行「あなたの予想 {要約} は、過去{N}レース中 {c}回（{p}%）{ラベル}」、最後に「決着 1-3-4 は、過去{N}レース中 {r}回（{p}%）{ラベル}」。決着の行も同じリストの listitem。1〜3着がそろわないときは決着の行を出さない |
| URL | `/race/:raceId`。AI予想タブはタブ名「AI予想」、結果タブは「結果」 |
