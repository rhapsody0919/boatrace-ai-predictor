## 承認範囲（画面・コンポーネント）

- レース詳細の「結果」タブの結果の表の上に「スタート隊形（コース順）」の絵（高さ約230px）
  - 龍神ソナーの展開シナリオのスリットの形の絵（SlitShapeIcon）と同じ描き方: 濃い水面、上が1コース、右のスリット線に近いほど早い、1艇身は約0.13秒の実縮尺、下に「1艇身（約0.13秒）」の目盛り
  - 左の札は「{n}コース」と艇番。艇の右に本番の ST（3桁表示ではなく公式と同じ2桁「.15」）、一番早い艇（F を除く）に「最速」
  - F: 線の先に赤い枠の艇、赤字「F .04」
  - 出遅れ（L）: 点線の艇と「L 出遅れ（ST なし）」
  - 欠場: 一番下の行に薄く「{n}号艇は欠場」（行は消さない）
  - 前付け: 出走した艇の中で、枠なりの順（艇番の順）より内側のコースに入った艇に「前付け」の札。欠場で繰り上がっただけの艇には付けない
- 結果の表（着順の行）の右の ST の矢印は外し、ST の数字と「最速」だけにする。表の下の説明は「右の数字は ST。スタートの並びは上の絵で見る」
