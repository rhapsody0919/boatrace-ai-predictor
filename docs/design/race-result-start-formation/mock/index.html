レース結果の「スタート隊形」の絵（案）

BOA-811。レース詳細の「結果」タブに、実際のスタート隊形をコース順の絵で出す。絵は龍神ソナーの展開シナリオの「スリットの形の絵」と同じ描き方（上が1コース、右のスリット線に近いほど早い、1艇身は約0.13秒の実縮尺）。左の電話の枠は 375px。下のボタンで例のレースと案を切り替えられる。

承認してほしいこと（推奨。ファン4人・UI/UX デザイナー役とも賛成）

  • 結果のタブの表の上に「スタート隊形（コース順）」の絵を足す（高さ約230px。今より増やさない）
  • 結果の表（着順の行）の右の ST の矢印は外して、ST の数字と「最速」だけにする（絵と表で同じ ST を別の並び・別の縮尺で出さないため。デザイナー役の P1）

意見が割れたのは置き場所だけ（ファン1人は「着順の下」）。推奨は表の上（スタートから順に読める）。

F は線より先に赤で「F .04」、出遅れ（L）は点線の艇と「L 出遅れ（ST なし）」、欠場は一番下の行に薄く「○号艇は欠場」。前付けはコースの順に並べ、枠なりより内側に入った艇に「前付け」の札（欠場で繰り上がっただけの艇には付けない）。ファンパネルと UI/UX デザイナー役のレビューを反映した版。

見方

  • 上から1コース〜6コース。左の札は「コース・艇番」。前付けがあると艇番が入れ替わる（例: 前付け）
  • 右の白い縦線がスリット（スタートライン）。線に近いほど早いスタート。線より右は F（フライング）
  • 艇の右の数字は本番の ST。一番早い艇に「最速」
  • 下の目盛り「1艇身」は約0.13秒（龍神ソナーの絵と同じ縮尺）

データ

本番 DB（race_start_timings・race_results）で確かめた: 2026-09-10〜10-09 の 4,633 レースのうち、6艇の ST がそろうのは 4,590 レース。進入コースは本番 ST の entry_course（9/22 以降ほぼ全件）を先に、無ければ race_results の actual_course（4,633 件すべてにある）で埋める（今の結果のタブと同じ）。F は 81 レース・109 艇（例は 津 6R 2026-09-25 の3号艇 F .04）、出遅れ（L）は 1 艇（ST なし）、欠場 42 艇。
