# 選手占い機能 Step1 検証結果レポート

対応: [spec.md](./spec.md) / [plan.md](./plan.md) / [tasks.md](./tasks.md)

## 概要

4占術（西洋占星術・四柱推命・九星気学・六星占術）について、選手の生年月日から算出した「その日の調子スコア」と実際のレース結果（複勝圏内か否か・ST）との統計的相関を検証した。

- 検証対象: 195,239エントリ（選手1,627人、`racer_profiles`に生年月日が登録済みの選手のみ）
- 実行日: 2026-08-25
- 生データ: [correlation-report-2026-08-25.json](../../../data/analysis/racer-fortune-telling/correlation-report-2026-08-25.json)

## 前提となった実データ制約

`race_results`テーブルには1〜3着の艇番号（`rank1`/`rank2`/`rank3`）のみが記録されており、4〜6着の着順データは存在しない。そのため「着順との相関」は当初spec.mdが想定した連続値ではなく、「複勝圏内（1〜3着）か否か」の二値として検証した（[ADR](../../adr/)には含めていないが、spec.md本文に反映済み）。

複勝圏内の基準率（ベースライン）は50.05%（サンプル188,767件）。6艇中3艇が複勝圏内という定義上、ほぼ50%になるのは想定通り。

## 検証方法

- **複勝圏内との関係**: 各占術のスコア（5〜7段階の離散値）ごとに複勝率を算出し、全体の複勝率をベースラインとした二項比率の正規近似z検定（`proportionZTest`）
- **STとの関係**: スコアと`start_timing`（連続値）のPearson相関係数・p値（`pearsonCorrelation`/`pearsonPValue`）
- 統計手法の選定根拠: [ADR 0020](../../adr/0020-fortune-correlation-statistical-method.md)

## 解釈（Claude提案）

**4占術とも採用を推奨しない。**

九星気学の2区分（score=60・65）のみ統計的に有意な差が出たが、以下の理由から「占術としての効果」ではなく生年コホートの交絡である可能性が高いと考える。

1. **効果量が小さい**: 複勝率の差はベースライン50.05%に対して1〜2ポイント程度。サンプル数が2万〜4万件規模あれば、この程度の差は容易に統計的有意になる（統計的有意性 ≠ 実用上意味のある効果）
2. **構造的な交絡リスク**: 九星気学のスコアは「本命星（生年から一意に決まる）」と「対象年の九星」の組み合わせで決まる。そのため特定のスコア区分は必然的に特定の生年（世代）の選手集団と一致する。生年が近い選手同士はデビュー時期・級別分布・引退選抜等の理由で実力分布が偏りうる世代効果があり、これは占術とは無関係な要因
3. **他指標との不整合**: STとの相関はp=0.061で僅差ながら非有意。複勝圏内では有意差が出たのにSTでは出ていないというのは、本当に占術的な効果があるなら両方に一貫したシグナルが出るはずという期待と整合しない

西洋占星術・四柱推命・六星占術は複勝圏内・STのいずれの指標でも有意差が見られなかった。

「占術として採用するか」の最終判断はユーザーが行う（spec.md受入基準）。

## 未解決の論点

- 六星占術は12年周期（運気リズム）の正確な起点計算式が公開情報から確認できず、運命星+陰陽の12分類で代用した（[ADR 0021](../../adr/0021-rokusei-senjutsu-simplification.md)）。この簡略化自体が、六星占術の効果を正しく検証できていない可能性がある
- 生年コホートの交絡を統制した再検証（同世代内での比較等）は今回のスコープ外
