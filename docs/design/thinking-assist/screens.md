- A ヘッダー（FR-2）: 会場・R・グレード・ラウンド（札から TC-T8）・締切。海水・汽水の会場は潮の「?」（TC-T3）。下に「このレースは堅い？荒れる？」の枠（FW-22。押すと TC-R1 のシートに材料を並べる）。展示前は風・波・天候を出さない。風（矢印＋m）・波（cm）・天候は図と小さな数字。時点の切り替え（展示前/展示後、v16 の status に従う）。オッズの取得時刻。龍神ソナーへの「もっと詳しく見る」
- 上部の表示の切り替え（既存ページとの関係の案2、ユーザーの確認待ち）: 「出走表とタブ／思考アシスト」。同じ位置をレース詳細にも置き、選んだ方を次も開く。既定は従来
- 比べる基準の見せ方（全画面で共通、D-21）: 割合を出すところは「基準つきバー」（値・ぶれ幅・全国のいつもの太い点線・会場の全レースの細い点線・3段階の言葉・ポイント差）
- 説明の種類（全画面で共通）: 「?」＝用語の意味（用語集のシート）、「傾向 ›」＝過去レースの傾向（セオリーカード）、数字のタップ＝6艇比較（深掘り2段目）。最初の1行の案内でこの3つを説明する
- A ヘッダーの会場名「{会場} ›」: 会場の特徴のシート（水質・型・1号艇の1着・直近1年の決まり手・潮の傾向、詳しくは既存の会場ページ）
- B レンズ（FR-4）: 下に使い方の1行（閉じられる）。上に固定の4ボタン「軸」「展開」「機力」「買い目」と、下に1行の問い（軸「1号艇は逃げる？」、展開「スタートでどこが出る？」、機力「足が良いのは？」、買い目「オッズに見合う？」）。右端に「ガイド」の切り替え
- C レースの図（FR-3、R-1 は案②に決定）: 行は上から1〜6号艇（公式の艇色の丸＋艇番＋苗字＋級）。良し悪しのある横軸は、良い方の端に「良い」の札と良い方への薄い色。右端の印に何着の候補か（「1着」「2·3着」）。横軸の名前を図の上に常に出す。レンズで横軸と重ねるものが変わる（下の表）
- D レンズの要約: レースの全体に関わる値（例: 軸レンズの「1号艇の1着率」）を1〜3行。セオリーの印
- E 深掘り（FR-5）: 艇・項目・図をタップしたときに開く。図 C がその観点で描き変わり、E に詳しい数字。2段まで。閉じるボタン1つ
- F 固定フッター（FR-7）: 買い目の要約・点数・合成オッズ。開くとマークシート（S-1a）

### S-1a マークシート（フッターを開いたとき、ボトムシート）
- 1着・2着・3着 × 1〜6 のマス。押すと候補に入る/外れる。点数をその場で出す
- 予算の入力と「均等」「均等払戻」の切り替え（FR-8）。100円単位。丸めた後の払戻と合成オッズ
- 組み合わせの一覧（オッズ・人気順・類似レースの件数・金額・払戻・トリガミの印）。類似レースの件数は並べるだけ（FW-19、掛け合わせた値・1÷オッズの％は出さない）。配分の余りを出す
- 注記: オッズは締切まで動く／返還で配当が変わる。免責文

### S-1c ガイド（重ね表示、FR-10）
- 5段: ①堅い？荒れる？（ヘッダーの枠を光らせる。水面と風を含む）→ ②1号艇は逃げる？（軸レンズ、1号艇の行）→ ③壁と攻める艇（展開レンズ、2・3号艇と攻める艇）→ ④足が良い艇（機力レンズ）→ ⑤買い目を組む（買い目レンズ、F）
- 各段: 光らせる場所・1行の問い・「次へ」「戻る」「閉じる」。閉じても状態は残る。吹き出しは光らせた場所と重ならない側（上か下）に出す。⑤以外の段では固定フッターを隠す（光らせた場所に重ならないように）
- 初めて開いたときにガイドを出すか: 既定は出さず、B の「ガイド」で始める（localStorage は使わない）

## 状態
v16 の文言（`docs/design/analogy-finder/screens.md`「状態」）にそろえる。v16 のデータが無いときも、出走表・オッズで描ける部分は描く。

| 状態 | 画面 |
|---|---|
| 展示前 | 時点は「展示前」。展開の横軸は平均ST、機力は展示タイム無し。展示の値・チルト・部品交換・展示進入・風・波を出さない |
| 展示の反映中 | 「展示後」は押せず「展示の結果を反映しています」 |
| 締切後に展示後が無い | 「展示後」は押せず、1行は出さない |
| 欠場があった | v16 の部分（差がつく材料・手がかり・類似レース）を出さず「欠場があったため、過去レースの傾向は出していません」。図・買い目は5艇で描く |
| v16 の保存が無い | v16 の部分を出さず「このレースは、過去レースの傾向を表示できるデータがありません」 |
| オッズが無い（発売前） | 買い目レンズの横軸を艇番順にし、「オッズは発売後に出る」。合成オッズ・配分を出さない |
| 取得の失敗 | その部分に「表示できませんでした。時間をおいて開き直してください」。ほかは出す |
| フラグが無い | ページは開ける（URL 直接）。レース詳細に入口を出さない |

- トークンで足りる: 文字・背景（意味トークン `--text-primary`・`--surface-card` 等。ダークモードで反転）、余白、角丸、影
