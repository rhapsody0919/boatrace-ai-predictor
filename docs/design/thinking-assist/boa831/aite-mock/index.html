流しの相手は「相手」のレンズで、6艇の2着以内と3着以内を同時に見る

ユーザーの回答「やはり軸タブとは別で分けた方が良い」を受けた案。ファンパネルと UI/UX デザイナー役のレビューを反映した。赤い点線が足す・変わる場所。

固定: 軸レンズは「1号艇が1着になったのは」だけに戻す（着順の切り替えを外す）。変わる: 新しい「相手」のレンズで6艇の2着以内（●）と3着以内（○）を同時に出す。買い目の切り替えは買い目だけのものになる。
ファンにとっての価値
  1. 軸（1着は誰か）と相手（2着・3着に残るのは誰か）は別の問い。場所を分けると「3号艇を選んだのに1号艇の数字が出る」が起きない。
  2. 相手のレンズは他のレンズと同じレースの図で、横軸を割合にする。1艇の行に2着以内と3着以内が並ぶので、切り替えずに「2着までなら残るが3着だと…」が一目で分かる。行の「+」でその場で相手を候補に入れられる。
  3. 値は艇ごとの範囲で、深掘り・買い目と同じ（3号艇の3着以内はどこでも 65%）。

決まりと規模
  • 相手レンズの図は、他のレンズと同じレースの図（艇の行・横軸の点・「+」で候補・艇を押すと深掘り）。横軸は割合 0〜100%、●が2着以内・○が3着以内。数字は1艇2個（N-2 の範囲）
  • 切り替えは置かない。買い目レンズの「1着／2着以内／3着以内」は買い目だけのものにする（共有しない。選べる数が違う切り替えを共有すると、知らないうちに状態が変わるため）
  • 軸レンズは1着だけに戻す。「1号艇が1着のとき、2着・3着」の表は相手レンズへ移し、見出しを「1号艇を軸にしたときの2着・3着」にする。ほかの艇を軸にした分は BOA-845
  • 360px 以下では「ガイド」をタブの列から外し、問いの行の右端へ。タブは1行で折らない
  • ファンパネル: 4人とも相手を別にする案。案Y（買い目レンズの先頭に置く）は、オッズの図が2画面目へ押し出され、買い目の「過去の〇〇」と同じ情報が2回出るので採らない
  • 規模: PR 2本（相手レンズを足す／軸から切り替えと表を外す）。API の変更なし。spec D-46・FR-4・FR-9（FW-01・07・18）・ガイドを更新
