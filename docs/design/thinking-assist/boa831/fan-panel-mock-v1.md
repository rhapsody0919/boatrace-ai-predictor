# BOA-831 モック v1 のファンパネル

対象: 思考アシストに2着・3着・ボックスの視点を足すモック v1（例のレース 2026-10-06 徳山10R 準優勝戦、本番の値）。ファン4人のロールプレイなので結論は仮説。検証はモック承認と公開後の GA4（assist_*）で行う。

## 発言

| ペルソナ | 主な意見 |
|---|---|
| 20代男（穴寄り・3連単） | 案3が一番効く。1着の割合だと外の艇は全部1桁で差が読めないが、3着以内なら「6号艇は14%で消す、4・5号艇は45%前後で残す」が決まる。案4は今すぐ欲しい。ボックスを毎回1マスずつ押すのは面倒 |
| 20代女（推し選手・初心者寄り） | 軸と買い目で着順の切り替えが連動するのは便利。ただ知らないうちに2着以内になっていると「さっき見た数字と違う」になる。どの着順の数字か、数字の見出しで毎回分かるようにしてほしい。案2の2段の棒は、1着と2着が同じ色で見分けにくい |
| 30代男（1号艇本命から流し・理論派） | 案1bが本命。「逃げたら2着は2・3号艇で6割強」はそのまま買い目の絞りになる。ただ軸の大きい数字は準優勝戦119件なのに、案1bは3,276件で範囲が違う。同じ準優勝戦の範囲で出してほしい。案1の3着以内（79%）は、裏返すと1号艇が3着にも残らないのが2割という意味で、穴党にも使える |
| 30代女（ボックス派） | 案3で3着以内に残りやすい艇を決めて、案4でボックスにする流れが自然。流しの「2・3着を全部に」は押すと点数が一気に増える（1着1艇で20点）ので、押す前に何点になるか分かるとよい |

## 割れた点

- 案4を今回やるか: 20代男・30代女は今回、30代男は後回しでよい（判断の材料ではない）。20代女は中立
- 案1bの範囲: 30代男は軸の大きい数字と同じ範囲を求めた。他の3人は「件数が書いてあればよい」

## 結論（仮説）

- 案1・案3（着順の切り替え、軸と買い目で共有）を入れる。数字の見出しに選んだ着順を毎回書く（「過去の3着以内」「1号艇が2着以内に来たのは」）
- 案1bを入れる。範囲は軸の大きい数字と同じにする（例のレースは準優勝戦の範囲で1号艇が1着の65件。65/119 の65と一致する）
- 案2を入れる。1着と2着の棒は見分けがつくようにする
- 案4は割れたので、ユーザーの判断に回す。入れるなら近道のボタンに押した後の点数を添える

## 議論とは別の事実

- 案1bを軸と同じ範囲で出すには、軸の範囲キー（例 NCR:2-2-2-0:1B1:junyu）で scenario をもう1回取る。API は scope 引数で受け付ける（本番で確認、n=112・1号艇の1着65件）。展開レンズは既定の範囲（NC）のまま
- 準優勝戦の範囲は件数が少ない（2着の内訳 25・18・11・7・4件）。件数を必ず添える
