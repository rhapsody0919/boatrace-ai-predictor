推奨

案B v2 の決まり

  • 1着を選んでいるときは今のまま（「1号艇が1着になったのは 54.6%」と徳山の全レースの棒）
  • 2着以内・3着以内を選んだときは、大きい数字を6艇の行に置き換える。1号艇の行は今の大きい数字と同じ値（79%・94/119）
  • 行の値は艇ごとの範囲で、深掘りの「全体」・買い目の「過去の〇〇」と同じ。行に級の札を付け、件数が艇ごとに違う理由（枠と級で集めている）を見せる。詳しい説明は「件数が上の枠と違う理由」の中に1段落足す
  • 深掘りで開いている艇の行を強調する。行は高さ44pxで右端に「›」、押すとその艇の深掘りが開く（艇の丸と同じ動き）
  • 並びは艇番順（図の丸・深掘り・買い目と同じ順。ファンパネルでは割合の高い順の声もあった）
  • 徳山の全レースの棒は1着のときだけ。下の「1号艇が1着のとき」の箱は今のまま（2着・3着の2列なので、6艇の1本の棒と見た目で分かれる）
  • 縦の伸び: 375px で約 +190px（大きい数字の分が減る）

データ: v16 facts（取得済み、API の変更なし）。規模: PR 1本（小）
