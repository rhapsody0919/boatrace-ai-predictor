## 問1: 3着の列は出さないが、スジや着順の流れへの導線を置くか

| ペルソナ | 主な意見 |
|---|---|
| 20代男（穴寄り・流し） | 3着はよく出た3連単（4-1-2・4-1-5）が見えれば絞れる。サンキー図は見たいが、ページを移るなら1行の導線で十分 |
| 20代女（初心者寄り） | サンキー図は初めてだと読みにくい。よく出た3連単の3つで足りる。導線は「もっと詳しく」の扱いで目立たせなくてよい |
| 30代男（1号艇本命から流し） | 3着の列を出さないのは納得（データで変わらない）。2連単は2着の表と同じ情報なので要らない。導線先で軸の艇が選ばれていないと、向こうで1着の四角を押し直すことになる。それを一言添えてほしい |
| 30代女（ボックス派） | よく出た3連単は上位5つ欲しい。サンキー図への導線は賛成 |

- 割れた点: よく出た3連単の数（3つ: 3人、5つ: 30代女）
- 結論（仮説）: 3着の列は出さない。軸に合わせたよく出た3連単は今の3つのまま。2連単は足さない（2着の表と同じ）。表の下に龍神ソナーの展開シナリオへの導線を1行（「着順の流れを見る（龍神ソナー）› 1着の{X}号艇を押すとその流れ」）。軸を選んだ状態で開く URL は、今回は足さない（ソナーの共通部品の変更になるので別チケット）

## 問2: 最初に選ばれている軸の艇

| ペルソナ | 主な意見 |
|---|---|
| 20代男 | 1着の候補に合わせる。買い目を組んでから相手を見る流れなので |
| 20代女 | 常に1号艇の方が分かりやすい。知らないうちに変わると戸惑う |
| 30代男 | 前に選んだ艇を覚えていてほしい（ソナー等へ移って戻ったときに1号艇に戻っているのは困る。D-45 と同じ） |
| 30代女 | 1着の候補が1艇だけならその艇 |

- 割れた点: 1着の候補に合わせる（2人）、常に1号艇（1人）、前に選んだ艇（1人）
- 結論（仮説）: 3つを順に使う。前に選んだ艇（同じタブ・同じレース、D-45 の保存と同じ）→ 無ければ1着の候補が1艇だけならその艇 → 無ければ1号艇。1着の候補に合わせたときは「1着の候補に合わせた」と小さく書き、勝手に変わったと思わせない（20代女の心配への対応）
