# 相手レンズ案 v3 の UI/UX デザイナー役（visual-designer）レビュー

独立したサブエージェントが v3 を 375px（ライト・ダーク）・1440px で撮り、本番の CSS でタブを5つにした幅を 375px・320px で測った。v4 への反映は下の「対応」。

実測（本番の CSS、16px 太字・gap 6px・ガイド63px）: タブ5つで 375px は 52px（「買い目」の余り1px）、320px は 41px（44px を割り「買い目」が2行に折れる）。

| # | 重大度 | 指摘 | 対応（v4） |
|---|---|---|---|
| P1-1 | P1 | 320px でタブ5つが入らない | 360px 以下では「ガイド」をタブの列から外し、問いの行の右端へ。タブは折らない（`white-space: nowrap`）。320px で1行に収まることを E2E で固定する |
| P1-2 | P1 | 相手レンズだけレースの図を使わず、目の置き場所と「+」（候補）が消える。6行の棒は短く差が見えない | 相手レンズもレースの図（艇の行・横軸の点・「+」・押すと深掘り）。横軸は割合 0〜100% |
| P1-3 | P1 | 案Y はオッズの図を2画面目へ押し出し、買い目の「過去の〇〇」と同じ情報が2回出る | 案Y は採らない |
| P2-1 | P2 | 選べる数の違う切り替え（相手2つ・買い目3つ）を共有すると、知らないうちに状態が変わる | 相手レンズでは切り替えを置かず、●2着以内と○3着以内を同時に描く（数字は1艇2個）。買い目の切り替えは買い目だけ |
| P2-2 | P2 | ガイドの②を「軸と相手」にまとめると、1段1レンズの作りに合わない。相手は展開・機力の後で決めるもの | 決めること2（6段にするか、5段で⑤を相手にするか）。タブの位置も決めること1（買い目の隣を推奨） |
| P2-3 | P2 | 「1号艇が1着のとき」の表は1号艇を軸にしたときだけ役に立つ | 見出しを「1号艇を軸にしたときの2着・3着」にし、ほかの艇は準備中（BOA-845）と1行 |
| P2-4 | P2 | PC の配置が無い | 1440px の絵（左に図・右に深掘りと表）を足した |
| P2-5 | P2 | 選んだ行の黄色の強調が「相手に選んだ」と読める | 深掘りを開いた行は今のレースの図と同じ見た目 |
| P3-1 | P3 | 見出しが長い | 「1号艇を軸にしたときの2着・3着」。「（6艇）」と硬い説明は外した |
| P3-2 | P3 | 買い目レンズの「今のまま」の絵が本番と違う | 買い目の絵は外し、文で「買い目は今のまま（切り替えは買い目だけ）」と書いた |
| ― | P3 | モックのタブの字が本番より小さく、窮屈さが隠れる | v4 はタブを本番と同じ16px 太字で描いた |
