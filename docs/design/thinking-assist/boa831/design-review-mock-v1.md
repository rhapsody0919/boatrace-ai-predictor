# BOA-831 モック v1 の UI/UX デザイナー役レビュー

独立したサブエージェント（設計に関わっていない）が v1 を 375px・1440px で実測してレビューした。v2 への反映は下の「対応」。

## 実測
- 現行の軸レンズは 1797px。案1 +80px、案1b +405px（v1 の形）。両方で約 2280px、体感 0.75 画面分伸びる
- 案2 は展開に +170px、案3 は買い目に +100px。375px で横スクロールなし。禁止語なし

## 指摘と対応

| # | 重大度 | 指摘 | 対応（v2） |
|---|---|---|---|
| P1-1 | P1 | 案4「ボックスにする」が1着1〜2艇のとき0点になる | 「1着の艇でボックス」に改名。1着が3艇未満は押せず「1着に3艇以上入れると使える」。押すと何点かを添える |
| P1-2 | P1 | 案4「2・3着を全部に」の説明と挙動がずれる。上書きを戻せない | 説明を「1着以外の艇を2・3着に（1着が2艇以上なら1着の艇どうしも入る）」。押した直後に「元に戻す」 |
| P1-3 | P1 | 案1b の札（3,276件のうち1,074件）と軸の大きい数字（119件）で範囲が違い、33% と 55% で迷う。内側の切り替えが軸の切り替えと見分けにくい | 範囲を軸と同じ準優勝戦にした（1号艇が1着の65件＝上の 65/119 の65）。内側の切り替えをやめ、2着・3着を1つの表に。展開レンズへ移す案は採らない（範囲をそろえたので軸の問いに答える位置に残す。ファンパネルの30代男の要望とも一致） |
| P1-4 | P1 | 案2 の「2着の艇」は1着を問わない2着なのでスジが読めない。1艇の数字が4個 | 2着の段をやめ「よく出た2連単」上位5つを1行に |
