# BOA-845 2〜6号艇を軸にしたときの2着・3着のファンパネル（2026-10-12）

前提（統計検証、オーケストレーターの data-scientist、学習〜2026-03・検証 2026-04〜09 の12,462R）: 2着は軸の艇で変わる（無条件より Brier 3.4% 良い）。3着は1着の艇だけで条件を付けても良くならない。範囲は会場の全レース（VA）固定が一番良く、6号艇でも10%点400件・最小342件。3着の相対区間は [−0.54, +0.08]%（出典: docs/design/thinking-assist/analysis/boa845-axis-place.md、#1407）。級でそろえた範囲は件数が足りない（中央値69件、30件未満24%）。ユーザー「仮に件数が少なくても必要」。`docs/knowledge/sns-fan.md` を読んだ。ロールプレイなので結論は仮説。

例のレース（2026-10-06 徳山10R、徳山の全レース 17,278件）: 4号艇が1着の1,326件で、2着は1号艇 37%・2号艇 20%・5号艇 18%・3号艇 13%・6号艇 13%。軸を問わない2着は1号艇 16%。

## 割れた点
- 範囲: 30代男は全艇を会場の全レースにそろえたい。ほかの3人は件数が書いてあればよい
- 最初に選ばれている艇: 30代女は1着の候補（1艇のとき）、ほかは1号艇でよい

## 結論（仮説）
- 「{X}号艇を軸にしたときの2着」を相手レンズに出す。軸の艇は6つのボタンで選ぶ
- 範囲は全艇とも会場の全レース（統計検証で単独で一番良い）。件数の札を必ず出す
- 3着は出さない（軸で変わらない）。「3着は軸の艇でほとんど変わらない。図の○（3着以内）を見る」と1行
- 各行に軸を問わないときの値を細い線で添え、軸で何が変わったかを見せる
- 最初に選ばれている艇: 1着の候補が1艇だけならその艇、それ以外は1号艇（ユーザーに聞く）

## 知見ノートに足す行
- 流しの相手は「2着は軸で変わる、3着は変わらない」。3着の条件付きの表は出さず、3着以内の無条件の値で足りる（2026-10-12 BOA-845 の統計検証とファンパネル）
- 軸の艇を切り替える表は、全艇を同じ範囲（会場の全レース）にそろえる。艇ごとに範囲が違うと件数の桁が変わって比べにくい（同 30代男）
