# 流しの相手の案 v1 のデザイナー役（visual-designer）レビュー

独立したサブエージェントが v1 を 375px（ライト・ダーク）・1440px で撮り、本番の画面（3号艇の深掘りを開いた状態・軸の要約）と比べた。v2 への反映は下の「対応」。

| # | 重大度 | 指摘 | 対応（v2） |
|---|---|---|---|
| P1-1 | P1 | 6行を条件の直後に入れると、すぐ下の会場の棒（1号艇の値）が続きに読める。下の「1号艇が1着のとき」の6艇の棒と意味の違う6艇の棒が縦に2組続く。周りの部品を省いたモックでは判断できない | 本番の部品を省かずに描いた。会場の棒は1着のときだけ出す。下の箱は2着・3着の2列のままで、1本の棒の6行と見た目で分かれる |
| P1-2 | P1 | 押せる行が 32px で「›」が無い | 行を 44px・右端に「›」。注記で補わない |
| P1-3 | P1 | 答え（3号艇）が大きい数字（1号艇 79%）の約290px下。79% が2回出る | 2着以内・3着以内では大きい数字を6行に置き換える。見出し「3着以内に来たのは（6艇）」 |
| P2-1 | P2 | 縦の伸びが説明（+220px）と違う（実測 367px） | 見出し1行・説明1行・注記なし。置き換えで約 +190px |
| P2-2 | P2 | % と件数を1つの欄で右寄せにすると % の位置がずれる | % と件数の欄を分けた |
| P2-3 | P2 | 艇ごとに件数が違う理由が行から読めない | 行に級の札。詳しい理由は「件数が上の枠と違う理由」に1段落足す |
| P2-4 | P2 | 1440px の姿が無い | 最大720px・左端をタブの列にそろえた絵を足した |
| P3-1 | P3 | 括弧の件数の字が小さい | 0.8rem に上げた |
