思考アシスト／相手レンズ BOA-845 モック v3（例: 2026-10-06 徳山10R・本番の値）

軸にする艇を選ぶと、その艇が1着のときの2着が出る

今の相手レンズの「1号艇を軸にしたときの2着・3着」を、6艇どれでも軸にできる形に広げる案。赤い点線が変わる場所。

固定: 相手レンズの図（●2着以内・○3着以内）とタブの並びは今のまま。変わる: 「1号艇を軸にしたときの2着・3着」を「{X}号艇を軸にしたときの2着」にし、軸の艇を6つのボタンで選ぶ。範囲は全艇とも会場の全レース。3着の表は外す。
ファンにとっての価値と統計検証
  1. 流しは軸（1着）を決めてから相手を選ぶ。1号艇以外を軸にする人（4号艇のカド一撃狙いなど）にも、2着の相手が分かる。
  2. 2着は軸の艇で変わる。例: 4号艇が1着のとき、2着は1号艇 37%（軸を問わないと16%）。4-5 のスジも出る（5号艇 18%、問わないと10%）。統計検証では、軸で分けた2着は分けないより当たる（Brier 3.4% 良い。2026-04〜09 の12,462R で確認）。
  3. 3着は、1着の艇だけで分けても当たり方が変わらない。だから3着の表は出さず、図の○（3着以内）を見る形にする。
  4. 範囲は会場の全レース。級でそろえた範囲は件数が足りない（中央値69件、30件未満24%）。会場の全レースなら、6号艇が軸でも件数の10%点が400件、最小でも342件ある（出典: docs/design/thinking-assist/analysis/boa845-axis-place.md、#1407）。

推奨: 3つを順に使う。前に選んだ艇（同じタブ・同じレース）→ 無ければ1着の候補が1艇だけならその艇（「1着の候補に合わせた」と小さく書く）→ 無ければ1号艇

決まりと規模
  • 軸の切り替えは1本の帯（「軸（1着）」の札＋6つ、各ボタンは丸と「軸」の2段、52px）。選んだ艇は塗り。図の艇の丸（押すと深掘り）と見た目を分ける。見出しにも艇の丸。読み上げは radiogroup
  • 見出しの下に結論の1行（2着に一番来る艇と、軸を問わないときの値）。その下に3着を出さない旨の1行
  • 範囲の札: 「{会場}の全レース {X}号艇が1着の{k}件」。行は6艇で固定（軸の艇は「軸（1着）」と書いて残す。切り替えで行が動かない）。棒は軸のときの2着、縦線と「問わず{p}%」は軸を問わない2着。1行の数字は2個。よく出た3連単は軸の艇に合わせて3つ
  • 30件未満のとき（会場の全レースでは出にくい）: 割合を出さず件数だけ
  • 表の下に龍神ソナーの展開シナリオ（着順の流れ）への導線を1行。軸を選んだ状態で開く URL は今は無いので、「1着の{X}号艇を押すと、その流れになる」と添える
  • 3着の列は外す（軸で変わらない）。2連単は足さない（2着の表と同じ）。今の「同じレース／返還」の注記は外す（範囲が会場の全レースになり、軸の大きい数字とつながらないため）
  • データ: scenario API の scope=VA（会場の全レース）の3連単。今ある関数（winFollowers）の艇の引数で作れる。バッチ・範囲キーの変更なし
  • 規模: PR 1本
ユーザーに聞くこと
1. 範囲を全艇とも会場の全レースにそろえるか推奨: そろえる（統計検証で一番良く、件数も足りる。1号艇の値も今の「準優勝戦の範囲 65件」から「徳山の全レース 10,910件」に替わる）。別案: 1号艇は今の範囲のまま、ほかの艇は会場の全レース。
2. 3着の列は出さず、よく出た3連単（軸に合わせて3つ）と龍神ソナーの着順の流れへの導線を置くか推奨: 置く（ファンパネル。3連単は3つで足りる3人、5つ欲しい1人）。
3. 最初に選ばれている軸の艇推奨: 前に選んだ艇 → 1着の候補が1艇だけならその艇 → 1号艇の順（ファンパネルは A 2人・B 1人・C 1人で割れたので、3つを順に使う）。別案: 常に1号艇。
