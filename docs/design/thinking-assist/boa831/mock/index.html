2着・3着の見方を、今のレンズの中に足す

タブは増やさない。軸・展開・買い目の3つのレンズとマークシートに、流し・ボックスで考える人のための材料を足す案。赤い点線の枠が今回足す場所。

ファンにとっての価値
  1. 「1号艇は逃げる」と決めた人が次に悩むのは「2着・3着は誰か」。今の画面は1着の割合しか出さないので、ここで手が止まる（spec FW-01「逃げるなら2・3着を絞る」の材料が無い）。
  2. ボックス派・流し派は「どの艇が3着以内に残りやすいか」を見たい。1着の割合だけだと、外の艇が全部「低い」に見えて差が読めない（1着: 5号艇3.4%・6号艇0.8% → 3着以内: 43.9%・14.0%）。
  3. 買い目を組む手間。ボックス・流しを1マスずつ押すのは、5艇ボックス（60点）で15回のタップ。

推奨 案3

買い目の「過去の1着」を、選んだ着順に

チケットの元の案は「2着・3着のボタンを押したら自動で変わる」。押した結果で表示が勝手に変わるのは FR-7「見えない動きにしない」とぶつかるので、軸と同じ切り替えを置き、軸で選んだ着順をそのまま引き継ぐ形にした。

  • 1行に出す数字は今と同じ2つ（人気・過去の〇〇）。件数は割合の括弧に入れる（70%（83/119））
  • 1着以外を選んだときは人気側を「人気（1着）」と書いて薄くし、着順の違う2つの数字を取り違えないようにする
  • 1着人気（オッズ）は着順を変えても1着のまま。オッズの2着・3着人気は作らない
  • 例のレース: 3着以内にすると 2号艇57%・3号艇65% と 4号艇45%・5号艇44% の差が見える（1着では 9%・9%・6%・3%）

マークシートに「ボックス」「流し」の近道

押せる。「1着の艇でボックス」は1着の段に入れた艇（3艇以上）を2・3着の段にもそろえる。3艇未満のときは押せず、理由を1行で出す。「2・3着に全部入れる」は1着以外の艇を2・3着に入れる（1着が2艇以上なら1着の艇どうしも入る）。押した直後に「元に戻す」を出す。

  • 3連複・2連単は作らない（範囲外のまま）
  • 後回しの理由: 判断の材料ではなく入力の手間の話。案1〜3で「誰を残すか」が決まった後に、使われ方（GA4 の assist_* の点数）を見てから決めても遅くない
