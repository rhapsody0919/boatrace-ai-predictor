## 1. 「イン崩れ指数はこのモックに無いよね？」
- 無い。spec の「出さない」に既存の AI 予想（展開予測・イン崩れ注意度）が入っていて、モックにも表示は無い（対応表の FW-02 の行に名前が出るだけだったのは「イン崩れ（読み）」という予想スタイルの名前）
- spec U-9 は、上部の切り替え（D-22）でレース詳細と行き来したときに、AI予想タブのイン崩れ注意度（会場の中での順位）と思考アシストの「堅い？荒れる？」（全国の全レースとの比較）の両方を見ることになる、という話だった。思考アシストの画面の中の問題ではなく、AI予想タブの整理は今はやらない（request.md §1）ので、**範囲外として消した**（spec D-28）

## 2. 「堅い？荒れる？」のカードの2つの数え方
前提の事実（パネルに渡したもの）:
- 全国・同じ級の並び（3,276件）: 6人の級の構成が今日と同じ（A1・A2・B1が各2人。艇番は問わない）で、1号艇の級も同じ（B1）。ラウンド・勝率は問わない
- 類似レース（63件）: ラウンド（準優勝戦）・1号艇の級（B1）・勝率トップの艇番（3号艇）・1号艇と勝率トップの全国勝率の差の段階（今日は1.26点、1.14〜1.91点の段階）の4つがそろう。級の構成は問わない
- 2つは包含関係に無い。共通は「1号艇B1」だけ
- 調べ直して、v3 からモックと spec の類似レースの定義が「3つがそろう」になっていて、勝率差の段階が抜けていたのを見つけた（v6 で直した）

割れた点: 「類似レース」を中身の名前に変えるか（20代女は変えたい、30代男は龍神ソナーとそろえて残したい → 残す）／「全国・同じ級の並び」の呼び名（「全国」を外すと徳山の数字と混ざる → 「全国・級の並びが同じ」）／条件を行ごとか冒頭1回か（冒頭1回）／チップの表は「問わない」が一目で分かるが、スマホで潰れる（本文には使わず、「問わない」を文で書く）

推奨・v6 の対応（案D）:
- 「堅い？荒れる？」のシートと万舟の枠の冒頭に「数え方は2つ（どちらも全国の過去レース 2019/4/1〜）」を1回だけ書く:
  - 全国・級の並びが同じ 3,276件: 6人の級が今日と同じ（1号艇B1、ほかにA1が2人・A2が2人・B1が1人）。艇番の並び・ラウンド・勝率は問わない
  - 類似レース 63件: 準優勝戦・1号艇B1・勝率トップが3号艇・その勝率差が1.1〜1.9点。級の並びは問わない
  - そろえる条件が違うので件数も違う（類似レースは準優勝戦などに絞るぶん少なく、ぶれ幅が広い）
- 行の見出しは短い名前（「全国・級の並びが同じ 3,276件」「類似レース 63件」）
- 呼び名「全国・同じ級の並び」→「全国・級の並びが同じ」（全画面・用語の「?」・spec・screens）
- ヘッダーの枠の3行目: 「全国・級の並びが同じ（1号艇B1・A1が2人・A2が2人）3,276件で数えた ›」
- 軸レンズの要約: 「返還のあったレースも含めて数えるので、上の枠（返還を除いて3,276件）と件数が少し違う」と書いた（32.3% と 32.8% の件。D-25）
- 差がつく材料の見出しに「全国・級の並びが同じレースで数えた」、展開レンズと買い目の表の注記に類似レースの4条件
- 用語の「?」: 「全国・級の並びが同じ」に「艇番の並び・ラウンド・勝率は問わない」、「類似レース」に4条件と「級の並びは問わない」「龍神ソナーの類似レースと同じ」

## 3. 追加の質問「直近のレースの情報は思考アシストの中で見られるか」（2026-10-07）
- 外した理由: 無い。request.md・spec・handoff・パネルの記録に、1走ずつの結果を外すと決めた記述は無い。spec の FW-13（今節の調子・勝負駆け）は「節間成績」を見るデータに挙げ、使うデータの表にも `getMeetScoreboard` を書いていたが、モックに描かなかった（作る側の抜け）
- 確かめた: 1号艇の今節の平均着順点 8.57 は、前日までの7走（10/2 2・2着、10/3 1着、10/4 3・2着、10/5 1・1着）の 8+8+10+6+8+10+10＝60点 ÷ 7走で、v16 の値と一致する。今日の3R（3着）は入っていない
- ファンパネル（設計に関わっていないサブエージェント）: 「8.57 でも 1・1・6・1 と 2・2・2・2 では読み方が違う。並びが見たい」（20代男）、「締切前は並び1行で十分」（20代女）、「何コースからの着かで重みが違う。今節の各走と、他の場の直近5走が見たい」（30代男）、「今日の前の走が点に入っていないと分かるように。深掘りがこれ以上長くならないよう表は畳む」（30代女）

v6 の対応（案d）:
- 深掘りの「今節の平均着順点」の下に日ごとの着順の並び（1着は太字）。今日の走は灰色で「今日 3R 3着（点に入れない）」
- 「1走ずつ見る ›」で同じ段の中に表を開く: 今節（日・R・進入・ST・着・点。今日の行の点は「—」）と最下行「平均 8.57＝60点÷7走（前日まで。今日の走は平均に入れていない）」、今節より前の5走（日付・場・R・進入・ST・着）。下に既存の今節タブ（得点率・ST の推移）への導線（モックではリンク先なし）
- 直近30走の1着率に件数（例 7/29走。モックは値から逆算した件数で、本実装は集計の件数を出す）、平均ST に「直近30走、F除く」
- 6艇比較（2段目）: 今節の平均着順点なら各行に今節の着順の並び、平均ST なら直近5走の ST
- 札「今節好調」の理由に「8.57＝60点÷7走、着順 2・2・1・3・2・1・1、前日まで」
- データの出どころ（本実装）: 今節の各走は既存の今節タブと同じ `getMeetScoreboard`（`supabaseDataService.js`、race_entries・race_start_timings・racer_series_points 等）と `seriesPoints.js`。直近5走は `getRacerScopedRaceStats`（1選手ずつ、race_results の着順・race_start_timings の進入と ST）。モックの値は race_entries × race_results × race_start_timings の読み取り
- spec FR-5 に「深掘りの中の開閉（1走ずつの表など）は段に数えない」を足した

ユーザーが決めること（推奨つき）: 1走ずつの表は畳んで置く（推奨）／他の節の直近の走は5走（推奨）／今日の前の走は灰色で点を「—」（推奨）／値を押したときの動きは6艇比較のまま（推奨）／今節タブへの導線を置く（推奨）
