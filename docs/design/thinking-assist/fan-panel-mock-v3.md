## 2. 万舟・荒れやすさの「比べる基準」
ファンの結論:
- 基準は「全国の全レース（同じ期間）」に固定し、呼び名を「全国のいつも」にする。会場（徳山の全レース）は参考の細い線（30代男は会場を推したが、同じ級の並び・類似レースは全国で数えているので範囲がそろう全国にした）
- 主役は言葉と目盛りの基準線。差（ポイント）は小さく添える。倍率は出さない（煽りに見え、小さい割合では誇張される。20代男以外が反対）
- 言葉はぶれ幅で決める3段階: ぶれ幅が全部基準より上＝「全国のいつもより高め」、全部下＝「低め」、重なる＝「差ははっきりしない」。良し悪しの色は付けない
- 「荒れる」「堅い」の一言判定は出さない（20代女は欲しいが、残り3人は spec の「決めつけない」に反すると反対）
- 「堅い？荒れる？」の枠（FW-22）も同じ型にする

v4 の対応:
- 共通の「基準つきバー」: 値とぶれ幅に、全国のいつもの太い点線と徳山の全レースの細い点線、3段階の言葉、「全国のいつも {b}%より +{d}ポイント（k/n、ぶれ幅）」
- ヘッダーの枠: 「1号艇の1着 33% ↓ 全国のいつも（55%）より低め」「万舟 22% ↑ 全国のいつも（17%）より高め」「全国・同じ級の並び（1号艇B1）3,276件で数えた」
- 買い目レンズの万舟: 全国・同じ級の並び 21.8%（↑高め、+4.7ポイント）、類似レース 17.5%（差ははっきりしない、+0.4ポイント、ぶれ幅10〜29%）
- 堅い？荒れる？のシート: 1号艇の1着と万舟を、全国・同じ級の並びと類似レースで基準つきバーにした。徳山の全レースの値（1号艇の1着 63.1%・万舟 14.4%）は参考として文に
- ガイド①: 「全国のいつもと比べると、このレースの級の並び（1号艇B1）では1号艇の1着は低め（33%）、万舟は高め（22%）。徳山は1号艇が強い会場なのも材料」

## 3. 「公式のタイムラインの埋め込み」とは（ユーザーの質問。2026-10-07 に X の公式文書で確認）
- 何か: X が配っている埋め込みのコードを自分のページに貼ると、そこに X の投稿の一覧が枠ごと出る仕組み。中身（投稿の文・画像・いいね等）は X が描いて送ってくるので、こちらで文を作ったり選んだりはしない。種類は「1つのアカウントの最新の投稿」と「公開リストに入れた複数アカウントの投稿」の2つ（[docs.x.com timelines overview](https://docs.x.com/x-for-websites/timelines/overview)）。いいね・コレクション・モーメントの埋め込みは 2023-01-13 に廃止された（同ページ）
- どこに・どういう形で: たとえば選手ページに、その選手本人の X アカウントの枠（幅 180〜520px、表示件数 1〜20件で指定できる）を置く形
- 費用: 公式文書に料金や API キーの記載は無い。publish.x.com でコードを作り、X のスクリプト（widgets.js）を読み込むだけで、開発者登録の手順も出てこない。条件として書かれているのは「1日のインプレッションが1000万を超えたら連絡」だけ（[Developer Policy](https://docs.x.com/developer-terms/policy)）
- 一番の問題（見られない人が多い）: 見る人が X にログインしていないと、最新の投稿が時系列で出ない。X の開発者フォーラムでの X 側の回答では、ログインしていない人には「あらかじめ選んだ人気の投稿」を出す仕様。2023年7月には、ログインしていない人には何も出なくなった時期があり、その後も古い投稿（2019年など）が出るという報告がある（第三者のサイトの報告: [arlingtoncardinal](https://www.arlingtoncardinal.com/xembeds/)）。スマホで X にログインせずに見るファンには、直前の選手の投稿を見る用途で当てにできない
- 規約: 投稿の文を変えてはいけない、X のロゴを付ける等の表示のルールは、公式の埋め込みなら自動で満たされる（[Display Requirements](https://docs.x.com/developer-terms/display-requirements)）。選手と X アカウントの対応をこちらで登録することが、X の「外部の身元とアカウントの結び付け」の規定（公開データに基づくなら同意なしで可）に当たるかは、言い切れる文言が無く分からない（法務の判断）
- プライバシー: 埋め込みを見た人の、見たページ・IP・ブラウザ・Cookie 等を X が集める（[docs.x.com privacy](https://docs.x.com/x-for-websites/privacy)）。このサイトの Cookie 同意（`CookieConsent.jsx`）は GA と AdSense だけを対象にしていて、プライバシーポリシー（`PrivacyPolicy.jsx`）も「同意を得た場合にのみ Cookie を使用」と書いているので、埋め込むと記述と食い違う。日本の電気通信事業法の外部送信規律（2023-06 施行）の通知・公表の対象になりうる（[総務省](https://www.soumu.go.jp/main_sosiki/joho_tsusin/d_syohi/gaibusoushin_kiritsu_00002.html)）
- 手間: 選手とアカウントの対応を手で登録・保守する、同意の後に読み込む、プライバシーポリシーに X を足す、枠の高さを固定して表示のずれ（CLS）を防ぐ
- まとめ: 費用はかからないが、ログインしていない人に最新が出ない・Cookie 同意とポリシーの直し・対応の手作業が要る。思考アシストには入れない（ユーザー決定で X 検索のリンクも消した）。起票はしていない

## 4. 既存ページ（従来のレース詳細のタブ・分析ツール）との関係
調査の事実:
- 分析ツールの本体は `/winning-technique` の1ページに19タブ。`?tab=&venue_code=&race_id=&motor=` で開ける（`WinningTechniqueAnalysis.jsx:76-80`）。艇まで指定できるのはモーターだけ。19タブはファン評価・ファン視点のレビューを受けた記録が見つからない（推定）
- レース詳細の8タブは `?tab=&boat=` で艇まで指定できる。レース詳細から分析ツールへのリンクは既に5か所以上ある（DataRaceTable・VenueTendencyPanel・RaceBeforeInfoTab・OutcomePatternPreview・VolatilityDisplay・RaceDetailPage）
- 龍神ソナーはレース詳細の AI予想タブの中で、内部の状態を URL で指定できない

ファンの結論: 行ったきりで戻れないのは困る（30代男）／思考アシストを最初に開きたい（20代女）／19タブのページに飛ばされ、会場とタブを選び直すのは萎える（20代男）／思考アシストで「?」とぶれ幅に慣れた後に、言い方の違う分析ツールに飛ぶと混乱する（30代女）。全員: イン崩れ指数（会場の中での順位）と「堅い？荒れる？」（全国のいつもとの比較）が違う答えを出すと信用が落ちる

推奨: 案2。思考アシストから既存の分析ツールへは、今はリンクを貼らない。改善したツールから順に、そのレース・その艇・その項目の位置で開く「この項目を詳しく ›」でつなぐ。19タブの先頭に落とすだけのリンクは貼らない。レース詳細側に既にある分析ツールへのリンクは、この作業では触らない。v4 のモックは上部に切り替えを描いた（切り替え先は無し）

分析ツールの改善は別チケットにする（推奨。起票はユーザーの判断の後）:
- 親1つ＋ツールごとの子。最初の子は motor（機力レンズの行き先）、st・topstart（展開レンズ）、outcome（買い目レンズの万舟・よく出た3連単）。次の候補は nige・venueranking・venuegrade・extime・extrend・techprofile。volatility（イン崩れ指数の実績）は UI だけでモデルには触らない
- 各ツールで見直す: 19タブ1ページの構成をレンズに合わせて分ける、`race_id`・艇番を受け取ってその位置で開く、思考アシストと同じ決まり（用語の「?」、数えた範囲の呼び名と件数、ぶれ幅、「良い」の札、基準つきバー）、375px、思考アシストへ戻る導線
