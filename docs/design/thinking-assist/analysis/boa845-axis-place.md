# 2〜6号艇を軸にしたときの2着・3着の検証結果（BOA-845）

思考アシストの「1号艇を軸にしたときの2着・3着」（BOA-831、`winFollowers`）を2〜6号艇の軸にも広げるとき、どの範囲のレースで見せれば件数が足り、無条件の値（相手レンズ）より情報が増えるかを見た。2026-10-12 に行った検証を残したもの。数値は `data/analysis/boa845-axis-place/*.json`、スクリプトは `scripts/analysis/boa845-axis-place/`。

## 結論

| 問い | 答え | 根拠（要約） |
|---|---|---|
| 級でそろえた範囲（VC/NC、今の1号艇と同じ作り）で件数は足りるか | **足りない** | 2〜6号艇が1着のレースは中央値69件、30件未満24%、6号艇は57% |
| 会場の全レース（VA）なら足りるか | **足りる** | 中央値1,698件、最小342件（6号艇、10%点400件） |
| 2着は軸で変わるか | **変わる** | 全国で1号艇 +11〜+22pt、2号艇 −6〜−12pt、4が1着なら5が +6pt。時系列の検証で無条件の値より Brier が3.4%良い [2.8, 4.0]% |
| 3着は軸で変わるか | **1着だけの条件では良くならない** | 無条件の3着率に対して Brier −0.24% [−0.54, +0.08]%、区間は0をまたぐ |
| 級でそろえた範囲の率をそのまま出してよいか | **30件未満は出さない** | 30件未満の帯で2着 Brier 0.8123、無条件 0.7856 より悪い。3着は 0.8792 |
| バッチの変更は要るか | **要らない** | 1号艇の範囲キーに VA・NA があり、`winFollowers(scenario, boat)` は軸の艇番を受ける |

## 方法

1. 件数: 見せる側の600R×軸 w=2〜6 で、範囲ごとに「w が1着になったレース」の件数（`today_counts.py`）
2. 全国での効き目: NA で「w が1着のときの j の2着・3着率」と、無条件の率（w を除いて割り直したもの）の差（`effect.py` (a)）
3. 時系列の検証: 範囲は 2019-04-01〜2026-03-31 のレースで作り、2026-04-01〜10-01 の2〜6号艇が1着の 12,462R で2着・3着を当てる。1着の艇を除く5艇の Brier（二乗誤差の和）と対数損失。比べる案は無条件（相手 j の構成×級の率を w を除いて割り直し）・NA・VA・NB・own_NC・own_default・縮小（own_default を無条件または NA へ、件数30で半々）・段（own_default→own_NC→NB を件数30または100以上の最初）（`effect.py` (b)）
4. 差の区間: レース単位のブートストラップ2000回（種 845）の 2.5%・97.5%点（`boot.py`）
5. 見せ方の案ごとの数字: 600R×軸×相手のセルで、各案の率の Wilson 95% 区間の半幅と、無条件の率が区間の外に出る割合（差が無ければ約5%）（`display.py`）
6. 1号艇の範囲の scenario をそのまま使う場合: b1_default（1号艇の VC、300件未満なら NC）の件数と時系列の Brier（`b1scope.py`）
7. API との照合: 本番の `api/analogy/scenario` の1号艇の範囲の件数と、この母集団の件数を6レースで比べた（下の表。スクリプトは残っていない）

## 言えること

- 2〜6号艇が1着のときの2着は、軸によって変わる。1号艇が残る・2号艇が残りにくい・4が1着なら5が来る、は全国で件数の揺れの無い大きさで、時系列の検証でも無条件の値より当たる（Brier 3.4%）
- 会場の全レース（VA）・全国（NA）なら件数は全レース×全艇で足りる（VA 最小342件）。2着では VA が NA よりわずかに良い（+0.17%、区間は0をまたがない）。3着では NA がわずかに良い（0.08%）
- 級でそろえた範囲（own_default）は件数が足りず、30件未満では無条件より悪い。全体でも NA より悪い（2着 −1.66%、3着 −2.26%）
- 3着は、1着だけを条件にしても無条件の3着率より良くならない

## 言えないこと

- 2着・3着の両方（1着と2着を条件にした3着）の当たりは見ていない。3着が良くならないのは「1着だけの条件」の話
- 母集団は 2026-10-01 時点の書き出しで、本体期間は実進入の条件を外している。本番の母集団（実進入あり）とは本体期間の一部が違う
- 見せる側は 10/8〜10/11 の4日・600R。季節・グレードの偏りは見ていない
- 縮小（own_default を無条件へ、件数30で半々）は2着で NA より 0.27% 良いが区間の下端が0。採る根拠には弱い
- 会場×軸の級（VB）は件数（中央値500）だけ見て、当たりは検証していない

## UI への示唆

- 2〜6号艇を軸にしたときの2着は出す価値がある。範囲は会場の全レース（VA）。件数は全レースで数百件以上あり、区間の半幅は約2pt
- 3着は1着だけを条件にした値を出しても、相手レンズ（無条件）より情報が増えない。出すなら「1着・2着が決まったとき」の形を別に検証する
- 級でそろえた範囲を使うなら、30件未満は割合を出さず件数だけにし、件数が足りる範囲（VA など）へ広げる。今の1号艇の表（30件未満は件数だけ）と同じ扱い
- 見出しの範囲が1号艇の表（級でそろえた範囲）と違うことを明記する（「この会場の全レース」など）

## 作るなら要るもの

- バッチの変更は無し。1号艇の範囲キー（`v16_defs.scope_keys`）に VA・NA があり、`api/analogy/scenario/[raceId].js` は `scope=VA:{会場}` を受ける。scenario の `cells.all.forms.any.tri` から `src/utils/assistSummary.js` の `winFollowers(scenario, boat)` が軸 boat の2着・3着を出せる

- 3着を出すかどうかの判断（上の「言えないこと」1つめを検証してから）
