決まりと規模
  • 図の上に結論2行: 「本番のスタートの形」（主の形・割合・件数と、手がかりが当てはまらないときの基準の棒）と、展示後は「今日の展示」1行（攻める艇の展示順位とその区分の1着、件数）
  • 図: 横軸は展示前も展示後も平均ST（このコース・直近30走）。各艇の札は「展示{r}位」と「★平均STの手がかり（形）」だけ。攻める艇は点の横の ▶ の印。オリジナル展示の印は図に置かない
  • 形が2つ当てはまるときは、主と次の形を同じ形式（名前・割合・件数）で並べ、選んでいる方だけを塗る。押すと下の「もし」と「今日の展示」が変わる。1つのときは枠を付けない
  • もし{形}になったら: 攻める艇が1着のときの決まり手の内訳 → 1着の艇 → {形}のときによく出た2連単 → スジのチップ。3連単は買い目レンズへ
  • 今日の展示を入れると: 攻める艇・1号艇それぞれ、展示タイムの順位の区分ごとの割合（範囲の件数つき）。全国の差を1行で添える。今日の区分は前の札「今日」と塗りで示す。30件未満の区分は棒を出さず「N件だけ（少ないので割合は出さない）」
  • 進入: 展示が全艇枠なりなら「全国で、本番も全艇枠なりは 93%（3,602/3,862）」
  • オリジナル展示（ある会場だけ）: 周回・まわり足で6艇で一番の艇に印と、全体の効き目の1行。直線と秒数は出さない（秒数は機力レンズ）。形ごとの言い回しはしない
  • データ: v16 scenario（NC・NA の attack と hints）、オリジナル展示（今の取得）。API の変更なし。spec FR-4 の「展示後は展示ST」を改める D-xx が要る
  • 規模: PR 2〜3本
