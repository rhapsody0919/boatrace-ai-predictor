# グランプリ特集 /grandprix — ファン4人の議論（2026-11-27、discussion-panel）

問い: グランプリ（大村 12/15〜20）の前・開催中に「見て楽しい・見たい」物は何か。オーナーの差し戻し「もっと見て楽しいコンテンツがあった方がよさそう」（11/27）を受けて。
同じモデルのロールプレイで、結論は仮説。検証はモックの承認と公開後の実データ。

## 前提の事実（議論とは別）
- 公開は 12/5 頃。チャレンジカップは 11/29 に終わるので、公開の時点で出場18人と賞金の順位は確定している（公式の発表を確かめてから入れる）
- repo の静的データ（src/data/venueSummaryStats.js、2025-10-31〜2026-10-30）: 大村の1コース1着 2,341件中 61.0%、全国 55,604件中 55.5%（全国より高いと判定）。決まり手は逃げ 58.2%（全国 53.0%）、まくり 11.6%（全国 15.8%、低いと判定）
- 過去の優勝戦 2021〜2025: 1号艇の1着は5回中4回（2022〜2025、逃げ）。2021 は4号艇（3コース）のまくり
- 選手の写真は使わない。展開予測にはつながない。本番 DB には作り手が繋げない（選手ごとの集計は画面が実行時に既存のサービスで取る形なら可）

## 4人の意見
- 20代男: いちばん見たいのは賞金ランキングの18人の棒。6位と7位の間に線があり、2ndから出る6人と1stから出る12人が一目で分かると「誰が崖っぷちか」で盛り上がる。開幕までの日数もあると毎日開く
- 20代女: 18→12→6 の勝ち上がりを1枚の図で。文の表より、人が減っていく形が見えると楽しい。過去の優勝戦は表よりカードで、優勝した枠番の色の丸が並ぶと「1号艇が強い」が絵で分かる
- 30代男: 大村の1コースが全国よりどれだけ強いかの横棒（件数つき）と決まり手。まくりが少ない会場だと分かれば、優勝戦の買い方が変わる。過去の優勝戦の3連単の配当も並べてほしい（荒れたか堅かったか）
- 30代女: 出場選手のカードに、今年の勝率の推移と大村での成績が欲しい。ただし賞金の暫定の順位（11/25 時点）を確定前に出すと混乱するので、確定した数字だけにしてほしい

## 割れた点
- 選手カード（推移・大村の成績）: 30代2人は必須、20代2人は「賞金の棒で足りる、カードは開催中で良い」。→ 12/5 は棒と名前（選手ページへのリンク）、カードの推移・大村の成績は第2段
- 配当の色分け: 30代男は高配当を色で目立たせたい、30代女は「強い色は煽りに見える」。→ 色の強弱で煽らず、配当は数字だけ、枠番の色の丸（公式の艇の色）だけ使う

## 結論（12/5 の本番に入れる順）
1. 賞金ランキングの18人の横棒（6位と7位の間に線、2nd から／1st から の2色）— 11/29 の確定の後に公式の数字を入れる
2. 勝ち上がりの1枚の図（18人 → 1st 12人 → 2nd 12人 → 優勝戦6人）
3. 大村の水面の図: 1コース〜6コースの1着率の横棒を全国と並べる（件数・期間の札つき）＋決まり手（逃げ・まくり）
4. 過去の優勝戦のカード: 年・会場・優勝者・枠番の色の丸・決まり手・3連単の配当。1号艇が5回中4回と1行で
5. 開幕までの日数（開催中は「○日目」、終わったら優勝者）
- 第2段（開催中〜）: 出場選手のカード（今年の推移の小さな図・大村の成績、既存の部品）、日ごとの勝ち上がりの更新

## 知見ノートに足す行（案）
- 大会の特集は、文の表より「人が減っていく流れ」「誰がどこから出るか」を1枚の図で見せると見て楽しい。確定前の暫定の順位は出さない（2026-11-27、ファン役4人、グランプリ特集）→ fan-reactions.md
- 配当は色の強弱で煽らず数字だけにし、色は公式の艇の色（枠番）だけに使う（2026-11-27、ファン役4人）→ fan-reactions.md
