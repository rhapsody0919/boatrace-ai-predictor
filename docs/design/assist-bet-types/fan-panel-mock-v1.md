# 思考アシストの買い目の式別（BOA-990）ファンパネル v1

`discussion-panel` の手順で、熱血ボートレースファン4人（20代男・20代女・30代男・30代女）が、買い目に3連複・2連単・2連複・拡連複を足すときの見せ方を議論した。同じモデルのロールプレイなので結論は仮説。確かめるのはモックの承認と公開後の実データ（GA4 の式別ごとの利用）。

読んだ知見: `docs/knowledge/fan-reactions.md`・`docs/knowledge/user-insights.md`・`docs/knowledge/number-wording.md`・`docs/knowledge/glossary.md`。

## 議論の前提（事実。議論には混ぜない）

- 今の買い目は3連単だけ。図の「+」かマークシートで1着・2着・3着の候補を入れ、組（フォーメーション）・予算・均等／均等払戻の配分・人気・合成オッズ・類似レースの件数を出す（`src/components/race/assist/BetSummary.jsx`・`MarkSheet.jsx`・`src/utils/oddsMath.js`）
- 4式別のオッズは DB に既にある（`race_odds` の `trio_all`・`exacta_all`・`quinella_all`・`wide_all`、オッズ一覧タブが使っている）。思考アシストは3連単だけ読んでいる。取得を足す必要は無い（spec.md「オッズの取得状況」）
- 拡連複のオッズは公式が下限〜上限の幅で出す。払戻は確定まで決まらない
- 組の数: 3連単120・3連複20・2連単30・2連複15・拡連複15
- 式別ごとの数字の言える範囲は hq のデータサイエンティスト社員に起票済み（BOA-1171）。答えはまだ無い

## 論点と発言

### 論点1: 5式別を並べるか、切り替えるか

- 20代男: 切り替え一択。375px で5式別の表が縦に5つ並んだら買い目のレンズが終わらない。タブを1列で押せればいい
- 20代女: 切り替えでいい。ただ、切り替えた後に入れた候補が消えるなら使わない。同じ候補のまま式別だけ替えたい
- 30代男: 切り替えだけだと「同じ読みなら3連単と3連複のどっちが見合うか」を比べるのに5回押すことになる。同じ候補で式別ごとの点数と合成オッズを1行ずつ並べた小さい表がほしい。行を押したらその式別に切り替わる形
- 30代女: 30代男の表に賛成。ただ数字は点数と合成オッズの2つまで。人気や払戻まで5行並べたら日和と同じで見づらい

→ **切り替え（タブ5つ）＋上に「式別で比べる」の小表（5行×点数・合成オッズ）**。4人一致。

### 論点2: 候補の入れ方（順序の無い式別をどうするか）

- 20代男: 3連複・2連複・拡連複は「この艇たちの中から」で買う。1着・2着・3着の段のままだと嘘っぽい。ボックスの近道が要る
- 20代女: 段を式別ごとに別にされると、切り替えのたびに入れ直しになる。段は1つで共有がいい
- 30代男: 実際のマークシートも3連複は「1艇目・2艇目・3艇目」のフォーメーションがある。段は共有して、連複のときだけ見出しを「1艇目・2艇目・3艇目（順不同）」に替えればいい。1-23-234 を3連複にしたら同じ組を1つにまとめて点数が減る、それが分かるのが面白い
- 30代女: 2連系に替えたら3着の段はどうなるか。消すと戻したときに困るので、薄くして「2連単では使わない」と1行。ボックスは近道があってもいいが、押した後に元に戻せること

→ **段は1つで全式別が共有**。連単は今の「1着・2着・3着」、連複は「1艇目・2艇目・3艇目（順不同）」。2連系は3着の段を薄く残して使わない旨を1行。**「この艇でボックス」の近道**を置く（押した直後に「元に戻す」）。割れた点: 20代男はボックスを最初の入力にしたい（段を後に）。3人は段を主に、ボックスは近道で、とした。

### 論点3: 点数・組の表記

- 30代男: 連単は「-」、連複は「=」が舟券の書き方。3連複は「1=23=234」、拡連複は「1=2」
- 20代女: フッターに「3連複 1=23=234（3点）」と出れば、何を組んだか分かる
- 20代男・30代女: 同意

→ **連単は「-」、連複・拡連複は「=」**。フッターの頭に式別の名前。

### 論点4: オッズの見せ方（とくに拡連複の幅）

- 30代女: 拡連複は幅のまま「1.8〜2.4」と出す。1つの値に丸められると、公式の画面と違って見える
- 30代男: 配分と払戻はどちらかの値で計算しないと出ない。安く見積もる下限で計算して「払戻は下限で計算」と書いてあれば信用する。上限で計算してトリガミ（払戻が合計を下回る）を見逃すのが一番困る
- 20代男: 拡連複は1レースで3組当たることがある。払戻が足し算になるのを1行で書いてほしい
- 20代女: 人気は式別のオッズの順でいい。3連単の人気を3連複に出されると混乱する

→ **拡連複のオッズは幅のまま、配分・払戻・合成オッズ・トリガミは下限で計算し注記**。「同じレースで最大3組が当たる」を1行。**人気はその式別のオッズの順**。

### 論点5: 類似レースの件数の列

- 30代男: 3連複なら類似レースで「1=2=3 が何回」の方が3連単より件数が増えて見やすい
- 30代女: 件数が少ないなら出さない方がいい。件数がどこからなら出せるかは数字で決めてほしい
- 20代男・20代女: 列は今の3連単と同じ位置でよい

→ **類似の列は式別ごとに数え直す方向**。ただし出す下限は BOA-1171 の答えで決める（それまでは3連単だけに出す）。

### 論点6: 既定の式別

- 4人: 開いたときは今と同じ3連単。最後に選んだ式別は同じレースの中で覚える

## 結論と推奨

1. 買い目のレンズとマークシートの上に式別のタブ5つ（3連単｜3連複｜2連単｜2連複｜拡連複）。1つずつ切り替え。既定は3連単
2. 買い目のレンズの頭に「式別で比べる」小表（同じ候補での点数・合成オッズの5行）。行を押すとその式別に切り替わる
3. 候補の段は全式別で共有。連複は見出しを「1艇目・2艇目・3艇目（順不同）」、2連系は3着の段を薄く残して使わない旨を1行
4. 近道「この艇でボックス」（直後に「元に戻す」）
5. 表記は連単「-」・連複「=」、フッターの頭に式別
6. 拡連複は幅のまま表示、計算は下限で注記、最大3組当たる旨を1行。人気はその式別のオッズの順
7. 類似の列は BOA-1171 の答えまで3連単だけ

割れた点: ボックスを主の入力にするか（20代男）／段を主にしてボックスは近道か（3人）。モックは3人の案で作る。
