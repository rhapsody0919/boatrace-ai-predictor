思考アシストの買い目に券種を足す（モック v1）

3連単だけだった買い目に、3連複・2連単・2連複・拡連複を足す案。券種は上のタブで1つずつ切り替え、1着・2着・3着の候補は券種をまたいで共有する。買い目のレンズの頭に、同じ候補で5券種の点数と合成オッズを並べた小表を置く。

数字はすべてモックの例の値（架空）。例の候補: 1着 1号艇、2着 2・3・4号艇、3着 2・3・4・5号艇。

このモックで決めた形（ファン4人の議論から）

  1. 券種のタブ5つ（3連単｜3連複｜2連単｜2連複｜拡連複）で1つずつ切り替える。既定は今と同じ3連単。最後に選んだ券種は同じレースの中で覚える
  2. 買い目のレンズの頭に「券種で比べる」小表。同じ候補での組・点数・合成オッズだけを5行。行を押すとその券種へ
  3. 候補の段は全券種で共有。連複・拡連複は見出しを「1艇目・2艇目・3艇目（順不同）」に、2連の券種は3段目を薄く残して使わない旨を1行
  4. 近道「選んだ艇でボックス」と、押した直後の「元に戻す」
  5. 表記は連単「-」、連複・拡連複「=」。フッターの頭に券種の名前
  6. 拡連複のオッズは公式の幅のまま。払戻・トリガミは下限で計算。合成オッズは出さず、1組だけ当たったときの倍率を出す
  7. 人気はその券種のオッズの順。類似レースの件数の列は、統計の答え（BOA-1171）が出るまで3連単だけ

オーナーに決めてほしいこと

  1. 「核連複」は拡連複（公式の呼び名。通称ワイド）のことでよいか（推奨: 拡連複として作る）
  2. 切り替え（タブ）＋比べる小表の形でよいか（推奨: この形）
  3. 候補の段を全券種で共有し、ボックスは近道にする形でよいか（推奨: この形。ファン3対1で、ボックスを主の入力にする案もある）
  4. 拡連複に合成オッズを出さず、1組だけ当たったときの倍率を出す形でよいか（推奨: この形。拡連複は複数の組が同時に当たることがあるので、3連単と同じ合成オッズの式は当てはまらない）
  5. 取得の予算の案 A5（3連複・2連・拡連複のオッズを締切60・15・5分前だけにする）を採るか（推奨: この機能のためには採らない。採ると買い目に出すオッズが最大10分古くなる）
