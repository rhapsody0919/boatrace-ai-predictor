# 操作キャプチャ動画 台本（Task 1成果物）

## 選定条件（動画制作のたびに再適用する）

レースは開催当日ごとに入れ替わるため、以下の条件を満たす**発走前のレース**を、動画制作（Task 2）実行時にあらためて1件選び直す。

1. **展開予測に明確な本命がいる**: 1着候補の最上位確率が概ね30%以上
2. **イン崩れ指数バッジが付いている**: 「イン崩れ確率高」または「本命有利」（会場内パーセンタイルが標準から離れている＝画面のゲージが視覚的にわかりやすい位置にある）
3. **データ出走表に視覚的にわかりやすい差がある**: コース別勝率の最大−最小が20pt以上、または回収率のハイライトセルが100%を大きく超えている
4. **未確定レース（締切前）であること**: 結果確定済みだとAIデータ分析セクション自体が表示されないため（`PredictionPanel.jsx`仕様）

## 検証用の実例（2026-09-01、多摩川2R）

上記条件で実際に検索し、条件を満たす例として多摩川2R（本日開催、締切11:29）を確認した。本番の動画制作時は日が変わり別レースになる前提だが、台本の「どんな数値が出てくるか」の具体イメージとして実例を残す。

- 展開予測: 1号艇「逃げ」38%（実測1着的中率78%、過去3240レース）
- イン崩れ指数: 会場内パーセンタイル73「イン崩れ確率高」。根拠3点（①1号艇の今節STは標準0.169秒 ②AI逃げ確率が低い37%→まくり・差し有利 ③1号艇の全国勝率がやや低い4.51→崩れやすい）
- データ出走表: コース別勝率 28%(1号艇)〜0%(6号艇)、回収率ハイライト 121%・438%

**2026-09-01追記**: 当初あった6シーン目（ロゴ＋CTA文言）はローカル確認で「全然ダメ」との指摘を受け削除した。データ出走表のシーンで終わる5シーン構成に変更済み。動画自体は`FirstVisitGuideCard`（カードの見出し・導線）や埋め込みページ側で完結させ、動画の中に別途CTAを作り込まない方針とする。

**2026-09-01追記2**: 当初16:9横長で作成したが、埋め込み先（`FirstVisitGuideCard`・`HowToUse.jsx`）がモバイル最優先の縦長カードで、中身もスマホ実画面キャプチャ（縦長）だったため、横長キャンバスに収める→さらに狭いモバイル幅に収める二重の縮小が発生し、文字が判読不能になった。9:16縦長（1080x1920）に作り直して解消。詳細な再発防止ルールは`.claude/CLAUDE.md`の「モバイル対応で注意すること」に追記済み。

## 制作メモ（Task 2実行者向け）

- 実データ・実画面のみ使用し、作り話・仮の数字は含めない（`docs/operation/sns-video-producer-prompt.md`の原則）
- 横方向のズームはしない（scale=1固定）。見せたい範囲は縦方向の表示位置とその要素単体の`locator.screenshot()`切り出しで対応する（同資料の教訓）
- 対象レースが未確定であることを、キャプション編集・レンダリング作業が終わって投稿直前になった時点でも再確認する
- 吹き出し・注釈のみで音声ナレーションは無し（BGM要否はTask 2実行時に判断してよい。オンボーディング動画のため過度に賑やかにしない方向を推奨）
