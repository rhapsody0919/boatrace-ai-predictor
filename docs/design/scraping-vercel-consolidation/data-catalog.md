## 0. 読み方

### 0.1 根拠の区分

推測で埋めず、根拠を項目ごとに区別する。

| 記号 | 意味 |
|---|---|
| [実] | 本調査（2026-09-20）で、実ページ・実ファイルを取得して確認した |
| [F] | リポジトリのfixture（実ページ由来のHTML・Kファイル）で確認した |
| [C] | コード・既存ドキュメントの記述から確認した（実ページとは未照合） |
| [D] | 本番DBの実測（2026-09-20、SELECTのみ）。充足率の分母は期間別: (a)2025-12-03〜2026-03-31、(b)2026-04-01〜2026-08-31、(c)2026-09-13〜2026-09-19 |
| [推] | 推測（未検証） |

### 0.2 価値評価の区分

| 判定 | 意味 |
|---|---|
| 必須 | 既存機能の正確性、または[BOA-271](https://linear.app/boat-ai/issue/BOA-271)（アナロジー・ファインダー）・ポジション確立サブテーマ（BOA-272〜277）の前提になり、無いと分析・表示が誤る、または成立しない |
| 望ましい | 予測特徴量・分析の説明力・監視の質を上げる。無くても成立する |
| 不要 | 自社データから導出できる、または用途がない。取得しない（導出可の場合はその旨を書く） |

判断根拠は、用途表（[§4](#4-価値評価の物差しと用途)）に集約した。**実測に基づく判断と、推測に基づく判断は、根拠の記号で区別している。**
