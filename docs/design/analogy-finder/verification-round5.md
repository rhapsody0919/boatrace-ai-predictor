# 検証 第5回（2026-10-03）: モック Version 13

ユーザーの指摘（2026-10-03）を受けて Version 13 を作った。指摘は次のとおり。
- 文言が分かりにくい
- 「AIの見立て: 勝負を分けそうなのは？」が何を表すか分からない
- 1件ずつの見比べは控えめでよい
- 「類似している過去レース」「類似している過去レースの傾向」という名前にしてほしい
- 条件で比べるのは寄与度だけでよい
- 3タブにしてほしい

あわせて、6艇で同じ値の材料（天候・水面、レースの条件）についてユーザーから問いがあった。「5号艇に有利な天候があるかもしれない」というもの。これを、数えた値（prep6）とモデルの値（env-check）の両方で確かめた。

**数えた値**
- 風が強いほど1号艇の1着率が下がり、外の艇が上がる（1号艇: 0〜1m 58.2% → 6m以上 47.6%）
- 波も同じ向き
- 天候（晴・曇り・雨）では、差はほぼ無い
- 準優勝戦・優勝戦は、1号艇が高い

**モデルの値**
- 同じ向きで、ほぼすべての帯で区間が0をまたがない
- 大きさは、艇の合計の数%
- 例外が1つある。G1・SG で、モデルの1号艇の値がわずかにマイナスになり、数えた値と向きが逆になる

**結論**: この2テーマは、艇ごとの材料として残した（ユーザーの観点を採用。前の「外す」という推奨は撤回した）。

独立したエージェント（second-opinion-reviewer）に第5回の検証をかけた。

## 画面に出してよいもの・いけないもの（第5回で追加、採用）
**出してよい**
- 天候・水面とレースの条件を、艇ごとのテーマとして出すこと（展示後の段だけ。条件の中身を名前に入れてよい）
- 数えた値を参考として添えること（別の枠。「まざった率」と明記する）
- 条件ごとの材料の割合（構成比であること、6艇のばらつき、判定の基準が仮の値であること、を添える）

**出してはいけない**
- モデルの矢印と数えた率を同じ行に並べること
- 展示前の段で天候・水面を出すこと
- 丸めた SD での判定、絶対 pt だけの「ほぼ同じ」
- 割合の差から「この条件では○○が効かない」と読める見せ方
- 艇番ごとの割合を向きの説明なしで出すこと
- 会場をそろえていない基準だけを点線にすること
