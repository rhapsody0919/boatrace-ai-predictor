推奨: 件数の札「168件 ›」を押すと、図の下に元のレースの一覧が開く（どこを押しても同じ形）
  • 押す所: 1着の棒・決まり手の棒・万舟・よく出た3連単の行・着順の流れの帯（3連単の一番下に1つ）。行全体が押せる（高さ 44px）
  • 一覧は押した行のあいだではなく、その図（6行など）の下にまとめて開く。6艇の見比べを崩さない。押した行は金枠で残り、一覧の見出しに押した物と ✕
  • 1件は2段で、行全体がそのレースの結果へのリンク: 「10/06 戸田 9R 2-1-4」「差し・1,980円」。選んでいる進入・形は見出しの下に1回だけ
  • 直近5件、「もっと見る」で20件まで。全国の全レースなど件数の多い範囲は、見出しの下に「直近3,000件の中から出している」を1行
  • 棒は今の本番と同じ（級別の札と分母・全体の点線・ぶれ幅）。件数の列が札になるだけ
  • PC（2カラム）では右の列で開き、左の図は見えたまま
  • 3着以内の棒は押す所に入れない（ファンパネルで挙がらず、1着と同じレースが多く重なるため）
