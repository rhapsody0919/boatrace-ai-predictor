# ファンパネル: 展開シナリオの文字を減らし、艇ごとの件数を絵で伝える（BOA-806 と合わせて）

前提: 締切5分前、スマホ（375px）片手。参加は熱血ボートレースファン4人だけ（`fan-panel-heptagon.md` と同じ4人）。
同じモデルのロールプレイなので、結論は仮説。検証はモックをユーザーが触ることと、公開後の実データで行う。

- 20代男（20男）: 3連単で穴寄り。頭の艇を決めてから相手を探す
- 20代女（20女）: 2連単中心。数字は見るが表は苦手
- 30代男（30男）: 本命党。1号艇が飛ぶかどうかを最初に見る
- 30代女（30女）: データ派。件数と集め方を気にする

## 出発点（事実）

- ユーザーの依頼（原文）:「展開シナリオの文字数が多いので、適宜折り畳めたり図やイメージにできるところは修正してほしい。」「もっとUI/UX的にわかりやすい表示は可能？天才UI/UXデザイナーの目線で。」（BOA-806 の③④）
- 文の棚卸し（多摩川12R 10/5、375px、②カド一撃、全部開き）: 全部で5,237字・高さ9,650px。閉じていても見えるのが3,683字。そのうち③が1,751字（48%）で、③には折りたたみが1つも無い。③の表2つのセルに「全国・同じ級別の組み合わせ」が24回、「少ない」が24回
- 同じことを2回以上言っている所が17件。いちばん大きいのは「どの数字がどの範囲のレースから出ているか」の説明が3か所（計266字）
- 独立の UI/UX レビュー（③④）: P1 が2件。③で「1号艇の逃げ」が36%と34%の2つ出て、理由が下の箇条書きにしか無い。④の上の「362件」が6艇全部の母数に見える（実際は362・413・362・359・419・235）
- 守ること: 情報（詳細度）は減らさない。消すのではなく、折りたたむ・図にする・1か所にまとめる

## 論点1: ③攻めは決まった？ の長さ

### 案③-1: 答えを先に、表は「区分で見る」に畳む

```
③ 攻めは決まった？            [多摩川・同じ級別×枠なり×カド一撃]
攻める艇 ④ 4コース・カド  (i)
┌ ④B1のレース 67件 ─────────────┐
│ 4号艇が1着        ▓▓▓░░░░░ 15%   │
│ 4号艇が2着以内    ▓▓▓▓▓░░░ 28%   │
│ すぐ外の5号艇が1着 ▓▓▓▓░░░░ 19%   │
└──────────────────────────────┘
┌ ①A1のレース 68件 ─────────────┐
│ 1号艇が逃げた     ▓▓▓▓▓▓░░ 34%   │
│ 1号艇が2着以内    ▓▓▓▓▓▓▓▓ 57%   │
└──────────────────────────────┘
今日の4号艇: 展示 2位（上位）・モーター 2位（上位）
 → 上位のとき 4号艇の1着 24%（6/25）・少ない
▶ 展示タイム・モーターの区分で見る（表）
```

### 案③-2: 今のまま、表のセルの繰り返しだけを凡例にまとめる

**20女**: 今の③は表が2つ縦に並んで、どこを見ればいいか分からない。案③-1の「答えの棒が5本」なら読める。表は開きたい人だけでいい。

**30男**: 1号艇の逃げが36%と34%で2回出るのが一番気持ち悪かった。③-1みたいに「④B1のレース」「①A1のレース」の札で箱を分けてくれれば、違う箱の数字だと分かる。36%（4号艇の箱の中の1号艇の逃げ）は1号艇の箱に寄せて、4号艇の箱には出さないでいい。

**30女**: 数字を消さないなら賛成。4号艇の箱で1号艇が逃げた割合（36%）も情報としてはある。消すのではなく、4号艇の箱を開いた中（区分で見る）に残してほしい。今日の区分の1行（上位のとき 24%）は表を開かなくても見たい。

**20男**: 表を開いたときに「全国・同じ級別の組み合わせ 33%」が全部のセルに出るのは読む気が失せる。凡例1回と小さい点線の印でいい。案③-2の直しは③-1でも必要。

**結論**: 案③-1（答えを先に、箱は範囲の札で分ける、表は畳む）。③-2の凡例のまとめは、畳んだ表の中にも入れる。4号艇の箱の「1号艇の逃げ 36%」は表の中に残す。

## 論点2: ④で艇ごとに件数が違うこと

### 案④-1: 棒の左に「級＋件数」の札

```
1着になった艇   各艇、自分の級のレース（足しても100%にならない）
① A1 362 ▓▓▓▓▓▓▓▓▓▓▓ 74% 268
② A2 413 ▓▓          13%  55
③ A2 362 ▓▓          10%  38
④ B1 359 ▓            4%  15
⑤ A2 419 ▓            7%  28
⑥ B1 235 ┊            0%   1
```

### 案④-2: 上に合計100%の内訳の帯、その下に艇ごとの率

**20女**: ④-1がいい。艇ごとに「A1 362」が付いていれば、件数が違うことは見れば分かる。今の4行の注記は読まない。

**30女**: ④-2は、2号艇の13%と内訳の12%が2つ並ぶので、また「どっちが本当？」になる。④-1。件数が少ない艇（30件未満）は棒を薄くして、凡例に「薄い＝30件未満」を足して。

**20男**: 「当たり」は舟券の的中に聞こえる。数字の右は「268」だけでいい（1着の回数と、札の件数で分かる）。

**30男**: 上の「68件」は1号艇の箱の件数なので、「①A1のレース 68件」の札にしてほしい。③と同じ札なら覚えることが1つで済む。

**結論**: 案④-1。上の件数は「①A1のレース 68件」の札にし、着順の流れ・3連単・決まり手・万舟は同じ札の下に置く（1号艇の範囲だと札で分かる）。④-2は採らない。

## 論点3: ①②と手がかり、注記

**30女**: 「1号艇の1着率」が①で4回・②で8回出る。列の上に1回でいい。②の7枚の絵の「スリット」「1艇身（約0.13秒）」も、上に1回の凡例でいい。

**20女**: 手がかりの「このコース＝…全体＝…」の説明は、選んでいる方だけ1行にして、両方の比較は（i）で。

**20男**: 注記の折りたたみが「割合の出し方・注意」という同じ名前で2つあるのは迷う。一番下の1か所にまとめて、中を「進入」「手がかり」「スリットの形」「③」「④」の小見出しで分けて。

**30男**: 「どの数字がどの範囲か」は文章3か所ではなく、一番下の折りたたみに1枚の表（行＝③④の各部品、列＝1号艇の級でそろえた／その艇の級でそろえた）にまとめて。普段は札だけ見れば足りる。

**結論**:
- ①②の「1号艇の1着率」とスリットの絵の凡例は、列・段の上に1回
- 手がかりの平均STの説明は、選んでいる方だけ1行、比較は（i）
- 注記は一番下の折りたたみ1つ（小見出しで分ける）。範囲の対応は1枚の表

## 論点4: ステップで1段ずつ見せるか（案B）

### 案B: ①〜④を1段ずつ開く（開いた段だけ中身を出す）

```
① 進入        枠なり ▼
② スリット    カド一撃 ▼
③ 攻め        4号艇が1着 15% ▼   ← 開いた段だけ中身
④ 結果        1号艇の1着 74% ▼
```

**20男**: 結果まで全部ひと続きで見たい。押すたびに閉じたり開いたりは締切前には面倒。

**20女**: 私はBの方が迷わない。今どこを選んでいるかが上にまとまっている。

**30男**: Bは閉じた段の1行に答え（15%・74%）が出るなら、それで足りることが多い。

**30女**: Bにすると④の棒と③の箱を同時に見比べられない。比べたい人には不便。

**割れた点**: ひと続きで読みたい（20男・30女）か、1段ずつ（20女・30男）か

**結論**: 推奨は案A（ひと続き・答えを先に・詳しくは畳む）。案B（1段ずつ）はモックで切り替えて触れるようにし、ユーザーに選んでもらう。
