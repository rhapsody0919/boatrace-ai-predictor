# ファンパネル: 七角形に6艇を全部重ねて読めるようにする

前提: 締切5分前、スマホ（375px）片手。参加は熱血ボートレースファン4人だけ（`fan-panel-heptagon.md` と同じ4人）。

- 20代男（以下 20男）: 3連単で穴寄り。頭の艇を決めてから相手を探す
- 20代女（以下 20女）: 2連単中心。数字は見るが表は苦手
- 30代男（以下 30男）: 本命党。1号艇が飛ぶかどうかを最初に見る
- 30代女（以下 30女）: データ派。件数と集め方を気にする

同じモデルのロールプレイなので、結論は仮説。検証はモックをユーザーが触ることと、公開後の実データで行う。

## 出発点

- 前回のパネルは「6艇を全部重ねると読めない」で全艇重ね（案C）を落とし、主役＋2艇まで（モック v2）にした
- ユーザーの回答（原文）:「これはなんで全艇で重ねないの？重ねた方がどれが良いかぱっと見わかるのではと思った。」
- 読めなくなる理由は2つ: (1) 白（1号艇）と黒（2号艇）の線が紺の背景で片方消える、(2) 7軸で6本の線が交差して、どの線が何号艇か辿れない。今回はこの2つをデザインで解く

## 論点1: 6本の線をどう描き分けるか

### 案D1: 6艇とも細い線。押した艇だけ太く・塗り、ほかは薄く

```
        全国勝率
       ／￣￣＼
     ／ ━━④   ＼   ━ 押した艇（太線＋塗り）
    ｜ ─①─②─③  ｜   ─ ほかの5艇（細線・薄く）
     ＼ ─⑤─⑥  ／
       ＼＿＿／
 [①][②][③][④][⑤][⑥]  ← 凡例＝押すボタン
```

### 案D2: D1 ＋ 頂点の外に、その項目で一番上の艇番

```
          ④           ← 全国勝率は4号艇が1位
        全国勝率
   ①  ／￣￣＼  ④
 今節点        当地勝率
```

### 案D3: 6艇の線の端（頂点の点）すべてに小さな艇番の丸

```
   ④①②
  ／ ③⑤⑥＼   ← 7頂点×6艇＝42個の丸
```

**20男**: ユーザーさんの言う「どれが良いか」は、外に張り出してる艇がどれかってこと。D1で全部細線にしておいて、気になる艇を押したら太くなる、なら6艇全部見ながら相手を探せる。前回のCが駄目だったのは「主役以外が全部同じ薄さで、何号艇か分からない」からで、押せば分かるなら話が違う。

**20女**: D3は丸が42個で無理。D2の「その項目の1位の艇番」はすごく分かりやすい。7つの頂点を一周見るだけで「4号艇が3項目で1位」が分かる。線を辿らなくていいのが大事。

**30男**: 1号艇が飛ぶかを見るなら、1号艇の線が最初から見えてないと困る。D1で何も押してないときは全部同じ太さだと、1号艇の線を探すことになる。最初は1号艇（またはソナーで選んでる艇）を太くしておいてほしい。

**30女**: 白と黒の線の問題は、紺の背景なら白はそのまま、黒は白い縁取りを付けた黒線にすれば見える。舟券の枠色と同じ色を使うのは大事で、2号艇だけ灰色にすると「灰色って何号艇？」になる。それと、D2の1位の艇番は、同じ順位の艇がいたら両方出してほしい（並び順で片方だけ出すと嘘になる）。

**割れた点**
- 最初に何も太くしない（20男）か、選んでいる艇を太くしておく（30男）か
- D2の頂点の艇番を全部の軸に出すか（20女）、同順位の扱い（30女）

**結論**: D1＋D2。D3は採らない。
- 6艇とも枠の色の細い線で重ねる。塗りは太くした艇だけ
- 最初は、一番上で選んでいる艇（主役）を太線＋塗り。凡例の艇番を押すと、その艇が太く・塗りになり、ほかは薄くなる。もう一度押すと主役に戻る
- 2号艇（黒）は白い縁取り付きの黒線、1号艇（白）は白い線
- 頂点の外に、その項目で今日一番上の艇番を出す。同順位なら全部出す

## 論点2: 「どれが良いか」をひと目で出すか

### 案E1: 凡例に「上位2位以内の項目数」を出し、多い順に並べる

```
 ④ 7項目中 5項目で2位以内
 ① 7項目中 4項目で2位以内
 ③ …
```

### 案E2: 七角形の面積（張り出しの大きさ）で並べる

**20女**: E1は分かる。「5項目で2位以内」は言葉で読める。面積は「面積って何？」になる。

**30女**: E1でいい。ただしこれは「今日の順位がいい項目の数」であって、1着しやすさではない。並べ替えると「上から順に強い」と読まれる。並べ替えはせず、艇番順のまま数だけ添える方が誤解が少ない。

**20男**: 数が出ていれば並べ替えなくても目で拾える。艇番順でいい。

**30男**: 賛成。艇番順が崩れると押す場所を毎回探すことになる。

**結論**: E1の数だけを凡例に添え、並べ替えはしない（艇番順のまま）。E2は採らない。

## 論点3: v2（主役＋2艇）とどう切り替えるか

**4人とも**: 6艇重ねで押せば1艇を太くできるなら、v2の「主役＋2艇」は「2艇だけ消したいとき」用になる。切り替えは残してよいが、最初に出すのは6艇重ね。「6艇を見渡す」（小さな七角形の並べ）は、6艇重ねで同じ役割を果たすので3つ目の切り替えとしては要らない。

**結論**: 切り替えは「6艇を重ねる」（最初）と「主役＋2艇」の2つ。「6艇を見渡す」は外す。

## まとめ（モック v3 に入れること）

1. 最初の表示は6艇を重ねる。6艇とも枠の色の細い線、主役だけ太線＋塗り
2. 凡例の艇番を押すとその艇が太く・塗りになり、ほかは薄くなる。もう一度押すと主役に戻る
3. 2号艇は白い縁取り付きの黒線、1号艇は白い線
4. 頂点の外に、その項目で今日一番上の艇番（同順位は全部）
5. 凡例に「7項目中◯項目で2位以内」。並べ替えはしない
6. 点線（1着になったときの平均の順位）は太くした艇の1本だけ
7. 「主役＋2艇」へ切り替えられる。「6艇を見渡す」は外す
