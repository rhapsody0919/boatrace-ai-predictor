龍神ソナーを「基本情報」と「AI予想」の間のタブにする

v2 への回答を反映した（スリットの形の絵は本番のまま、級別の組み合わせの書き方、単位）。数字・件数・ぶれ幅・注意書きは今の画面から1つも減らしていない。数字は桐生10R（10/8、展示前・1号艇・1着）の本番の値。ソナーの点・類似レースの日付などは例。

決まった点（v1 の回答）タブ名「龍神ソナー」／カードは「差が大きい」だけ開く／並べ方は「類似度の高い順」／?tab=aiPrediction&sonar=… はソナーへ送る／AI予想タブの下に案内1行
ソナーの点タップ: 近い点を最大5件、図の下に並べる。長押し（0.4秒）: 一番近い1件をその場の吹き出しに。押している間は輪が満ちる。指が10px動いたらスクロール扱い。吹き出しは外をタップか画面を送ると閉じる
スライダーで拡大・縮小件数を減らすと図が拡大し、外周がその件数になる。内側の輪は10・50・100・200・400番目（最大4本）
件数の言い方レースを絞る話は「集める」（集めたレース）、割合の作り方は「出す」（割合の出し方・注意）。注意は「過去の割合で、原因とは限らない」
級別の組み合わせ（枠は同じか）同じではない。そろえているのは6艇の級別ごとの艇数と、選んだ艇の級別だけ。1号艇以外の5艇がどの枠にいたかは問わない
スリットの形の絵本番の今の絵（大きさ・並べ方）のまま。変えていない
オレンジの枠＝今の画面から変えた所
