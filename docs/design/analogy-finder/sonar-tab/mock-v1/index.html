龍神ソナーを「基本情報」と「AI予想」の間のタブにする

数字・件数・ぶれ幅・注意書きは今の画面から1つも減らしていない。置き場所と形（絵・凡例・表・折りたたみ）を変えて、締切前に読む所だけを上に残した。数字は桐生10R（10/8、展示前・1号艇・1着）の本番の値。ソナーの点・類似レースの日付などは例。

依頼1 点が押しづらい長押しをやめ、タップで固定表示。当たり判定は指の大きさ（半径20px）。範囲内の近い点を最大5件、図の下に並べる
依頼2 文字が多いカード6枚の「見方」は凡例の絵に1回。まとめの文は数字に分解して棒の下へ。カードは1行に畳む。スリット図は絵に描き込む
依頼3 別タブ基本情報 ／ 龍神ソナー ／ AI予想。中の3つの切り替えは上に固定
依頼4 禁止語「ふつう」「全体の」「似ている」をなくした。比べる相手は「桐生・同じ級別の組み合わせの全レース」のように書く
