# UI/UX レビュー: 龍神ソナーの PC 表示（BOA-813）

設計に関わっていない UI/UX デザイナー役（独立サブエージェント、修正禁止）が、本番 津4R（2026-10-10）を 375・1024・1440・1920px で見た結果。

## 実測

| 幅 | ソナーの列 | 左右の空き | 画面に占める割合 |
|---|---|---|---|
| 375 | 359 | 8 / 8 | 96% |
| 1024 | 720 | 152 / 152 | 70% |
| 1440 | 720 | 360 / 360 | 50% |
| 1920 | 720（ページは1600） | 600 / 600 | 37.5% |

- 原因: `AnalogyV16.css` の `.af-v16 { max-width: 720px; margin-inline: auto }`。ブレークポイントの指定が無い
- 列の中の図も小さく止まっている: 七角形・ソナーの SVG は 440px（暗い箱の左右に約140px ずつ空く）、スタートの手がかりの絵は 520px、スリットの形の札は 356px の2列
- 縦の長さはスマホの 87〜91%（差がつく材料 4212 / 類似レース 4114 / 展開シナリオ 6626 / カド一撃 5113、1440px）
- 1440×900 の最初の画面に図が1つも出ない（中身は y≈565 から、七角形は y≈1020 から）
- 同じ 1440px の他のタブ: 基本情報 1392、今節・枠別 1200 で左寄せ、直前情報 1392、モータ 1344、AI予想・ソナー 720 で中央、思考アシスト 480
- 前例: 旧版 `AnalogyFinder.css:379` に 1024px 以上の2カラム（`minmax(0,22rem) minmax(0,1fr)`）

## 指摘（PC だけ変え、375px は今のまま）

| 重大度 | 場所 | 問題 | 直す方向 |
|---|---|---|---|
| P1 | 3つのタブ全部 | 1440 で左右 360、1920 で 600 空く | 1024px 以上で最大 1200 に広げ、セクションの中を2カラム |
| P1 | 着順の流れ→よく出た3連単 | 帯を押した結果（3連単）が帯の箱の下で、画面の外に出る | 左に流れの図、右に3連単（上に止める） |
| P1 | 差がつく材料 | 艇の行が図の下。下の艇を押すと七角形が画面の上に外れる | 左に七角形（止める）、右に艇の行・項目の詳細・差のカード |
| P1 | 類似レース | 点を押すと出る近い5件・扇で変わる棒が図の下 | 左にソナーとスライダー（止める）、右に近い5件・勝った艇・決まり方 |
| P2 | 展開シナリオ③ | 攻める艇の箱と1号艇の箱が縦に積まれる | 左右に並べる |
| P2 | 展開シナリオ④ | 1着と3着以内、決まり手と万舟が縦に並ぶ | 2つずつ左右に |
| P2 | 展開シナリオ② | 形の札が2列×4段（約700）。手がかりの絵の右が空く | 1280 以上で4列×2段。絵の右に当てはまる条件 |
| P2 | タブ全体 | タブは x=24、ソナーの中身は x=360 から | 中身の左端をタブの列にそろえる |

| P3 | 押せる所 | 中のタブ・艇の行はマウスを重ねても変化が無い | 重ねたとき枠を金色・背景を少し濃く |

| P3 | 文言 | PC でも「タップ」 | 「押す」 |

## 読む順

①〜④の見出しは横幅いっぱいで上から順に読む。2カラムは各セクションの中だけ。①②を左・③④を右のような割り方はしない（②で選ぶと③④が変わるつながりが見えなくなる）。

## サイト共通の決まり案（別チケット）

全幅（6艇を列に並べる表）／最大1200・2カラム（図とリスト・操作の組: ソナー・思考アシスト・今節）／720（文章と1行1項目のリスト: AI予想・払戻）の3段にし、どの段も左端をタブの列にそろえる。
