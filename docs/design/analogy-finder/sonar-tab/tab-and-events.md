# 龍神ソナーの別タブ化: URL・タブ・計測の整理（案）

モックと一緒にユーザーに見せる。決めるのはユーザー（BOA-271 は見せ方をユーザーが決める）。

## タブ

| 項目 | 案 |
|---|---|
| 位置 | `basic` → **`sonar`** → `aiPrediction` → `meet` → … |
| タブ id（URL の `?tab=`） | `sonar` |
| ラベル | ja 龍神ソナー／en Ryujin Sonar／zh-TW 龍神聲納／ko 용신 소나（機能名と同じ。`raceTabs.sonar` を足す） |
| 出す条件 | `isAnalogyFinderEnabled()` が true のとき（フラグは残す）。保存の無いレース（10/5 以前など）もタブは出し、中で「保存がありません」を出す。タブの有無をデータで変えると、facts を読むまでタブ列が決まらず並びが動くため |
| 結果確定後 | 出す（過去レースの振り返りにも使える）。既定タブは今どおり確定前 `basic`／確定後 `result` |
| 下の分析ツール群 | `showPreRaceAnalysisTools` の除外に `sonar` を足す（AI予想タブと同じく、タブの下にデータ出走表などを続けない） |
| AI予想タブ | ソナーの節を外す。代わりに一番下へ「類似レース・展開シナリオは龍神ソナーのタブへ」の1行の案内（押すとソナーのタブ）を置くかはモックで判断 |

## URL

| 来た URL | 開くタブ | 理由 |
|---|---|---|
| `?tab=sonar` | ソナー（内部は「差がつく材料」） | — |
| `?tab=sonar&sonar=similar` | ソナー（内部は類似レース） | #1324 の `?sonar=` を引き継ぐ。読むだけで書き換えない |
| `?tab=aiPrediction&sonar=…` | **ソナー**（内部は指定どおり） | 公開後に投稿したリンクの形。`sonar=` が付いていればソナーを見に来た人 |
| `?tab=aiPrediction`（`sonar=` なし） | AI予想（今どおり） | 集客レーンの投稿は今これ。AI予想を見に来た人をソナーへ送らない。投稿のリンク先は今後 `?tab=sonar` に変える（hq に連絡） |

- 節まで縦にスクロールする処理（#1324 の `SONAR_SECTION_ID` への移動）は、ソナーがタブの先頭に来るので外す。`id="ryujin-sonar"` は残す
- `linkUsedRaces`（レースごとに1回だけ `?sonar=` を効かせる）は残す。ほかのタブから戻るたびに内部タブが選び直されないため

## 計測（#1312・#1320 の定義との合わせ方）

| イベント | 今の意味 | 別タブ化後 | 扱い |
|---|---|---|---|
| `race_tab_select` | レース詳細のタブを押した | `tab_id=sonar` が「ソナーを開いた」になる | **ソナーへの入口の正本**。ファネルの「AI予想タブ（押した）」段を「ソナーのタブ（押した）」に差し替える |
| `race_tab_initial` | `?tab=` のリンクで開いた | `tab_id=sonar`（`?tab=aiPrediction&sonar=…` から送った場合も sonar） | 送り直した先の id で送る |
| `analogy_section_view` | facts が出たら1回（AI予想タブの下に描画された） | タブを開いて facts が出たら | 意味が「AI予想タブを開いた人の大半」から「ソナーを開いた人」に変わる。**切り替え日を events.md に書き、前後の数を比べない**。今はタブを開き直すたびに作り直されて再送される（ref が mount ごと）ので、`linkUsedRaces` と同じくモジュールの集合で「レースごとに1回」にそろえる |
| `analogy_section_visible` | 節が画面に入った（スクロールして下まで来た） | タブを開いた直後にほぼ必ず入る | section_view とほぼ同じ数になり、区別の意味が薄れる。残す（`markAnalogySeen` の時刻記録に使うため）が、ファネルの段からは外す |
| `analogy_tab_select` | 節の中の3タブを押した | 同じ（「差がつく材料／類似レース／展開シナリオ」の切り替え） | 名前・パラメータは変えない（`analogy_tab` は内部の3つのまま）。レース詳細のタブとまぎれないよう events.md に「内部の切り替え」と明記 |
| `analogy_control_change` | 条件の変更 | 同じ。ソナーの点の新しい操作（タップで固定等）を足すなら `analogy_control` に値を足す | — |
| `analogy_return_visit` | 7日以内の再訪 | 同じ | — |
| 画面の中の声（#1322） | `analogy_feedback_view／vote／send` | 同じ。置き場所だけ変わる | — |

夕方の点検（handoff 5）で見る `analogy_tab_select` は、別タブ化の前後で意味が変わらないので、そのまま比べられる。
