- 20代男（以下 20男）: 3連単で穴寄り。頭の艇を決めてから相手を探す

- 30代女（以下 30女）: データ派。件数と集め方を気にする

### 案C: 主役を濃く＋残り5艇を薄く全部重ねる

```
        全国勝率
       ／￣￣＼

    ｜ ･･･②③   ｜   ･･･ ほかの5艇は細く薄い線
```

**20男**: 頭を決めたら相手を5艇から探したいから、全部見えないと困る。Bの小さな図なら6艇が一画面に入る。形だけで「この艇は外に張り出してる」は分かる。軸の名前が小さいのは我慢できる。

**20女**: Cは無理。薄い線が5本重なったら、どれが何号艇か分からない。色で分かるのは2本まで。Aで「1号艇と4号艇」を重ねるのが一番ぱっと見で分かる。ユーザーさんの言う「ぱっと見」はたぶんこれ。

**30男**: 本命党としては1号艇を軸に、脅かす艇1つを重ねられれば足りる。Aでいい。ただ、どの艇を重ねるかを自分で探すのは手間。最初から「1号艇に一番近い形の艇」か「差が大きい項目で1号艇より上の艇」が1艇重なっていてほしい。

**30女**: Bは6艇を同じ物差しで並べられる点で前回の表の良さを引き継げる。でも375pxで2列だと1枚が160px前後。七角形の半径が30pxちょっとになって、7軸の順位1つの違い（約5px）が目で拾えない。Bは「形の大まかな張り出し」用で、数字の比較は無理。

**割れた点**
- 6艇を全部見たい（20男・30女のB）か、2〜3艇を重ねて読みたい（20女・30男のA）か
- 重ねる艇を自分で選ぶか（20女）、最初から1艇選んであるか（30男）
- Cは4人とも「読めない」で一致して落ちた

**結論**: 重ねるのは最大3艇（主役＋2艇）。それ以上は線が読めない。最初は主役＋1艇を自動で重ねて出す（どの艇を選ぶかは下の推奨で決める）。6艇を見渡したい人向けには、Bの小さな図の並べを「6艇を見渡す」として切り替えで残す。Cは採らない。

## 論点2: 「1着になったときの平均の順位」の点線を、重ねたときにどう見せるか

### 案2-1: 主役だけ点線

```
 ━━ ①今日   ┅┅ ①1着時   ━━ ④今日
```

### 案2-2: 全艇の点線を出す（3艇なら線6本）

```
 ━━①今日 ┅┅①1着時 ━━④今日 ┅┅④1着時 ━━③今日 ┅┅③1着時
```

### 案2-3: 選んだ1艇だけ点線（艇のチップを押すと点線がその艇に移る）

```
 重ねる: [①] [④]   点線: ④の1着時 ← 押した艇に移る
 ━━①今日  ━━④今日  ┅┅④1着時
```

**20男**: 4号艇を頭にしたいかを見るなら、要るのは4号艇の点線。主役だけ点線（2-1）だと、比べる艇が「勝つときの形」に近いか分からない。それじゃ前回の画面と同じ不満が残る。

**20女**: 線6本は無理。実線と点線が同じ色で3組あったら、どの点線がどの艇か追えない。点線は1本だけがいい。

**30男**: 2-3がいい。1号艇を押せば1号艇の1着時の形、4号艇を押せば4号艇の形。今日の実線との「ずれ」を見るのは1艇ずつで十分。

**30女**: 点線は艇ごとに件数が違うから、点線の横か凡例に件数が要る。B級の艇の1着時は件数が少ないことがある。少ない艇の点線は「件数少」と書くか、薄くしてほしい。

**割れた点**
- 主役固定（2-1）か、押した艇に移す（2-3）か。2-1を推す人は出なかったが、20女は「点線が動くと最初は戸惑う」とも
- 件数の出し方（30女は凡例に件数、20男は不要）

**結論**: 点線は常に1本。最初は主役の艇の点線。重ねた艇のチップを押すと点線がその艇に移る（2-3）。凡例は「┅ ④が1着のときの平均（○件）」と艇番と件数を明記し、件数が少ないときは点線を薄くして「件数少」と添える。2-2は採らない。

**20男**: 3-2の点を押すのは375pxで指が当たらない。点が3つ近くに集まったら、どれを押したか分からない。押すなら軸の名前（3-1）のほうがまだ当たる。

**20女**: 3-1がいい。「全国勝率を押すと6艇の数字」なら、七角形で気になった軸だけ数字を見る、っていう順番になる。いきなり表が出るより分かりやすい。

**30男**: 3-3の小さな表は、七角形の下にあると結局表を読むことになる。ユーザーさんが表より七角形と言ったんだから、常時出すのはやめたほうがいい。

**割れた点**
- 常時の数字（3-3）を出すかどうか。出したい人はいなかったが、30女は「順位の数字だけなら1行で出してもいい」と言った
- 3-2の点押しは4人とも375pxでは厳しいで一致

**結論**: 軸の名前を押すと、その項目の6艇の今日の値と順位、重ねた艇のその順位での1着率（全レースでの1着率つき）が七角形の下に開く（3-1）。棒は今の項目カードへ「この項目のカードを開く」で飛ぶ。点押し（3-2）と常時の表（3-3）は採らない。

## 論点4: 375px で指で操作できるか

**20男**: 艇の切り替えは七角形の上に艇番のチップを横一列。主役の6つのボタンとは別の段にしないと、主役を変えたのか重ねる艇を変えたのか分からなくなる。

**20女**: 実線は2.5px以上の太さがほしい。色だけだと1号艇（白）と、ほかの薄い色の艇が背景で見えにくいことがある。艇番の丸を線の外側の端に置いてくれると、どの線か分かる。

**30男**: 軸の名前が押せることが分からないと誰も押さない。項目名に下線か▼を付けて、押せる見た目にしてほしい。七角形自体は今の大きさ（カード幅いっぱい）のまま。重ねるときに縮めない。

**30女**: 軸の名前は7つが円周に並ぶので、押せる範囲は1つあたり幅60px・高さ40px前後は要る。隣同士が近い上側（全国勝率と今節点・当地勝率）が詰まらないか、モックで確かめたい。

**割れた点**: 大きくは割れず。主役の選択と重ねる艇の選択を別の段に分けることで一致。

**結論**:
- 主役は今の `[1]〜[6]`。その下の段に「重ねる」チップ（主役以外の5艇、最大2艇まで押せる）
- 実線は太め（2.5px前後）、重ねた艇の線の端に艇番の丸を付ける
- 軸の名前は押せる見た目（▼）にして、押せる範囲を広く取る
- 七角形は重ねても縮めない

## 議論とは別の事実（パネルには混ぜていない）

- 今の七角形（`src/components/race/analogy/FactHexagon.jsx`）は viewBox 幅500に対して半径100。375px のカード幅（約343px）では半径およそ69px。2列の小さな図（1枚160px前後）にすると、ラベル込みで半径30px前後になり、順位1つの差は約5px
- 各艇の線を「その艇を一番上で選んだときと同じ集め方」で出すため、重ねる艇ごとに集め方・件数が違う。点線（1着時の平均）は艇ごとの1着件数で決まり、B級の艇では件数が少ないことがある
- 「6艇を見渡す」は6艇×その艇の集め方の取得になり、今の1艇ぶんよりデータが増える。負荷と件数の扱いは設計側で確かめる
- 集め方は別の統計の検証で変わる可能性があり、変われば論点2の件数の扱いと自動で重ねる艇の選び方も見直す
