七角形で艇を比べる

表ではなく、7項目の七角形（外側ほど6艇の中で上位）に艇を重ねて比べる案。数字は多摩川12R（10/8・準優勝戦・展示後・1着）の本番の値。各艇の線は、その艇を一番上で選んだときと同じ集め方で出す。集め方は検証の結果で差し替えられる作りにしてある。

重ねる艇（2艇まで）

項目の名前（▼）を押すと、その項目の6艇の今日の順位と、その順位のときの1着率がここに出る

モック: 項目カード（棒・件数・ぶれ幅）は下に今のまま続く。詳しい棒は項目の表の「棒を見る」からカードへ移る
ファンにとっての価値（ファン4人のパネル）
  • 七角形の形の張り出しで、艇の強みがぱっと見で分かる。ただし6艇を全部重ねると読めないので、重ねるのは主役＋2艇まで
  • 最初は主役＋1艇を自動で重ねる（主役が1号艇以外なら1号艇、主役が1号艇なら、その艇の全レースでの1着率が次に高い艇）
  • 点線（1着になったときの平均の順位）は1本だけ。凡例の「点線」を押すと、その艇の点線に切り替わる
  • 表の良さ（数字が読める）は、項目の名前を押すと6艇の数字の表が出る形で残す。線の点を押す案は375pxでは指が当たらないので採らない
  • 6艇の形の見比べは「6艇を見渡す」で小さな七角形を並べる。押すと重ねる側に入る
決めてほしいこと（推奨を先に）
  1. 重ねる数: 主役＋2艇まで／主役＋1艇まで
  2. 最初に出すもの: 重ねて比べる（主役＋1艇）／6艇を見渡す
  3. 点線: 1本だけ（押した艇に切り替え）／重ねた艇の分すべて

集め方: 今は「その艇の級別がそろうレース」。「同じ枠に同じ級」の検証の結果で集め方が変わったら、同じ図のまま数字だけ差し替える
