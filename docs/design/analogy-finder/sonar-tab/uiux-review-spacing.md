# 龍神ソナーの余白・区切りのレビュー（2026-10-09）

ユーザーの指摘「3つのタブすべてで、セクションごとの余白が無くて読みづらい」を受けて、設計に関わっていないサブエージェントが UI/UX デザイナーとしてレビューした。対象は PR #1336 の Preview（多摩川12R 2026-10-08-05-12・若松6R 2026-10-08-20-06）で、幅は 375px と 1440px、3つの内部タブすべて。修正はしていない。

## 原因
3つの内部タブの中身を包む要素（`div.af-tab-facts`・`div.af-tab-similar`・`div.af-tab-scenario`）に CSS が無く、ただの block になっている。外側の `.af-v16-box` の `gap:10px` が中まで届かない。中の要素どうしの間は、h3/h4 の `margin-top: 4px` だけで決まっている。そのため、要素間は 0〜6px、見出しの上は 4px、見出しの下は 0px になっている。1440px でも中身は最大幅720px なので、値は同じ。

## 余白の決まり（提案、design-tokens の値）
| 対象 | 375px | 1440px | 今の実測 |
|---|---|---|---|
| 外側の節間（操作の箱・タブの中身・使っている項目） | 16px | 16px | 12px |
| タブの中身の外枠 | 枠を外して 0 | 0 | 12px（枠・背景あり） |

| 説明文→本体 | 12px | 同じ | 0px |

| 図↔凡例 | 8px | 同じ | 0〜8px |

実装は、タブの包みを flex column（gap 12px）にし、h3 単位の `section` に区切りの規則を1つ当てるのが一番手数が少ない。要素ごとの margin は消して gap に寄せる。
