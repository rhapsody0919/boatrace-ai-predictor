BOA-816 龍神ソナー ・ 着順の流れの帯を押したときの「よく出た3連単」の内訳 ・ 数字は戸田6R（10/9、集めたレース4,708件）の本番の値

内訳の行に、集めたレース全体の中での割合を出すか

帯「1着1号艇→2着2号艇」615件を押した状態。帯を押す前の「よく出た3連単」では、1-2-3 は「5.3% 249件」と出ている

ファン4人のパネルの結論: 推奨は案C
  • 3連単のオッズと比べるのは「全体の中でどれくらい出るか」（1-2-3 が5.3%）。帯の中の40%はオッズと比べられない
  • 案Cなら、同じ出目は帯を押す前と後で同じ数字（5.3% 249件）。今の形は押すと「249件（帯の中の40%）」に変わり、数字が合わないように見える
  • 帯の中での大きさ（3着の選び方）は、棒の長さと件数（249／615）で見える
  • 文字は今より増えない（行の「帯の中の◯%」が消え、見出しに「全体の◯%」が1つ増えるだけ）
  • 案Aは1行に％が2つで読めない、案Bは見出しの13%と行の40%が混ざる、で落ちた
