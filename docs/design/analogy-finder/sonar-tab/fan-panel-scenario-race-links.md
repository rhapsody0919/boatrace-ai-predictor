# ファンパネル: 展開シナリオ④から元の過去レースに飛ぶ（BOA-823）

ユーザーの依頼（原文）:「展開シナリオの「結果はどうなったセクション」においても過去のレースに飛べるようになっていて欲しい。」

前提: 熱血ボートレースファン4人だけ。同じモデルのロールプレイなので結論は仮説。

## 前提の事実（議論とは別。コードと本番 API で確認、津4R 2026-10-10）

- 今の保存（`scripts/ml/analogy/v16_scenario.py` の `_cell`）は、進入×形のセルごとに件数の集計（1着の艇・2着・3着・決まり手・万舟・3連単の件数）だけを持つ。元のレースの一覧（race_id など）は、件数が30件未満のセルだけ `races` に入る（`MAX_ROWS = 30`）。30件未満のときの一覧（`ScenarioRaceList`）にも、レース詳細へのリンクは無い
- 範囲ごとの件数: 津・同じ組み合わせ（VC）は数百件、全国・同じ組み合わせ（NC）4,208件、津の全レース（VA）16,438件、全国の全レース（NA）403,149件。応答は今 1範囲あたり約 160〜190KB（gzip で約 24KB）
- 全件の一覧をいまの応答に足すのは無理（NA で 1,600 万字以上）
- 足し方の案: 範囲ごとに「直近 3,000件」の短い一覧（race_id・進入の型・スリットの形・1〜3着・決まり手・払戻）を別のファイルに置き、押したときだけ読む。1範囲 約 130KB（gzip 約 35KB）。朝のバッチは +30〜60秒・アップロード +20〜30MB の見込み（範囲のファイルは同じキーなら全レースで共有）
- 類似レースのタブは、点を押すと近いレースが最大5件出て「見比べる」とレース詳細へのリンクがある

## 論点1: どこを押したら、どのレースを見たいか

**20男**: 3連単の行。「1-3-5 が11件」なら、その11件がどんな日・どの会場だったか、配当はいくらだったかを見たい。穴の出目の実例がいちばん欲しい。

**30男**: 1着の棒。1号艇の飛んだレース（2〜6号艇が勝った）を押して、どんな負け方だったかを見たい。

**20女**: 万舟。荒れたレースを見て、展示や進入に何かあったかを確かめたい。決まり手の棒（まくり差し）も同じ。

**30女**: 着順の流れの帯。帯を押すと3連単が内訳に絞られる（BOA-816）ので、その下から帯のレースに飛べると流れがつながる。

**結論**: 押す所は 1着の棒・3連単の行・着順の流れの帯（内訳の下）・決まり手の棒・万舟。どれも「押すとすぐ下にそのレースの一覧が開く」同じ形にする。

## 論点2: 何件・何を出すか

**30女**: 何件のうちの何件かを必ず書く。「220件のうち直近5件」。

**20男**: 最初は5件で十分。「もっと見る」で20件まで。

**20女**: 1件ごとに日付・会場・R、1〜3着、決まり手、3連単の払戻。押すとそのレースの結果へ。

**30男**: 進入とスリットの形も小さく。今の30件未満の一覧と同じでよい。

**割れた点**: 全国の全レースなど大きい範囲で「直近3,000件の中から」になることを書くか。30女は書く、20男は要らない。→ 書く（件数が合わないときの理由になる）。1行の注記だけ。

## 結論（推奨）

1. 押す所: 1着の棒（艇）・3連単の行・着順の流れの帯（内訳の下に「この帯のレースを見る」）・決まり手の棒・万舟の棒
2. 押すと、すぐ下に「◯◯のレース　全220件のうち直近5件」と一覧が開く。もう一度押すと閉じる。同時に開くのは1つ
3. 1件: 日付・会場・R ／ 1〜3着の丸 ／ 決まり手 ／ 3連単の払戻 ／ 進入・形（小さく）／「結果を見る ›」でレース詳細へ
4. 「もっと見る」で20件まで
5. 大きい範囲（直近3,000件を超える範囲）は「直近3,000件の中から出している」を1行
6. PC（2カラム）では右の列に開く
