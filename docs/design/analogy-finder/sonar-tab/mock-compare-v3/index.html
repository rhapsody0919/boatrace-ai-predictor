七角形で艇を比べる

7項目の七角形（外側ほど6艇の中で上位）に6艇を全部重ね、外に張り出している艇をひと目で探せるようにした案。v2 の「主役＋2艇」にも切り替えられる。数字は多摩川12R（10/8・準優勝戦・展示後・1着）の本番の値。各艇の線は、その艇を一番上で選んだときと同じ集め方で出す。

モック: 項目カード（棒・件数・ぶれ幅）は下に今のまま続く。詳しい棒は項目の表の「棒を見る」からカードへ移る
ファンにとっての価値（ファン4人のパネル）
  • 6艇を全部重ねると、外に張り出している艇（今日の順位が上の項目が多い艇）がひと目で分かる
  • 読めなくなる2つの理由をデザインで解いた: 線は6艇とも細くし、太く塗るのは1艇だけ（最初は主役、凡例を押すとその艇）。2号艇の黒は白い縁取りを付けて紺の背景でも見える
  • 線を辿らなくても読めるように、頂点の外にその項目で今日一番上の艇番を出す（同順位は全部）
  • 凡例に「7項目中◯項目で2位以内」を添える。並べ替えはしない（上から強い順と読まれないように）
  • 点線（1着になったときの平均の順位）は太くした艇の1本だけ
  • v2 の「主役＋2艇」は、2艇だけを見比べたいとき用に切り替えで残す。「6艇を見渡す」（小さな図の並べ）は6艇重ねと役割が同じなので外した
決めてほしいこと（推奨を先に）
  1. 最初に出す図: 6艇を重ねる／主役＋2艇
  2. 頂点の外の艇番（その項目で今日一番上の艇）: 出す／出さない
  3. 凡例の「7項目中◯項目で2位以内」: 出す／出さない
