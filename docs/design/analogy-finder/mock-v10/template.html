テーマが見込みを動かした量（全国=100）

寄与度用のモデル（版 2026-10-02）で、各テーマが6艇の見込みを6艇の平均からどれだけ動かしたか（テーマの中の上げ下げを足し合わせた後の大きさ。A の割合と同じ単位）を、全国を100として比べた値。6艇の差の大きさや荒れやすさではない（テーマ同士で打ち消し合う分も含む）。合計や順位は出さない。

「全国より大きい／小さい」は、全国との差が10以上で、かつ ± の2倍以上のときだけ書く（± はレースの選び方の揺れだけで、モデルの学習の揺れは入っていない）。その条件で6艇の値（勝率など）が近いと、そのテーマは小さく出る（例: SG・G1 の「選手の実力」）。※ 天候・水面とグレード・ラウンド・節は6艇で同じ値なので、ほかの要素との組み合わせを通してだけ動く。大きく出ても、そのテーマ自体の効きが大きいとは言えない。

見てほしい点

  1. 構成: A このレース → B 似た過去レース → C 条件で探る の縦の流れ。着順は上の1つで全体に効き、艇は A と B で共有、会場などの条件は C の中だけ
  2. 艇の見せ方: A で艇を選ぶと「参考: その艇番の着順率（若松の全レースと G1、数えた値）」と「モデルの見立て: 枠以外で6艇の平均と比べて上げているもの・下げているもの（矢印と棒）」が別の枠で出る（検証で「出発点＋上げ下げ」の並びが足し算に読まれると指摘され、名前と枠を分けた）。上の切り替えで代案（艇の六角形）と比べられる
