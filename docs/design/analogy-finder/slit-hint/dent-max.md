# 凹みの定義を「両隣より遅い」に変えた前後の数字（Q-F4、BOA-777）

2026-10-06 ユーザー決定。2コース凹み・カド受け凹みの判定を、早い方の隣（min）より0.05秒以上遅い → 両隣（遅い方の隣＝max）より0.05秒以上遅い、に変えた。説明文「両隣より0.05秒以上遅い」と判定式を一致させるため。ほかの5形（横一線・内3艇そろう・カド一撃・イン凹み・ダッシュ勢先行）は変えていない。

- 旧: d2 = c2 − min(c1, c3) ≥ 5、d3 = c3 − min(c2, c4) ≥ 5（1/100秒の整数）
- 新: d2 = c2 − max(c1, c3) ≥ 5、d3 = c3 − max(c2, c4) ≥ 5
- 実装: `scripts/ml/analogy/v16_defs.py` `slit_forms_matrix`、`src/utils/analogyScenario.js` `slitForms`（同じ答えを `verify-analogy-facts.js` が 300 ケースで検査）
- 手がかりの条件（`d2_slow01`・`d3_slow01`）は元から両隣（max）で判定していたので変えていない
- 凹みの3形（イン凹み・2コース凹み・カド受け凹み）では、③の「攻める艇が内の艇より0.05秒以上前に出た割合」を出さない（新しい定義では定義から100%）

- 過去の母集団の本番 ST は F・L の艇を含まない（D-2、tab3_ok が返還艇のいるレースを除く）
