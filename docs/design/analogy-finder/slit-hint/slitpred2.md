# 条件ごとの平均STでスリットの形を当てられるか（slitpred2）

- **data_version**: 艇のデータ＝model-prep/data（2026-10-02 取得の CSV。features.py の load_kb・load_main・attach_grade_from_series をそのまま使用）。枠なりの判定＝slitpred の raw/（本番 Supabase 読み取りのみ、2026-10-04 取得、md5 一致済み）。今回は新たな DB クエリなし
- **population**: slitpred と同じ（2019-04-01〜2026-09-26、全艇枠なり・返還艇なし・本番 ST 6艇そろう・st_mean30 6艇そろう）＝ **313,938R**。形の判定（round(ST×100) の7形）・差を広げる方式・lift の比べ方（その形と出なかったレースとの比）も同じ
- **check**: 自前で作り直した A（全体30走）と races.pkl の st_mean30 の差は最大 1.5e-08（全艇一致）。B〜D は A と同じ関数の「グループを足しただけ」なので、未来の情報が入らないことも A と同じ
- **as-of（未来の情報を混ぜない）**: どの平均STも「前日までの走」だけ。当日の前のレースの結果も入れない（features.py `_first_of_day` と同じ。そのグループのその日最初の走の値を同じ日の全走に配る）
- **F・出遅れの扱い**: slitpred（st_mean30）と同じ。F・出遅れの走の ST は平均から除き、30走の窓には1走として数える（＝直近30走のうち F・出遅れでない走の平均）。E・F は F・出遅れの走を除いた全走の平均
- **走数の下限**: A〜D は **5走**（その条件で ST が取れた走が5走未満の艇は「欠け」）。E・F は **100走**（会場×コースの全選手の走数）。A だけは母集団の定義上3走以上

## 平均STの定義

| 記号 | 中身 | 窓 | 備考 |
|---|---|---|---|
| A | 選手の直近30走の平均ST（既存の st_mean30） | 直近30走 | 全会場・全コース |
| B | その選手のその会場での直近N走 | その会場での直近30走まで | |
| C | その選手のそのコースでの直近N走 | そのコースでの直近30走まで | 過去走のコースは「その走が全艇枠なりだったときの艇番」。枠なりでないレースの走（全体の約22%）はコースが分からないので C から外す（DB に全走のコースが無い期間があるため、今回は枠なりの走だけで作った） |
| D | その選手の同じグレード区分での直近N走 | 同区分での直近30走まで | 区分は SG・G1／G2・G3／一般 の3つ。グレードは races.pkl と同じ（長期は kb_archive_venue_days.race_grade、本体は races.race_grade、無ければ race_series の期間で補う）。グレード不明の走は外す |

## 要点

- **単独で一番効くのは C（コース別）**。6艇内の差と本番の差の相関は C 0.319・A 0.275・D 0.269・B 0.236（A〜F がそろう 221,089R で比較）。形の lift も C が A より高い（イン凹み 2.11→2.34、ダッシュ勢先行 2.03→2.28）。D は A とほぼ同じ、B は A より悪い（会場別は走数が少なくぶれる）
- **E（会場×コースの基準値）は単独では形を当てられないが、A・C に足すと一番上積みが大きい**。E は会場ごとにほぼ同じ並びなので単独の lift は 1.0〜1.5。ただ A は「6コースは遅れやすい」などコースの違いを含まないので、E を足すと補える。2019-2023 で重みを決めて 2024-2026 で確かめると、相関は A 0.274 → A+E 0.338、A+C 0.333、A+C+E 0.362（6つ全部の重回帰 0.365 とほぼ同じ）。重みを決めずに「(A＋C)÷2＋E」としても 0.362
- **会場の分の上積みは小さい**: E の代わりに全国のコース別平均（会場によらない）を足すと A+N 0.325（A+E 0.338）。上積みの大半は「コースの違い」で、会場の違いは +0.01 程度。F（風速で分ける）は E と同じ（0.338）で、風速区分は上積みにならない
- **効く順（6艇内の差の相関、全 313,938R・欠けたら A で埋める版）**: (A+C)/2+E 0.359 ＞ A+C 0.329 ＞ C 0.312 ＞ A+B 0.283 ≒ A+D 0.279 ≒ A 0.277 ≒ D 0.271 ＞ B 0.238。E・F は単独 0.218
- **欠けやすさ（5走未満の艇）**: B 8.2%（6艇そろわないレース 25.4%）・C 2.6%（7.2%）・D 0.9%（2.5%）・A 0.13%。E 0.5%・F 2.0%（主に 2019 年の序盤と、珍しい風速区分）。B は30走そろう艇が半分以下（48%）
- **会場ごとの形の出やすさ（E・F の使い方）**: 会場で形の割合ははっきり違い、期間を分けても同じ（2019-2024 と 2025-2026 の会場ごとの割合の相関 0.78〜0.93）。カド一撃は 福岡 9.3%〜尼崎 21.8%、ダッシュ勢先行は 福岡 9.1%〜尼崎 21.4%。風速区分を足すとセルが細かくなり安定性は下がる（7形で 0.57〜0.85）。風が強いほど横一線が減り（0〜2m 16.0%→5m以上 12.8%）、イン凹みが増える（10.9%→12.8%）
- **若松・6艇とも A1**: 898R。C は欠けが少ない（6艇そろわない 1.2%）が、B は 21.1% 欠ける。相関（欠けたら A）は (A+C)/2+E 0.272・A+C 0.238・C 0.224・A 0.192・D 0.154・B 0.137。全国より全体に弱い（A1 どうしは平均STの差が小さい）が、順番は全国と同じ。件数が少なく形ごとの lift は CI が広い
- **例（2026-09-27 若松12R）**: 本番は横一線。A だけ→カド受け凹み・イン凹み、C→どれにも当たらない、(A+C)/2+E→内3艇そろう・カド一撃。どれも横一線は出していない（下の5）
- **限界**: 相関 0.36 でも本番の差の分散の約13%しか説明しない。形ごとの lift は予想の件数（倍率 K）で変わるので、平均ST どうしの比較は「6艇内の差の相関」を主に見る。C は枠なりの走だけで作ったので、進入が動く選手の C は走数が少なめ。追い風・向かい風は分けていない

## 2 各平均STの並びで7形を判定したときの lift
