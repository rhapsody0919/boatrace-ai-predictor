# 1マークはどうなる？ スリットの形 × 攻める艇・1号艇のモーター／展示タイム順位（mark1）

- **period**: 2019-04-01〜2026-09-26
- **population**: 枠なり・返還なし・本番ST6艇・平均ST6艇そろう（slitpred と同じ 313,938R）。艇データ＝knn/work2/races.pkl（rank1〜3・round）・boats.npz（motor_2・motor_2_rank・exh_time・exh_time_rank・cls_ord・st_result）。形＝本番 ST を round(×100) して load.py の forms で判定（重なりうる）
- **scopes**: 全国の枠なり 313938R（モーターそろう 313547・展示タイムそろう 313938）、若松の枠なり 12485R（モーターそろう 12410・展示タイムそろう 12485）、若松・6艇ともA1の枠なり 898R（モーターそろう 897・展示タイムそろう 898）、全国・6艇ともA1の枠なり 20868R（モーターそろう 20865・展示タイムそろう 20868）、全国・6艇ともA1の優勝戦の枠なり 438R（モーターそろう 438・展示タイムそろう 438）。A1＝cls_ord==4、優勝戦＝races.pkl の round==yusho
- **technique**: 本番Supabase 読み取り（MCP execute_sql SELECT、2026-10-04 取得、md5一致）: race_date≦2025-12-02 は kb_archive_races.technique、以降は race_results.winning_technique。母集団の内訳: 逃げ 171935・まくり 44692・差し 40415・まくり差し 35221・抜き 21507・恵まれ 167・未記録(null) 1。raw/tkA・tkB・tkM.txt に保存（extract_tk.py）
- **攻める艇**（枠なりなのでコース＝艇番）: カド一撃→4号艇、イン凹み→2号艇、2コース凹み→3号艇、カド受け凹み→4号艇、ダッシュ勢先行→4号艇、横一線・内3艇そろう→なし（1号艇だけ見る）
- **順位**: motor_2_rank・exh_time_rank（features.py の rank(method="min")、レース内6艇。モーターは高いほど1位、展示タイムは速い（小さい）ほど1位。同じ値は同じ順位（小さいほう））。3区分は 1〜2位＝上位・3〜4位＝中位・5〜6位＝下位。同順位があると 1位が3艇などになり、区分の件数は均等にならない
- **指標**: 攻める艇の1着率／攻める艇の決まり手（まくり・まくり差し・差し、分母はその形のレース全体。json には攻める艇の1着を分母にした `_of_win` もある）／1号艇の逃げ率（1着が1号艇かつ決まり手が逃げ）／1号艇の2着以内率／攻める艇の内側の艇（攻める艇−1号艇）の2着以内率。イン凹みの内側の艇は1号艇なので1号艇の2着以内率と同じ
- **限界**: 1マークの位置のデータは無いので、着順と決まり手で見ている。枠なりだけ。モーター2連率は節の途中の値ではなく出走表時点の値（features.py のまま）。展示タイムは会場・風で水準が違うが、6艇内の順位なので影響は小さい

## 要点

- **全国（313,938R）では、7形すべてで展示タイムの順位のほうがモーター2連率の順位より差が大きい**。攻める艇の1着率（上位→下位）: カド一撃 展示 0.403→0.223（モーター 0.349→0.274）、イン凹み 展示 0.384→0.235（0.344→0.292）、2コース凹み 展示 0.207→0.110（0.175→0.138）、カド受け凹み 展示 0.285→0.142（0.235→0.184）、ダッシュ勢先行 展示 0.336→0.180（0.279→0.223）。1号艇の逃げ率も同じ形で、展示タイムの差（例: カド一撃 0.381→0.254、イン凹み 0.302→0.180、横一線 0.682→0.550）がモーターの差（0.360→0.311、0.275→0.225、0.656→0.612）より大きい。モーターの差は 4〜8 ポイント、展示タイムは 9〜18 ポイント
- **展示タイムの上位区分は件数が多い**: 展示タイムは 0.01 秒刻みで同タイムが多く、min 順位で同タイムは小さいほうの順位になるため、1号艇の上位（1〜2位）は約半数のレースに入る（例: 横一線 25,445/47,320）。区分の件数が均等でないことに注意
- **若松・6艇とも A1（898R）**: 各形 93〜242R でほぼ CI が重なる。上位と下位の差が2標準誤差を超えたのは カド受け凹み（攻める4号艇の1着 展示 0.284 vs 0.045、z=3.7／1号艇の逃げ モーター 0.690 vs 0.453、z=2.7）とカド一撃（攻める4号艇の1着 展示 0.356 vs 0.054、z=3.3／1号艇の逃げ モーター 0.702 vs 0.455、z=2.2）だけ。2コース凹み・イン凹み・横一線・内3艇そろう・ダッシュ勢先行は差が出ない
- **全国・6艇とも A1 の優勝戦（438R）**: 各形 21〜140R。差が2標準誤差を超えたのは 2コース凹み（攻める3号艇の1着 展示 0.250 vs 0.025、z=3.0）、カド一撃（攻める4号艇の1着 モーター 0.571 vs 0.000、14R と 16R、z=3.5）、ダッシュ勢先行（モーター 0.400 vs 0.000、15R と 12R、z=2.5）、カド受け凹み（モーター 0.250 vs 0.065、z=2.0）。件数が少なく、モーターと展示タイムのどちらが効くかはこの範囲では決められない。1号艇の逃げはどの形でも差が出ない
- **決まり手**: 攻める艇が1着のとき、4号艇（カド一撃・カド受け凹み・ダッシュ勢先行）はまくりが 64〜70%、まくり差し 18〜24%。2コース凹みの3号艇はまくり 46%・まくり差し 40%。イン凹みの2号艇はまくり 59%・差し 33%（2号艇は内に1艇しかいないのでまくり差しは0）
