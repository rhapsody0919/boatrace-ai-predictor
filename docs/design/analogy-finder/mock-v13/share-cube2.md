# BOA-271 share-cube（AIの見立て: 会場×グレード×ラウンドごとの材料の割合、テーマ単位）

- 定義: share_cube.py の docstring。要点: テーマ内の SHAP を艇ごとに符号つきで足す → レース内で中心化 → 6艇の |値| の和をスライス内で平均 → 全テーマの和で割る。艇番ごとはその艇の |テーマ値| の和 ÷ その艇の全テーマの |値| の和
- モデル: 版 2026-10-02 の model_win・top2・top3。母集団: test 2025-10-03〜2026-09-26 から 2025-12, 2026-01 を除いた 44,092R。SD: 日単位ブートストラップ 200回（SD・差の SD は小数6桁で保存、割合は3桁）
- セル: 750 中、n ≥ 300 の 164 セルに値。形式: cells["venue|grade|round"] = {n, n_days, shares: {model: {boat: {theme: [share, sd]}}}, vs_national: {model: {boat: {theme: [差, |差|<2×セルのSD, 差のSD, |差|<2×差のSD, 相対差（|差| ÷ 全国の割合）]}}}}
- 出典: 指標=テーマのシェア（テーマ単位・中心化）／比較=全国（0|all|all）／版=2026-10-02／キー `cells`
