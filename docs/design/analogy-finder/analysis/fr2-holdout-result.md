# FR-2 類似レース検索の方式比較（時系列ホールドアウト）

BOA-271 FR-2 の方式（層別集計 vs SHAP重み k-NN）を、決まり手分布の予測精度で比べた結果。数値の正本は同ディレクトリの `fr2-holdout-result.json`、再現は `scripts/analysis/analogy-finder-fr2-holdout.py`。

## 判定

事前に固定したルール: k-NN（全会場プール）が層別に対して、決まり手(a)の対数損失のペア差 95%CI が 0 をまたがず改善したときだけ k-NN を採る。層別は cal で strat_d / strat_b の良い方（＝strat_d）。

- **k-NN − strat_d（決まり手 LL）= −0.02029、95%CI [−0.02566, −0.01472] → 判定ルール上は k-NN**
- 感度分析（プール2026-03以降）でも −0.02399 [−0.0296, −0.01885] で同じ結論
- 事後的に最良だった層別（strat_g、cal基準）に対しても −0.01367 [−0.01906, −0.00872]（本番）/ −0.01592 [−0.02071, −0.01127]（感度）で k-NN が上

ただし次の留保がある（実装判断に効く）。

1. **改善幅は小さい**。決まり手の対数損失で約1.5%（1.330→1.310）、Brier で 0.0085。1着艇番(b)・1着コース(c)の改善（−0.094 / −0.066）の方がずっと大きい。k-NN が拾っているのは主に「6艇の勝率の並び」
2. **近傍は会場をほぼ無視している**。会場一致率 4.8%（ランダム 4.2%）。重みの 61% が `win_rate_diff` と `win_rate_rank`、会場は 1.9%。モーター・展示・気象は近傍でもランダムとほぼ同じ距離（比 0.95〜1.00）。ソナーに出る「類似レース」は「選手の力関係が似た、別会場・別条件のレース」になる
3. **SHAP重みの寄与は小さい**。等重み k-NN との差は決まり手で −0.00241 [−0.00545, +0.00094]（本番、有意でない）/ −0.00768 [−0.01089, −0.00479]（感度）。(b)(c) では有意に SHAP 重みが良い
4. **同一会場内 k-NN（ハイブリッド）は決まり手で層別と同等**（−0.00048 [−0.00553, +0.00446]）。会場を揃えると決まり手の優位が消える
5. **重みの再学習で近傍が2〜3割入れ替わる**（Jaccard 平均 0.72〜0.78）。主因は early stopping の不安定さ（同じ期間・seed違いで best_iter 11 → 119）

## データ・分割

- データ: `export-training-data.js` で 2026-10-01 に本番 Supabase から再出力（読み取りのみ）。46,770R（2025-12-02〜2026-10-01）、艇単位 280,620 行
- 1着コース(c)は `race_results.actual_course_{rank1}` を別途取得（`data/ml/actual_courses.csv`、46,773 行）。**export の `actual_course` 列は `course_1〜6` 由来で全期間 艇番と100%一致（BOA-257 の無効列）なので使っていない**。正しい列では 1着艇の進入コース≠艇番 が 5.83%
- 分割（時系列順）: train 2025-12-02〜2026-06-30（32,270R）/ cal 2026-07（4,916R）/ test 2026-08-01〜2026-10-01（9,584R）
- 母集団: cal のチューニングは train プール、test は train+cal の固定プール（test より前のレースのみ）
- 感度分析: プールを 2026-03-01 以降に限定（train 18,425R）。2025-12〜2026-02 は展示データ 100% 欠損、2025-12〜2026-01 は風速 ~100% 欠損のため
- 決まり手: 表記は 逃げ 24,739 / まくり 7,340 / 差し 5,689 / まくり差し 5,631 / 抜き 2,971 / 恵まれ 388 / 欠損 11 / 「逃げ抜き」1。揺れは「逃げ抜き」1件のみで、欠損と合わせて12R を(a)から除外
- (c) は actual_course 欠損 1,568R を除外（test 内 490R）。**欠損はランダムでない**（morning-data-digest spec の M-4: 欠損行は逃げが少なくまくりが多い）

## 方式

| 記号 | 内容 |
|---|---|
| base | 学習プール全体の周辺分布 |
| venue | 会場別（全体へ Dirichlet 平滑化、α は cal） |
| g1only | 1号艇級別のみ（参考） |
| strat_d | 層別・階層 Dirichlet: 全体→会場→×1号艇級別→×風速ビン(0-2/3-4/5+/欠損)→×グレード区分(一般/G3以上/欠損)。p_L=(c_L+α p_{L−1})/(n_L+α)、α は cal |
| strat_b | 層別・ハードバックオフ: n≥nmin の最細層（その層は親へ α=1 平滑化）、nmin は cal |
| strat_dw | strat_d に風向4方位ビンを追加（参考） |
| strat_g | strat_d と同じ最細層だが階層順を 1号艇級別→会場→… に変えたもの（事後に追加した参考） |
| knn | SHAP重み k-NN、全会場プール。近傍分布は会場分布を事前分布に Dirichlet 平滑化。k∈{50,100,200,400}、α∈{1,2,5,10,20,50,100} を cal で選択 |
| knn_v | 同一会場内 k-NN（ハイブリッド） |
| knn_unif | 等重み k-NN（重みのアブレーション） |
| knn_r76 | 木の数を 76（本番ワトソンの best_iteration）に固定して学習した SHAP 重みの k-NN |

k-NN の距離: レース単位ベクトル 203 次元 = 艇別特徴量 24 種×6艇 + レース共通数値 7 種 + カテゴリ one-hot（会場・風向・天候・グレード）。train で z-score、欠損は 0（平均）埋め。重みは LambdaRank（train_watson.py と同じパラメータ）の pred_contrib を**レース内で中心化した |SHAP| の平均**を (特徴量, 艇番) ごとに取ったもの。レース共通特徴量は6艇分の和、カテゴリは不一致で距離²に w²（1SD差と同等）。重み付きユークリッド距離。

- 中心化の理由: LambdaRank はレース内の相対スコアだけが意味を持ち、全艇一様に効く主効果（会場・気象の平均的効果）は順位に影響しないため
- **boat_number の扱い**: 生の平均|SHAP| は 0.11516 で全特徴量中最大だが、レース単位ベクトルでは全レース同じ並びで次元にできないため除外。効果は「艇番スロットごとの重み」（例: win_rate@1 と win_rate@6 を別の重みにする）として間接的に入る
- LambdaRank の学習は train のみ（early stopping は train 末尾 15%）。best_iteration は 11（本番ワトソンは 76）

## 実装上の注意

- **as-of**: 近傍・層の母集団は「対象レースより前」に限る。本検証は固定プール（train+cal）で、test 期間中の追加はしていない。本番で日次にプールを伸ばす場合も当日レースを含めない
- **進入コースは `race_results.actual_course_1〜6` を使う**（`actual_course_{艇番}` = その艇のコース）。`export-training-data.js` の `actual_course` は無効列で、ML 学習データ側にも同じ問題がある（別途要修正）
- **欠損期間**: 2025-12〜2026-02 は展示・風速が欠損。k-NN では 0 埋めのため、この期間のレースは「展示が平均的」なレースとして近傍に混ざる。感度分析では除外しても結論は同じ
- **平滑化の強さ**: k-NN は決まり手で k=400・α=50（事前=会場分布）、(b)(c) は α=1〜5。k は格子の上限で選ばれており、k>400 の方が良い可能性がある（未検証）。層別は α=200〜500
- **表示の n**: k-NN は常に k（=400、(c) は欠損除外で中央値 389）。ソナーのしきい値スライダーで絞ると n が減るので、推定（分布）には k=400 を使い、表示はしきい値で絞る、のように「推定用 n」と「表示用 n」を分ける必要がある
- **SHAP 重みの再現性**: early stopping の best_iter が 11〜119 で揺れ、近傍が 2〜3 割入れ替わる。木の数固定を推奨
- **会場の扱い**: 全会場プールの近傍は会場が揃わない。ユーザーが「同じ会場の類似レース」を期待するなら、表示側で会場フィルタを持つか、会場一致の重みを上げる必要があるが、同一会場限定は決まり手の精度が層別と同等まで落ちる

## 使えなかったデータ・妥協点

- 風向は会場ごとの向き（追い風/向かい風）が不明なので方位をそのまま使った。4方位ビンは悪化
- ラウンド種別（予選/準優勝/優勝）は BOA-226 で取れないため層に入れていない
- 事故・アクシデント（BOA-279）、進入コース（特徴量としての使用）は対象外
- オッズは特徴量に入れていない
- 1着コース(c)の欠損 1,568R は非ランダム
- `scripts/ml/train_watson.py` は import すると副作用（ディレクトリ作成等）があるため、LambdaRank 設定はスクリプトに転記した
- 近傍の性質チェックのテーマ分けはスクリプト内の THEMES（7テーマの正式定義とは別の簡易版）
