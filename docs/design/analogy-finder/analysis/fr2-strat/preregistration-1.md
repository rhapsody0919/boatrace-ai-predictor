- 指標: 多クラス対数損失（主）、Brier（参考）
- CI: 「日×会場」のクラスタ単位のブートストラップ（1,000回、seed 0）。ペア差 A−B、負なら A が良い

## F5'（出走表時点だけのモデル）
- Phase M の主モデル F5 と同じ設定（LightGBM 二値、1着、レース内 softmax と温度合わせ、木の数は固定）で、入力から展示・気象の列を外したもの
- pool と cal の P' は out-of-fold で作る: pool を日単位の連続ブロック5つに分け、各ブロックはそれ以外の4ブロックで学習したモデルで予測する。cal・test の P' は pool 全体で学習したモデルで予測する
- （A の比較用に、元の F5 の P も同じ out-of-fold で作り直す）

## A 較正写像
- 入力: log P（6艇の1着確率の対数、6次元）、出力: 決まり手6分類。多項ロジット（L2、強さ C は cal で {0.01, 0.1, 1, 10} から選ぶ）
- 学習: pool の out-of-fold の P で学習する
- 比較: 較正写像 vs 予測分布 k-NN（P 空間の近傍、会場ペナルティなし・あり）vs ⑨。同じ P（元の F5 と F5' の両方で）
- 判定: ⑨（または ⑨'）が較正写像にペア差 CI で有意に勝てば「過去レース由来の上積みがある」、勝てなければ「上積みはモデル由来」とする

## C 条件の軸
- 候補（出走表時点で、ファンが言葉で言えるもの）:
  - V 会場（24）
  - C1 1号艇の級別（A1/A2/B1/B2）
  - N1b 1号艇の全国勝率のレース内順位（1位／2〜3位／4位以下）
  - Gap5 1号艇の全国勝率 −（2〜6号艇の最大の全国勝率）の5帯（分位で切る。境界は pool で決める）
  - C26nA 2〜6号艇の A 級の数（0〜5）
  - Ntop 全国勝率1位の艇（1〜6）
  - M1b 1号艇のモーター2連率のレース内順位（上位2／中2／下位2）
  - S1b 1号艇の平均ST（直近）のレース内順位（上位2／中2／下位2）
  - G グレード（一般／G3以上／不明）
  - Rd ラウンド（予選／準優勝戦／優勝戦／その他）
  - RN レース番号帯（1〜4R／5〜8R／9〜12R）
- 選び方（cal で行う。test は見ない）:
  1. 層別（階層 Dirichlet。親は1つ前までの軸の層、根は全体の分布。α は cal で {10, 50, 200, 1000} から）で、空の集合から始め、候補のうち cal の決まり手 LL を最も下げる軸を1つずつ足す（前向き選択）
  2. 止める条件: 足しても cal LL の改善が 0.001 未満、または「最も細かい層の件数の中央値」が 100 未満になる、または 4 軸に達した
  3. ここで決まった軸の並びを、層別（S*）と ⑨'（完全一致の絞り込み）の両方に使う
- ⑨' の k は cal で {200, 400, 800, 1600, 3200} から選ぶ。層に k 件無いときは末尾の軸から緩める（hybridP.py と同じ）。α は cal で {1, 10, 50}
- knn_p（展示・気象を外したもの）は、MD-6 と同じ距離・λで、k を cal で {400, 800, 1600, 3200} から選ぶ。加えて k=1600 固定の値も出す
- test で比べるのは1回だけ: S*、⑨'、knn_p（選んだ k と 1600）、較正写像、予測分布 k-NN

## D 表示の差
- 「ファンが条件を選ぶ層別」= 会場＋1号艇級別（V×C1）、および C で選んだ S*。各レースの n を出す
- ⑨'・knn_p と、決まり手6分類の表示%（逃げ・差し・まくり・まくり差し・抜き・恵まれ）の差: レースごとの平均絶対差（%ポイント）と、逃げ%だけの平均絶対差・90%点。1着艇の%も同様

## E 言語化
- 基準: 対象レースと「同じ S* の層」の中から無作為に選んだ同数のレースを比較相手にする
- 各軸（候補の全軸＋テーマ別の連続値）について、近傍での一致率（連続値は「差の小さい側 1/3 に入る率」）÷ 層内無作為での一致率 を倍率とする
- 倍率 1.5 以上で、かつ S* の軸そのもの・S* の軸と入れ子の軸（例: C1 と N1b）・相関 |r|≥0.7 の軸を除いたものを「似ている点」として残す
- 2,000R の test で、レースごとに残った軸の数の分布と、よく残る軸の上位を報告する
