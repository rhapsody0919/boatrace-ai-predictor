# BOA-271 レースごとの寄与度（B）学習側: 出走表時点専用モデル `win_racecard` と特徴量の約束の変更 事前登録（2026-10-02、学習を回す前に固定）

レースごとの寄与度（ADR-0083）の出走表時点の段に使う1着モデル `win_racecard` を、週次の学習（`train.py`）に足す。同じ PR で、学習と日次の両方に効く特徴量の約束を変える（plan「学習側の設計」）。ここでは、初回の本番学習（tasks T10-8）で何をどう判定し、何を記録するかを、結果を見る前に固定する。分析中に変えない。変えたら「事後」と明記する。second-opinion-reviewer の方法論レビュー（2026-10-02、指摘7件）を反映した版。

## 選ばないこと（このモデルの形は分析で選ばない）
- 特徴量・木の数・設定は ADR-0083 と plan で決めてある（`win` の44列から直前情報8列を除いた36列、木 250本、`win` と同じ設定、seed 0）。複数の案を test で比べて選ぶことはしない。判定は「品質ゲートを通るか」だけ
- 特徴量の約束の変更は、日次ジョブ（朝 6:40）と推論側で同じ値になるための変更で、精度で選んだものではない:
  1. 36列を「朝 6:40 に分かる値」で定義する。本体期間の節の日目・最終日は `race_series` から導く。体重・支部は前日までに分かっている最後の値（当日の値を使わない）
  2. 風向 null・風速0 を無風（0）にする
  3. `branch_code` を学習時に作る対応表で符号化する（番号は今の `cat.codes` と同じ）
  4. 長期の `is_final_day` を BOA-696 の修正後の値にする
  - 2連率の丸め（朝と取り直し後で桁が違うという観測）は、T10-1b の実測で決める。変える場合は、この学習の前に「事後でない変更」としてここに追記してからコミットする
  5. 【追記 2026-10-02、学習を回す前】2連率4列を小数1桁にそろえる（JS の `toFixed(1)` と同じ丸め）。根拠はコード（朝の経路 `generate-predictions.js:436-445` が `toFixed(1)` した値を書く）。結果を見る前の変更

## 判定（止めるもの）
1. `win_racecard`: 基準1（会場×1号艇の級別の過去の1着艇分布）に対する、レース単位の対数損失の差（モデル − 基準）の日クラスタ・ブートストラップ95%CI の上限が0未満
2. `win`・`top2`・`top3`: 今までの品質ゲートのまま（基準に有意に勝つ、参照版 2026-10-02 から許容幅以上に悪化しない）
3. `win_racecard` の参照版との比較は、参照版にモデルが無いので行わない。「比較なし（参照版にモデルが無い）」と metrics に書く
- どれか1つでも通らなければ、版全体（条件ごとの寄与度の更新を含む）を切り替えない

## 参照版との差の読み方（判定2の解釈）
学習の期間は全部が長期データなので、変更の効き方は次の通り:
- 長期の `is_final_day`: 参照版の学習では定数0だった。新しいモデルだけが学習に使える。参照版の評価し直しでは、test の長期分の入力が変わる
- 本体の節の日目・最終日の導出、体重・支部の前日化、風向 null: 学習の期間には効かず（体重・支部の前日化は長期にも効く）、主に test の本体分の入力を変える
- `branch_code`: 番号は同じなので変わらない
- 個々の変更の寄与は分けない（同時に変えるため）。差は「これらの変更をまとめた効果」として報告する

## 不通過のときの手順

- 判定2が通らない: 変更を1つずつ戻して再学習し、どれが効いたかを診断する。この再実行は「事後」と明記する。データ版が変わったら別の実行として扱う
- いずれも、その版は切り替えず、今の版（2026-10-02）の表示を続ける

## 追記A（2026-10-03、1回目の本番学習を回す前）: 風向の基準
- 変更: 本体の風向（直前情報・結果ページのアイコン）から、会場ごとに (方位マーク M − 9) × 22.5° を引いて K ファイル（方位）の基準に直す。DB の風向が空で風速>0 の本体のレースは K の風向で埋める（#1213、`docs/design/analogy-finder/wind-basis.md`）

- 開示: 実装の確認のため、手元で同じデータを使い、補正あり・なしの2通りを学習して、品質ゲート（対数損失）と条件ごとの寄与度を見た（1着の対数損失 1.19099 / 1.19103、どちらもゲート通過）。補正を採るかの判断はこの結果を見る前に決まっており、結果で変えていない。fit の期間は全部が長期分なので、補正の有無でモデルは同じ（test と推論の入力だけが変わる）
