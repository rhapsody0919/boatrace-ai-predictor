# BOA-271 FR-1×FR-2 「寄与度の高いテーマでそろえた似たレース」の裏付け 事前登録（2026-10-02、結果を見る前に固定）

ユーザー要望（2026-10-02、オーケストレーター経由）: 「寄与度で何が効いているかを見る → その寄与度が高い要素で似ている過去レースの結果を見る」流れにしたい。これをデータで正当化できるかを cal だけで確かめる。test は使わない（FR-2 の自動4条件は確定済みで、ここで変えない）。分析中に変えない。変えたら「事後」と明記する。

## データ
- R2.pkl（preregistration-2 と同じ）。pool＝2019-04-01〜2025-05-31、cal＝2025-06-01〜2025-12-02
- 寄与度: 本番の is_active の版（2026-10-02 時点）の `analogy_contribution_profiles`。1着・全艇（boat_number=0）・全グレード・全ラウンドの会場別のシェア（24会場）
- 推定は S*（Gap5→C1→V→Ntop、α=1000 の階層 Dirichlet）に軸を1つ足した5段目。足す軸とテーマの対応（出走表時点で作れるもの）:
  - ST・直前情報 → S1b（1号艇の平均ST順位帯）
  - 機力 → M1b（1号艇のモーター順位帯）
  - 環境 → Rd（ラウンド）、G（グレード）
  - 選手・基礎成績 → N1b（1号艇の勝率順位帯）、C26nA（2〜6号艇のA級の数）
  - 会場×枠 → RN（レース番号帯）
  - 選手・属性 → 候補の軸が無い（年齢・体重・支部は候補11軸の外）
- 目的変数: 決まり手（FR-2 の主）と1着艇（FR-1 の寄与度と同じ目的）

## 検証1（テーマ単位）
各軸を S* に足したときの cal LL の改善を、2つの目的変数で出す。テーマ別の寄与度の順位（全体: 基礎成績 > 会場×枠 > ST・直前 > 機力 ≈ 属性 > 環境）と、改善の順位を並べる。判定はしない（記述）。

## 検証2（スライス単位: 寄与度が高いスライスほど、そのテーマでそろえると良くなるか）
- 会場ごと（24）に、cal のその会場のレースだけで、S1b・M1b・Rd を S* に足したときの LL の改善（1着艇・決まり手）を出す
- それぞれ、会場別のそのテーマのシェア（S1b↔ST・直前、M1b↔機力、Rd↔環境）との Spearman の順位相関を出す。p 値は会場のラベルを入れ替える並べ替え検定（10,000回、seed 0、片側 ρ>0）
- 判定: ρ>0 かつ p<0.05 の組があれば「スライス単位で、寄与度の高いテーマでそろえると当てはまりが良くなる」と言える。無ければ言えない
- 注意: 会場別のシェアの幅は小さい（例: ST・直前 0.125〜0.163）。検出力が低いので、言えない場合は「無い」ではなく「この幅では確かめられない」と書く
