## 方法

- 順位: レース内6艇の順位（秒数が小さいほど1位、同値は min＝同着1位も1位）。区分は上位1-2・中位3-4・下位5-6
- 1位が2艇以上のレースの割合: 周回 2.5%、まわり足 5.9%、直線 14.0%、展示タイム 13.3%
- 偏差: レース内の z（平均0・SD1）。ロジットでは「速いほど＋」に符号をそろえ ±3 で切った
- 率の区間: Wilson 95%
- 条件付きロジット: レース内6艇の softmax で1着を当てる。進入コース（2〜6のダミー）を必ず入れる。区間は日単位ブートストラップ300回（同じ日の会場・レースの相関を残す）
- 時系列の検証: 学習 〜10/03、検証 10/04〜。項目を入れたモデルと入れないモデルの、検証期間の1レースあたり対数損失の差（負＝改善）。区間はレース単位ブートストラップ2,000回
- 会場別: 展示タイムをそろえた条件付きロジットの傾き、Wald 95%。50R 未満は出さない

## 言えること

- 周回とまわり足は、展示タイムの順位をそろえても、さらに勝率・モーター2連率をそろえても、1着に効く（係数の区間が0を含まない、時系列で分けた検証でも改善する）
- 2〜6コースで、まわり足1位の1着率は 0.129、周回1位は 0.161。それ以外の艇（0.079・0.076）より高く、展示タイム1位（0.139 vs 0.075）と同じ大きさ
- 直線は展示タイムの情報と重なり、上積みが無い
- 初回保存は発走の約7分前で、保存後の書き換えは無い。結果を見てから値が入った形跡は無い

## 言えないこと

- 主モデル（phase-m の LightGBM）への上積みの大きさ。今回の土台は線形で、勝率・展示タイム・モーター以外（過去ST・当地成績・級別等）を入れていない。MD-4 と同じ方式で、期間を延ばして測り直す必要がある
- 会場ごとの効き方の差。会場あたりの件数が足りない
- スリット7形ごとの差
- 生の秒数の比較。会場ごとに区間の取り方・距離が違い、会場をまたいで秒数を並べられない
- 2着・3着への効き方 → `original-exhibition-top2-top3-makuri.md`（2026-10-15）で検証済み。周回・まわり足は効く、直線は効かない
- 期間 20日・秋の一時期の結果。季節・水面条件が変わったときに同じかは未確認

## UI への示唆

- 「周回1位」「まわり足1位」の印は出せる。展示タイム1位と並べて同じ重さで見せてよい
- 秒数は会場ごとに区間が違うので主役にしない。レース内の順位（1〜6位）か印で見せる
