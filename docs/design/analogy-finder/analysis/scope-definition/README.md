# 集めるレースの範囲: 「同じ枠に同じ級」にするかの検証（2026-10-09）

ユーザーの問い（原文）:「現在は「今日と同じく、6艇のうちA1が4艇・A2が2艇で、1号艇がA1の過去レース。1号艇以外の5艇がどの枠にいたかは問わない」となっているが、本来は「同じ枠に同じ級」のレースを選ぶべきじゃないの？統計的に天才データサイエンティストの検証結果でこうなってるんだっけ？」

**探索的な分析で、事前登録はしていない。** 決定は [spec.md](../../spec.md) の Q1 に反映した。

## 結論と決定（2026-10-09 ユーザー回答「はい、納得できたので上記の点も併せてあなたの推奨通りの進め方で良い。」）
1. タブ1・タブ3の範囲は今の定義（構成＋選んだ艇の級別）のまま。「同じ枠に同じ級」にはしない。2〜4号艇を選んだときに1号艇の級別を足す案（h）も採らない
2. タブ3の③④で1号艇以外の艇の率は、艇ごとに「構成が同じで、その艇番がその級別」の範囲で出す。6艇の合計は100%にならない旨を画面で断る（[BOA-806](https://linear.app/boat-ai/issue/BOA-806)）
3. 今の定義は、件数と、選んだ艇の級別との交絡（9.3pt）で決めたもので、「ほかの枠の級別は効かない」ことはこれまで確かめていなかった。今回確かめた。readiness-review の boat_number の重要度（−28.25pt）は選んだ艇自身の艇番の効き目で、どの定義にも入っている

## データと方法
- データ: 本番 DB の書き出し（`export_pool.js` の CSV、2026-10-05 書き出し。長期 kb_* 2019-04〜2025-12-02、本体 2025-12-03〜2026-10-05）。読み込みは `scripts/ml/analogy/v16_pool.py` の `load_kb_boats`・`load_main_boats`。書き出し本体はリポジトリに入れない
- 対象: 6艇・欠場なし・6艇の級別がそろう（A1/A2/B1/B2）・1着が1艇のレース。返還艇は「1着でない」
- 時系列で分ける: 学習 2019-04-01〜2025-03-31（326,531R）、検証 2025-04-01〜2026-10-05（83,711R、艇の行 502,266）
- 予測値: 学習期間の同じ範囲キーの率。生の率（画面と同じ、平滑化しない）と縮小版（今の定義の全国の率へ擬似件数100で寄せる。100 は事前に決めた）
- 切り替え: 会場で300件以上なら会場、未満なら全国（今の仕様）
- 指標: Brier・対数損失。ぶれ幅は日単位ブートストラップ500回

候補の定義: (a) 今（構成＋選んだ艇の艇番・級別）、(b) 6枠すべて同じ級別、(c) 1〜3号艇は枠ごと＋残りは艇数、(d) 選んだ艇と隣の枠は枠ごと、(e) 選んだ艇より内の枠は枠ごと、(h) a＋1号艇の級別

## 結果
### 1. 件数（今日＝2026-09-05〜10-05 の艇の行、集める＝それより前の全期間。`scope-eval2.py`・`run2.txt`）
| 定義 | 全国 中央値 | 全国 300件未満 | 会場 中央値 | 会場 300件未満 | 会場 30件未満 |
|---|---|---|---|---|---|
| a 今 | 7,323 | 1.7% | 319 | 47.8% | 5.1% |
| c 内3枠 | 1,210 | 17.5% | 53 | 85.9% | 33.6% |
| d 隣 | 2,001 | 10.6% | 88 | 80.9% | 23.1% |
| e 内側 | 1,333 | 18.0% | 65 | 77.1% | 33.5% |
| b 6枠 | 507 | 33.0% | 23 | 88.4% | 57.8% |

### 2. 選んだ艇の1着率（今の定義との Brier の差 ×1e-4、負が良い。生の率・切り替えあり。`scope-eval.py`・`scope-eval-scores.csv`・`scope-eval-boot.csv`）
| 選んだ艇 | c | e | b |
|---|---|---|---|
| 1号艇 | +11.4 | 0（a と同じ） | +27.0 |
| 2号艇 | −8.7 | −11.5 | −0.9 |
| 3号艇 | −4.9 | −4.9 | +2.0 |
| 4〜6号艇 | +1.4〜+3.0 | +1.4〜+5.1 | +3.0〜+5.1 |
| 全艇 | +0.7［−0.1, 1.4］ | −1.2［−1.7, −0.6］ | +6.8［5.6, 7.8］ |

- 上の表は「会場で300件未満なら全国」に切り替えた値。切り替えずに会場のまま出すと、全艇で a +10.4・c +65.6・d +44.9・e +46.8・b +126.7（`scope-eval-scores.csv` の rule=VC）
- 3着以内率は、生の率で細かい定義ほど悪い（全艇 c +8.7・b +20.2）
- 縮小版では細かい定義が良い（e −3.6）が、spec の「割合は件数÷n（平滑化しない）」とは両立しない
- h（`rv-check2.py`、second-opinion-reviewer が実行）: 2号艇 −11.5［−13.5, −9.4］、3号艇 −4.2、4号艇 −1.2、5・6号艇 差なし。会場で300件未満は 55%→79%（2号艇）

### 3. 枠の並びで本当に変わる差（学習期間・全国、a の範囲の中で細かく分けた差。`scope-eval2.py`）
- 1着率: 標本の揺れを引いた真の差の標準偏差は約2pt（平均絶対差で約1.6pt）。3着以内率は 0.4〜1pt
- 例: A1が4艇・A2が2艇・1号艇A1（全国3,458R、1着率70.6%）。並び10通りの1号艇の1着率は 67.6〜74.3%（各198〜651件）

### 4. レース単位（選んだ艇＝1号艇。`scope-eval3.py`・`run3.txt`、切り分けは `rv-check.py`）
- 1号艇の1着率・スリットの形（カド一撃など4形）は、どの定義でも改善しない（差 0.3%未満）
- 1着艇の分布（6値の Brier）: 今の定義 0.6259 → 各艇が自分の級別をそろえた率（並びなし）0.6142（差 −0.0117［−0.0126, −0.0108］）。b 6枠（縮小版）は 0.6148 で、並びを入れてもそれ以上は良くならない
- つまり ③④の1号艇以外の艇の率は、並びではなく「その艇の級別が今日とずれている」ことでずれる（決定2）

### 5. 30件前後の平均で後のレースを当てられるか（`predict30-all.py`・`predict30-all-output.txt`）
会場×6枠の並びが同じ集まり（40〜60件）を日付順に半分に分け、前半約30件の率で後半約30件の率を当てた。比べる相手は、後半が始まる前のレースだけで出した全国の率。外れた幅の平均（pt、全艇の平均、929の集まり×6艇）:

| 着順 | 会場×並び同じの30件 | 今の定義 | ＋1号艇の級別（h） | 並び同じ（全国） |
|---|---|---|---|---|
| 1着 | 6.7 | 5.3 | 5.2 | 5.3 |
| 2着以内 | 9.4 | 7.0 | 6.9 | 7.1 |
| 3着以内 | 10.6 | 7.7 | 7.7 | 8.0 |

- h が効くのは1着の2・3号艇だけ（2号艇 6.6→6.0pt、3号艇 5.7→5.4pt）。2着以内・3着以内は差が 0〜0.1pt。着順を切り替えると範囲が変わるので、h は採らない（決定1）
- 後半の30件にもたまたまの揺れがあるので、どの方法でも外れは0にならない

### 6. 会場×並びの実例（`lookup23.py`・`lookup23-output.txt`、`halves-ex.py`）
- 並び A1 A2 A1 A1 A2 A1（1号艇から順）: 全国300件・1号艇1着率71.3%。会場あたり4〜28件で、1着率は 40.0%（江戸川、10件）〜91.7%（児島、12件）
- 同じ集まりを古い半分と新しい半分に分けると、会場×並び（半分20〜30件、929の集まり）は差が平均11.0pt・10pt以上ずれたのが47%。今の定義（半分300件以上、124の集まり）は平均3.0pt・0.8%
- 例: 徳山・B1 B1 A2 B1 A1 B1 は前半30件で12勝（40%）、後半30件で21勝（70%）

## セカンドオピニオン（second-opinion-reviewer）の指摘と対応
| 指摘 | 重大度 | 対応 |
|---|---|---|
| 全艇平均で2・3号艇の改善が隠れている | 高 | 採用。h を測り、後に2着以内・3着以内も測って h は採らないことにした |
| レース単位の改善は並びではなく、各艇の級別の不一致 | 高 | 採用。結果4の解釈を変え、BOA-806 を起票 |
| レース単位にブートストラップが無い | 低 | 採用（レビュアーが補った区間を記載） |
| 「精度は上がらない」は平滑化しない前提 | 表現 | 採用（結果2に明記） |
| 9.3pt と 2pt は物差しが違う | 表現 | 採用（平均絶対差 約1.6pt を併記） |
| 縮小先が全国の率で細かい定義に不利 | 低 | 採用（注記のみ。結論の向きは変わらない） |
