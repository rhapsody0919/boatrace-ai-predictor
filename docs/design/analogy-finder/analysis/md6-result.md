## 結論

- 事前ルールの判定: **k-NN を採る**。4つの k-NN すべてが比較相手の層別（strat_g）に、決まり手(a)の対数損失で有意に勝った
- 採る方式: **会場不一致ペナルティ付き k-NN（knn_p）**。(a) の test 対数損失が最小（1.29177）。全会場版（knn）にも有意に勝つ（−0.00162 [−0.00255, −0.00054]）ので、「会場を揃える版が全会場版に負けない範囲なら会場版を推す」条件も満たす。精度と説明しやすさの両方でこれになる
- 同一会場に限る版（knn_v）・会場クラスタ内の版（knn_c）は、層別には勝つが全会場版に有意に負ける
- 予備結果との違い: 同一会場版も層別に勝つようになった（予備は差なし）。近傍の会場一致率は 4.8% → knn_p で 36.1%（k=800）／66.6%（近い100件）
- ただし近傍が揃っているのは主に「選手の力量（勝率・級別、特に1号艇）」と「展示タイムの差」。機力・気象・グレード・ラウンドはランダムとほぼ同じ。画面で「6テーマで似ている」とは言えない（下の「近傍の性質」）
- 類似度スライダー 65〜95% は今の距離の尺度では使えない（65%以上の過去レースがあるレースは 3.3%）。表示は順位ベースに変える必要がある（下の「表示用の n」）

## 方式

| 記号 | 内容 |
|---|---|
| venue | 会場だけの層（参考） |
| g1only | 1号艇の級別だけの層 |
| strat_d | 階層 Dirichlet: 全体→会場→×1号艇級別→×風速ビン(0-2/3-4/5+/欠損)→×グレード区分(一般/G3以上/不明) |
| strat_g | 同じ最細層で、順を 1号艇級別→会場→風速→グレード（予備の最良形） |
| knn | 全会場 k-NN |
| knn_v | 同一会場に限る k-NN |
| knn_c | 同じ会場クラスタ内の k-NN（pool_cal の1号艇1着率で24場を6場ずつ4群。イン有利度が似た会場） |
| knn_p | 会場が違う過去レースの距離²に λ を足す k-NN（λ は cal で選ぶ） |

- 層別の確率: p_L = (c_L + α p_{L−1}) / (n_L + α)。α ∈ {1〜100,000} を cal で選ぶ
- k-NN の確率: (近傍のラベル件数 + α × その会場の事前分布) / (k + α)。k ∈ {100,200,400,800,1600,3200,6400}、α ∈ {0.1〜2,000}、λ ∈ {1/32,1/16,1/8,1/4,1/2,1}×L（L = cal の先頭500R で全会場 k-NN の400番目の距離²の中央値 = 0.6122）を cal で選ぶ。予備の反省（k が格子の上限 400 で選ばれた）から k を 6400 まで広げた
- 比較相手（事前に固定）: g1only・strat_d・strat_g のうち (a) の cal 対数損失が最小のもの → **strat_g**（cal 1.32907）
- 距離: レース単位 337 次元（艇別の数値 29 項目×6艇、レース共通の数値 9、会場・天候・グレード・ラウンド・支部（艇別）の one-hot）。数値は pool_test で z 化・欠損0。重み付きユークリッド
- 重み: Phase M F5 主モデル（1着、`main_win_F5.txt`、313本）の `pred_contrib` を、2025-01〜12-02 の無作為 5,000R（test は使わない）で計算し、**レース内で中心化した |SHAP| の平均**を (特徴量, 艇番) ごとに取った。レース共通の項目は6艇分の和、one-hot は w/√2（不一致で距離²に w²）。艇番（boat_number）は次元にできないので外した（中心化後の全体の 35.2%。スロット別の重みとして間接的に入る）
- 重みのテーマ別シェア（艇番を除く）: 会場×枠・進入 3.8%／選手・基礎成績 53.5%／ST・直前情報 23.7%／機力 8.1%／環境 3.2%／選手・属性 7.7%。上位: 勝率のレース内偏差 19.2%、展示タイム偏差 12.4%、直近1着率偏差 7.8%、平均ST偏差 5.4%、モーター2連率偏差 4.3%、全国2連率 3.5%、会場 3.1%、勝率順位 2.9%、級別 2.9%、1号艇の勝率 2.7%、年齢 2.7%。艇番スロット別 17.6/15.8/15.5/16.1/16.8/18.2%
- 予備（ワトソン型）との差: 予備は win_rate_diff と win_rate_rank で 61%、展示タイム順位 6.9%。今回は基礎成績が 54% に下がり、展示タイム偏差・平均ST偏差を含む ST・直前情報が 24% に増えた
- 近傍探索は厳密（全件の距離）。ペナルティ版は「全会場の上位 12,800 ∪ 同一会場の上位 6,400」から選び、不一致側の上位 6,400 が候補に収まらなかったクエリは cal・test とも0件（厳密）

- 言える: **1号艇の級別と勝率**（比 0.40、級別一致 63.5% vs 32.0%）、**6艇の勝率の並び（力関係）**（勝率偏差 0.40、2〜6号艇の勝率 0.46、2連率 0.49）、**直近の調子**（直近1着率・3着内率 0.61〜0.64）、**展示タイムの差（相対）**（0.62。絶対値は 0.85 で揃わない）、**当地成績**（0.72〜0.75）、**会場**（36.1%、近い100件なら 66.6%。ランダム 4.2%）
- 言えない: 機力（モーター 0.90、ボート 0.96）、気象（風速 0.89、風速ビン一致 42.5% vs 38.8%、天候 42.4% vs 42.3%）、グレード（75.1% vs 68.8%）、ラウンド（51.7% vs 45.1%）、属性（年齢 0.89、体重 0.95、地元 0.97）。平均ST（0.80）・波高（0.80）・R番号（0.77）は境界
- 画面の文言は「選手の力関係（特に1号艇）と展示の差が似たレース。同じ会場を優先」が実態に合う。6テーマのレーダーと並べて「6テーマで似ている」とは書けない。機力・気象を揃えたいなら条件チップ（会場・風）で後から絞る形になるが、絞ると n が減る

## 重みの再学習での近傍の入れ替わり（木の数固定）

F5 と同じ train 期間・ハイパーパラメータで、seed（学習レースの35%抽出・bagging・feature_fraction）だけ変え、木を313本に固定（early stopping なし）して2回学習し直した。λ は同じ倍率（L/4）で L を引き直し。test 2,000R、k=800 の Jaccard:

## 表示用の n

- 推定（分布）に使う n: knn_p は常に k=800（(a)(b)(c) とも。欠損は (a) の6R だけ）。予備の 400 から増えた
- 類似度 s = 1 − d / d_ref（d_ref = test と母集団の無作為ペアの距離の中央値 1.4226）で見ると、母集団の順位ごとの s の中央値は 1位 0.581、100位 0.488、200位 0.470、400位 0.450、800位 0.429、1600位 0.404、3200位 0.377、6400位 0.344
- s ≥ 65% の過去レースが1件でもある test レースは 3.3%（全会場、同一会場では 3.0%）。75%・85%・95% は 0%。**スライダー 65〜95% をこの尺度でそのまま使うと、ほぼ全レースで0件になる**
- 提案: 推定は k=800 固定で計算し、表示のしきい値は順位ベース（例「近い順に上位 100／200／400／800 件」）か、レースごとに上位800件の距離で正規化した相対類似度にする。spec の「類似度スライダー（65〜95%）」は尺度の定義の変更が要る（screens で確定させる事項）
- 層別（参考）: 最細層の n は中央値 1,470、10%点 112、90%点 2,528、n<30 は 4.3%（長期の母集団を使ったので予備の中央値 116 から増えた）

## 妥協点

1. **cal は長期（kb）期間、test は本体期間**。決まり手の表記・実進入の取得元が期間で違う（kb の technique／course と、本体の winning_technique／actual_course）。1着コース≠艇番の率は cal 5.76%、test 5.68% で近く、決まり手の分布も近い
2. **重みは F5 主モデル**（train 〜2025-12-02、early stopping は 2025-09〜12）。cal 期間（2025-06〜12-02）は重みの学習期間と重なる。cal は k・α・λ の選択だけに使い、判定は test で行った。test は重みの学習にも母集団にも入っていない
3. 母集団から 2025-12-03〜2026-03-31 を除いた。本番では test 直前の4か月が母集団に入るので、結果は本番よりやや保守的
4. 長期に無い項目は距離に入れていない（展示ST・展示進入・チルト・オリジナル展示等）。直前情報の類似は展示タイムと過去STだけで測っている
5. 長期の展示タイム・気象は結果ファイル由来（Phase M と同じ）
6. 近傍の性質のテーマ比は z 値の平均絶対差（重みなし）で、テーマ内の項目を単純平均した簡易指標
7. 「画面で言える」の基準（比 0.75 以下・一致率 1.5倍以上）は報告用の目安で、事前に固定したものではない
8. 実行時のマシン負荷（load average 50〜200、他セッションの E2E が並走）で近傍探索に約80分。最初の探索は k の上限が 800 で、(a) の k が上限に張り付いたため、k を 6400 まで・α と λ の格子を広げて探索し直した（結果はやり直し後のもの）
