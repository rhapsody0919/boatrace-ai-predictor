## 2. 全件での確定（pool 335,699R・cal 27,228R・test 28,172R。特徴量は本番の features.py と同じ定義）

### 軸
- **S\* ＝ Gap5（1号艇と他艇の勝率差5帯）→ C1（1号艇の級別）→ V（会場）→ Ntop（勝率1位の艇）、α=1000**（格子 {10〜30000} の内側）
- 各段の cal LL の改善: +0.04292 / +0.00532 / +0.00397 / +0.00145。4軸の上限で止まった
- 4軸目は「会場」に決まったが僅差。α=50 の「…Ntop→S1b（1号艇の平均ST順位帯）」との cal の差は −0.00033 [−0.00202, +0.00145]（事後）。手順どおり V を採った
- Gap5 の境界（pool の分位）: −1.91 / −1.14 / −0.49 / +0.19

### 小さい層の戻し方
- **m=200、α'=50**（件数が200未満なら末尾の軸から外して親の層へ。表示する層の割合を、その親の層の割合に向けて α'=50 で平滑化）。m・α' とも格子の端で決まった。事後に cal だけで格子を広げると、m=200 は内側の最良、α' は200がわずかに良い（1.3197）
- 表示に使う層の深さ（test）: 4軸のまま 70.5%、3軸（勝率1位の艇を外す）27.2%、2軸（会場も外す）2.3%、1軸以下 0%
- 使う層の件数（test）: 中央値545、10%点242
- 戻さない階層 Dirichlet との差（test）: +0.00073 [−0.00025, +0.00183]。**有意差なし**。戻し方（外した条件と件数を画面に出す）を採るかは、精度ではなく見せ方で決めてよい水準
- 戻し方 − 会場×1号艇級別（test）: −0.01143 [−0.01357, −0.00915]

## 3. 訂正
MD-6 と FR-2 の以前の版で「一番近い過去レースでも類似度は6割前後で、ほぼ同じ過去レースは無い」と書いたのは、全次元の重み付き距離という1つの尺度での話にすぎなかった。出走表時点で言葉にできる4つの条件に絞れば、すべて同じ過去レースは中央値約300件ある。

## 4. 軸の上限を外した前向き選択（2026-10-02、事前登録 [preregistration-3](./fr2-strat/preregistration-3.md)）
