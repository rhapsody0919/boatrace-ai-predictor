## T1-2 今節の平均着順点（前日まで）の走数の絞り込み（第9回 指摘3、spec Q6）

問い: 節の序盤（前日までの走が少ない）の値は、6艇の差（一番高いとき／一番低いときの率の差）を小さくするか。小さくするなら、何走以上で絞るか。

- 値: spec Q6 の定義（同じ節で、レースの日より前の日の走の着順点の平均。同じ日の前の走は含めない）。`series_score_rows.pkl` から作り直す。値の無い艇（前日までの走が0）は数えない（今の数え方）
- m＝そのレースの6艇の、前日までの走数の最小値（値の無い艇は0）
- 母集団: 全国（NA）、2019-04-01〜2026-09-26 の完全レースから、**準優勝戦・優勝戦（T1-1 の新しい判定）を除く**（得点順で枠が決まり、点の1位がほぼ1号艇になるので、差が機械的に広がる。Q7 で一文を出さない日でもある）。期間を P1＝2019-04-01〜2022-09-30、P2＝2022-10-01〜2026-09-26 に分ける
- 指標
  - S(m): m ごとの層（m＝1・2・3・4以上）の中で数えた、艇番ごとの「6艇で一番高いときの1着率 − 一番低いときの1着率」（spec A の一番良いとき／一番悪いときと同じ数え方。同じ値の扱いも同じ）を、1〜6号艇で単純平均したもの（pt）。節の日目の偏りを見るため、日目別の S(m) も出す
  - 各 m の層の割合
  - 絞ったときの画面への影響: k ∈ {0（今）, 2, 3, 4} で「6艇とも k 走以上のレースだけ数える」としたとき、VC（会場×組み合わせ×選んだ艇の級別）の件数の中央値・300件未満の割合と、来る艇の条件のカードの判定（差が大きい／小さい／はっきりしない）の分布（例のレースの範囲と、全国のレースから無作為に選んだ200レースで）
  - 参考: 2着以内・3着以内の同じもの、艇番ごとの値と Wilson の幅
- 判定（P1 と P2 で別々に出す）
  - k* ＝ S(m=k) ≥ S(m≥4) − 2pt となる最小の k（k ∈ {1, 2, 3, 4}）。k*＝1 なら「序盤の値でも差は小さくならない」→ 絞らない
  - k* ≥ 2 なら「k* 走未満の値が混ざると差が小さく出る」
  - P1 と P2 で k* が違えば大きいほうを採る
- 絞るかどうか・今日のレースで k* 未満の艇がいるときの表示（カードの注記・出さない）は、上の画面への影響（件数が減り、はっきりしないが増える）と一緒に、案＋推奨でユーザーに確認する（この分析では決めない）

## T1-3 返還レースの除外が展開シナリオの割合に与える影響（第10・11回の残り）

- 返還の判定（両方の版で同じ）: 長期は `finish_raw` が F・L0・L1。K0・K1 は出走前の欠場とみなし、そのレースは母集団に入らない（完全レースの定義）。本体は `is_flying`・`is_late_start`、`finish_mark` が F・L・欠、`race_results.refund_boats`（BOA-635 の D-5 と同じ）
- 形は BOA-635 の7形の1段目（round(ST×100) の整数で比べる）。進入不明のレースは両方の版で除く
- 範囲: 全国（NA）、全国・6艇ともA1、若松・6艇ともA1。2019-04-01〜2026-09-26
- 指標: 形ごと（どの形でも＋7形）の件数、4号艇の1着率、1号艇の1着率、版B − 版A（pt）と日単位のブートストラップの幅。F の艇の進入コース別の件数
- 判定: 全国（NA）か 全国・6艇ともA1 のどちらかで、カド一撃の4号艇の1着率、またはどれかの形の1号艇の1着率の |版B − 版A| が 2pt 以上なら、タブ3の脚注に「F で返還になったレースを除いているので、{形}の{艇}の1着率はやや{高め/低め}に出る（含めると{x}%）」を足す案をユーザーに出す（文言はユーザー確認）。2pt 未満なら記録だけ（画面は変えない）。母集団の定義（返還を除く）は変えない（spec）

## T1-4 手がかりの条件のしきい値の期間分割（第10回の残り）

問い: 手がかりの8条件のうち、しきい値を持つ6条件（kado4_02・in_slow02・d2_slow01・d3_slow01・dash03・flat03）は、全期間のデータで値を選んだ。期間を分けても同じ値が妥当か。

- 定義: `slit-hint/hint2.py` の条件と母集団（6艇とも枠なり・返還を除く。hint2 の POP）。平均ST は 1/1000秒に丸める。主は画面の既定「このコースで」（そのコースで5走未満の艇は全体の平均ST で埋める。spec C-2）。画面の切り替え「全体」（全体の直近30走の平均ST）も同じ判定を出す。当たる形は条件ごとの `form`
- 期間: P1＝2019-04-01〜2022-09-30、P2＝2022-10-01〜2025-12-02、P3＝2025-12-03〜2026-09-26（長期と本体の境目で分ける）
- しきい値の候補: 各条件で {.00, .01, .02, .03, .04}（今の値を含む）
- 指標: 候補ごと・期間ごとに、当てはまるときの形の率 p_hit、当てはまらないときの率 p_miss、lift＝p_hit／p_miss、当てはまる割合 h、選び直しの指標 U＝(p_hit − p_miss)×h（Wilson とブートストラップの幅）
- 判定
  - 今の値を残す条件: 3期間すべてで lift > 1（幅が1を含まない）、かつ 3期間の lift の最大と最小の差が 0.3 以内（安定）。件数が数万あるので「幅が1を含まない」はほぼ必ず通る。判定の中身は安定のほう
  - 満たさない条件は、P1＋P2 で U が最大の候補を選び（lift の最大化は一番厳しい値に寄るので使わない）、P3 で lift > 1（幅が1を含まない）と、P1＋P2 との lift の差が 0.3 以内を確かめる（P3 はこの確認に1回だけ使う）。P3 で通らなければ、その条件を手がかりから外す案をユーザーに出す
  - 画面の札は今のとおり「当てはまるときの率が当てはまらないときより高い条件だけ」（第10回）。しきい値を変えた条件は、モックの数字（例のレースの札）が変わるかを結果に書く

## T1-5 1号艇の展示タイムが系統的に速い理由（第11回の残り）

問い: 1号艇は展示タイムの順位で上位に入りやすい（全国で約半数）。力のある選手が1号艇に入るから（選手の違い）か、1号艇の位置・測り方によるもの（同じ選手でも速く出る）か。

- 値: 展示タイムをレースの中で中心化した値（6艇の平均を引く）。0以下と 6.30〜7.50秒の外は欠損とする。欠場・値なしの艇は除き、5艇以上あるレースだけ。参考に中央値で中心化した版も出す
- 母集団: 2019-04-01〜2026-09-26 の完全レース。**主は予選のレース**（準優勝戦・優勝戦・ドリーム戦・選抜戦・特選などを除く。T1-1 の判定と `raceStageConfig.js` の種別の規則で、長期は名前が無ければ `stage_kind` が qualifier・other のもの）。勝ち上がりのレースは1号艇に強い選手が入る仕組みなので、選手×節の中でも1号艇の走が強い相手の日に偏るため。全レースの版も参考に出す。長期（`kb_boats.exhibition_time`）と本体（`exhibition.exhibition_time`）は記録元が違うので、分けて出す
- 指標
  - 艇番ごとの中心化した値の平均（生の差 Δ_raw＝1号艇 − 2〜6号艇）と、展示順位1位の割合（同じタイムは min 順位で、spec A-7 と同じ）
  - 同じ選手・同じ節（モーターも同じ）の中での差 Δ_fe: 選手×節ごとに「1号艇のときの平均 − 2〜6号艇のときの平均」を取り、両方の走がある選手×節で平均。艇番ごとにも同じものを出す。幅は日単位のブートストラップ
  - 説明される割合 r＝Δ_fe／Δ_raw
  - 参考: 同じ選手×節で、節の日目の差が1日以内の走どうしの比較
- 判定（主の母集団、長期と本体のそれぞれで）
  - r ≥ 2/3（かつ Δ_fe の幅が0を含まない）→「位置・測り方による」。③の注記を「1号艇は展示タイムが速く出やすい（同じ選手でも1号艇のときに約{|Δ_fe|}秒速い）」にする案
  - r ≤ 1/3 か Δ_fe の幅が0を含む →「選手の違いによる」。注記を「1号艇には力のある選手が入りやすく、展示タイムでも上位に入りやすい」にする案
  - その間 → 両方を書く案
  - 長期と本体で判定が違えば、両方の数字を出し、本体（今の記録の仕方）の判定を採る案にする
  - 注記の文言はユーザーに確認する（オーケストレーター経由）
- 限界: 予選に絞っても、選手×節の中で1号艇の日と調子が相関しうる
