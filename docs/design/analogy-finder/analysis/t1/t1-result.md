## T1-5 1号艇の展示タイムが速い理由

出典: `t1-5-boat1-exhibition.json`。主の母集団は予選（T1-1 の v2 で種別が qualifier・general。勝ち上がりのレースを除く）、展示タイムはレースの中で平均を引いた値。長期（2019-04-01〜2025-12-02、予選 214,408R）と本体（2025-12-03〜2026-09-26、26,637R）を分けた。Δ は負なら1号艇が速い。

| | Δ_raw（1号艇 − 2〜6号艇） | Δ_fe（同じ選手×節、幅） | r＝Δ_fe／Δ_raw | 判定 |
|---|---|---|---|---|
| 長期 | −0.0169秒 | −0.0170（−0.0174〜−0.0170） | 1.007 | 位置・測り方 |
| 本体 | −0.0178秒 | −0.0177（−0.0185〜−0.0173） | 0.996 | 位置・測り方 |

（`judgment.primary.{kb,main}`。両方の走がある選手×節は長期 168,545・本体 20,987）

- 判定: **位置・測り方による**（長期と本体で一致。`judgment.kb_main_agree`）。同じ選手・同じ節（同じモーター）で比べても、1号艇の差がほぼそのまま残る
- 参考版も同じ判定: 全レース（勝ち上がりを含む）は r 0.92〜0.93（勝ち上がりで1号艇に強い選手が入る分が少し出る）、中央値で中心化 r 1.00〜1.01、節の日目が1日以内の走どうし −0.0174〜−0.0181秒、名前で種別が決まらないレースも含めた版 r 0.95
- 艇番ごと（予選・長期）: 1号艇 −0.014、2号艇 −0.004、3号艇 +0.002、4号艇 +0.004、5号艇 +0.007、6号艇 +0.006秒（6艇の平均との差）。内の艇ほど速く出る
- 展示順位1位（同じタイムは min 順位）の割合: 1号艇 28.3〜28.5%、2号艇 約20%、3〜6号艇 15〜17%。第11回の「全国で約半数」は1〜2位に入る割合（mark1.md）で、1位の割合ではない
- 限界: 展示航走で内の位置を走るためか、測り方（計測の区間・位置）によるものかは分けられない。予選に絞っても、1号艇の日と調子が相関しうる（日目1日以内の比較でも差は残った）
- ブートストラップは日を抜くと選手×節の片側が抜けるので、点推定が幅の外に出るセルがある（ずれは0.0001秒未満、判定に影響なし。`notes`）

見せ方の案（ユーザー確認。オーケストレーター経由）:
- ③「攻めは決まった？」の1号艇の表の注記（今は「1号艇は展示タイムで上位に入りやすい（全国で約半数）」）
- 案1（推奨）:「1号艇は展示タイムが速く出やすい（同じ選手でも1号艇のときに約0.02秒速い。展示で内を走るためと見られる）。展示タイムの順位で上位でも、割り引いて見る」
  - 理由: 選手の違いではなく位置の分なので、順位をそのまま読むと1号艇を過大に見る。「約半数」は1〜2位の割合で、言い方が曖昧
- 案2: 機械的に出る文だけ（「1号艇は展示タイムが速く出やすい（同じ選手でも1号艇のときに約0.02秒速い）」）
- 案3: 今の注記のまま、「上位」を「1〜2位」に直すだけ
- 補足: 展示タイムの順位は、タブ1の材料（直前情報）とタブ2の距離にも使っている。1号艇の位置の分を割り引くか（艇番ごとの平均を引いてから順位を付けるなど）は、寄与度用モデル・類似レースの定義に関わるので、この分析では提案しない（必要なら別の起票）
