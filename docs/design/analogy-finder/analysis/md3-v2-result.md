## 判定の扱い

- **事前固定ルール（比較A、ε=0.001）: 材料にしない**。CI 上限 +0.00012
- 判定が境界にある根拠: ε=0.003 で CI 上限 −0.00004、日クラスタで −0.00012。比較Bは全 ε で有意
- 比較A の検出力: per-race SD 0.162。観測差 0.00255 を80%で検出するのに test 約3.2万R（今の取れ方で月約4,500R → test 7か月分）。比較B は SD 0.074 で約6,100R で足りる
- 選択肢（依頼元の判断）
  1. 事前ルールどおり「材料にしない」。2026-11 以降に test を伸ばして比較A を再判定
  2. MD-4 と同じ比較B（土台＝主モデル）を判定に使い直して「採る」。シェアの順位は崩れないので「採る」側の条件も満たす。ただし判定方式を結果を見た後で変えることになる点を明記する必要がある
- どちらでも「シェアを吸いすぎる → 市場を別枠表示」には当たらない（10分前 0.118、5分前でも 0.248 で順位不変）

## 妥協点

- 比較A は 2026-04 以降のデータだけで一から学習しており train が小さい（1.2万〜2.1万R）。主モデル（F5 の test 1.1911）より弱い土台での上積み
- 比較B は線形の上積みしか見ない。F5 は 2025-12 までの学習で期間のずれがあり、艇番の切片で吸収している（MD-4 と同じ）
- 票0の艇の確率 ε は事前に決めず感度で見た。生の市場確率には ε の正解が無い（票の総数が取れていないため「1票分」の確率を出せない）
- 締切時オッズの天井は race_odds_final が 322R しか無く出せない。0〜60分前で代用
- 時点は「締切10分前に最も近い過去」だが、実際は 10〜15分前に 96% が集中（取得窓が −15・−10 のため）。直前情報時点（10分前）より数分古い
- 期間は 2026-04〜09 の6か月。季節・グレード構成の偏りは未確認
