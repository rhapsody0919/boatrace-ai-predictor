# BOA-271 類似レース knn5（展示前）・knn6（展示後）: 優勝戦・準優勝戦はラウンドをそろえる

例のレース 2026-09-27 若松12R（G1ヤングダービー優勝戦）。本番 DB は SELECT のみ（書き込みなし）。

## 作り方

- `knn_build.py` に `KNN_ROUND=1` を追加。今日のラウンドが優勝戦（round_code=2）または準優勝戦（1）のときだけ、層の条件に「ラウンドが今日と同じ」を足す。予選・その他の日は足さない（`layer.key.round` が null になる）
- 距離・重み・L・λ は knn3/knn4 と同じ（層で絞る前の母集団で作る）。knn5 = knn3 と同じ距離（`KNN_DROP=weather_code,wind_x,wind_y,wind_speed,wave_height,is_final_day_num`、racecard）、knn6 = knn4 と同じ距離（`KNN_DROP=is_final_day_num`、with_exh）。L は knn3 0.3534／knn4 0.5400 と一致
- 実行: `KNN_TAG=knn5 KNN_LAYER=1 KNN_ROUND=1 KNN_DROP=... ./run.sh knn_build.py` → `export_ids.py` → `fetch_outcomes.mjs`（SELECT）→ `KNN_TAG=knn5 ./run.sh knn2_report.py`。knn6 も同様（`KNN_PRIMARY=with_exh`）。補足表は `./run.sh knn56_extra.py`（work5/knn56_extra.json）
- `knn2_report.py` の変更: knn5/knn6 の対応（比較の基準 knn3/knn4、knn6 は with_exh）。層が 800件未満のとき、段（knn_rate・outcome_agg・d2_share_by_group_mean・overlap）は「800未満の段＋層の全件（76）」だけ出す（以前は件数を超える段も黙って全件で計算していた）。`pool` に `layer_n`・`n_ranked`・`note` を追加（既存キーは変えない）

## 所見

- 1位は knn5・knn6 とも 2026-01-28 若松12R 一般戦の優勝戦（旧1位は knn3＝2025-08-28 若松9R SG 予選、knn4＝2020-07-19 尼崎7R G2 ラウンド「その他」で、どちらも層から外れた）。ラウンドはそろったが、グレード（一般）と年齢（40代中心）は今日と違う。層 76R の 74% が一般戦で、グレード・年齢は層の条件ではなく距離の中の1要素なので、会場一致（若松は距離に λ の差が付く）が優先されて上位に若松の一般戦が並ぶ
- 1〜10位で今日と同じ G1 は knn5 で5位の児島 G1 だけ、knn6 で8位びわこ G1（SG は10位尼崎）。年齢が今日（22〜29歳）に近いのは knn5 3位 2020-02-04 若松、6位 2024-11-28 芦屋、knn6 4位 2022-07-27 徳山
- knn3 との重なり（knn5 の上位 n と knn3 の上位 n）: {'20': 2, '50': 3, '76': 4}。knn4 との重なり: {'20': 3, '50': 6, '76': 6}。knn5 と knn6 の重なり: {'20': 14, '50': 40, '76': 76}
- mock 側は `D.knn3layer`（3条件の層 1,565R の結果）を「3条件がそろった過去レース全体」として出している。knn5/knn6 に差し替える場合、この比較用の層全体も 76R 版が必要になる（今回は作っていない）
