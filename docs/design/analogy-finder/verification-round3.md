  - くわしく
- 似たレースは自動で条件を外さない（初期は4条件ぜんぶ一致の 74件）

## 画面に出してよいもの・いけないもの（第3回で追加、採用）
**出してよい**
- 条件チップと「外すと○件」
- 一覧（小さい n でも全件）
- 似たレースの割合（ひげつき）
- ソナー（4輪を同じ目盛りの割合にそろえ、輪の名前が差分集合と一致していること）
- サンキー（2段目が1着を問わないことを明示するか、1着で絞った本当の流れで描くこと）
- 3連単の件数（同数と母数つき）

**出してはいけない**
- 輪ごとに違う符号化を混ぜ、輪どうしを比べさせること
- 差分集合と違う輪の名前
- 全国の点線だけを比較の基準にして、条件で選んだ結果を状況の効果のように見せること
- AI を主語にしない「勝負を分ける」の見出し
- 補助の値を、6艇のばらつきの注記なしで「全国より大きい／小さい」と出すこと
