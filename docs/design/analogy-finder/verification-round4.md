## 自分の結論（検証前）
**方式**: 例のレースで knn_p を計算した。
- 出走表時点の特徴量で測る。展示タイム・天候・風・波・最終日は距離に入れない
- 重みは、寄与度用モデル（版 2026-10-02 の model_win）の中心化 |SHAP| の重要度
- λ = L/4
- 母集団は 2019-04-01〜2026-09-26 の 408,888R

**画面**: 次の順に並べた。
1. スライダー（似ている順 N件）
2. 同じ節のチップ
3. ソナー
4. 何が似ている？（項目ごとに、今日と同じ帯に入る割合）
5. 1件ずつ見比べる（全項目を ○△×、結果つき）
6. 似たレースでは、こう決まった

## 画面に出してよいもの・いけないもの（第4回で追加、採用）
**出してよい**
- k-NN の近い順の一覧
- 1件ずつの ○△× の見比べ（全項目。近さに入れていない項目には印を付ける）
- N件での結果（ひげつき。N<100 では800件の参考を添える）
- 同じ節のチップ
- 「AI が重く見る項目で近さを決めた」という説明

**出してはいけない**
- 順位を%にしたもの、「ぐっと似た」
- 初期値を100件以下にして、その割合を主役にすること
- 全体との差だけで「何が似ている」を選ぶこと
- 中身が同じ項目を二重に数えること
- 広げると点が動くソナー
- 全国の点線だけを比べる相手にすること
- 似たレースの結果を「AI とは別の裏付け」と読ませること
- 「似ているから同じ結果になる」と読める見出し
