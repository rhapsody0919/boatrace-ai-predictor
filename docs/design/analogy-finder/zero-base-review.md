対象: 今のモック（scratchpad の mock-current.html、表記は「モック v6 統合案」）と、当初のモック v6（assumptions-vs-findings.md「当初の思想」）。実装はしない。ファン4人パネルは同じモデルのロールプレイなので、結論は仮説。モックの承認と公開後の実データで確かめる。

v6 が見やすかった理由（比べて分かったこと）: 操作が「条件」と「着順」と「艇」だけで、どれも全部の図に同じ意味で効いていた。数字は割合1種類だった。今のモックは分析で分かったこと（このレースの値、他艇、指数）を足すたびに、既存の操作に別の意味を重ねた。

## 2. 技術・データの前提（ファンの議論には混ぜず、事実として添える）
- 寄与度の割合は条件でほとんど変わらない。会場24場で 枠・コース .331〜.381、実力 .373〜.403（±3pt 程度）。艇番では大きく変わる（1着の枠・コース 1号艇 .594・3号艇 .078）。着順でも変わる（3着以内は実力が約 +8pt、1位のテーマが入れ替わるのは「枠・コース→実力」の一方向）。2着以内は1着とほぼ同じ（差は雑音の約2倍） — fr2-strat-result.md 5、perrace-finish-targets.md b
- 正規化前の大きさ（6艇の差の大きさ）は、全体では会場で 94〜105（全国=100）、SG・G1 は 89（一般の約88%）。**テーマ別に見ると動きが大きい**: 実力は G1 68・SG 69・優勝戦 77、枠・コースは 優勝戦 108・G1 107、スタート・展示は会場で 88（江戸川）〜118（桐生）、モーターは 83（三国）〜119（多摩川）— perrace/venue-magnitude.json（1着、縮小学習のモデル、test 2026-04〜09 の 28,185R。本番の版での再計算と、ブートストラップの誤差幅が要る。SG は 288R）
  - 小さいテーマ（天候・水面・節は全体の約2%）は、指数が 138 でも全体への影響は小さい
- 実際の決着は条件で大きく変わる（1号艇の1着率: 会場で 40.9%〜62.9%、準優勝戦 73.9%、予選 47.8%）— 同 json の b1_win_rate
- このレースの値（レース内で中心化）は、1位のテーマが 枠・コース 60%・実力 40% で、レースごとに違う — perrace-contribution.md 1
- 寄与度は寄与度用のモデルの説明で、原因ではない。押し上げ・押し下げの値は log-odds で、確率の差ではない（加法にならない）— perrace-finish-targets.md a・e
- 他艇の不出来は、結果を条件にして数えた割合で、原因ではない。全国×優勝戦で6号艇1着（98件）のうち、1号艇が4着以下か F・出遅れ・失格は 52.0%（全体 12.3%）。若松×G1×優勝戦は9件で、6号艇1着は0件 — other-boats-counting.md
- 他艇をモデルで出す案（レース単位モデル）は精度が下がり、seed で6割入れ替わるので使わない — perrace-race-level.md
- 他艇の表を出すには、母集団に艇ごとの4〜6着と F・出遅れ・失格の印を足す必要がある。長期分は転覆・落水を区別できない — other-boats-counting.md 3
- 類似レース（S*）は「勝率差・1号艇の級別・会場・勝率1位の艇」が同じ過去レース、中央値約300件 — fr2-strat-result.md

## 3. ファン4人パネル

論点ごとの発言の要旨。

### 予想のときに何を知りたいか
- 20代男性: 「穴を狙う艇が来る筋があるか」。6号艇を押して、6号艇が勝ったレースで何が起きていたかを見たい。寄与度そのものより、そっちが本命
- 20代女性: 「このレースは堅いのか荒れるのか」。最初の一目で、枠どおりのレースか、実力差のレースかが分かればいい
- 30代男性: 「似た力関係の過去レースで、逃げが何%か、どの出目が多いか」。数えた値が一番信用できる。モデルの説明は添え物
- 30代女性: 「買う艇の弱みと強み」。この艇は実力で上がっていて、展示で下がっている、のように艇ごとに知りたい。2連単も買うので2着以内も見たい

### どの順で見たいか
- 20代女性・30代男性・30代女性: このレース → 似た過去レース → (気が向いたら) 条件で遊ぶ。予想の画面なので、まずこのレース
- 20代男性: 条件で遊ぶのが一番楽しいので上にほしい。ただ、このレースの見立てが一画面目にあるなら下でもいい
- 4人とも: ①②③のタブで隠れるより、縦に流れるほうがいい。ただし長くなるので、条件で探る部分は折りたたみでなく「見出しで区切る」程度

### 条件を切り替えて何を確かめたいか
- 20代男性: 「G1 だと実力の差がつきにくい」が六角形でへこむのは面白い。会場ごとに形が変わるのを24場ぐるぐる回したい
- 30代男性: 割合が ±3pt しか動かないなら、割合の六角形を切り替えても意味が無い。動くもの（差のつきやすさ、実際の1着率）で見せて。差が誤差の範囲なら「全国並み」と書いて
- 30代女性: 地元の会場の1号艇の1着率と決まり手が、全国とどう違うかを並べて見たい
- 20代女性: 指数の 100 が何か分からない。「全国より差がつきやすい／つきにくい」と言葉で書いてほしい

### 他艇の不出来をどう見たいか
- 20代男性: 件数が0件でもそのまま見せてほしい。「7年で0回」はそれだけでネタになる。広げたら何件かも知りたい
- 30代女性: 件数が少ないときは実際のレースを1件ずつ見たい（日付・出目・1号艇が何着だったか・ST順）
- 30代男性: 自動で条件を広げるなら、広げたことを見出しに書く。「ふだん（全レース）」との比較の棒は必須。原因と言わないこと
- 20代女性: 転覆か落水かまで知りたいが、無理なら「F・出遅れ・失格」でいい

### 「寄与度」という言葉・六角形で伝わるか
- 20代女性: 「寄与度」は分からない。「何で差がつくか」なら分かる。艇の六角形は、押し下げなのに面積が大きいと強いと読み違える
- 30代男性: 寄与度は小さく併記すればいい。艇の押し上げ・押し下げは向きが大事なので、六角形より矢印の一覧がいい
- 20代男性: 六角形は好き。レース全体と条件の比較は六角形がいい
- 30代女性: 「枠・コース」で2号艇を押して「枠が一番」と出ても、2号艇なのは知っている。「2コースの平均から、実力で上げている」の形なら分かる

### 割れた点
| 論点 | 割れ方 | 統合 |
|---|---|---|
| 条件で探る部分の位置 | 20代男性は上、3人は下 | 下に置き、一画面目にこのレースの見立てを置く（20代男性も条件付きで同意） |
| 艇を選んだときの見せ方 | 20代男性は六角形、30代男性・20代女性は矢印の一覧、30代女性は「出発点＋上げ下げ」 | 六角形はレース全体と条件の比較に使い、艇は「出発点＋上げ下げの矢印」にする |
| 2着以内のタブ | 30代女性は要る（2連単）、30代男性は1着とほぼ同じなら不要 | 1着・2着以内・3着以内の3つを残す（2026-10-03 ユーザー決定）。ただし2着以内が1着とほぼ同じことは、切り替えたときの1行で伝える |

## 4. 推奨の画面構成（1つ）

### 方針
- **方法（寄与度・類似レース・組み合わせ）でなく、ファンの問いで区切る**。①②③のタブは無くす
- **このレース（予想用）と、条件で探る（遊び用）を別の節にする**。モード切り替えは無くす
- 1つの図・1つの行に、1種類の数字だけ。モデルの値と数えた値は見出しで分ける

### 画面の流れ（375px、上から）
図の数字は例（若松の2コース 14.4% は venue-magnitude.json の test 期間の値、312件・31件は架空）。

### 操作の単位
- 全体で1つ: 着順
- A と B で共有: 艇（1艇）。B のチップは B の中だけ

## 5. 代案と、推奨にしなかった理由

### 代案1: 艇カード型（6艇を主語にする）
6艇それぞれのカードに「出発点＋上げ下げ」「その艇が来たときの過去」を入れ、レース全体の六角形と条件の切り替えは置かない。
- 推奨にしなかった理由: 375px で6枚が縦に長い。条件で探る楽しさ（ユーザー要望）と六角形（2026-10-02 ユーザー決定「棒より六角形」）が無くなる。20代男性・20代女性が反対

### 代案2: v6 のタブ構成に戻し、言葉と数字だけ直す
上に条件・着順・艇の共通バー、①②③のタブ。①の割合の六角形を指数に替え、枠を出発点にする。
- 推奨にしなかった理由: ①の前提（条件で割合が大きく変わる）が崩れていて、共通バーの「条件」を変えても①の割合は ±3pt しか動かない。「このレース」を入れるとモード切り替えが要り、C2 の問題（同じ操作が別の意味）が戻る。タブで②③が隠れる（4人とも縦の流れを支持）
