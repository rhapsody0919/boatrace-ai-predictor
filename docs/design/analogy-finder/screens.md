## 画面

### S-1 レース詳細 > AI予想タブ > 節「アナロジー・ファインダー」（既存画面の拡張）
`RaceAiPredictionTab.jsx` の既存ブロックの下に節を足す。中は上から:

1. **節の見出し**「アナロジー・ファインダー · {会場}{R}R」
2. **上部の操作**（3タブ共通）
   - 時点: 「展示前（出走表）」「展示後（直前情報も）」。「展示後」は展示後の段（類似レースの並べ直しと今日の展示の値）が保存されてから押せる。それまでは `disabled` で、下に1行（状態の表）
   - 着順: 「1着」「2着以内」「3着以内」。展開シナリオのタブでは行ごと隠す
   - タブ: 「来る艇の条件」「類似レース」「展開シナリオ」。既定は「来る艇の条件」
3. **タブの中身**（下の S-1a〜S-1c）
4. **使っている項目**（折りたたみ、3タブ共通。FR-D）

- 中止確定のレースは節ごと出さない。それ以外（確定後・予想なし・未確定）は出す。予想（predictions）の有無とは切り離す
- 発走後・確定後は、発走前に保存した値で出す（spec「時点の固定」）。保存が無いレース（公開前のレース・朝のバッチで作れなかったレース）は、節の中を1行「このレースは、表示できるデータがありません」だけにする
- 選んだタブ・艇番・時点・着順は URL にも localStorage にも残さない（spec「やらないこと」）

### S-1a 来る艇の条件（FR-A・FR-E）
上から:
1. 見出し（h3）「{艇番}号艇が{着順}のは、どんなとき？」
2. 艇番ボタン 1〜6（既定1）。「もう1艇と比べる」（折りたたみ。中に比べる艇番の select）
3. 数えるレース（VC・NC・NCR・VA。NCR は今日が優勝戦・準優勝戦のときだけ）
4. 六角形（`role="img"`、aria-label に項目と今日の順位）と凡例（実線＝今日、点線＝{範囲}で{艇番}号艇が{着順}のときの平均の順位）
5. 大きい数字「{範囲}で、{艇番}号艇の{着順}率」「65.5%」「743/1,134レース（2019/4/1〜{前日}）」
6. 説明文（spec A-7）
7. 項目ごとのカード（並びは spec A-7）。カードの中: 項目名・説明・判定のラベル・「6艇で一番{良い}とき」「一番{悪い}とき」の率と件数・6つの順位の棒・凡例・今日の一文・（2艇比較のとき）比べる艇の1行
8. ボート2連率（折りたたみ、一番下）
9. 級別の1行（6艇とも同じとき）
10. 脚注
11. 今日の風・波（展示後だけ。展示前は1行）
12. AIの見立て（補助）（折りたたみ。中に7テーマの割合の行、各テーマを開くと項目・割合・向き。脚注2つ）

### S-1b 類似レース（FR-B）
上から:
1. スライダー（件数、`input type="range"`）と「{n}件」、両端「少なく｜多く」、下の1行（一番遠い{n}件目でも…）
2. 見出し（h3）「類似レース」と説明文（spec B-3）
3. ソナー（SVG。中心＝今日、点＝類似レース、扇＝1着の艇）と下の説明。点の長押し・ホバーで吹き出し（日付 会場 R・グレード ラウンド・1〜3着・決まり手）
4. 何が似ている？（折りたたみ）→ 中に「全33項目（近さの計算に使わない項目も含む）を見る」（折りたたみ、表）
5. 1件ずつ見比べる（折りたたみ）→ 行を押すとその行の下に全項目の比較を開く
6. 見出し（h3）「類似レースの決まり方」、大きい数字「{n}件」「似ている順の{n}件で」
7. どの艇が勝った？（棒6本・ぶれ幅・点線・凡例・吹き出し）
8. どう決まった？（決まり手6本）
9. 着順の流れ（「すべて／1号艇以外が勝ったレース」の切り替え、サンキー、吹き出し、注記）
10. よく出た3連単（上位3、折りたたみ「残り{k}通りを見る（全{m}通り）」）
11. 脚注

### S-1c 展開シナリオ（FR-C）
上から:
1. 見出し（h3）「展開シナリオ」と説明
2. 数えるレース（VC・NC・NCR・VA・VG・NA。NCR・VG は条件つき）
3. ①進入はどうなる？（型の選択ボタン。前付けありの下に組の選択。展示後は今日の展示の印）と注記
4. 今日のスタートの手がかり（①が枠なりのとき。①の既定は枠なり）: 使う平均ST（このコース／全体）、絵、表、当てはまる条件のボタン、脚注
5. ②スタートはどう並ぶ？（「どの形でも」＋7つの形のボタン、それぞれ絵・割合・件数・1号艇の1着率、手がかりの札）と注記
6. ③攻めは決まった？（形を選ぶまでは案内の1行。選ぶと攻める艇の表と1号艇の表）
7. ④②の形のとき、どう決まった？（件数・説明・凡例、1着になった艇・3着以内に入った艇・どう決まった？・万舟・着順の流れ・よく出た3連単。30件未満は一覧）
8. 脚注

## データ取得

| フック | 中身 |
|---|---|
| `useAnalogyFacts(raceId, stage)` | `GET /api/analogy/facts/[raceId]?stage=` 今日の値（6艇の項目・順位・風・波）と、範囲ごとの集計（タブ1）、AIの見立て。今節の平均着順点を出さない範囲では、その項目を集計に含めない |
| `useAnalogySimilar(raceId, stage)` | `GET /api/analogy/similar/[raceId]?stage=` 似ている順（最大800件）と各件の項目・結果、比べる相手の層の集計（タブ2）。スライダーの件数での集計は画面で行う |
| `useAnalogyScenario(raceId, scope, stage)` | `GET /api/analogy/scenario/[raceId]?scope=&stage=` その範囲の①〜④の全セル（進入×形）と、30件未満の一覧。進入・形の切り替えは画面で行い、取り直さない |

タブを開いたときに初めて取得する（タブ1は節の表示時）。

## 画面の構造と操作要素（受け入れ E2E の前提）

| 対象 | 形 |
|---|---|
| 節 | `<section aria-labelledby>`。見出し（h2 相当）「アナロジー・ファインダー」 |
| 時点 | `role="group"`（ラベル「時点」）の中の button 2つ（`aria-pressed`）。名前「展示前（出走表）」「展示後（直前情報も）」。展示前に「展示後」は `disabled` |
| 着順 | `role="group"`（ラベル「着順」）の中の button 3つ（`aria-pressed`）「1着」「2着以内」「3着以内」。展開シナリオのタブでは出さない |
| タブ | `role="tablist"` の中の `role="tab"` 3つ（`aria-selected`）「来る艇の条件」「類似レース」「展開シナリオ」。中身は `role="tabpanel"` |
| 来る艇の条件の見出し | h3「{n}号艇が{着順}のは、どんなとき？」（1着は「1着になった」、2着以内・3着以内は「2着以内に入った」） |
| 艇番 | `role="group"`（ラベル「艇番」）の中の button 1〜6（`aria-pressed`） |
| もう1艇と比べる | `<details>`（summary「もう1艇と比べる」）の中の `<select>`（ラベル「比べる艇」）。選択肢は自分以外の艇番で、表記は「4号艇」。空の選択肢は置かない（開いたときは自分の次の艇番を選んだ状態） |
| 数えるレース | `role="group"`（ラベル「数えるレース」）の中の button（`aria-pressed`）。名前は spec の画面の名前（例「若松・6艇ともA1」） |
| 六角形 | `role="img"`。aria-label に「全国勝率 6艇中6位」などの今日の順位 |
| 大きい数字 | 「{範囲}で、{n}号艇の{着順}率」と「xx.x%」「a/bレース（期間）」 |
| 項目ごとのカード | `<article>`。見出しに項目名、判定のラベル（「差が大きい」「差は小さい」「差ははっきりしない」）、「6艇で一番○○とき」の率「76%」と件数「205/270」、順位の棒（`role="img"`、aria-label に6つの率）、今日の一文（「今日の{n}号艇は…」） |
| ボート2連率 | `<details>`（summary「ボート2連率（着順との関係が小さい項目）」）。中にボートのカード |
| 今日の風・波 | 見出し「今日の風・波（風{x}m・波{y}cm）に近いレースでは」。艇番ごとの行「66%（風を問わず57%）」。展示前は「今日の風・波は、展示の後に出る」 |
| AIの見立て | `<details>`（summary「AIの見立て（補助）: ほかの項目をそろえたうえで、どの項目が効くか」）。中にテーマの行（名前と%）、各テーマは `<details>`（項目・割合・向き）。展示前で集計が無ければ「展示前のAIの見立ては準備中。展示後に切り替えると見られる」だけ |
| スライダー | `input type="range"`（ラベル「似ている順に」）。段は spec B-4（最後の段は層の件数）。値の表示「{n}件」 |
| 類似レースの説明 | h3「類似レース」の下に spec B-3 の文 |
| ソナー | 外枠は `role="group"`（aria-label「今日に似た過去レース{n}件」）。点は `role="button"`（aria-label「{日付} {会場}{R}R 1着{艇番}号艇」）。扇は `role="button"`（aria-label「{艇番}号艇が勝ったレース {k}件」）で、押すと「どの艇が勝った？」の棒と同じ動き |
| 何が似ている？ | `<details>`（summary「何が似ている？（項目ごとに、今日と同じだった割合）」）。行に項目名・「今日: …」・「57%（近いも含め93%）」。中の `<details>`（summary「全33項目（近さの計算に使わない項目も含む）を見る」）に `<table>`（列見出し「項目（今日の値）」「同じ（{n}件中）」「近いも含む」「全レースで同じ割合」） |
| 1件ずつ見比べる | `<details>`（summary「1件ずつ見比べる（今日と全項目を並べる）」）。行は button（名前に「{日付}{会場}{R}R」「同じ{a}・近い{b}・違う{c}」）。押すと `aria-expanded="true"` で全項目の比較 |
| 類似レースの決まり方 | h3「類似レースの決まり方」。「どの艇が勝った？」の棒は button（名前「{n}号艇 {p}% {k}件」）、押すと吹き出し（`role="status"`）を出し、同時に「着順の流れ」をその艇が勝ったレースに絞る（もう一度押すと戻す）。凡例に「点線: {比べる相手の名前}{件数}件」 |
| どう決まった？ | 見出し「どう決まった？」。行「逃げ 64% 9件」 |
| 着順の流れ | 見出し「着順の流れ」。`role="group"` の button「すべて」「1号艇以外が勝ったレース」（`aria-pressed`）。サンキーは `role="img"`、帯・四角は `role="button"`（aria-label「1着 1号艇→2着 2号艇 3件」） |
| よく出た3連単 | 見出し「よく出た3連単」。行「1-2-4 21.4% 3件」。`<details>`（summary「残り{k}通りを見る（全{m}通り）」） |
| 展開シナリオの数えるレース | `role="group"`（ラベル「数えるレース」）の button（`aria-pressed`） |
| ①進入 | 見出し「進入はどうなる？」。`role="group"` の button（名前に型・割合・「1号艇の1着率xx%」、30件未満は「N件（少ないので1着率は出さない）」）。展示後に当てはまる型の名前に「今日の展示」 |
| 手がかり | 見出し「今日のスタートの手がかり」。`role="group"`（ラベル「使う平均ST」）の button「このコース」「全体」。`<table>`（行見出し「このコース」「全体」「{会場}で」「{会場}の全選手（コース別）」「今日の展示」）。当てはまる条件は button（名前に条件と「→ 過去、{形}になったのは…」） |
| ②スリットの形 | 見出し「スタートはどう並ぶ？（スリットの形）」。`role="group"` の button 8つ（「どの形でも」と7つの形、`aria-pressed`）。名前に形・割合・件数・1号艇の1着率 |
| ③攻め | 見出し「攻めは決まった？（攻める艇と1号艇の着順）」。形を選ぶ前は案内の1行。選んだ後は `<table>`（セル「36%（16/45）」、50件未満は「少ない」） |
| ④結果 | 見出し「②の形のとき、どう決まった？（③の順位では分けていない）」。件数、「1着になった艇」「3着以内に入った艇」「どう決まった？」「万舟（3連単1万円以上）」「着順の流れ」「よく出た3連単」。30件未満は割合の代わりに一覧（listitem に「日付 会場 R 進入 1〜3着 決まり手 払戻」） |
| 使っている項目 | `<details>`（summary「使っている項目（どの数字から出しているか）」） |
| URL | `/race/:raceId`、タブ「AI予想」 |
