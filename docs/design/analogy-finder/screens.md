# アナロジー・ファインダー screens

元: [spec.md](./spec.md)。置き場所はレース詳細の AI予想タブ（`src/components/race/RaceAiPredictionTab.jsx`）内の新しい節。既存の展開予測・イン崩れ・出現パターンのブロックはそのまま残し、その下に足す。

## 画面

### S-1 レース詳細 > AI予想タブ（既存画面の拡張）
- 既存ブロック（PredictionCard / TurnPatternList / VolatilityDisplay / OutcomePatternPreview）の下に「アナロジー・ファインダー」節を足す
- 節の中は3つの切り替え（①寄与度 ②類似レース ③組み合わせ）。②③は同じ類似レースの集合を使うので、件数スライダーは②③共通の場所に置き、①では隠す
- 中止確定のレースは既存どおり節ごと出さない（`isCancelled`）。それ以外の分岐（確定後・予想が無い・未確定）ではすべて出す。予想（predictions）の有無とは切り離す
- 発走前のデータ段を節の見出しの下に1行で出す（例: 「出走表 7:30 時点のデータ（前日までの成績）」）

App.jsx 側にこの節は置かない（レース詳細のタブにだけ出す）。共通化の対象は無い。

## コンポーネント

新規はすべて `src/components/race/analogy/` に置き、`src/components/race/index.js` の barrel export に足す。

| コンポーネント | 新規/既存 | 役割・主要素 |
|---|---|---|
| `AnalogyFinderSection` | 新規 | 節の外枠。3つの切り替え、データ段の表示、②③共通の件数スライダー。データ取得のフックを呼ぶ |
| `ContributionView`（FR-1） | 新規 | テーマ別の相対シェア。レーダー（recharts `RadarChart`）または横棒（recharts `BarChart`）。着順タブ（1着／2着以内／3着以内）、詳細条件（グレード・ラウンド・艇番比較）の折りたたみ、n・期間・モデル版、n<30 の小標本フラグ |
| `ContributionBreakdown` | 新規 | テーマを押したときの内訳。似た意味の項目をまとめ、個別値は参考の注記 |
| `BoatCompareTable` | 新規 | 艇番2つの比較表（テーマ／艇番A／艇番B） |
| `SimilarRacesView`（FR-2） | 新規 | 分布の4ブロック（決まり手6分類・1着艇・1着の進入コース・出目トップ3）、n・期間、事故情報の常設注記、類似レース一覧 |
| `SonarChart` | 新規 | 自作 SVG（viewBox）。中心＝今日、同心円＝近さの順位（上位○件）、6扇形＝艇番、光点＝過去レース。件数を絞ると自動ズーム。光点⇄一覧行の双方向ハイライト |
| `NeighborCountSlider` | 新規 | 近い順に100／200／400／800件の4段のスライダー（既定800件）。値は端末内に保存 |
| `CombinationView`（FR-3） | 新規 | サンキー図、組み合わせ一覧（上位10件）、干渉効果のコールアウト、「1号艇以外が1着」の切り替え |
| `FinishSankey` | 新規 | 自作 SVG。1着→2着→3着の3段を常に出す。少ない流れも艇の色のまま薄く描く（まとめない）。帯タップで件数・%。帯とノードは艇の公式色、1号艇の白は枠線つき |
| `BoatBadge` | 既存を共通化 | 今は `RaceOddsListTab.jsx` 内のローカル関数。本機能でも使うので `src/components/race/BoatBadge.jsx` に切り出し、色は `src/utils/colors.js` の `BOAT_COLORS` を使う（2箇所以上で使うため共通化の規約に該当） |
| `RaceAiPredictionTab` | 既存を拡張 | 末尾に `AnalogyFinderSection` を足すだけ。既存ブロックは触らない |

recharts のサンキー（`Sankey`）は帯の色を艇ごとに変える・帯タップで件数を出す・細い帯を薄く描き分ける、の3点を自前で描くほうが単純なので使わない。

## データ取得

| フック | 中身 |
|---|---|
| `useAnalogyContribution(venueCode, grade, round, finishTarget)` | 永続化した SHAP 集計（モデル版つき）を読む |
| `useAnalogyNeighbors(raceId)` | スナップショット（BOA-627）の近傍800件を読む。②③で共有し、件数 N の絞り込みは画面側で先頭 N 件を数え直す |

テーブル・RPC・Edge Function の形は `/step2` で決める。

## デザイントークンと CSS

- トークンで足りる部分: 余白（`--space-*`）、文字（`--font-size-*`）、カード（`--surface-card`）、文字色（`--text-primary` / `--text-secondary`、ダークモードで反転するもの）、境界線
- 艇の公式色: `src/utils/colors.js` の `BOAT_COLORS`（JS 定数）を SVG の fill に渡す。CSS 変数は新設しない
- 新規 CSS が要る部分: ソナーとサンキーの SVG の配置、帯のハイライト、比較表の列。クラス名は `af-` 接頭辞（`.af-sankey-band` 等）で衝突を避ける（`verify:css-collisions`）
- 375px で横スクロールなし。サンキーは幅に合わせて viewBox で縮め、ラベルは艇番だけにする。`e2e/layout.spec.js` に AI予想タブの節を足す

## 画面の構造と操作要素（受け入れ E2E の前提。2026-10-01 に決めた）

| 対象 | 形 |
|---|---|
| 節 | `<section aria-labelledby>`。見出し（h2 相当）は「アナロジー・ファインダー」 |
| データ段 | 見出しのすぐ下に1行。「出走表 7:30 時点のデータ（前日までの成績）」。確定済みのレースでも同じ表示に「（発走前）」を付ける |
| 3つの切り替え | `role="tablist"` の tab。名前は「寄与度」「類似レース」「組み合わせ」。各パネルの中に同じ名前の見出し（h3 相当）を置く |
| 着順タブ（FR-1） | tab。「1着」「2着以内」「3着以内」 |
| 詳細条件（FR-1） | `<details>`（summary「詳細条件」）。中の select は閉じていても DOM にある。グレード（一般／G3／G2／G1／SG）・ラウンド（予選／準優勝戦／優勝戦／その他）の select（ラベル「グレード」「ラウンド」） |
| 艇番比較（FR-1） | チェックボックス「艇番で比較」と、艇番A・艇番B の select。オンにした時点で既定の 1号艇・6号艇 の比較表が出る |
| テーマの内訳（FR-1） | 各テーマは button（`aria-expanded`）。押すと内訳が開き、「個別の値は参考」の一文が出る |
| n の表記 | FR-1:「n=1,234レース（7,404艇）」、FR-2・FR-3:「n=800」。期間は「2019-04〜2025-12」。モデル版は「モデル 2026-10-05」 |
| 小標本 | n（レース数）<30 のとき「小標本」 |
| 件数スライダー（FR-2・FR-3） | `input[type=range]`（0〜3 の4段）。ラベル「見る件数」、`aria-valuetext`「近い順に800件」、横に「800件」を表示。値は端末内に保存し、レースをまたいで引き継ぐ |
| 分布（FR-2） | 見出し「決まり手」「1着の艇番」「1着の進入コース」「よく出た出目」。各ブロックに n と期間 |
| 光点・一覧行 | 光点は表示中の N 件すべて。`<button>` 相当（`aria-label`「2025-05-03 大村 3R、近さ12位」）。一覧行は listitem で、同じ「日付 会場 R」を含む。選ばれた一覧行は `aria-current="true"`、選ばれた光点は `aria-pressed="true"` |
| サンキーの帯（FR-3） | `role="button"`・`aria-label`「1着 1号艇→2着 2号艇 14件 10.9%」、2段目は「2着 3号艇→3着 4号艇 9件 7.0%」。%の分母は図全体の n。押すと同じ文言を図の下に出す |
| 1号艇以外の切り替え（FR-3） | トグルボタン（`aria-pressed`）「1号艇以外が1着のレースだけ」。オンのとき図の下の n はその件数に変わる。件数スライダーはそのまま |
| 組み合わせ一覧（FR-3） | 組み合わせは「1-2-3」の形。上位10件＋「その他」の1行（常に出す。0件なら0%）。合計100%（丸め誤差を除く）。行は listitem |
| URL | レース詳細は `/race/:raceId`。AI予想タブはタブ名「AI予想」 |
