# 当初の想定と分析の結果（BOA-271 アナロジー・ファインダー）

当初のモック v6（https://claude.ai/artifact/9oj6muu3iBcU3vXY86xFtk）が置いていた想定ごとに、分析で何が分かり、想定をどう変えたかを並べる。モックや仕様を直すときは、この表を先に見て、消してはいけない機能と、変えた理由を確かめる（2026-10-03、ユーザー指摘「個別に分析したことで、一貫性と当初の思想が消えている」を受けて作成）。

## 当初の思想（変えていないもの）
- 3つの切り口を1本の流れで見る: ①何が着順に効くか（単独で効く要因）→ ②過去の似たレースはどうなったか → ③1着・2着・3着の組み合わせ（艇同士の干渉）
- ①〜③は、上で選んだ条件（会場・グレード・ラウンド）・着順・艇を共有する。②と③は同じレースの集まりを見る
- ①はテーマ（六角形）から要素（艇番・会場・勝率まわり…）まで掘れる。数値はテーマにも要素にも出す
- 結論を言い切らず、件数と分布を見せる
