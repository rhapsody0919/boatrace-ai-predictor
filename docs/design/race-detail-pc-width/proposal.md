## visual-designer の評価（要旨）
- 推奨 A。C は見出し左・中身中央で左端が2本になり今より悪い。B は 1920 で注記が約800pxの長い行になり、結果の着順で名前と ST が1000px以上離れる（「左寄り」は消えるが「間延び」が出る）
- 列 1200 でよい。6艇表は 15px で1艇の列 155〜165px、窮屈に見えない（BOA-612 の判断は文字を 15px に上げる前）。1280・1360 は 1440 での左右の空きが 40 以下になり、中央に置いた列に見えない。思考アシストの列 1200（BOA-880）とも合う
- 直す点（A に反映済み）: 結果の2段の上端そろえ、思考アシストの入口の帯が 720 で浮く、切り替えの帯が列の外、AI予想が左の 344px に寄る、枠別のコース別成績が 1200 に伸びて数字が約350px離れる
- 残り（実装時）: オッズ一覧の注意書きと帯の右端 16px のずれ、モータ情報の注記の縦積み
- e2e の決まり案: 列 colW=min(vw−48,1200)・colL=(vw−colW)/2 に、パンくず・h1・帯・タブ・タブの中身の直下の子・攻略ガイド・その他のレース・思考アシストの切り替え・本体・フッターをそろえる（±1px）。タブを切り替えても x・幅が同じ。6艇表の1艇の列 ≥150px。2段のセルは上端が同じ、右のセル ≥300px、文章のセル ≤600px。720 の上限の要素は 2段の左のセルの中にだけ置く。375・768 は今の値のまま
