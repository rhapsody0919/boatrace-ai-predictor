## 位置づけ

- 龍神レーダーは、ブラックボックスの予想をなるべくしない。過去のデータで「どうだったか」を見せる（analogy-finder spec「位置づけ」）
- 展開予測（AIが出す1マークの決まり手の確率）は、龍神ソナーの展開シナリオと思考アシストの展開レンズが過去の実績で同じ問いに答えるので、画面から外す
- イン崩れ注意度は、0〜100 の会場内の順位（指数）をやめ、「1号艇と他の艇の勝率差が今日と同じ帯の過去レース（全国）で、1号艇が1着を逃した割合」にする。値を作る時刻・保存・画面への流れは今の指数のまま（案Y。改修を小さくするため）
- 検証（round1〜3）: 当てる力（AUC、2026-09-22〜10-10 の 2,869R）は今の指数 0.664、案Y の値 0.677、類似レースの割合 0.684。案Y の値は今の指数より Brier −0.0050［−0.0085, −0.0013］、長期では展開予測の値を抜いた指数より AUC +0.0069［+0.0040, +0.0097］（round4）。当てる力の大半は勝率差1つから来ていて、平均ST は勝率と一緒だとほぼ効かない。画面では「よく当たるようになった」とは言わない
- 類似レースの割合（今日と出走表が近い過去レース）は、注意度の値にはせず、龍神ソナーへの導線で見せる

### FR-2 イン崩れ注意度の値（P0）

- 値: 勝率差（1号艇の全国勝率 − 2〜6号艇の最高の全国勝率、前日まで）を0.5刻みの帯（端は「−3.5未満」「+3.0以上」にまとめる。統計検証の clamp(floor(差/0.5), −8, 6) と同じ。2026-10-13 に「−4.0未満」の書き違いを直した、plan §1）にし、その帯の全国の過去レースで1号艇が1着を逃した割合と件数
- 帯の割合の期間: 全期間（2019-04〜前日）。全期間・3年・2年・1年で当てる力の差は Brier 1/10,000 未満で、全期間なら帯の件数が十分（1%点で5,000件超）（round4）
- 帯の割合はラウンドで分ける: 「準優」「優勝戦」「それ以外」。準優・優勝戦は勝率差による差がつきにくく、分けないと率が高く出る（準優は予測 36.4% 対 実際 27.6%、分けると較正のずれ 17.0pt→4.6pt、round4）。準優・優勝戦には「勝率差による差がつきにくい」の注記。帯（ラウンド×勝率差の帯）の前日までの件数が100未満なら注意度を出さない。100〜299件は出して「件数少なめ（n件）」を付ける（2026-10-13 ユーザー決定。出さないのは 2025-06〜2026-10-10 の完全レースの 0.04%（準優 0.77%・優勝戦 0.17%）、件数少なめは 0.23%（優勝戦 8.05%）。[analysis/sparse-cells.md](./analysis/sparse-cells.md)）
- 欠場の艇がいるレース: 1艇欠場で1号艇が出るレースは、残りの艇で勝率差を出して同じ帯の率を使い、「欠場あり（5艇）」と注記（AUC 0.667、3,983R、round4）。1号艇が欠場したレースは出さない。2艇以上の欠場は件数が少なく未検証なので出さない
- 母集団: 完全レース（中止・不成立・出走前の欠場を除く）。1号艇が F・L のレースは「1着を逃した」に含める（round1 と同じ）
- 作る所・時刻: 今の指数と同じく、朝の予想の生成（`generate-unified-predictions.js`）。帯ごとの割合は、夜に作る「日×帯」の小さな表を朝に RPC で期間を指定して合計する（[architecture-y.md](./architecture-y.md)）。保存は新しいキー `inCaution`（`volatilityPercentile` の意味は変えない）
- 勝率差は 1/100 の整数で計算する（浮動小数では 0.041% のレースが下の帯にずれる、round4）
- 勝率が無い艇がいるレース（新人等）: 1号艇に勝率が無ければ出さない。2〜6号艇は勝率のある艇の最高で出す（plan で確定）
- 時点の固定: 朝に保存した値を発走後・確定後も出す（今と同じ）
- 受入基準: 例のレースで、注意度の割合・件数が、同じ帯の過去レースを DB から出し直した値と一致する（data-accuracy-verifier）

### FR-3 イン崩れ注意度の見せ方（P0。置き場所はモックで決める）

- 大きい数字: 「1号艇と他の艇の勝率差が今日と同じくらいのレース（全国 {n}件）で、1号艇が1着を逃したのは {p}%」と、基準「全国の全レースは {b}%」との比較（棒と点線）
- 段階: 3段（35%未満・35〜55%・55%以上）。案Y の値でも長期・19日分とも段の区間が重ならない（実際の非1着率 26.7／42.6／65.5%、入る割合は約25／45／30%、round4）。段の言葉は wording-editor とモックで決める。0.7/0.3 の旧閾値は使わない
- 理由: 勝率差（「1号艇 {a}、他の艇で一番高い {x}号艇 {b}」）の1つだけ。ほかの材料は下の「ほかの材料（展示・モーター等）は龍神ソナーの『差がつく材料』で」の1行で龍神ソナーに渡す（承認したモック mock/1-ai-tab-375.png のとおり。2026-10-13 に plan で、2つめ以降の理由を出す当初の案をモックに合わせた。v16 の材料は朝 5時台の生成では読めない）。平均ST は出さないので BOA-818 の期間の食い違いは画面から消える
- 導線: 龍神ソナー（類似レースでの割合・差がつく材料）と思考アシスト（ja のみ）へ
- 置き場所: AI予想タブの先頭（案A、2026-10-12 ユーザー承認、[mock/APPROVED.md](./mock/APPROVED.md)）。その下に出現パターンを残す。今の「龍神ソナーへの案内」ボタン（`ai-tab-sonar-link`）はカードの導線と行き先が同じなので外す
- 確定後: 同じカードに「結果: 1号艇は{n}着」の1行を足す（1レースの当たり外れの判定は出さない）
- 段の札: ! 崩れやすい（塗り。承認時は ▲、2026-10-18 オーナー決定で予想の印と重ならない ! に）／中くらい（枠線だけ）／堅め（塗り）。色は意味トークンに置き換え、ダークモードでも 3:1 以上
- 棒: 基準（全国の全レース）の点線の真上に値、棒の下に3段の範囲の帯、両端に段の名前（visual-designer、mock-reviews-v1.md）
- 理由の下に「ほかの材料（展示・モーター等）は龍神ソナーの『差がつく材料』で」の1行
- 出現パターン（`OutcomePatternPreview`）はAI予想の本命に依存する予想。今のまま残す
- 0〜100 のバー（`VolatilityPercentileBar`）・`RaceMoodEffect`・「会場内パーセンタイル」の言葉はやめる
- 4言語（AI予想タブ・基本情報タブは翻訳対象）
- 受入基準: 375px・1440px で大きい数字・件数・基準・理由・導線が出る。0〜100 の数字が出ない。禁止語が無い

### FR-4 思考アシスト「堅い？荒れる？」の1着のバー（P1、(a) をユーザー承認）

- 見出しの「1号艇の1着」のバーを、注意度の裏返し（100−p%）にする。行に範囲の名前と件数（「勝率差が同じくらい 35,181件」）
- 万舟のバーは今の範囲（級の並び）のまま、行に範囲の名前と件数（「級の並びが同じ {n}件」）
- 枠の下に「1号艇の1着 {100−p}% は、イン崩れ注意度 {p}%（1着を逃した割合）の裏返し」の1行
- 受入基準: 同じレースで、AI予想タブの注意度と思考アシストの1着のバーの和が 100% になる

### FR-5 一覧・ホーム・/today・SNS の値の置き換え（P0）

- レース一覧のバッジと色線、ホームの今日のハイライト（上位・下位）、/today の各行の表示と注目レースの選び方（`digestMetrics.js` の方向一致度）、SNS のネタの本文・企画の判定（`snsCampaigns.js` の閾値）を、FR-2 の値と FR-3 の3段に置き換える
- 値を作る時刻は今と同じなので、/today（05:30）にも入る
- /today の説明・用語集の「当日の条件からAIが算出した」をやめ、FR-2 の中身で書く
- 受入基準: 同じレースで、一覧・ホーム・/today・AI予想タブの値と段が一致する

### FR-6 /accuracy を帯ごとの実績ページに作り替える（P1）

- 注意度の3段ごとに、実際に1号艇が1着を逃した割合・件数・ぶれ幅（Wilson の95%区間。「同じ日・同じ会場に偏るので、実際の幅はもう少し広い」と添える）。各棒の下に段の範囲の帯、全国の全レースの点線
- 「公開後」と「公開前の検証（2025/6/1〜2026/10/10）」を切り替えて出す（ユーザー承認）。公開前の検証は、公開前のレースに同じ作り方の値（前日までの過去レースだけで作る）を当てはめた結果（round4 の L、75,295レース）。公開後は公開日から起算し、旧指数の実績は出さない
- 公開後の段の件数が30レース未満のうちは、割合を出さず件数だけ（「30レースに届いた段から割合を出す」）
- 受入基準: 段ごとの率・件数が DB から出し直した値と一致する（data-accuracy-verifier）

## 制約・前提

- データ源: 本番 DB の出走表・全国勝率（前日まで）・結果。長期（2019-04〜2025-12-02）は kb_archive
- 本番 DB の変更はマイグレーション。RPC の CREATE OR REPLACE は最新の定義（109・110）を土台にし、適用後に `verify-rpc-output-keys.js`
- 用語: 「競艇」「似た」「似ている」「数える」「ふつう」「いつも」を画面・モック・説明に書かない（wording-editor で検査。「集計」「算出」「対象」は禁止語ではない、2026-10-12 docs/knowledge/glossary.md）。数字には単位（%・件）
- AI予想の免責文は残す。注意度は結果を保証しない旨の注記を引き継ぐ
