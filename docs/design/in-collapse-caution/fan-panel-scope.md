# ファンパネル: 展開予測を消す範囲とイン崩れ注意度の中身（BOA-822、2026-10-11）

`discussion-panel` の4人（20代男・20代女・30代男・30代女）。同じモデルのロールプレイなので仮説。検証はモックの承認と公開後の実データで行う。前提の事実は [inventory.md](./inventory.md)。

## 論点1: 展開予測を消す範囲

- 20代男: 「まくり35%」と出ても根拠が見えない。ソナーの展開シナリオの「もしこう並んだら」の方が納得できる。AIタブだけ消して、レース一覧の的中バッジと的中実績が残ると、見られない予想の当たり外れだけが出る。全部消してほしい
- 20代女: 一覧の的中バッジは見ていない。画面で確かめられない予想の的中率を出されても信じようがない。消すなら一緒に
- 30代男: 答え合わせは好き。展開予測が消えるなら、イン崩れ注意度の答え合わせ（注意度が高かったレースで実際に何%崩れたか）を残してほしい。1レースの当たり外れより、帯ごとの実績の方が信用できる
- 30代女: 進入・スリットの話はソナーと思考アシストで足りる。3か所目は要らない

**結論**: 展開予測は画面から全部消す（AI予想タブ・一覧の的中バッジ・的中実績・精度ページの展開予測の数字・シェア文）。割れたのは答え合わせの扱いで、30代男の案（イン崩れ注意度の帯ごとの実績で置き換える）を採る。

## 論点2: イン崩れ注意度は何を見せるか

- 20代男: 0〜100 の指数は「99」が「崩れる確率99%」に見える（BOA-706 で実際にあった）。「同じ条件のレースで1号艇が1着を逃したのは42%（全国の全レースは45%）」の方が分かる
- 20代女: 思考アシストの「堅い？荒れる？」と同じ問いなら同じ数字でないと困る。AIタブで38%、アシストで45% は一番混乱する
- 30代男: 指数の良さは今日の全レースを並べられること。ホームの「今日のイン崩れ注意」から買うレースを選んでいる。過去の実績の割合でも全レースで並べられればいい。並べた値が本当に当たるのかは数字で見せてほしい
- 30代女: 何で荒れそうなのかを知りたい。「1号艇の平均ST（直近30走）が6艇で5番目」のように、ソナーの差がつく材料と同じ言い方で理由を出し、詳しくはソナーへ

**結論**:
1. 主役は過去の実績の割合（今日と条件がそろう過去レースで1号艇が1着を逃した割合・件数・基準との比較）。0〜100 の指数はやめる。ただし、どの出し方（級の並び／類似レース／小さいモデル）にするかは当たり方の検証で決め、過去の実績の割合が今の指数より明らかに劣るなら指数を残す案に戻す
2. 思考アシストの「堅い？荒れる？」と同じ定義・同じ値にする（3か所で別の数字を出さない）
3. 理由は v16 の材料の言い方（期間つきの平均ST など）で最大3つ。詳しくはソナー・思考アシストへの導線
4. 今日の全レースを並べる場面（ホーム・レース一覧・/today・SNS）は残す

## 割れたまま残った点（モックで比べる）

- 置き場所: 20代男は「AIと名の付くタブに過去の実績の値を置くのは変」、30代女は「タブを開かなくても最初に見えるところに」。展開予測が消えると AI予想タブに残るのはイン崩れ注意度と出現パターンだけになる。モックで「AI予想タブを残してイン崩れ注意度を主役にする」と「AI予想タブをなくし、基本情報の上部に1行＋ソナーへの導線」を並べる

## 知見ノートに足す行

- 0〜100 の指数は「確率」に読まれる。過去の実績の割合（件数・基準つき）の方が伝わる（BOA-822 ファンパネル 2026-10-11、BOA-706 の実例）
- 同じ問い（1号艇が飛ぶか）の数字は、画面が違っても同じ値にする。違うと一番混乱する（同上）
- 1レースの当たり外れより、帯ごとの実績の方が信用される（同上）
