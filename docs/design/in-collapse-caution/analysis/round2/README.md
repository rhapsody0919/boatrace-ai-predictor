# 統計検証 第2回: 類似レースの割合（C2）を長い期間で作り直して比べる（2026-10-11、data-scientist）

やり直しの上限3回のうちの2回目。記号は [第1回](../round1/README.md) と同じ。結果の正は `result2.json`。

## 作り方

- C2 は v16_morning・v16_similar の関数（そろえる条件・SHAP 重みの距離・会場違いの λ・上位400件・展示前）で過去のレースに作り直した。候補はそのレースの前日まで。重みは本番と同じ版 2026-10-06 のモデル
- 再現の確認: snapshot（2026-10-06〜10、733R）と照合。層の件数は 95.2%、1号艇の1着数は 96.3% が一致し、C2 の差の平均は 0.00017
- 長期は標準化を月ごとに直した近似（日ごととの差は最大 0.0025）

## 結論

- 当てる力は C3 ＞ C2 ＞ O'・O・C1。C2 は C3 に少し届かないが、今の指数と C1 よりはっきり良い
- C2 と C3 の差は「堅い」側に出る（下位10%の非1着率 23.9% 対 18.3%）
- 層が400件未満のレース（4.2%）では C2 の当てる力が落ちる（AUC 0.651、167R で区間は未検証）。全国の率に寄せる縮小は効かない（m=0 が最良）
