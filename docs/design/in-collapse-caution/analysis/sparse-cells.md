# 件数の少ない帯で注意度を出さないレースは何件か（BOA-822、2026-10-13）

ユーザーの質問「実際にどれくらいのレースでイン崩れ注意度がない状態になるの？」への回答（Orchestrate 経由）。推測ではなく、統計検証の元データ（round1 の races.pkl、完全レース 410,994、2019-04-01〜2026-10-10）を数えた。

- 定義は [plan.md](../plan.md) §1。セル＝(ラウンド, 勝率差の帯)。ラウンドは準優・優勝戦・それ以外（一般と予選は同じ「それ以外」の率を使う）。セルの件数は 2019-04-01〜前日の完全レース
- **出さない**＝セルが無い、または前日までの件数が100未満。**件数少なめ**＝100〜299件（出して「件数少なめ（n件）」を付ける）
- 分母は完全レース。欠場などで完全レースでないレース（期間内に 1,012）は分母に入れていない（1艇欠場のレースは残りの艇で出す。1号艇の欠場・2艇以上の欠場は別の理由で出さない）
- スクリプト: `scripts/analysis/in-collapse-caution/round4/sparse_cells.py`、結果: `data/analysis/in-collapse-caution/round4/sparse_cells.json`

## 読み方

- 出さないのは全体の 0.04%（30日で2レース）で、ほぼ準優の「1号艇が他より2.5以上弱い」レースに限られる。優勝戦は件数少なめ（8%）の方が多い
- セルの件数は日ごとに増えるので、出さないレースは時間とともに減る
