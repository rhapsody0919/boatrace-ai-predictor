### 3.2 モバイル（幅 480px以下。既存のモバイル余白ルール: padding・gap 0.75〜1rem）

```
┌───────────────────────┐
│ ピットレポート（選手コメント）    │
│ 出典: BOAT RACE オフィシャル   │
│ ウェブサイト ピットレポート     │
│ レポーター: 八王子　スゴ六      │
│ 取得: 9/18 15:42             │
│ [ 公式サイトで見る ↗ ]         │←全幅ボタン（タップ領域44px以上）
├───────────────────────┤
│ ①  西山 貴浩 A1    前走 7R   │←1行目: 枠番チップ・氏名・級別・前走
│ 整備をしたけど、前半レースは良 │
│ くなかった。急いでリングを外し │←本文は全幅・全文・折りたたまない
│ ます。                       │
│ コメント自信度 ★☆☆          │←2行目右寄せ、または本文の下
├───────────────────────┤
│ ②  若林 将  A1    前走 2R    │
│ …                           │
└───────────────────────┘
```

- 1艇1カード（縦積み）。表（`table`）にせず、カードのリストにする（本文が20〜115字で、表の1セルに収めると、モバイルで縦に潰れる）
- 本文は`white-space: pre-wrap`（改行を保持）、`overflow-wrap: anywhere`。**切り詰め・折りたたみ・「続きを読む」は使わない**（改変・要約をしない要件。全文を既定で表示）
- 枠番チップは、既存の`BOAT_COLORS`（`src/utils/colors.js`）と、`DataRaceTable`・`RaceBeforeInfoTab`と同じ配色（1白・2黒・3赤・4青・5黄・6緑）
- 氏名は`translate="no"`（ブラウザの自動翻訳で名前が壊れるのを防ぐ。`.claude/CLAUDE.md`の共通ルール）。氏名・級別は、タブが既に持つ`players`（出走表）から枠番で引く（公式ページのHTMLに由来する氏名は保存していない）。`players`に無い艇（欠場等）は、登録番号（`racer_id`）のみ表示
- 前走: 「前走 7R」（`previous_race_number`がNULLなら表示しない）。公式ページのリンク先（前走の結果）は、内部の結果タブへ誘導せず、テキストのみ（YAGNI）

### 3.3 コメント自信度（★）の表示

- 公式は、★（塗り）と☆（空）の3つ組（★☆☆・★★☆・★★★）。**公式と同じ、3つ組のまま**表示する（`confidence_stars`が0〜3）
- 見た目: 「コメント自信度」の小さいラベル＋★☆☆（塗りは強調色 `--brand-accent-primary` 等のデザイントークン、空は`--text-secondary`の薄い色）。色だけに依存しない（★の形で区別できる）
- アクセシビリティ: `aria-label="コメント自信度 3段階中1"`、視覚の★は`aria-hidden`
- 自信度が付かないコメント（`confidence_stars`がNULL。「【取材者寸評】」の形式）: ★の行を**出さない**（0や「なし」と誤読させない）
- 自信度の意味の説明: `TermHintButton`（既存のヒント。説明文は`src/components/race/termHints.js`の`TERM_HINTS`に日本語で持つ）に、キー`pitConfidence`を追加し、「公式のレポーターが付けたコメントの自信度（★が多いほど自信あり）。当サービスの評価ではありません」を置く案

### 3.4 出典表記の位置（spec.md §4.2）

| 要素 | 位置 | 内容 |
|---|---|---|

| レポーター | 出典の下（**表示の要否はユーザー判断**。spec.md §4.3の2） | 「レポーター: 八王子　スゴ六」（公式の表記のまま） |

## 4. 状態

| 状態 | 条件（`getRacePitReport`の`state`と、レースの状況） | 表示 |
|---|---|---|
| **コメントあり** | `state === "published"` | 3.1〜3.4の全体 |
| **公開待ち** | `state === "pending"`（行なし）、かつ、対象になりうるレース（SG全レース、G1・G2の7R以降）、かつ、発走60分前〜結果確定前 | 小さいカード: 見出し「ピットレポート（選手コメント）」＋「まだ公開されていません。公開されると表示されます。」＋「公式サイトで見る ↗」。自動更新はしない（タブを開き直す・ページを再読込で取得。他のタブと同じ） |
| **対象外・非表示** | `state === "not_target"`、または、対象外のグレード（G3・一般戦・ippan）、G1・G2の1R〜6R、または、公開待ちの条件から外れた（発走60分より前、結果確定後で行なし） | **セクションごと出さない**（空のカードも、「対象外です」の文言も出さない。95%のレースで、タブが空にならない） |
| **読み込み中** | 取得の途中 | 見出し＋`drt-loading-chip`（既存のローディングチップ）。カードの高さを確保して、レイアウトのずれ（CLS）を避ける |
| **取得エラー** | 例外（ネットワーク・権限） | 見出し＋「ピットレポートを読み込めませんでした。」＋「再読み込み」ボタン。**「対象外」「未公開」に化けさせない**（BOA-359の教訓）。ただし権限エラー（086が未適用）は、セクションを出さない（本番の公開順序の保険） |
| **コメントの一部が無い** | 6艇のうち一部だけコメントあり | コメントのある艇の行だけを出す（枠番順）。無い艇は行を出さない（「コメントなし」とは書かない） |

- 「発走60分前〜」の根拠: 取得ジョブの窓の開始（`pit_reports`の`offsets: [-60]`）。窓の前は、行が無いのが正常で、公開待ちと書くと、最終日のG1・G2の7R〜11R（対象外）で、誤って「公開待ち」を出す（対象外の行が入るのは、窓が始まってから）
- **結果確定後で行なし**（対象なのに、コメントが取れなかったレース）: セクションを出さない。過去日のレース詳細を見たときに、公開待ちが残り続けないようにする

## 5. 多言語

- コメントの本文（日本語の自由記述）は、翻訳しない（`lang="ja"`を付ける）。UIの文言（見出し・出典・ボタン・注記・状態）のみ、4言語（ja/en/zh-TW/ko）の`pitReport.*`キーを追加する
- 非ja言語では、セクションの注記に「コメントは日本語の原文のまま表示しています」を加える
- レース詳細は多言語対応済み（`/race/:raceId`の言語別URL）。3区分は「翻訳対象」のページ内の、ja専用のコンテンツ（コメント）を含む、という位置づけ

## 9. データの契約（画面が読む形。詳細・却下した案は [plan.md §3](./plan.md)）

画面は、**RPCを増やさず、`race_id`単位の単独のSELECT**（`race_pit_reports`と`race_pit_comments`の2回）で読む。`supabaseDataService.getRacePitReport(raceId)`が、次の形にして返す（`withCache` 30分。失敗は例外で、「対象外」「未公開」に化けさせない）。

```
GET /rest/v1/race_pit_reports?race_id=eq.{raceId}&select=status,target_from,target_to,reporter_name,comment_count,created_at,updated_at
GET /rest/v1/race_pit_comments?race_id=eq.{raceId}&select=boat_number,racer_id,comment_text,confidence_stars,previous_race_number&order=boat_number.asc

→ { state: "published" | "not_target" | "pending",   // 行なし=pending
    reporterName, capturedAt, updatedAt, targetRange: {from,to}|null,
    comments: [{ boatNumber, racerId, text, stars: 0..3|null, previousRaceNumber: number|null }] }
```

- 呼ぶ条件（リクエストを減らす）: `raceGrade`が SG・G1・G2 または不明（NULL）のレースのみ。SGは全レース、G1・G2は7R以降（`isPitReportCandidate`と同じ規則を画面側にも置く）。G3・一般戦・G1/G2の1R〜6Rでは呼ばない
- 匿名で読めるのは、マイグレーション086の適用後（085だけでは、SELECTが権限エラーになる）。画面のコードは、権限エラーを「セクションを出さない」として扱う
- 出典のURL: `raceId`（`YYYY-MM-DD-VV-RR`）から、`https://www.boatrace.jp/owpc/pc/race/pitreport?rno={RR}&jcd={VV}&hd={YYYYMMDD}`
