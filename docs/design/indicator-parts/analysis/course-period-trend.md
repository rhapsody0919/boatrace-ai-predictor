# 選手の進入コース別成績を期ごとの線にしない（F-031 の例外、2026-11-28）

## 決定

オーナーの方針は「時系列で表せる指標は線にする」。ただし、選手ページの進入コース別成績（公式）を期ごとの線にする案（F-031）は作らない。

- オーナー 2026-11-28: 「推奨どおり例外にする」（窓口経由）
- 進入コース別は、今のまま直近3期の合算の棒と表で出す。1着率の棒・全選手の縦線・▲▼ の印は #3671 のまま。

## 理由（data-scientist、e2e の録画の183人・2,581行・2019年2期〜2027年1期、本番 DB は読んでいない）

1. **1期・1コースの走数が少ない。**
   - 中央値は A1・A2・B1 で15〜22走。
   - 1期で30走を超えるのは、全級の全期で見て 1コース 18%、2〜5コース 2〜4%、6コース 7%。
2. **期と期の差は大半が偶然。**
   - 1着率・2連対率・3連対率では、期→期の差の分散のうち偶然で説明できないのは 1〜14% だけ。
   - 1期の値の95%の幅の半分は ±14〜21pt で、本当の変化の SD（1.3〜6.0pt）よりずっと大きい。
3. **今の「直近3期の合算」の方が、次の期をよく当てる。**
   - 時系列で分けた当て（偶然の分を引いた RMSE）で、直前の1期より3期の合算が良い。6期の合算はさらに良い。
   - 例: 1コースの1着率で 10.9 → 7.3 → 6.3pt。
   - 期をまたいだ上下は、大半が平均に戻るぶれ。前からある期別の勝率の知見（期→期の変化の相関 −0.357）と同じ向き。
4. **平均ST だけは、少し動きがある。**
   - 期→期の差の 19〜43%、3期の束で 35〜57% が偶然で説明できない。外のコースほど高い。
   - ただ、勝率と一緒に見ると着順にはほぼ効かない（stat-findings の平均ST（1C）の行）。作る価値は低いので、線にしない。

## 見送った案（オーナーに画像で見せた物）

- 案A: 今の1着率の棒に、走数から見た偶然の幅（95%）の横線を足し、行を開くと期ごとの「◯走中◯勝」を出す。
- 案C: 選んだコースの平均ST を、3期ずつ束ねた点（30走以上、偶然の幅つき）でつなぐ。

## 言えないこと（未検証）

- 録画の183人は試験の対象に選ばれた選手で、全選手の代表ではない。A1 の1コースの中央値は、録画の29走に対して全選手で26走。
- 全選手（本番の racer_period_stats）での再計算はしていない。
- 平均ST の偶然の幅は、1走の SD を 0.064 と仮定している（選手ごとの違いは入れていない）。
