# 指標の族（カタログ）2026-11-23

入力: indicator-inventory の race.md（565行）・racer-tools.md（201行）・venue-list-accuracy.md（108行）・use-cases-draft.md。計約870行の棚卸しを「同じ問いに答える指標」の族にまとめた。読み取りと分類だけ。コード・本番 DB は触っていない。**数字・率・件数・窓は棚卸しの写しで未検証**（本書では確かめていない）。

> 行ID（r・rc・t・v・l・a）の出典の棚卸し（約870行）は大きいのでリポジトリに入れていない。族の定義はこの表を正とし、棚卸しの行は指標の定義を書く PR でコードから確かめ直す（system-architect 2026-11-23 の指摘）。数字・窓・閾値はどれも未検証の写し。

後半（6〜10の大分類・そろえるべき別計算・ユースケース×族）は `catalog-2.md`。

## 読み方

- 行ID の略記: `r`＝race-、`rc`＝racer-、`t`＝tool-、`v`＝venue-、`l`＝list-、`a`＝acc-。`r005-009` のように範囲で書く（本書では `r005〜r009`）。
- 種類: 公式（公式サイトの値そのまま）／集計（当社が数えた）／見立て（龍神のモデル・判定）。判定（札・並べ替え・注記）は 判定 と書いた。混ざる族は「集計（…は見立て）」のように書いた。
- 主語: 選手・艇番・進入コース・モーター・ボート・会場・レース・節・予想。**艇番（枠）と進入コースは別の主語**（前付けで入れ替わる）。「想定コース」は枠なり（艇番＝コース）を仮定した値で、前付けのとき外れる。
- 場面: R＝レース詳細、P＝選手ページ、V＝会場ページ、S＝節ページ、ホーム・/today・分析ツール・実績。
- 区別欄の **そろえる**＝同じ物の別計算（窓・母集団・数え方・表記の違い。1つの定義に寄せる）。**別物**＝本当に別の物（名前で分ける）。**最上位**＝同じ画面・同じ名前で値が違いうる物（後ろの一覧の A）。
- race.md は担当（A〜G）ごとに表と略記が分かれる。本書は全565行の名前・種類・主語・重なり欄・各担当の「重なり／食い違い」節から分類した。各行の計算・出所の細部は全行を読み直してはいない（個別の欄は読んだ範囲。分からない所は「未確認」）。
