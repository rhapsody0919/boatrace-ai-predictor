## 機械の検査（試作で入れる）

- 札の主の文字は各行10字前後で、札の字数÷秒数が8以下

## 試作の前に確かめること

- 「負けた」の定義: セルの n は3連単の件数の和と一致する（固定の材料の5セルで確認、2026-10-27）。つまり N は3連単が成立したレースだけで、M＝N−K は「3連単が成立し、1着が1号艇でない件」（1号艇の失格・転覆・欠場でも、1着の艇がいれば入る）。不成立・返還は N に入らない。札・字幕・本文はこの定義で同じ N・K・M を使う。言い方（「負けた」でよいか）は wording-editor に
- 「進入が枠なり」は結果で決まる条件。免責の言い方がこれで良いかを wording-editor に
