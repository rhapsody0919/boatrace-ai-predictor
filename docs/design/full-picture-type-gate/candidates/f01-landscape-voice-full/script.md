## 今の型より良い理由

- 視聴者の理由（仮説）: 今の縦の完全版は上半分にカード、下約4割が空きで、声が無い。24h の再生は中央値1。横＋声で、龍神の実画面の操作（タブ・軸の切り替え）を見せながら数字を言葉で読み上げるので、画面を見ていなくても章の答えが伝わる。YouTube の通常の動画の棚（横）に合う
- 運用の理由: 1レースに1本の横の完全版を、今の材料（bundle）から機械で作る。順位・比べは z の線を作る段で通す

## 試作で作る・確かめるもの（6節）

- 左の実画面の撮影: viewport 1280・deviceScaleFactor 2、章の部品の外枠（data-testid）で切り抜き、高さ 850px。縮めた後の最小の字の高さを機械で測る（28px は目安・根拠なし）。届かなければ2カット、それでも届かなければその章を出さず警報
- 照合（機械）: 左の画面の状態（軸・押した要素・カーソル）・右の数字・字幕・声を同じ bundle の値から作り照合する。章の札・道順と切り抜きの data-testid が同じ画面か
- 順位・比べの言い方は z の線（多項の z、複数は Bonferroni）。#1973 の rankOf・diffOf を使う
- 声: speedScale 1.1、audio_query の kana を辞書で照合（「313けん」「こんせつ」）、選手名は声で読まない、説明欄に「VOICEVOX:青山龍星」を機械で確かめる
- 試作は条件の違う過去3レース（本命が堅い・荒れる・データが薄い）
