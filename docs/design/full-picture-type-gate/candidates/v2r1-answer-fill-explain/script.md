## 直す3点

1. 題の問い「1号艇は堅い？」に、言葉で答える結論の一文を最初のコマに出す
2. 冒頭の画面の下6割の空きに、比べる基準の棒と形の説明を置く

あわせて直る食い違い: 冒頭の数字の範囲（会場・級の組み合わせ・期間）が書かれていない（number-wording.md）、X の本文に動画に出ない数字（会場の過去90日）が載る（x.md）。

## 決めたこと（オーナーの可で推奨どおり）

- 比べる基準: 同じ範囲（同じ会場・級の組み合わせ・期間・枠なり）のどの形でもの1号艇の1着割合。会場の過去90日（期間・級が違う）とは比べない
- 冒頭は3秒・1拍から5秒・2拍にする（棒は2.5秒から伸びる）。全体は約39秒（v2 は 36.9秒）
- 冒頭の数字は「1号艇の1着割合」に固定する（v2 は1着最多の艇の割合）

## 結論の一文を選ぶ規則

p＝同じ形の過去で1号艇が1着の割合、n＝件数、p0＝同じ範囲のどの形でもの割合、[lo, hi]＝p の 95% Wilson 区間。「約X割」は p を10%単位に丸める。

| 段 | 条件 | 答えの札 | 小さい文 |
|---|---|---|---|
| A | n≥30 かつ lo > p0 | 1着は約X割、いつもより堅い寄り | いつもより多い（過去の割合） |
| B | n≥30 かつ lo ≤ p0 ≤ hi | 1着は約X割、いつもと同じ程度 | はっきりした差は無い（過去の割合） |
| C | n≥30 かつ hi < p0 | 1着は約X割、割れやすい寄り | いつもより少ない（過去の割合） |
| D | n<30 | 形を問わず、1着は約X割（p0） | 同じ形の過去が30件未満 |

30件・95%は目安（根拠なし）。「堅い」「来る」を単独で使わない。

## v2 より良い点と、おそれ

- 良い点: 最初のコマで言葉の答えが出る（基準と件数つき）／範囲と本文の食い違いが直る／形の名前が初見で読める
- おそれ: 件数50前後だと区間が広く、多くの日が段B になり単調になりうる（統計検証で確かめる）／冒頭の字が増え尺が約2秒延びる（Shorts の平均視聴率で見る）
