## 直す3点

1. 題の問い「1号艇は堅い？」に、言葉で答える結論の一文を最初のコマに出す
2. 冒頭の画面の下6割の空きに、比べる基準の棒と形の説明を置く
3. スタートの形の名前（内3艇そろう等）に定義を1行添える

あわせて直る食い違い: 冒頭の数字の範囲（会場・級の組み合わせ・期間）が書かれていない（number-wording.md）、X の本文に動画に出ない数字（会場の過去90日）が載る（x.md）。

## 決めたこと（オーナーの可で推奨どおり）

- 比べる基準: 同じ範囲（同じ会場・級の組み合わせ・期間・枠なり）のどの形でもの1号艇の1着割合。会場の過去90日（期間・級が違う）とは比べない
- 冒頭は3秒・1拍から5秒・2拍にする（棒は2.5秒から伸びる）。全体は約39秒（v2 は 36.9秒）
- 冒頭の数字は「1号艇の1着割合」に固定する（v2 は1着最多の艇の割合）

## 結論の一文を選ぶ規則

p＝同じ形の過去で1号艇が1着の割合、n＝件数、p0＝同じ範囲のどの形でもの割合、[lo, hi]＝p の 95% Wilson 区間。「約X割」は p を10%単位に丸める。

| 段 | 条件 | 答えの札 | 小さい文 |
|---|---|---|---|
| A | n≥30 かつ lo > p0 | 過去の1号艇の1着は約X割、いつもより堅い寄り | どの形でもの Y% より多い（過去の割合） |
| B | n≥30 かつ lo ≤ p0 ≤ hi | 過去の1号艇の1着は約X割、いつもと同じ程度 | はっきりした差は無い（どの形でも Y% と比べて） |
| C | n≥30 かつ hi < p0 | 過去の1号艇の1着は約X割、崩れやすい寄り | どの形でもの Y% より少ない（過去の割合） |

データが薄いレース（同じ形の過去が30件未満、または形が「どの形にも当てはまらない」）は作らない（段 D は置かない。オーナー 10/25「データが薄い、というのはそもそも出す必要ない気はするけど」、選択肢の1「減ったままにする」）。そのレースは daily.mjs が stage=type-spec の type_unsupported で止め、その日の全貌は1本減る。別のレースで埋めるかは、本数が減る日の割合を見てから決める（BOA-1096 で件数30未満の日の割合も分かる）。

Y は p0 を整数%で。段 A・C は「約X割」が基準と同じ割に丸まることがある（例 64% と 57% がどちらも約6割）ので、小さい文に基準の値を出す。

30件・95%は目安（根拠なし）。「堅い」「来る」を単独で使わない。

## v2 より良い点と、おそれ

- 良い点: 最初のコマで言葉の答えが出る（基準と件数つき）／範囲と本文の食い違いが直る／形の名前が初見で読める
- おそれ: 件数50前後だと区間が広く、多くの日が段B になり単調になりうる（統計検証で確かめる）／冒頭の字が増え尺が約2秒延びる（Shorts の平均視聴率で見る）
