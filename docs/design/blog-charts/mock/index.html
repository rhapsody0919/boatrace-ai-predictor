見せ方（ファン役4人の議論の結論。docs/design/blog-charts/fan-panel-mock-v1.md）

  1. 棒の色: 金の1色。行の印に艇の色は使わない（進入コースの図なので、白い「1」が1号艇＝枠番に読まれる）。艇の色は枠番を行にする図だけで使う。割れた点: 20代女は艇の色の印を残したい、30代男女は外したい。
  2. 値の位置: 棒の右端のすぐ横。割れた点: 30代男は右に1列にそろえたい。縦に比べるのは本文の表で。
  3. 1着数: 棒には添えない。母数は札（「2,363レース」）、1着数は本文の表。割れた点: 30代男は添えたい。
  4. 切り替えの部品: 選択肢が6つまではボタン、7つ以上は選ぶ箱（上の「ほかの状態」の左がボタンの形）。
  5. 既定の会場: 記事の主題の会場（福岡の記事なら福岡）。全国は選択肢の先頭。
  6. 件数が少ない行: 1着が30回に満たない行は、値の横に回数を小さく添える（例「0.8%（19回）」）。部品が自動で付ける（推奨）／添えない。言葉の審査の指摘。福岡の6コースは19回。
  7. 作り: 横棒は HTML で描く（値が文字になり、AI 向けのページにも確実に載る）。見た目は既存の部品の色・文字に合わせる。
