# ファン役の議論: ブログの図のモック v1（2026-10-20）

`discussion-panel` の4人（20代男・20代女・30代男・30代女）。同じモデルのロールプレイなので仮説。前提に `docs/knowledge/fan-reactions.md`・`user-insights.md` を読んだ（「数値の表はグラフに」「一言の要約＋詳細」の順、2026-09-14 オーナー）。

題材: 記事の中のカード。見出し「進入コース別の1着率」、答えの1文、会場の選ぶ箱（全国＋24会場）、札（会場／期間／母数）、6行の横棒、値は棒の右端の横、目盛りは全会場共通（0〜70%）、注記と出典。図の下に本文の表。

## 1. 棒の色

- 20代男: 金1色でいい。棒を艇の色にすると、一番長い1コースの棒が白で地に溶ける
- 20代女: 艇の色の方が「1は白」で頭に入る。ただ棒が白いのは見えないので、印だけなら許せる
- 30代男: 艇の色の印そのものをやめたい。この図は進入コースで、枠番ではない。白い「1」を見ると1号艇の数字に読む。注記で「枠番ではない」と書くなら、絵も枠番に見せない方がいい
- 30代女: 色でコースを見るのは慣れだが、30代男の言う誤読はある。数字だけの印で十分

割れた点: 艇の色の印を残すか（20代女は残したい、30代男・30代女は外したい）。
結論: **棒は金1色。行の印は艇の色を使わず、数字だけ（「1コース」の文字）にする**。艇の色は枠番（艇番）を行にする図だけで使う。

## 2. 値の位置

- 20代男・20代女・30代女: 棒の右端のすぐ横。棒と数字が離れない方が一目で読める
- 30代男: 右に1列にそろえた方が、縦に数字を比べやすい

割れた点: 30代男だけ右端の1列。
結論: **棒の右端のすぐ横**（推奨どおり）。縦に比べたい人は本文の表で読める。

## 3. 1着数を棒に添えるか

- 20代男・20代女: 要らない。スマホで行が詰まる
- 30代男: 「1,400勝」があると母数の感覚がつかめる
- 30代女: 札に「2,363レース」があれば十分。勝ち数は表で見る

割れた点: 30代男だけ添えたい。
結論: **添えない**。母数は札、1着数は本文の表（推奨どおり）。

## 4. 切り替えの部品

- 4人とも: 25の選択肢をボタンで並べられても探せない。選ぶ箱でいい。3会場の比べ記事ならボタンの方が押しやすい
- 20代女: 全国と福岡を並べて見たいのに、1回切り替えないと全国が見えない

割れた点: なし（20代女の「並べて見たい」は、答えの1文に全国の値が入っているのと、本文の表で足りるとした。比較の線は契約で作らない）。
結論: **6つまでボタン、7つ以上は選ぶ箱**（推奨どおり）。

## 5. 既定の会場

- 4人とも: 記事の会場を最初に出す。福岡の記事を開いて全国が出たら違う記事に見える
- 30代男: 全国は先頭がいい。自分の地元の会場は箱から探す

割れた点: なし。
結論: **記事の主題の会場。全国は選択肢の先頭**（推奨どおり）。

## まとめ

推奨から変えたのは1点だけ: 進入コースの図では艇の色の印を使わない（枠番と誤読される）。
