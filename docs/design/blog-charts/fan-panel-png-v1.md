# ファン役の議論: ブログの図の PNG（X・note に添付）（2026-10-20）

`discussion-panel` の4人（20代男・20代女・30代男・30代女）。同じモデルのロールプレイなので仮説。前提に `docs/knowledge/fan-reactions.md`・`user-insights.md`・`x.md` を読んだ（「添付の静止画の中でも範囲・期間・条件・母数を示す」2026-10-13）。

題材: 承認したモック v1（福岡の進入コース別1着率、6行の横棒）をビルドで撮った PNG。オーナーが X・note の投稿に添付する。x-channel と visual-designer で割れた2点を、ファンにとっての価値から決める。

議論の前提（ファンの議論には混ぜない事実）: 図の下には出典の行「出典: ボートレース公式の競走成績（龍神レーダー集計）（集計日 …）」が既にある。注記は「進入コース別（枠番ではない）。中止・不成立のレースを除く。4〜6コースは1着の件数が少なく、会場の順位は年によって変わりうる。」（70字まで）。

## 1. ロゴ（サイトの名前）と URL を画像に入れるか

- 20代男: ロゴの絵は要らない。広告に見えると図を読む前に飛ばす。右下に小さく名前があれば十分
- 20代女: 画像だけがスクショで回ったとき、どこのデータか分からない図は信用しない。名前は欲しい。長い URL は邪魔、ドメインだけならいい
- 30代男: 出典の行に「龍神レーダー集計」と既にある。これ以上足すと宣伝が図より目立つ。足すなら出典と同じ大きさの1行まで
- 30代女: 画像を保存して後で見返すとき、サイトに戻る手がかりが要る。名前とドメイン（boat-ai.jp）があれば検索できる

割れた点: 30代男は「出典の行で足りる」、20代女・30代女は「ドメインまで欲しい」。ロゴの絵を入れたい人はいない。
結論: **ロゴの絵は入れない。サイト名とドメインを文字1行（出典と同じ大きさ、右下）で入れる**。転載・保存で出所が分かり、サイトへ戻れる。宣伝が図より目立たない大きさに留める。

## 2. 4:5 に収めるために注記を外すか

- 20代男: 正直、注記は読まない。外して棒を大きくした方がタイムラインで止まる
- 20代女: 「枠番ではない」が無いと、1コースの 59.2% を1号艇の勝率と読まれる。引用で突っ込まれるのはこっち。外さない
- 30代男: 画像だけが拡散されると、本文の注意は消える。4〜6コースの件数が少ないという断りが無い会場の比較の画像は一番まずい。外すのは反対
- 30代女: 外すのではなく、行の間と余白を詰めて収めたい。それでも収まらない図（行が多い）は、無理に 4:5 にせず縦長でいい

割れた点: 20代男だけ外したい（棒を大きく）。3人は残す。
結論: **注記は外さない**。誤読（コースと枠番の取り違え、件数の少ない行の比較）を防ぐ断りは、画像が単独で回る X ほど要る。収め方は行の高さ・余白を詰める方で調整し、それでも入らない図は 4:5 にせず撮らない（または縦長）を部品の側で決める。

## まとめ

- ロゴ: 絵は無し。サイト名＋ドメインを文字1行（右下、出典と同じ大きさ）
- 注記: 残す。4:5 は余白と行の高さで収める
