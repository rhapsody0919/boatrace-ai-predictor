## 3. 打ち手の候補

| # | 打ち手 | 効き方 | 大きさ・戻し |
|---|---|---|---|
| D | URL 検査を毎日の取り込みに入れ、索引の数を測る | 測るだけ。害が無く先にやってよい | 小（.github でオーナー）。API の1日の上限は公式で確かめてから枠を決める |
| B | 終わったレースの詳細に、日付で noindex。`middleware.js` の既存の matcher（`/race/:path*`）で race_id の日付を見て `X-Robots-Tag: noindex` を返す（JS の meta は描画後にしか効かず、ADR-0107 と同じ理由で退ける）。当日のレースは載せ続ける | H1 に直に効く | 中。戻しは revert。索引から消えるまで数週 |
| A | レース詳細をサイトマップから外す（ADR-0026 の改訂を戻す） | 新しい発見を減らすだけ。索引に入った物は残り、内部リンクから発見も続く。単独では H1 を確かめも直しもできない | 小 |
| C | トップを「独自のデータの集まり」として強める（何のデータを・どこから・何を計算して出すかを画面の文で、出典と更新頻度、運営の素性は /about へ内部リンク、WebSite に publisher・Organization に description、トップから実データの深いページへの内部リンク、「予想」より「過去の実績で数えたデータ」を軸に。aggregateRating は足さない） | H2 | 中〜大。見せ方はオーナーのモック承認 |
| E | title を元に戻す | H3 を確かめる唯一の方法 | 小。ほかの打ち手と別の週に単独で |

- B の日数の線は、レース詳細が検索に出た日数の分布（レースの日から何日まで表示があるか）から決める。出せなければ「目安（根拠なし）」と書く
- B の期間にサイトマップに残すか外すか（A と一緒にするか）は、B と同じ PR で決める（同じ仮説なので一緒でよい。混ざって困るのは C・E）
- 大きさの比: レース詳細が4週で得るクリックは、トップが1週で失ったクリックの1割強（実数は非公開の写し）

## 4. 進め方と見る数字

推奨の順（仮）:
1. D（測る）と、手元の確かめ（§2 の H1 と H2 を分ける）: ページの種類別の日ごとの表示回数（トップ・ブログ・会場・レース詳細）、検索に出たレース詳細の本数の週ごとの推移（10/31 の段差）、オーナーに GSC の画面の記録（ページのインデックス登録の推移3か月・サイトマップの送信／登録・クロールの統計）を取ってもらう
2. 12/4 以降に、11/25〜12/1 と 11/3〜9 を比べる（12/2 は GSC の遅れでデータがそろわない恐れ）。判断の分かれ目にはしない（回復は数週かかりうる）
3. B（＋A）は早くて 12/8（アップデートの後だけで基準14日を取れる日）から。E は別の週に単独で。C は B の後
- 比べの見方: 11/3〜9 の語の組を固定し、名前の語と一般の語に分けて、週ごとの表示回数・表示の重みの順位・表示があった語の数。アップデート前の6週の週ごとの比で揺れの帯を作り、帯の外かで見る。開催の会場×日数と名前の語の表示回数（需要の目安）を横に並べる。端末別は補助
- 混ざる物: 祝日（11/3 文化の日）、開催の数と SG・G1（年末に向けて需要が増える。日程は未確認）、11/22 の他言語のレース詳細の noindex（BOA-1701）、December 2026 core update
- 効き目の判定: `scripts/lib/growth/seoEffect.js` の judgeRewrite は1ページの改稿用で、サイト全体の打ち手には使わない（対照で割ると効き目が消え、基準にアップデートが入ると「動かず」に寄る）。使うなら metric=impressions、coreUpdates の台帳に 11/10〜11/24 を登録（空だと黙って誤る）、基準はアップデートの後だけ。基本は「一般の語の固定の組の表示回数が、アップデート前の帯の下限まで戻ったか」の1点で見て、「分けられない」を前提に記録する

## 5. 言えること／言えないこと

言える: 11/11 PT からトップの一般の語の表示回数が6〜7割落ち順位が約3下がった、名前の語は1位のまま、公式の頁の November 2026 core update の開始と時期が合う、ボットの疑いの語の水増しは数％以下。

言えない: 原因が H1 か H2 か（ほかのサイトとの比べが無く、May 2026 にも同じ型がある）、11/12 以降の段に title が効いたか、打ち手の後の回復が打ち手の効き目かアップデートの揺れ・次のアップデート・季節か。
