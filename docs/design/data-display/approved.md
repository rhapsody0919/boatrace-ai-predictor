# 表とグラフの決まり: 承認の記録

- 承認日: 2026-11-23
- 承認の言葉（要旨）: オーナー「1〜5まで推奨通りで良い」（窓口の会話。決めてほしい点5つをすべて推奨どおり）
- 正にした物: レース詳細の出走表（`src/components/DataRaceTable.jsx` 周り。オーナー「私の理想の表のデザインや操作感はすでに出走表などで実現している」）
- モック: `mock/mock-375.png`・`mock/mock-1440.png`（数字はどれも見本の例で、本物の値ではない）
- 決まりの本文: `docs/reference/design-system.md` の「表とグラフ（データの見せ方）」

## 承認した5点
1. 6艇を比べる表は、どの画面でも「艇を列・指標を行」にそろえる（枠別情報のコース別成績は行が艇だった）
2. 決まり手・段などの系列は茶の濃淡と灰で塗り、艇の色（白・黒・赤・青・黄・緑）を使わない
3. 金の強調（行の中の最良）は、6艇を比べる表だけに使う。1人・1艇の一覧の表には使わない
4. 推移のグラフの軸は0から始めず、値の幅に合わせる
5. 出走表にも、選んだ艇（`?boat=`）の列の強調を足す（ほかのタブと同じ動き）
