**新しい画像・動画を作る前に必ずこのファイルのギャラリーを確認すること。** ゼロから発想せず、既存の採用実例を出発点にする。承認を得たら、その場でこのファイルに実例を追記すること（後日まとめて更新しない）。

### note ヘッダー画像（1920×1006px）

- **採用（2026-09-01）**: header-e — 実際の`/logo-light.png`を1650pxまで拡大しキャンバス右端でブリード配置（枠からはみ出す大胆な配置）、頭部付近だけ鮮明な小サイズを重ねて奥行きを出した。テキストは単一ウェイト・ゴールド一色で実ヘッダーと統一
  - 却下理由の記録: 初回に「空白が多い」という指摘を受け、ロゴを主役として大胆に使う方向へ作り直した結果採用に至った
- **却下**: header-D — 実ロゴ・実フォントは正しかったが、ロゴを110px程度の小サイズで左上に配置しただけで右側に大きな空白が残った（「もっと天才的な使い方ができないか」との指摘で却下）
- **却下**: header-C2 — 独自の六角形バッジ＋「龍」一文字の紋章、ロゴテキストも「龍神」太字ゴールド／「レーダー」細字白の分割ウェイトで構成。**実際のサイトヘッダーと異なるロゴ・フォントを新規に作ってしまった**ため却下（「ベースはトップページのヘッダーと同じデザインイメージ。同じフォントや同じロゴを使うこと」「龍紋章は不要」との指摘）
- **却下**: 初回案（絵文字🐉ベース） — 環境依存でカラフルなイラストとして表示され浮く。「クオリティが低い、天才デザイナーにゼロから作成させて」との強い指摘で作り直し

### X / TikTok 動画CTA（2026-09-01、ソースコード監査で判明）

- **ロゴ**: 現状、21本の動画テンプレート（`sns-video-studio/remotion/src/*CM.jsx`）は全てCTAシーンがテキストのみで「boat-ai.jp」と表示するだけ。**ロゴ画像（`/logo-light.png`）は一切使われていない**。noteヘッダーで確定した「実ロゴをそのまま使う」方針をここにも適用し、**今後の新規テンプレートはCTAシーンにロゴ画像を含めること**（採用済み、2026-09-01ユーザー承認）。既存21テンプレートへの遡及適用は`content-quality`ラベルでLinear起票済み（Linear参照）— 各テンプレートを個別に修正・再レンダリング確認する必要があり、一括での機械的修正はしない
- **CTA文言の基本型**: 「[話題]、無料で見れる/使える」を公式ルールとして確定（2026-09-01）。実例: 「全24会場のデータ、無料で見れる」「回収率データ、無料で見れる」。マンネリ防止のための話題部分のバリエーションは許容する（`docs/operation/x-operations-playbook.md`のマンネリ対策と整合）。**この型から外れる表現（絵文字付き「🎯これ、全部無料で使える」、「登録不要・アプリ不要」の別文言併記等）は今後の新規制作では使わない**。既存の型外れ表現も遡及修正は上記と同じLinearチケットで扱う
- **URL表記**: 「boat-ai.jp」（小文字）で統一済み、問題なし

### アプリ内公式文言の使い分け（2026-09-01確定）

サイト内には役割の異なる2つの公式文言が存在する。どちらも正しい使い分けであり、統一は不要:

- **`nav.logoTagline`**（ヘッダーロゴ下・フッター・チャネル素材共通）: 「ボートレースを見える化。迷ったら、データを信じる。」— ブランドの詩的なタグライン。note/X/TikTok等のチャネル素材はこちらを使う
- **`<title>`タグ・OGP description**（`useSocialMeta.js`・`common.json`の`meta.title`）: 「龍神レーダー - 無料のボートレースAI予想＆データ分析」— SEO・検索結果表示向けのキーワード重視の説明文。**変更しない**（検索順位・CTRへの影響が読めないため、変更するなら別途SEO施策として慎重に検討する）
- 2026-09-01時点で`introBannerText`・`footerText`は「無料のボートレースAI予想＆データ分析」から`logoTagline`に統一済み（PR参照）。`<title>`・OGP descriptionは意図的に未変更

## 運用ルール

1. **新規制作の着手前に本ファイルのギャラリーを確認する**（[`docs/design/content-ops-flow/spec.md`](../design/content-ops-flow/spec.md) C2）。既存の採用実例と矛盾する独自デザイン（新しいロゴバッジ、実ヘッダーと異なるフォント処理等）を作らない
2. **承認されたら、その場でギャラリーに追記する**（C3）。追記せずに次のタスクへ進まない
3. **却下された案も理由付きで残す**。同じ失敗（独自紋章の再発明、環境依存の絵文字使用等）を将来のセッションが繰り返さないようにする
