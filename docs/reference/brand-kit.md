# ブランドキット

龍神レーダー（boat-ai.jp）のnote/X/YouTube/TikTok/ブログ/静的ページ向けビジュアル制作で参照する単一ソース。トークン集ではなく、**承認済み実例のギャラリー**として運用する（詳細: [`docs/design/content-ops-flow/spec.md`](../design/content-ops-flow/spec.md) C1）。

**新しい画像・動画を作る前に必ずこのファイルのギャラリーを確認すること。** ゼロから発想せず、既存の採用実例を出発点にする。承認を得たら、その場でこのファイルに実例を追記すること（後日まとめて更新しない）。

## トークン

実際のサイトヘッダー（[`src/components/Header.jsx`](../../src/components/Header.jsx)・[`src/styles/design-tokens.css`](../../src/styles/design-tokens.css)）の実値をここに転記する。ここはミラーであり、実値の変更は必ずソース側で行う。

### ロゴマーク
`/logo-light.png`（1320×1405px、透過PNG）。龍の紋章＋波＋帆（レーダーの三角形）を円形に配置したデザイン。ライト/ダーク両テーマで同一ファイルを使用（透過のため両背景で機能する）。**新しいロゴバッジ・紋章を独自に作らない。既存のこのファイルをそのまま使う。**

### カラー
| トークン | 値 | 用途 |

### タイポグラフィ
ロゴテキスト「龍神レーダー」は**分割ウェイト・分割色にしない**。単一ウェイト（`font-weight: 700`）・単一色（ゴールド）で表示する（2026-08-21のADR 0018で明朝体から統一済み）。フォントスタックは `-apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans JP", "Hiragino Sans", sans-serif`。

### タグライン
「ボートレースを見える化。迷ったら、データを信じる。」（`common.json`の`nav.logoTagline`と同一文言をチャネル素材でも使う）

## チャネル別ギャラリー

### note ヘッダー画像（1920×1006px）

- **採用（2026-09-01）**: header-e — 実際の`/logo-light.png`を1650pxまで拡大しキャンバス右端でブリード配置（枠からはみ出す大胆な配置）、頭部付近だけ鮮明な小サイズを重ねて奥行きを出した。テキストは単一ウェイト・ゴールド一色で実ヘッダーと統一
  - 却下理由の記録: 初回に「空白が多い」という指摘を受け、ロゴを主役として大胆に使う方向へ作り直した結果採用に至った
- **却下**: header-D — 実ロゴ・実フォントは正しかったが、ロゴを110px程度の小サイズで左上に配置しただけで右側に大きな空白が残った（「もっと天才的な使い方ができないか」との指摘で却下）
- **却下**: header-C2 — 独自の六角形バッジ＋「龍」一文字の紋章、ロゴテキストも「龍神」太字ゴールド／「レーダー」細字白の分割ウェイトで構成。**実際のサイトヘッダーと異なるロゴ・フォントを新規に作ってしまった**ため却下（「ベースはトップページのヘッダーと同じデザインイメージ。同じフォントや同じロゴを使うこと」「龍紋章は不要」との指摘）
- **却下**: 初回案（絵文字🐉ベース） — 環境依存でカラフルなイラストとして表示され浮く。「クオリティが低い、天才デザイナーにゼロから作成させて」との強い指摘で作り直し

## 運用ルール

1. **新規制作の着手前に本ファイルのギャラリーを確認する**（[`docs/design/content-ops-flow/spec.md`](../design/content-ops-flow/spec.md) C2）。既存の採用実例と矛盾する独自デザイン（新しいロゴバッジ、実ヘッダーと異なるフォント処理等）を作らない
2. **承認されたら、その場でギャラリーに追記する**（C3）。追記せずに次のタスクへ進まない
3. **却下された案も理由付きで残す**。同じ失敗（独自紋章の再発明、環境依存の絵文字使用等）を将来のセッションが繰り返さないようにする
