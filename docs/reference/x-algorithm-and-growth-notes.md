# Xアルゴリズム・成長戦術の調査ノート（2026-08-23）

X（旧Twitter）公式リポジトリ「the-algorithm」・公式発言・信頼できるSNSマーケティング専門メディアを情報源に、Xのアルゴリズムの仕組みと小規模アカウントの成長戦術を調査した結果をまとめる。`docs/operation/sns-marketing-strategy.md`が「何を決めたか」の意思決定ログであるのに対し、このファイルは「Xというプラットフォームの仕組みそのものについて何がわかっているか」の知識ベースとして分離する。

情報源ごとに確度を明示する: **一次情報**（X公式コード・公式発言）／**業界分析**（SNSマーケ専門メディア）／**未確証**（個人ブログ・通説）。数値が付いた「◯倍改善」等の主張の多くはSEO目的のマーケティングブログが情報源であり、一次調査に基づかないものが多い点に注意。

## 音声・BGMはインプレッションに影響するか

**結論: 確証なし。TikTokのような「トレンド音源→おすすめ露出優遇」の仕組みはXには無いと考えるのが妥当。**

- 一次情報（2023年公開のthe-algorithmリポジトリ）に、音声・音楽トラックの有無をFor Youランキングの特徴量として扱うコードは確認できない（[TechCrunch](https://techcrunch.com/2023/03/31/twitter-reveals-some-of-its-source-code-including-its-recommendation-algorithm/)、[CSMaP NYU](https://csmapnyu.org/impact/news/what-can-we-learn-from-twitters-open-source-algorithm)の解析が一致。ただしCSMaPは「モデル重み・学習データは非公開で透明性は不完全」と留保）
- Xの動画はタイムライン上デフォルトミュート自動再生されるという仕様があり、「音声ON/OFF自体を評価軸にする動機が薄い」という仮説の傍証になる
- 「動画の85%は無音視聴」という数値がしばしば引用されるが、出典は2016年のFacebook広告主向けDigiday記事であり、X固有の実測データではない点に注意

**実務上の示唆**: 現状のBGM付き動画運用（Remotion+Pixabay Content License音源）を変える必要はない。ただしランキングを操作する手段としてBGMに期待するのは根拠不足。字幕・テロップで無音でも内容が伝わる設計を優先する。

## 初動フォロワー獲得は本当に重要か（コールドスタート問題）

**結論: 確度中〜高。「フォロワー数」より「投稿ごとの初速エンゲージメント」が構造的なボトルネック。**

- 一次情報（the-algorithmリポジトリのGraphJetの仕組み）: 非フォロワーのタイムラインに載る（Out-of-Network候補になる）には、閲覧者がフォローしている**誰か**がその投稿に「いいね・リプライ・リポスト」する、またはその投稿者をフォローするという二次的つながり（social proof）が無いと**候補集合にすら入らない**。フォロワーが少なく相互エンゲージメントの薄いアカウントはこの時点で不利になる（[GitHub: twitter/the-algorithm](https://github.com/twitter/the-algorithm)）
- 学術研究（[arXiv 2112.08237](https://arxiv.org/pdf/2112.08237)「Exposure Inequality in People Recommender Systems」）: 初期の露出格差が時間とともに拡大するrich-get-richerメカニズムを長期データで実証（ただしX限定の検証ではない）
- 反証: X自身、フォロワー500人未満でも初速エンゲージメントが良ければ数万リーチに達した事例を報告しており、「詰んでいる」わけではない
- 実地調査（BOA-210）で得た自社データとも整合: 直接競合@KAIPREDICTOR（1ヶ月・71フォロワー）は880ビュー水準、隣接ジャンル@keiba_pace（5年・69.7Kフォロワー）は数万ビュー水準——ただし後者は5年の蓄積と後述のエンゲージメント誘導CTAが交絡しており、「フォロワー数の差」だけに単純化できない

**実務上の示唆**: フォロワー55人は「アルゴリズム的に詰んでいる」状態ではない。フォロワー数を追うより、**投稿直後30〜60分以内に第三者から1件でもいいね/リプライ/リポストを得る**ことがOut-of-Network候補に入るための最低条件であり、そこに運用の焦点を当てるべき。

## Xアルゴリズムの優遇・冷遇要因（包括）

### エンゲージメントの重み付け（一次情報、Heavy Ranker公式コード）

| シグナル | 重み |
|---|---|
| リプライ | 13.5 |
| 投稿者がそのリプライにさらに返信 | **75.0**（最大級） |
| プロフィールクリック（good） | 11〜12 |
| リポスト | 1.0 |
| いいね | 0.5 |
| 動画50%再生 | 0.005 |
| ネガティブフィードバック（興味なし等） | -74 |
| スパム通報 | -369 |

出典: [twitter/the-algorithm-ml recap README](https://github.com/twitter/the-algorithm-ml/blob/main/projects/home/recap/README.md)（2023年公開、2026年5月の再公開版でも同様の優先順位が確認されている）。

**リプライはいいねの27倍重い。**さらに投稿者がそのリプライに返信すると150倍の重みになる。「いいねを増やす」より「リプライが生まれる・そこに自分が返信する」設計の方が桁違いに効く。

### 外部リンクの扱い（一次情報、Musk発言の変遷）

- 2023〜2025年頃、Xは外部リンク付き投稿のリーチを実際に抑制していた（Musk本人が「明示的なルールではないが滞在時間最大化の結果」と認めた発言あり）
- **2026年7月、Muskが「1年以上前からリンクへのペナルティはない」と発言、X製品責任者も「リンクをリプライに貼る必要はもうない」と明言**（[ppc.land](https://ppc.land/x-drops-year-old-link-penalty-musk-tells-zuckerberg-on-platform/)）
- ただし2026年5月時点の分析でも「Replies > Reposts > Likes > External Links」という優先順位自体は残っているとの指摘あり（[アルゴリズム分析記事](https://pasqualepillitteri.it/en/news/2594/x-algorithm-open-source-may-2026)）

**実務上の示唆**: 「リンクをリプライに逃がす」回避策はもう不要（公式に不要と明言）。ただし記事誘導投稿は「本文で要点が完結し、詳細を読みたい人だけ次の行動に誘う」設計の方が安全。

### X Premium（課金）の優遇（一次情報＋大規模実測）

- 公式コード: Premiumユーザーはフォロー内4倍・フォロー外2倍のブースト、リプライの表示順位も優先
- Buffer社の1,880万投稿分析（業界分析）: 実測でPremium(月8ドル)は約6倍、Premium+は約15倍のリーチ
- ただし「内容が悪ければ効果は限定的」「週3投稿未満・開設30日未満・ジャンル不明確なら課金しない方がよい」という条件付き推奨が複数の情報源で一致（ゼロに何倍してもゼロ）

**実務上の示唆**: 現状（投稿量が少ない・開設1年未満）ではX Premiumは見送り。まず投稿量・型を確立してから検討する。

### ネガティブシグナル（一次情報）

ミュート・ブロック・「興味なし」（-74）、スパム通報（-369）は極めて重い負のシグナルで、単発投稿だけでなくアカウント全体の評判スコアにも波及するとされる。誤情報・過度な連投・スパム的表現は将来のリーチ全体を毀損するリスクがある。

## X Communitiesは2026年に廃止済み（重要な事実確認）

**X Communities（コミュニティ）機能は2026年4月に廃止発表、5/30に完全終了した**（利用率0.4%未満・スパム比率の高さが理由、[TechCrunch](https://techcrunch.com/2026/04/23/x-is-shutting-down-communities-because-of-low-usage-and-lots-of-spam/)）。「ニッチコミュニティに参加して露出を増やす」という戦術は現在使えない。代替として、同ジャンルの大きめアカウントへの質の高いリプライがクラスタ形成（SimClusters）のトリガーになるとされる。

## 小規模ニッチアカウントの成長戦術（業界分析中心、確度は個別に注記）

| 論点 | 知見 | 確度 |
|---|---|---|
| 投稿タイミング | 火〜木9-11時が高エンゲージメントとの説（Buffer社870万ツイート分析） | 業界分析、業種差が大きく要検証 |
| スレッド vs 単発 | スレッドは単発比3〜5倍エンゲージメントとの説。ただし2026年の仕様変更で長文単一ポストが優遇される可能性も指摘され過渡期 | 業界分析、不確実性高 |
| 投稿頻度 | 5,000フォロワー未満は1日3〜5投稿が推奨されがちだが「質の低い10投稿より初速の付く2投稿」という逆説も併存 | 業界分析、通説の域 |
| 投稿間隔 | 2〜3時間未満の連投は自己競合（共食い）を起こすとの指摘が複数一致 | 業界分析 |
| プロフィール最適化 | 固定ツイートは通常投稿の最大6倍エンゲージメントとの説。抽象的な自己紹介より具体的な実績数値を固定する方が効く | 業界分析、方向性は説得力あり |
| ニッチ×データ分析系の成功事例 | 具体的な転換点を明示した一次情報は見つからず | 未確証・裏取り不十分 |

## 総合の実務的示唆（優先順位順）

1. **リプライ戦略を主戦力にする**: リプライの重み（13.5、著者が返信すれば75.0）は他のどの施策よりも桁違いに大きい。ボートレース・競艇予想・競馬予想等、自分の2〜10倍規模のアカウントへ実データ・数値を絡めた質の高いリプライを日常的に行う。X Communities廃止後の代替導線としても最も再現性が高い
2. **固定ツイートを実績ベースに差し替える**: 抽象的な自己紹介ではなく、具体的な実測数値（展開予測的中率79%等）を画像付きで固定し、プロフィール訪問→フォロー転換を狙う
3. **投稿直後30〜60分の初速を設計する**: フォロワー数そのものより、Out-of-Network候補に入るための「第三者からの1件目のリアクション」を得られる投稿設計（問いかけ・共感を誘う書き方）を優先する
4. **ネガティブシグナルを避ける**: 誤情報・過度な連投・スパム的な表現は評判スコア全体を毀損するリスクがあるため厳禁
5. **X Premiumは現時点で見送り**: 投稿量・型が確立してから再検討
6. **BGM・音声の作り込みへの過度な投資は不要**: ランキングへの直接効果は確認できないため、字幕での完結性を優先する
