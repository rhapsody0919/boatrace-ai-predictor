# noteディスカバリー機構・成長戦術の調査ノート（2026-09-04）

note公式ヘルプ・note株式会社公式発表（note.jp）・note pro公式・実際に伸びているnoteクリエイターの体験談・SNSマーケティング専門メディアを情報源に、noteで記事が読まれる仕組み（「アルゴリズム」というよりディスカバリー機構）と小規模アカウントの成長戦術を調査した結果をまとめる。`docs/operation/sns-pipeline-note.md`が「noteチャネルの制作手順」であるのに対し、このファイルは「noteというプラットフォームの仕組みそのものについて何がわかっているか」の知識ベースとして分離する（`docs/reference/x-algorithm-and-growth-notes.md`と同じ位置づけ）。

情報源ごとに確度を明示する: **一次情報**（note公式ヘルプ・note株式会社公式発表note.jp・note pro公式biz.note.com）／**業界分析**（SNSマーケ専門メディアの分析記事、実績のあるnoteクリエイターの体験談で複数人の言及が一致するもの）／**未確証**（個人の推測・出典不明の主張）。

**前提の注意（noteの構造的な特殊性）**: noteはYouTube/TikTok/Xと異なり、ランキングアルゴリズムのコードもモデル重みも一切公開していない。さらにnote公式ヘルプ自身が「人気・急上昇・新着の判定基準は不正防止のため公開していない」と明言している（[note内で検索をした際に表示される人気・急上昇・新着の判定基準はなんですか？](https://www.help-note.com/hc/ja/articles/4403256523289-note%E5%86%85%E3%81%A7%E6%A4%9C%E7%B4%A2%E3%82%92%E3%81%97%E3%81%9F%E9%9A%9B%E3%81%AB%E8%A1%A8%E7%A4%BA%E3%81%95%E3%82%8C%E3%82%8B%E4%BA%BA%E6%B0%97-%E6%80%A5%E4%B8%8A%E6%98%87-%E6%96%B0%E7%9D%80%E3%81%AE%E5%88%A4%E5%AE%9A%E5%9F%BA%E6%BA%96%E3%81%AF%E3%81%AA%E3%82%93%E3%81%A7%E3%81%99%E3%81%8B)、一次情報）。そのため「◯倍伸びた」系の主張の多くは、個人クリエイターの1アカウント分の体験・推測に基づくものであり、Xのthe-algorithmのようなコード検証はできない。数値付きの主張は特に厳密に出典を確認し、根拠が薄いものは鵜呑みにしないと明記する。

## 最重要の一次情報: 2026年2月、レコメンドエンジンが全面刷新された

調査の前提として、note株式会社は2026年2月12日、LLM（大規模言語モデル）を使った「レコメンドエンジン」を全面刷新したと公式発表している。旧アルゴリズムを前提にした個人クリエイターの「noteアルゴリズム分析」記事の多くは、この刷新前の観測に基づく可能性がある点に注意。

**結論: 確度最高（note株式会社公式発表・プレスリリース・技術ブログの3点が一致）。カテゴリページ経由のPVが2.2倍、表示回数が4.3倍に増加、SNS経由の流入シェアは20%→8%まで低下し「note内回遊+検索」が7割を占める構造に変化した。**

- 一次情報（note株式会社公式note、[レコメンドエンジンの刷新で閲覧数が大幅増！「書けば、届く」を実現するnoteへ](https://note.jp/n/nce2c203cc6fb)、[PR TIMES同内容プレスリリース](https://prtimes.jp/main/html/rd/p/000000368.000017890.html)）: 2025年夏から検証を開始し2026年2月12日に本刷新。**2026年1月の検証期間中、カテゴリページの表示回数が前年同月比4.3倍、そこからのPVが2.2倍、note内回遊が1.5倍**。2月末時点ではさらに表示回数4.5倍・PV2.6倍まで拡大したとの追加開示あり（[技術ブログ](https://note.jp/n/nce0a239e3c40)）
- 一次情報（同）: **2022年6月〜2025年11月の長期データで記事PVは3.2倍に増加**、その内訳として**note内回遊＋検索流入が73%を占める一方、SNS経由の流入シェアは20%から8%まで低下**したと開示されている。noteは「PVを最重要指標としない」「そのひとにしか書けないコンテンツを優先的に読者に届ける」方針を明言
- 一次情報（[技術ブログ: PV2倍を支えた組織とシステムの境界設計](https://note.jp/n/nce0a239e3c40)）: 技術的には、note AI creative社がGeminiでタグ付与・スコアリングを行い、Databricksで機械学習ロジックを処理、Snowflakeを責任分界点にS3・SQS経由で本体へ非同期反映する構成。カテゴリを22新設し全53カテゴリへ拡充、さらに「食べ物」のような大カテゴリから「和食」のような細分化された「トピック」単位でのレコメンドへ移行。行動履歴の集計期間を最適化し直近の関心事項を即座に反映する仕組みも導入
- 一次情報の傍証（[note.jp: 推しアルゴリズムについて](https://note.com/fladdict/n/n5b78bb223b35)、note CXO深津貴之氏本人の発信）: このレコメンド刷新と並行して、AI時代のコンテンツ評価方針として「一次情報・独自性・検証可能性」を重視する優先順位を明示している。優先順位は①人間による一次情報・体験記録・作品 → ②一次情報をAIツールで編集・構成したもの → ③ユニークなAI自動生成記事 → ④新規性のない大量生成記事、の4段階。優遇される例として実体験レポ・失敗談からの学び・専門家情報・まだない情報の初出・一次創作が、冷遇される例として攻撃的/煽動的コンテンツ・他人のバズ記事の無検証な再構成・過剰一般化・フェイクニュースが挙げられている
- 業界分析（複数の個人クリエイター記事が一致）: この刷新の受け止めとして「フォロワー数ゲームの終わり」「バズらなくても届く時代」という論調が多い（[note攻略さん](https://note.com/note_kouryaku/n/naef0e16019ec)、[上谷宗久氏](https://note.com/mune22/n/n8d87212aef21)）。ただし発信側の推測であり、note公式が「フォロワー数は無関係」と明言したわけではない点は区別する

**実務上の示唆**: 龍神レーダーのnoteアカウントは新規・小規模スタートになるため、この刷新は追い風の可能性が高い。旧来の「フォロワーを増やしてから発信力を得る」戦略よりも、**カテゴリ・トピックへの正確な分類がされる記事作り**（後述のタイトル・見出しの明確さ）と、**一次情報性（実データ・実測値・自社独自の分析）を前面に出す構成**が、AI分類器・スコアリングの双方に効きやすいと考えられる。特にAIの実測的中率・回収率データを使った記事はnoteが推す「一次情報・専門家情報」の型に合致する。

## 発見・配信の仕組み

### 記事が読者に届く経路の全体像

**結論: 経路は大きく「note内（フォロー中フィード/カテゴリ・トピックページ/急上昇/編集部ピックアップ/ハッシュタグ/note内検索）」「note外（Google検索）」「SNSシェア」の3系統に分かれ、上記のレコメンド刷新でnote内経路の比重が急速に高まっている。**

| 経路 | 特性 | 確度 |
|---|---|---|
| フォロー中フィード | フォロワーに直接届く。新規アカウントはここでのリーチが薄い | 一次情報＋業界分析が一致 |
| カテゴリ・トピックページ | 2026年2月刷新の主戦場。LLMによる自動タグ付けで記事内容を理解し該当トピックに配信。53カテゴリまで細分化 | 一次情報（note.jp技術ブログ） |
| 急上昇セクション | 投稿数が伸びているトピックを日替わりで最大5つ表示、旧「カテゴリ単位」から「トピック単位」の高頻度更新に刷新 | 一次情報（note.jp技術ブログ） |
| 編集部ピックアップ（今日の注目記事等） | 1日2万件以上の投稿から約10記事のみ選出という高倍率（次項で詳述） | 業界分析（複数クリエイターの体験談が一致） |
| ハッシュタグページ | 編集部の発見経路・お題/コンテスト参加経路として機能。新着順表示が中心 | 業界分析 |
| note内検索 | 「人気」「急上昇」「新着」の3タブ。人気は直近のスキ数・伸び率が重視されるとされるが、**判定基準自体は非公開**（一次情報） | 判定基準の存在は一次情報、詳細な重みは業界分析・推測 |
| Google検索（外部SEO） | ドメインパワーの高さでインデックス優位（後述のSEOセクション参照） | 業界分析、複数ツール実測値一致 |
| SNSシェア | 2026年時点で全流入の8%まで低下（一次情報） | 一次情報 |

**実務上の示唆**: X運用で得たフォロワー・エンゲージメント資産は、noteの主要流入経路（note内回遊・カテゴリ/トピック配信・Google検索）には直接転写されない。noteチャネルは「Xで既に獲得した読者への告知」ではなく「note内・Google経由での新規発見」を主目的として設計すべき。

### 「スキ」「コメント」「フォロー」がランキング・露出に与える影響

**結論: 確度中。件数そのものより「公開直後の伸び率」が重視されるという説が複数のクリエイター体験談で一致するが、note公式が数値的な閾値を開示したことは無い。**

- 業界分析（複数記事が一致、[noteアルゴリズムをAIと解析してみた](https://note.com/kaz_intheus/n/neab0bd449cba)等）: **公開後24時間以内に10件以上のスキを集めることが「おすすめ」掲載の重要なトリガー**という説が繰り返し言及される。ただし「10件」という具体的な数字の一次情報での裏付けは無く、鵜呑みにしない
- 一次情報（[note内検索の判定基準ヘルプ](https://www.help-note.com/hc/ja/articles/4403256523289)）: 「人気」順は「不正防止のため基準は公開していない」と明記。外部から観測できるのは「直近のスキ数・伸び率が効いていそうだ」という推測レベルまで
- 業界分析: 記事にスキをつけた読者がプロフィールを訪問し他の記事を読み、フォローに繋がるという間接的な導線効果は複数の体験談で一致

**実務上の示唆**: 公開直後（当日〜翌日）のスキ・コメントを増やす初速設計（Xでの告知タイミングをnote公開直後に合わせる等）が有効と考えられるが、「10件」等の具体的閾値を絶対視した施策設計は避ける。

### 編集部ピックアップ（「今日の注目記事」等）の選定基準・応募方法

**結論: 確度中〜高（応募方法自体は一次情報で確認、選定基準の詳細は非公開・業界分析ベース）。**

- 一次情報（[「今日の注目記事」を見る - noteヘルプセンター](https://www.help-note.com/hc/ja/articles/360010417113--%E4%BB%8A%E6%97%A5%E3%81%AE%E6%B3%A8%E7%9B%AE%E8%A8%98%E4%BA%8B-%E3%82%92%E8%A6%8B%E3%82%8B)）: 毎日投稿される記事の中から話題の記事をピックアップして表示する機能自体は公式に存在する
- 一次情報（[お題/コンテストに参加する - noteヘルプセンター](https://www.help-note.com/hc/ja/articles/900000394443-%E3%81%8A%E9%A1%8C-%E3%82%B3%E3%83%B3%E3%83%86%E3%82%B9%E3%83%88%E3%81%AB%E5%8F%82%E5%8A%A0%E3%81%99%E3%82%8B)）: 記事編集画面の公開設定から「お題/コンテスト」を選んで応募する導線が存在。ハッシュタグを付けることで編集部の発見機会が増えるとも言われる
- 業界分析（複数記事一致）: 1日2万件以上の投稿の中から約10記事のみという高倍率。選定の傾向として「独自性のある体験談」「読みやすい構成（見出し・短い段落）」「2,000〜5,000文字程度」「公開後24〜48時間でのスキ・コメント・シェア数の多さ」が挙げられるが、公式の明文化された基準ではない

**実務上の示唆**: 編集部ピックアップは応募可能なお題・コンテストがある場合のみ活用を検討する。ただし当選確率が低く（1日約10/20,000）、これを主要な集客経路として設計するのは非現実的。副次的な機会として扱う。

### 新規・小規模アカウントが伸びにくい構造の有無

**結論: 確度中。2026年2月の刷新前は「フォロワー数がものを言う」構造だったとする体験談が多いが、刷新後は公式が「フォロワーゼロでも良質な記事が届く」ことを目指したと明言しており、構造自体が変化した可能性が高い。**

- 一次情報（[レコメンドエンジン刷新の公式発表](https://note.jp/n/nce2c203cc6fb)）: 「書けば、届く」を実現するnoteへ、という刷新のキャッチコピー自体が「フォロワーに依存しない発見」を明確に志向している
- 業界分析: 刷新前の体験として「フォロワーが増えると起きる5つの変化」（[アオイネコ氏](https://note.com/aoineko222/n/n075dcd0a9598)）のように、フォロワーがいることで記事が自動的にタイムラインへ流れ、露出機会が指数的に増える、という旧来の構造を前提にした助言が多数存在する。ハッシュタグ活用が「フォロワー以外に届ける」代替策として推奨されてきた
- 未確証: 刷新後に実際に新規アカウントがどの程度伸びやすくなったかの定量データは、note公式・第三者いずれからも確認できていない（PV増加率2.2倍等はプラットフォーム全体の平均値であり、個別の新規アカウントの実績ではない）

**実務上の示唆**: 「フォロワーが少ないから伸びない」という旧来の通説を過度に恐れる必要は薄いが、実証はまだ無い。龍神レーダーのnoteアカウントは、カテゴリ分類が正確にされる記事構成（後述）とハッシュタグの併用で、フォロワーに依存しない発見経路を優先的に狙う設計にする。

## コンテンツ形式・メタデータの影響

### タイトル・見出し画像・文字数

**結論: 確度中〜高。タイトルは短め（15〜25文字程度）、見出し画像は必須級、本文の長さはコンテスト選出実績ベースで2,000〜5,000字程度が目安。**

- 業界分析（[タイトルと見出し画像のコツ - noteヘルプセンター](https://www.help-note.com/hc/ja/articles/360012426353-%E3%82%BF%E3%82%A4%E3%83%88%E3%83%AB%E3%81%A8%E8%A6%8B%E5%87%BA%E3%81%97%E7%94%BB%E5%83%8F%E3%81%AE%E3%82%B3%E3%83%84)は一次情報だが具体的な文字数までは明記していない）: note公式ヘルプはタイトル・見出し画像の付け方のコツを解説しているが数値基準は示していない。個人クリエイターの分析では「note内の記事一覧・X上での省略回避のため15〜25文字が推奨」との言及が複数ある
- 業界分析: 「見出し画像の有無でPV・スキ数に数十%の差がつく」という主張が複数記事にあるが、正確な倍率の一次データは確認できない。ただし「見出し画像を付ける」こと自体は業界内でほぼ全会一致の推奨事項
- 業界分析: `.claude/CLAUDE.md`のブログ記事ルール（2,000〜3,500字目安）と、note編集部ピックアップの目安とされる2,000〜5,000字はおおむね重なる

**実務上の示唆**: `sns-pipeline-note.md`が既にブログ本文をnote形式に変換する設計になっており、ブログ側の文字数ルール（2,000〜3,500字）・画像必須ルール（フローA-3で確立済み）はそのままnoteの推奨レンジとも整合している。追加対応が必要なのはタイトルの文字数調整（ブログ用タイトルがnote向けに長すぎないかの確認）。

### ハッシュタグ・マガジンの活用による発見率向上

**結論: 確度中。公式ヘルプが推奨個数（2〜4個）を明示しており、マガジンによるシリーズ化は継続読者の獲得に有効という業界分析が一致。**

- 一次情報（[ハッシュタグを設定する - noteヘルプセンター](https://www.help-note.com/hc/ja/articles/360011358913-%E3%83%8F%E3%83%83%E3%82%B7%E3%83%A5%E3%82%BF%E3%82%B0%E3%82%92%E8%A8%AD%E5%AE%9A%E3%81%99%E3%82%8B)）: ハッシュタグの設定方法自体は公式ヘルプで確認できる
- 業界分析（複数記事一致）: ハッシュタグの役割は「記事の分類」「編集部への発見機会提供」「お題・コンテスト参加」の3つ。推奨個数は2〜4個程度、20個等の付けすぎは逆効果とされる
- 業界分析: マガジンは記事同士の連続性を保つ機能で、同じタグを忍ばせることで発見率向上を狙えるという言及がある

**実務上の示唆**: note下書き生成時（`sns-pipeline-note.md`のステップ3）にタグ付与のロジックが既にあるが、個数の目安（2〜4個）を明文化する余地がある。ボートレース関連のジャンルタグ（#ボートレース #ボートレース予想 等、note上のハッシュタグページで既に90万件超の投稿実績がある大規模タグ）と、龍神レーダー独自のタグを併用する設計が妥当。

### 投稿頻度・投稿タイミングの目安

**結論: 確度中。読者側の期待は週1〜2回、継続可能な頻度としては週2〜3回が目安。時間帯は平日18〜22時（特に木・金）が推奨との説が複数一致。**

- 業界分析（複数記事一致）: 「週1回の質の高い記事」の方が「毎日の薄い記事」より価値がある、という論調が多い。読者が望む頻度は週1〜2回、継続可能な頻度は週2〜3回とされ、「週2回がベスト」という折衷案が繰り返し言及される
- 業界分析: 平日は朝7〜9時（通勤前）・昼12時台（ランチ）・夜21〜23時（就寝前）が読まれやすい時間帯とされ、特に**18時〜22時、木・金曜が高評価**という説が複数一致
- 業界分析: 「公開24時間以内の反応がその後の表示数に影響する」という説（前述の「スキ・コメント」項と同根）から、投稿時間帯の重要性が導かれている

**実務上の示唆**: X（1日4本以下推奨、`x-algorithm-and-growth-notes.md`参照）やTikTok（1日6本上限）と異なり、noteは**週2回程度**が目安。現状の`sns-pipeline-note.md`のトリガー（12時間おきポーリング、日次自動提案後）は生成の頻度であり実際の公開頻度とは別だが、量産よりも週2本程度の質重視ペースで承認・公開する運用がnoteの読者期待とは整合的。

### 動画埋め込み（YouTube等）の扱い

**結論: 確度中。URLを貼るだけで自動的にプレイヤー化される仕様は一次情報で確認済み（`sns-pipeline-note.md`にも既に記載あり）。SEO効果は一般論としては存在するが、note固有の効果測定データは無い。**

- 一次情報（noteヘルプ、動画埋め込み関連ページ群）: YouTube・Vimeo・X・TikTok等のURLを本文に貼りEnterを押すだけで自動的に動画プレイヤーへ変換される
- 業界分析: 動画埋め込みによるSEO効果は「ページ滞在時間の増加」「YouTube自体が検索エンジンとして機能するため動画検索からの流入も見込める」という一般的なWeb SEOの理屈に基づくもので、note固有の実測データは見当たらない
- `sns-pipeline-note.md`側の既存設計（2026-09-03追記）: YouTube動画URLをnote本文に貼ると自動でプレイヤー展開される点は既に把握・活用済み。ただしYouTube側の承認を待つブロッキング依存にはしない設計になっている

**実務上の示唆**: 既存の`sns-pipeline-note.md`の設計方針（YouTube公開後に人間が投稿導線でURLをコピーして貼る）は、noteの技術仕様（貼るだけでプレイヤー化）と整合しており変更不要。動画埋め込みが直接的にnote内レコメンドのスコアを上げるという一次情報の裏付けは無いため、「埋め込めば伸びる」という過度な期待は禁物、あくまで読者体験向上のためと位置づける。

## SEO・外部連携

### note記事のGoogle検索インデックスのされやすさ・ドメインパワー

**結論: 確度中〜高。note.comのドメインパワーは主要SEO分析ツールで90点台後半と、一般的な個人ブログ（10〜20点台）を大幅に上回るとされ、新規記事が早期にインデックスされやすいという説はSEO専門メディア含め複数で一致。ただし競合の激しいキーワードでの上位表示は記事の質次第で保証されない。**

- 業界分析（複数のSEO専門メディア・ツール実測が一致）: note.comのドメインパワーは100点満点で96.4という具体的な計測値が言及される（[LinkTasky記事](https://note.com/brave_whale6986/n/nf1c79c7dda48)）。独自ドメインのWordPressブログが数週間〜数ヶ月かかることもあるインデックス化が、noteでは投稿当日〜数日で反映されることも珍しくないとされる
- 業界分析: ただしこれは「インデックスされやすさ」の話であり、「検索上位に出やすさ」とは別。競争の激しいメインキーワードでは自社ドメインの専門サイトが上位を占めるという指摘も同時に存在し、noteのドメインパワーだけに依存する戦略には限界がある

**実務上の示唆**: 「個人ブログよりnoteの方がドメインオーソリティで有利」という説には一定の裏付けがある。ただし`docs/reference/i18n_technical_and_demand_audit_2026_08_16.md`メモリで確認済みの通り、boatAI本体（boat-ai.jp）は既に相応のドメインオーソリティ・SEO基盤を持つため、noteのSEO優位性は「boat-ai.jp単体では拾いにくい検索クエリ・新規読者層の獲得」という補完的な位置づけで捉えるのが妥当。

### note内検索とGoogle検索、どちらが主要な流入経路になりやすいか

**結論: 確度高（一次情報の長期データで裏付けあり）。「note内回遊＋検索（Google含む）」が流入全体の73%を占め、SNS経由は8%まで低下している。noteは実質的に「SEO・プラットフォーム内発見のハイブリッド」構造。**

前述の「最重要の一次情報」セクション参照。note公式が2022年6月〜2025年11月の長期データとして開示した数値であり、note内検索とGoogle検索の内訳は開示情報からは分離できないが、いずれにせよ**SNSシェアに依存しない設計が既に構造的に正しい**ことが一次情報で裏付けられている。

**実務上の示唆**: note下書きをX側の告知に依存させすぎない。note単体でGoogle検索・note内検索・カテゴリ配信から読まれる設計（適切なタイトル・見出し構成・ハッシュタグ・一次情報性）を優先する。

### X等の他SNSとの連携

**結論: 確度高（一次情報）。X連携をONにすると記事公開時に自動シェアが可能。ただしこれは「note→X」への一方向の告知機能であり、X側のエンゲージメントがnote側のスコアに反映される仕組みは確認できない。**

- 一次情報（[連携するX (Twitter) アカウントを変更する - noteヘルプセンター](https://www.help-note.com/hc/ja/articles/4411644956697)）: アカウント設定でX連携をONにでき、記事公開時に「Xで投稿する」のチェックで自動投稿が可能
- 業界分析: X連携の設定はブラウザ版推奨（アプリ版で連携エラーが多発するとの報告複数）
- 業界分析: note記事内にXのポストURLを貼ると視覚的なカード表示で埋め込める（逆方向の連携）

**実務上の示唆**: `.claude/CLAUDE.md`のTikTok/X投稿の自動化禁止ルールと同様、note記事公開のX自動シェア機能を有効化するかは運用判断が必要（現状の`sns-pipeline-note.md`はnote下書きの生成のみを担当し、実際の公開・SNS連携は対象外）。X連携ONによる自動シェアは「note公開＝Xにも即告知」という導線を作れるが、noteとX両方を承認制で運用する現行方針（sns-hubパイプラインのチャネル別承認フロー）とは別建てで検討する必要がある。

## 外部要因・制約

### note pro（有料プラン）・有料エリア設定がディスカバリーに影響するか

**結論: 確度高（note pro公式ブログで明言）。note proアカウントの記事はトップページのレコメンド枠に約2倍優先的に表示される。ただし月額88,000円の法人向けプランであり、個人アカウントでの導入は費用対効果が見合わない。**

- 一次情報（note pro公式、[読まれるチャンスがnoteの約2倍！note proなら届きやすい！](https://biz.note.com/n/ndee0fbd8a830)）: 2023年10月のアップデートでトップページのレコメンド枠アルゴリズムが変更され、note proアカウントは通常プランに比べ**約2倍優先的に表示される**（「必ず2倍になることを保証するものではない」との留保付き）
- 業界分析: note proは月額88,000円（税込）の法人向けプランで、独自ドメイン・ロゴ・テーマカラーカスタマイズ、予約投稿、note proアナリティクス（PV・読了率・参照元・記事内リンククリック等の詳細分析）等が主な機能

**実務上の示唆**: 龍神レーダーのnote運用は個人アカウント相当の規模であり、月額88,000円のnote proは現時点では投資対効果が見合わない。X Premiumの判断（`x-algorithm-and-growth-notes.md`）と同様、「投稿量・型が確立してから再検討」という位置づけが妥当。有料記事（マガジン等の部分課金）自体はnote pro無しでも設定可能だが、今回の調査観点（ディスカバリーへの影響）としては、note proほど明確な優遇効果の一次情報は確認できていない。

### ギャンブル関連コンテンツに対するnoteの利用規約・ガイドライン上の制約

**結論: 確度高（一次情報の条文引用あり）。noteは「賭博」を包括的に禁止する条項は持たないが、①金融商品取引法に抵触する内容（株式銘柄推奨等）、②「必ずもうかる」等の誤解を招く断定表現、③マルチ商法等の情報商材、の3点を明確に禁止している。ボートレースは公営競技であり違法賭博には該当しないため、予想コンテンツの販売自体は規約上問題ない（note上に競艇/ボートレース予想アカウントが多数存在する実態がその傍証）が、表現方法には規約上の制約がある。**

- 一次情報（noteご利用規約の条文、[パラリーガルきつね氏によるnote株式会社の公式規約条文引用](https://note.com/itsu_para/n/n33a15c9f786c)）: 禁止事項として「詐欺やそのおそれがあるもの」「マルチ商法等、当社がユーザーに不利益をもたらすと判断する情報商材」「『必ずもうかる』等、ユーザーに著しい誤解を招く表現を用いたもの」「株式の銘柄推奨、その他金融商品取引法に抵触するもの」等が明記されている
- 一次情報の傍証（note CXO深津貴之氏の見解を紹介した同記事）: 「利益保証の約束」「詐欺」「犯罪教唆」「ねずみ講」は明確に禁止、一方で一般的な「ノウハウ」コンテンツはグレーゾーン（露出抑制の対象）として扱われる、というケースバイケースの評価方針が示されている
- 業界分析（傍証）: note上には「#ボートレース予想」（92万件超）「#競艇予想」（240万件超）という大規模ハッシュタグが実在し、多数のクリエイターが競艇・ボートレース予想を有料販売している実態がある。日本の競走（競馬・競輪・ボートレース・オートレース）は公営競技として法律で認められた興行であり、私的賭博を禁じる刑法の賭博罪の対象外である（この法的区分自体はnote固有の話ではなく一般的な法制度の理解）
- 業界分析: 競馬予想の無断コピー・転売が問題化した事例（[ライブドアニュース](https://news.livedoor.com/article/detail/18847300/)）があり、note運営側が著作権侵害等で対応した実績がある。的中率・回収率を検証する第三者サイトの調査では「調査対象の予想家が軒並みマイナス収支だった」との報告もあり、根拠の薄い実績訴求が横行しやすいジャンルであることが伺える

**実務上の示唆**: 龍神レーダーのnoteコンテンツは、①「必ず当たる」「確実にもうかる」等の断定的な表現を避ける（AIの実測的中率・回収率を根拠付きで提示するのは問題ないが、保証表現にしない）、②的中率・回収率の数値は実データに基づくものに限定し誇張しない、という既存の`.claude/rules/sns-content-generation.md`のリスクチェック（`risk-rules.json`）方針と完全に整合する。noteのボートレース予想ジャンル自体は活況で規約上グレーではないため、ジャンル選択自体への懸念は無い。

**確度の注意**: 「的中さん」のアカウントページ自体には「開設3年で総フォロワー16万人突破」という自己申告の実績訴求があったが、userlocal.jpの実測フォロワー数は55,616人であり、3倍近い乖離がある。**アカウント自身のプロフィール・訴求文に書かれた実績数値は、第三者計測値と大きく乖離することがあり、そのまま信用しない**（「累計いいね数」等別指標を「フォロワー」であるかのように混同させる訴求が横行している可能性がある）。

**共通パターンの抽出（業界分析、確度中）**:
1. **投稿頻度と規模の相関**: フォロワー1万人超えのアカウントは月間50〜215本という高頻度投稿（1日2〜7本相当）を継続している。一方フォロワー1,000〜1,500人規模のボートエリートは月27.6本（1日1本弱）とやや控えめ。noteは前述の通り「週2回程度」が読者期待とされる一方、実際に伸びているアカウントは無料記事・有料記事を含め相当量の投稿を積み重ねている実態がある（読者向けの推奨頻度と、実際に伸びたアカウントの投稿量には乖離がある可能性）
2. **活動停止による失速の実例**: 「ジェイソン先生」はフォロワー18,054人・累計23,483本という蓄積がありながら、28日以上投稿が止まっている。noteのレコメンドは（Xの投稿頻度による疲弊とは逆に）継続的な発信が前提の設計であり、一度アカウントが育っても投稿が止まれば新規流入は先細ると推測される
3. **ジャンル内での差別化軸**: いずれのアカウントも「回収率重視」「ホームコース特化」「ハイブリッドBET方式」等、単純な予想の的中率訴求だけでなく独自の切り口・方法論を前面に出している。龍神レーダーの場合はAIによる実データ分析という切り口自体が差別化要素になり得る
4. **有料販売との一体運用**: 調査した4アカウントはすべて有料予想の販売を主目的としており、無料の情報発信・ブランディングという龍神レーダーの用途とは前提が異なる。boatAIのnote運用は「予想を売る」のではなく「blog記事の再配信によるSEO・新規読者獲得」が目的であるため、上記アカウントの投稿頻度・収益化戦略をそのまま模倣する必要はない

## 総合の実務的示唆（優先順位順）

1. **フォロワー資産に依存しない設計を前提にする**: 2026年2月のレコメンド刷新でSNSシェア経由の流入は8%まで低下し、note内回遊・検索が7割を占める構造になった（一次情報）。X運用のフォロワー・エンゲージメント戦略とnoteの成長戦略は別物として扱う
2. **一次情報性を前面に出す**: note公式が明言する「一次情報・独自性・検証可能性」の優先方針に合致するよう、AIの実測的中率・回収率・データ分析の「一次データ」であることを構成上明確にする（体験談・実験記録・専門家情報という型に寄せる）
3. **カテゴリ・トピック分類が正確にされる記事構成にする**: LLMベースの自動タグ付けが記事内容を理解して配信するため、タイトル・見出し構成が曖昧だと誤ったトピックに分類されるリスクがある。見出し（h2/h3）で構造化する既存のブログルールがそのまま活きる
4. **投稿頻度は週2回程度を目安にする**: X（1日4本以下）・TikTok（1日6本上限）とは全く異なるペース感。`sns-pipeline-note.md`のポーリング頻度（12時間おき）は生成側の頻度であり、実際の公開・承認ペースは週2回程度に抑えるのが読者期待と整合的
5. **タイトルは15〜25文字程度、見出し画像は必須**: ブログ側のタイトルをそのまま流用せず、note向けの短縮・調整が必要な場合がある
6. **ハッシュタグは2〜4個、ジャンル大タグ＋独自タグの併用**: #ボートレース #ボートレース予想 等の大規模タグと、龍神レーダー独自のタグを組み合わせる
7. **保証的な表現・誇張された実績数値を避ける**: note利用規約が明確に禁止する「必ずもうかる」型の表現、根拠不明な実績訴求（競合調査で「開設3年で16万人」という自己申告と実測55,616人の乖離が確認された）を避け、実データに基づく数値のみを使う。この方針は既存の`risk-rules.json`によるリスクチェックと整合済み
8. **note pro・有料化は現時点で見送り**: 月額88,000円の投資対効果が見合わない規模。X Premiumと同じ判断軸で「投稿量・型を確立してから再検討」とする
9. **note内公開時のX自動シェア設定は運用判断が必要**: 技術的には可能だが、現行の承認制フロー（sns-hubパイプライン）との整合を別途検討する
