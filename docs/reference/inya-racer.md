# イン屋（前付けの常習）の指標

選手ページ・レースページの「イン屋」の札の根拠。2026-11-03、オーナー依頼。画面は docs/design/inya-racer/。

## 指標
- 前付けの割合 A = 4〜6号艇で出た走のうち、実際の進入が1〜3コースだった割合
- 採らなかった指標: B（全走のうち1・2コースの進入率）は艇番の割り当ての写し（Spearman 0.947）。C（進入 < 艇番）は2・3号艇の1枠の動きを数えてしまう
- アウト屋の鏡 O（1〜3号艇の走のうち4〜6コース）は年→年 r=0.40・分布に切れ目なし・押し出しが混ざるので判定に使わない。小川晃司3352は1〜3号艇の走が直近204走中3走しかなく、O では拾えない（6コースの率は0.97）

## 境目
- 4〜6号艇の走30以上、A の Wilson 95% 下限0.30以上 → 現役1,620人中20人（1.2%、2025-11-03〜2026-11-02）。分布の切れ目（20人目0.482→21人目0.345）と重なる
- 30走ちょうどなら14走（0.467）から札。13走は札なし（scripts/maintenance/verify-front-taking.js）
- 分布: 中央値0.9%、p90 3.7%、p95 6.8%、p99 53.9%
- 年→年で20人中19人が同じ（Pearson 0.959）。会場の差（0.3〜4.2%）は桁が小さく、補正しても上位2%は不変
- 30走未満の1,606人は10走でも誤判定0

## レースへの影響（時系列で分けた検証、2,695R）
- 前付けの選手が4〜6号艇にいると、1号艇の1着 −10.2pt±1.8、枠なり進入 −53.3pt。2〜3号艇なら有意差なし
- 観察による差で、原因とは言えない。当日その選手が前付けするかは言えない

## 画面での数え方
- 画面は src/utils/frontTaking.js が選手の走の行（getRacerRaceHistory・getRacerScopedRaceStats、2025-12-03以降）から数える。today を含む365日。2026-12-02までは期間の始まりが2025-12-03になる（画面に期間を出す）
- レースページはレースの日を today とし、そのレースより前の走だけで判定する
