## 定義

| 項目 | 定義 |
|---|---|
| コース | 実際の進入コース（公式 K ファイル）。`race_results.actual_course_{艇番}`（2025-12-03〜）と `kb_archive_boats.course`（〜2025-12-02）。`race_results.course_1〜6` は艇番と同じ値なので使わない |
| 分母 | 結果のあるレース。中止・順延（結果の行が無い）と不成立は入らない |
| 分子 | 1着艇（返還艇を除く）の進入コース |
| 欠場で6艇に満たないレース | 分母に残す（12か月で568レース、影響は約1%） |
| 同着 | 1着の同着は1艇として数える（12か月で1レース、2025-12-11-17-01。結果 JSON の `dead_heat_first_races`＝18 は新しい表の remark「同着あり」で数えていて2着以下の同着も入る） |
| 丸め | `1着数 ÷ レース数 × 100` を小数第1位で1回だけ丸める |

枠番で数えると6が3.0%、進入コースでは1.9%（全国12か月）。6号艇が前付けで内から勝つ分が枠番の6に入るため。会場ページの枠番別（`winning_technique_stats`、直近90日・枠番）とは別の数字。思考アシストの会場の決まり手（`venue_technique_period_stats`、365日）とは母数が一致する（戸田2,256・江戸川2,068・徳山2,592）。

## 会場の差は本物か

信頼性は会場間の分散のうち偶然で説明できない割合。前半×後半は 2025-10-20〜2026-04-19 と後半6か月の会場順位の相関。

| コース | 信頼性 3か月／6か月／12か月 | 前半×後半 |
|---|---|---|
| 1 | 0.87／0.93／0.96 | 0.81 |
| 2 | 0.62／0.74／0.84 | 0.63 |
| 3 | 0.36／0.72／0.86 | 0.81 |
| 4 | 0.24／0.65／0.77 | 0.36 |
| 5 | 0.64／0.70／0.83 | 0.63 |
| 6 | 0.32／0.52／0.65 | 0.61 |

3か月は会場の最小が444レース（蒲郡）で、2〜6コースの会場差の大半が偶然で説明できる。直近1年なら全会場が1,959レース以上。

## 言えること・言えないこと

- 言える: 1コースの会場差と順位（42.6% 戸田〜61.6% 徳山・下関）。2・3コースの高い低いの大づかみ
- 言えない: 4〜6コースの会場の順位（年によって入れ替わる）。将来の1着率の予測、「◯コースが狙い目」
- 図に区間のひげは描かない。1コースは会場差（最大約19pt）に比べて区間の半幅が約±2pt と小さく、6コースは区間（±0.5pt）と会場差が同じくらいで、ひげを描いても読めない。本文で順位を言うのは差が区間を超えるときだけ
- 注記に書く文: 「進入コース別（枠番ではない）。中止・不成立のレースを除く」「会場ページの枠番別（直近90日）とは定義と期間が違う」「4〜6コースは1着の件数が少なく、会場の順位は年によって変わりうる」（「差は小さい」とは言わない。信頼性は4コース0.77・5コース0.83で会場差の大半は偶然でない。入れ替わりが強く言えるのは前半×後半の相関が0.36の4コースだけ）
