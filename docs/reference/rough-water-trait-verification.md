# 「荒れ水面に強い／弱い」は選手の性質として持続するか（BOA-716）

選手ページの条件別の表（`src/utils/racerConditionStats.js`、BOA-336）に「荒れ水面に強い／弱い」の印を付けるかを決める前に、効き目を確かめた。

## 結論

- **印を付ける根拠はない。** 選手ごとの「荒れ水面での差」は、期間をまたいでわずかに残る（偶然より大きい）。ただし大きさは1着率で約1pt、3連率で約1.6pt（選手間の真のばらつきのSD）しかない。画面の母数（1年で荒れの走が30〜40走）で見える差のSDは5.7pt（1着率）・7.8pt（3連率）で、その大半は偶然
- 画面の母数で見た差のうち、翌年に残るのは約4%（1着率・3連率とも）。「前の年に10pt強い」選手は、翌年は平均+0.4pt
- 「件数が足りず判定できない」ではない。6年分・220万走で、性質の大きさそのものが小さいと分かった。信頼度0.5（見えた差の半分が性質）にするには選手1人あたり荒れの走が約800〜900走、0.3でも約350〜400走要る。1年に約31走なので、それぞれ約26〜30年・約11〜13年分
- 比べる相手を「全選手の平均」にすると前後の相関は0.6〜0.7と高く出るが、全国勝率との相関が0.76〜0.94で、荒れ水面の性質ではなく選手の力量を測っているだけ
- 風5m以上と波5cm以上は、ほぼ同じレースを指す（風の荒れ15.7%・波の荒れ9.4%、どちらかで16.0%）。同じ期間の中で選手の風の差と波の差の相関は0.75〜0.85。分けても別の性質は見えない

## 指標（選手の「荒れ水面の差」）

| 名前 | 定義 |
|---|---|
| self | 荒れの率 − 本人の全体の率（今の画面の比べ方） |
| calm | 荒れの率 − 本人の静水の率 |
| pop | 荒れの率 − 全選手の荒れの率（「全選手の平均」と比べる案） |
| adj | (荒れの走の 実績−期待) の平均 − (静水の走の 実績−期待) の平均。期待は同じ期間の全選手の率で、進入コース×全国勝率の帯（0.5刻み）×荒れか×会場（200走未満の層は会場を外す）。コース・力量・会場の偏りを除く |
| adjv | adj を同じ会場の中で比べ、会場ごとの差を nR·nC/(nR+nC) で重み付けた平均。地元・得意会場が荒れやすい会場だと「荒れに強い」に見える分を除く |

率は1着率と3連率（3着以内の率）の2つ。

## 方法

- **期間の分け方**
  - year: 1年ずつ（10/1〜翌9/30）の隣り合う5組（2020-10→2021-10 … 2024-10→2025-10）を合わせる。画面の母数に近い
  - long: 前 2020-02-01〜2023-05-31 / 後 2023-06-01〜2026-09-30。性質の上限を見る
- 期待（adj・adjv）は期間ごとに、その期間の走だけで作る。前の期間の値に後の期間の結果は入らない
- 前の差と後の差の Pearson 相関（選手で再標本化するブートストラップ1,000回の95%区間）、前の五分位ごとの後の差、後の差を前の差に回帰した傾き
- **偶然との比較**: 選手ごと・期間ごと・会場ごとに、荒れの札を走数を保ったまま入れ替える（200回）。入れ替えた前後の相関の95%範囲と、1つの期間の中の差のSD（見かけ対偶然）を出す
- 残るばらつき（性質のSD）は、前後の共分散の平方根（誤差が前後で独立なら性質の分散に当たる）
- 最低走数は「前・後とも荒れ・静水がそれぞれN走以上」。year は10・20・30、long は10・20・30・50。下の表は year=20、long=30（ほかの値でも結論は同じ、JSON に全部ある）

### 3. 比べる相手

- **全選手の平均（pop）**: 前後の相関 0.53〜0.71 と高いが、前の期間の全国勝率との相関が 0.67〜0.95、1コースの走の割合とも 0.62〜0.89。荒れでも静水でも強い選手が上に来るだけで、荒れ水面の性質ではない。この比べ方で「荒れに強い」と出すと、A1選手のほとんどに付く
- **本人の全体（self）**: 全国勝率との相関 −0.02〜−0.07、1コースの割合とも −0.02〜−0.07。級別・コースの交絡は小さい（荒れでインが弱まる分、インの多い強い選手がやや「弱い」側に寄る程度）
- **コース・力量・会場で期待を合わせる（adj）**: 交絡は 0.00〜0.03 まで消え、相関は self より少し高い（year 荒れ1着率 0.038→0.054）。会場の中で比べる（adjv）と 0.042。どれでも大きさは同じ桁で、結論は変わらない
- 筋がよいのは「本人の全体」か「本人の静水」。「全選手の平均」は別の量（力量）を測る。self は calm に（1−荒れの割合）を掛けた量なので、両者の相関の大きさはほぼ同じ

- 同じ期間の中で、選手の風の差（adj）と波の差（adj）の相関は 0.75〜0.85（long 0.76／0.75、year の5組 0.78〜0.85）。同じレースを数えているため

## 言えること

- 荒れ水面での差は、選手の性質として「ゼロではない」が、1着率で約1pt・3連率で約1.6pt（選手間のSD）の小さなもの。2020-02〜2026-09、220万走
- 画面の母数（1年で荒れ30〜40走）では、見える差のSDは1着率5.7pt・3連率7.8pt で、偶然の入れ替えのSD（5.7pt・7.6pt）とほぼ同じ。1着率で ±11pt、3連率で ±15pt 程度の差は偶然でよく出る（偶然のSDの約2倍）
- 印の付いた選手の翌年の差は ±1.5pt 以内、向きが当たるのは51〜57%
- 「全選手の平均」との差は力量を測っている
- 風と波は同じレースを指していて、分けても別の性質は見えない

## 言えないこと

- 風向き（追い風・向かい風）、うねり、水面の種類（海水・淡水・干満）ごとの選手の得手不得手（今回の区分は風速と波高だけ）
- 5m・5cm 以外の閾値での結果（例: 風7m以上は未検証）
- 1レースの予想に使ったときの上積み（未検証。性質のSDが約1pt なので小さいと見込むが、測っていない）
- 選手の調子・体重・年齢で変わる、一時的な荒れ水面の得手不得手（期間を1年以上で切っているため、短い期間で変わる性質は見えない）
- year の組ごとの揺れ（2022-10→2023-10 だけ 0.13）の理由
- 本番DB（`race_conditions`）の値での結果。アーカイブのK（レース時）と本番DBの風速は一致しない走が多い（2026-02〜09 の6日・888レース: 風速が同じ 55.5%、5m以上かどうかが同じ 94.9%。波5cm以上かどうかは江戸川を除く852レースで 97.7% 同じ）。差の理由は未検証。区分の一致は95%前後なので、結論は変わらないと見込む
