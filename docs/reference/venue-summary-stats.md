## 定義

| 項目 | 定義 |
|---|---|
| 分母（決まり手） | 結果と決まり手のあるレース。不成立（`race_status='no_race'`）・中止（`is_cancelled` が false でない）・1着なし（返還艇を除いた1着が無い、記録の1着艇が無い）・決まり手なしを除く。6種（逃げ・差し・まくり・まくり差し・抜き・恵まれ）以外の決まり手も分母に残す（12か月で1R。6種の割合の合計は100%に1R分届かない） |
| 分母（コース） | そのうち1着艇の進入コースが分かるレース（12か月では全数） |
| コース | 実際の進入コース。枠番では数えない（6の1着率は枠番で3.0%、進入コースで1.9%） |
| 出典 | 〜2025-12-02 は `kb_archive_races`・`kb_archive_boats`、2025-12-03〜 は `race_results` |
| 信頼性 | 1 − 平均の標本分散 p(1−p)/n ÷ 会場間の観測分散（24会場）。会場差のうち偶然で説明できない割合 |
| 前後半 | 前半6か月×後半6か月の会場順位の Spearman |
| 全国との比較 | その会場を除く全国との2群の比率の z。Bonferroni（24会場）で \|z\|>3.08 |

### 1コースの逃げと1コース1着率の重なり

全国12か月の1コース1着 30,840回のうち逃げ 29,482（95.6%）・抜き 1,294・恵まれ 63・その他 1。1コース以外が逃げで勝った回数は0。1コース1着率 − 逃げ率は全国で2.44pt で、会場の順位・Bonferroni を通る顔ぶれもほぼ同じ。本文の主役は1コース1着率だけにし、逃げは表に載せる。主語は「全レースの決まり手のうち逃げ」と書き、「1号艇の逃げ率」と混ぜない。

## 水面の特徴（src/data/venueWaterProfiles.js）

中身は水質（淡水・汽水・海水）と干満差の有無だけで、公式の場データ（2026/06/30現在）の静的な事実。データから導いた主張は入っていない。

- 水質・干満から水面の動きや1着率への因果を書かない（例「海水で潮があるのでイン有利」）
- 潮の有無を水質から推定しない（蒲郡・常滑・津は海水・汽水でも干満差なし）
- ナイター・水面の広さなどを足すときは、公式の会場ページで照合してから書く

- 有利／不利（数字で言い換える）
- 荒れる・荒れやすい会場（万舟率は未検証）

## レースページの展示タイム（GS01-c）で言わないこと

- 「展示2位」は着順と取り違える。「展示タイム2位」と書き、小さいほど速いことを近くに書く
- 1号艇は同じ選手でも約0.017秒速く出る（[stat-findings.md](../knowledge/stat-findings.md)「直前情報・展示」）。順位や色づけで「1号艇の足が良い」と読ませない
- 同タイムが多い（準優・優勝戦の1号艇は23%が他艇と同タイム）。同順位の扱いを決める
- 会場をまたいで秒数を比べない。上位に「有利」、下位に「足が落ちた」と書かない。色づけは順位の事実だけ
- 括弧付きの値・未取得の扱いは、公式の仕様を確かめてから決める（[data-definitions.md](../knowledge/data-definitions.md)）

## 今のカード（VenueCharacteristicsCard）との食い違い

1. **期間**: カードは直近90日（`outcome_distribution`・`winning_technique_stats`）。90日は会場の最小が468Rで、2〜6コース・差しの会場順位が12か月と合わない
2. **枠番と条件付きの割合**: 決まり手の欄は枠番で数え、その枠が勝ったときの内訳（若松の1号艇は逃げ94.13%）。見出しが「主な決まり手」だけで、全レースの割合と誤読される
3. **`venues.cluster` が止まっている**: `docs/db-migration/001_schema.sql` の `update_venue_stats()`（枠番1の1着率が60%以上で in_strong、50%未満で out_strong、直近90日）に呼び出し元が無い。同じ式を12か月の値に当てると11/24会場、90日だと16/24会場が DB の値と食い違う（若松 out_strong・実際58.5%、桐生 in_strong・49.8%、下関 balanced・60.9%）。別の票で扱う
4. **母数の単位**: 脚注は「直近N走」だが、中身はレース数（`total_races`）
5. **窓の終わり**: `winning_technique_stats`・`outcome_distribution` は終わりの日を切っていない（コードから読んだだけで、影響は未測定）。`venue_technique_period_stats` は前日で切っている
