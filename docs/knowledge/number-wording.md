# 数字の言い方と定義

画面・SNS 動画・ブログで数字をどう言うか。用語と禁止語は [glossary.md](glossary.md)、値の定義は [data-definitions.md](data-definitions.md)。書き方は [README.md](README.md)。

## 母数・範囲・条件
- 数字には母数を付ける（例 179件中57勝）（2026-10-11、オーナー、hq の boatrace-fan ノート）
- 過去の割合は「範囲・条件・結果」の3つを添える。「1号艇は1着76%」は会場の1号艇の1着率か選手本人の1コースの1着率か分からない（2026-10-12、オーナーの v11e への指摘）
- 30件未満の範囲は割合を出さず件数だけ。件数が足りる範囲へ広げる（2026-10-12、stat-findings.md「思考アシスト」）
- 条件付きの統計は、見出しの下に「範囲・条件（本番のスタートの形など）」「何で分けたか」「結果」の3つを書く。条件が小さな注記だけだと価値が伝わらない（2026-10-12、オーナーの12R v12d「展示で見る分かれ目」への指摘）
- 割合は「N件中X%」の形で分母を明示する。「X%（N件）」はNが分母か分子か読めない（2026-10-12、hq の X スレッド点検）
- 平均ST は期間を名前に付けて出す。名前だけの「平均ST」と「蓄積した全期間」は出さない（2026-10-10、docs/design/avg-st-definition/mock/APPROVED.md、BOA-815 承認）
- 同じ艇の同じ着順の割合は、画面のどこでも同じ範囲・同じ値にする。場所で値が違うと信用されない（2026-10-11、docs/design/thinking-assist/boa831/fan-panel-nagashi.md、BOA-833）
- 本編と同じ指標で龍神の画面の値が違うときは「条件が違う集計」と明記する（2026-10-11、デザイナー役 v9e 評価、hq の designer ノート）
- 集客の文面に予想の実績の数字を使う前に、予想なしの基準と比べる。展開予測の的中率 79.5% は「1〜3号艇のどれかが1着」の81.5% を下回り、トップから外した。方針は「的中率・回収率の土俵では戦わない」（控除率25%で長期の回収率は75%へ寄る）（2026-10-01 ユーザー判断、memory seo_keyword_strategy_2026_09_29、PR #1032、BOA-617）
- SNS の全貌動画の文（x_text・YouTube と Shorts の title・description）で過去の割合（1着率など）を使うときも、画面と同じく母数（件数）を書く。件数の無い「X%」だけは不可（2026-10-18、wording-editor、~/ryujin-marketing/out/full-picture-template/split/render/full-picture-bundle.py 35-39行）
- 動画で範囲が切り替わる区間（会場→全国、全国→本人）では、常設注記・母数札・答えも切替先の範囲へ識別子で置換する。会場名を固定した注記や、注記を足しただけで前の条件の母数が残る状態は不可。JSON の非描画メタ情報に範囲を残しても視聴者への説明にならない（2026-10-14、2026-10-14-scene1-r3-scene2.md・2026-10-16-full-picture-generator.md）
- 展開の条件別結果と全国結果で件数の優劣が逆になるときは、切替先の範囲を答えと同じ場面に示す。矛盾や同じレースの確率の変更という誤読を防ぐ（2026-10-16、2026-10-16-split-full-rounds-text.md）
- 会場の枠番表（短期）と風別の進入コース表（長期）は、丸め値が同じでも同じ統計とみなさない。記事・字幕では期間と母数の違いを明記し、会場の母数を示しただけで全国平均の母数を補ったことにしない（2026-10-13、2026-10-13-venue-20261013-10-wakamatsu.md・2026-10-13-venue-20261013-02-tokuyama.md）
- 丸めた2つの率から差（pt）を再計算すると、画面の差とずれることがある。差も公開 JSON・画面の値を転記し、本文・字幕で再計算しない。画像内に pt があるときは本文に「会場全体の1着割合との差」と添え、相対的な増減率との取り違えを防ぐ（2026-10-13、2026-10-13-venue-20261013-02-tokuyama.md・2026-10-14-scene1-trial.md）
- 強風ランキングの「何番目」は、同率の有無と並び順を確認する。表示差が同率の行を、独自の差の順位として解釈しない（2026-10-13、2026-10-13-plan-review-20261013-31.md）
- 風の区分は公開画面の区分名と数値（追い風2〜3m、4m 以上など）で呼ぶ。「弱い追い風」と呼ぶと別区分の「弱い・横風（1m 以下・横風）」と混同する（2026-10-13、2026-10-13-venue-20261013-06-shimonoseki.md）
- 風速区分の境界は指標ごとに違う。イン1着率の区分を外枠有利のしきい値へ転用しない。別レーンの検証報告の「定義案」は、素材化の承認や効き目の検証完了を意味しない（2026-10-14、2026-10-14-plan-2010.md）
- 「節開始時」のモーター率は値の基準時点で、使用開始日や観測期間の開始ではない。保存 UI と部品定義で裏付けても、使用期間・母数の未取得は別に残し、推定で埋めない（2026-10-13、2026-10-13-plan192617-shorts.md・2026-10-13-plan-1926.md）
- 過去日のレースを題材に撮り直しても、選手ページの期間などは撮影日時点の移動窓で、開催日時点の成績には戻らない（取得日と開催日を区別する）。全国平均等の参照値やページ部品が、過去日 URL でも保存素材と一致する保証もない。確定字幕を維持する改訂では、再撮影前に値・部品・時点の一致を確認する。後日撮った画像を古い字幕と混ぜない（2026-10-15、2026-10-15-scene3-trial.md・2026-10-15-motion-rules.md）
- 「全期間」は画面が取得する窓内の全期間を指す。「最大過去2年」は730日取得窓の表現で、暦の2年（閏日を含む）との差と、過去レースでは当該レース以前への制限を別に確認する（2026-10-14、2026-10-14-plan-review-20261014-09.md・2026-10-13-plan-review-20261013-13.md）
- 過去の一部にある結果は「〜した例がある」と表し、条件付きの全件が同じ結果だったような「この形では〜した」と区別する（2026-10-16、2026-10-16-split-full-rounds-text.md）
- 形の成立率（手がかり）と、その形が成立したレースの着順は母集団が違う。切替時に条件・分母を再掲し、前者から後者へ絞ったような動きにしない（2026-10-14、2026-10-14-script-review-gate.md・2026-10-17-split-r13-text.md）
- 母数が公開表示に無い割合は台詞・図に出さず、確認済みの6艇内順位で材料を比べる。元の割合は未使用の監査資料として残し、撮影も割合の領域を映さない（2026-10-14、2026-10-14-script-review-gate.md）
- 本人1枠の全出走表と絞込履歴の母数が合わないとき、勝利時の決まり手帯を確認できても本人の1着率は確認済みにならない。全出走率と勝利内訳を別項目にする（2026-10-14、2026-10-14-script-model-review.md）
- 「1号艇の逃げ率」と全艇の決まり手「逃げ」は別指標。同率表現へ直すときも主語を落とさない（同じ画面の決まり手内訳と矛盾する）（2026-10-17、2026-10-17-split-r13-r17.md）
- 「今日の風」は、対象レースの更新値・先行レース時点・ソナーの展示保存値のどれかを明示する。結果由来の observedAt には予定時刻が入ることがある（2026-10-14、2026-10-14-ryujin-feature-catalog.md）
- 枠番の出目応答と決まり手応答の分母を、同じ会場ページだからと一致する部分集合とみなさない。各欄の件数を転記し、除外規則を確認できないときは逆算や混合比較に使わない（2026-10-13、2026-10-13-venue-20261013-11-tsu.md）
- 既存バッチの抽出最低母数と新しい SNS の掲載最低母数は別。表示を見送ったことを「元データ該当なし」と書き換えない（2026-10-15、2026-10-15-morning-info-discussion.md）
- イン崩れの実績が「1着を逃した割合」なら、3着に残った実例を「崩れに至らなかった」と別の着順定義で評価しない。指数の相対順位・非1着の実績・3着以内の割合を分ける（2026-10-13、2026-10-13-plan-review-20261013-07.md）
- 係数や予測損失差の区間が0を含む結果は「上積み未確認」と書き、無効果の証明や不採用の判断と同一視しない（2026-10-16、2026-10-16-review-20261016-03.md）
- SNS 投稿の出典照合では、claims から除外した値も X 本文・説明文に残れば消えない。本文の全数値を照合対象にし、映像を変えない指定なら映像側の未照合値を別に記す（2026-10-14、2026-10-14-sns-v1-bundle-trial.md）

## 全国の数字と個人
- 全国の数字には「全国・母数」を付け、選手名の小見出しの下に置かない（選手本人の成績に読まれる）（2026-10-11、ファン役 v9b 評価）
- 過去の割合は艇番で言い、選手名を付けない。締めで「1着 池田」と予想せず「過去の割合で多いのは1号艇」と統計で言う（2026-10-12、オーナーの v11e への指摘）
- 全国の数字を個人の評価（「弱め」等）に言い換えない。締めの字幕も「材料は減った」まで（2026-10-11、ファン役 v9d 評価）
- 優勝戦の1号艇A1は展示順位で1着率がほぼ動かない（67〜80%、facts by.exh_time）。全国の横一線の数字（68/55）を1号艇に当てはめない（2026-10-11、ファン役 v7 評価）

## 展示の言い方
- 「展示2位」は着順と取り違える。「展示タイム2位」と書き、「展示上位」も展示タイムか展示ST かを毎回書く（2026-10-12、ファン役 v10b・デザイナー役 v9b）
- 回数は何の回数かを書く。「今節7走中6回」では読めない（展示1位の回数）（2026-10-12、ファン役 v10b）
- 展示後の言い方は過去形で言い切る（「〜だった」）。条件の札（「カドなら」）に過去形の事実（「展示5位だった」）を続けると噛み合わない（2026-10-12、ファン役 v10・v10b）
- 展示順位の低下を「足が落ちた」と書かない。見出しも字幕と同じ基準で点検する（2026-10-11、ファン役 v8、12R で高橋も下がっていて「2人」に絞れなかった）
- 「通常」と比べる値は割合を並べる。母数が小さいときは矢印や「上がった」を付けない（2026-10-12、デザイナー役 v10）
- 「展示順位 2位 → 1位（8走・6.87→6.88）」のような矢印は、何が良くなったか単独で読めないので撤去した。矢印・上下の記号は凡例なしで読めるか確かめる（2026-09-27、memory race_detail_fan_review_loop_2026_09_27、PR #866・#871）

## 未検証の付け方
- 「未検証」は効き目が未検証の情報にだけ付ける。主役の情報に付けない（2026-10-11、ファン役 v9b）
- 部品交換・チルトは「事実＋効き目は未検証」と並べ、有利・不利を書かない。オリジナル展示の周回・まわり足は効き目を確認済み（stat-findings.md）（2026-10-11、ファン役 v7。2026-10-12 の検証でオリジナル展示を未検証から外した）
- 期間の表記は終了年を省略しない。「2019/4/1〜10/10」は両方 2019年に見える（2026-10-12、BOA-822 wording-editor、docs/design/in-collapse-caution/mock-reviews-v1.md）

## 点検での見落としを防ぐ知見
- 公式表示が割合のみで母数を示さない場合、別データの件数を分母として補わない。（2026-10-12、2026-10-12-task-39-venue-article-v2.md）
- 公式の季節別表を引用するときは季節名だけでなく表示年・期間も残し、本文と画像内の水質札の両方を公式と照合する。（2026-10-12、2026-10-12-task-41-venue-amagasaki.md）
- 本文内の矛盾は同じ対象・条件の命題で判断し、一般的な保証否定と特定組番の低頻度を同じ命題として扱わない。（2026-10-13、2026-10-13-audit-20261013-02.md）
- 券種の組合せ数の逆数を使う等確率の基礎例と、実戦で選んだ組番の予測確率を区別し、まとめでの条件省略も点検する。（2026-10-13、2026-10-13-audit-20261013-04.md）
- 数値台帳と本文は数字の一致だけで結び付けず、単位・項目・本文位置で対応を確認する。（2026-10-13、2026-10-13-audit-20261013-05.md）
- 枠番別の1着割合から決まり手内訳へ進むときは、分母が会場全体からその枠が勝ったレースへ変わると明記する。（2026-10-13、2026-10-13-task-47-venue-naruto.md）
- 展示タイムは秒数が小さいほど速く、棒が長いほど速い表示の場合は両方を近接して説明し、秒数・展示順位・本番着順を区別する。（2026-10-13、2026-10-13-task-51-note-light-drafts.md）
- 割合の転記一致・集約件数からの算術一致・個票からの独立検証を区別し、過去90日の表示だけで期間境界・除外規則を確認済みにしない。（2026-10-13、2026-10-13-task-61-heiwajima-numbers.md）
- 本文で取り上げない画像内の値も全数値照合に含め、一部の本文の一致だけで採用画像全体を検証済みとしない。（2026-10-13、2026-10-13-task-64-new-article-kiryu-ai-data-numbers.md）
- 3着以内の周辺割合・3着単独の割合・着順付き3連単の組合せ割合は別の問いで、周辺割合の積を組合せ確率に置き換えない。（2026-10-13、2026-10-13-task-68-new-article-top3-rate-numbers.md）
- 注記に渡す艇数・件数は「欠けている側」か「残っている側」かを文で分かるようにする。イン崩れ注意度の「欠場あり（5艇）」は出走する艇の数で、ja は spec の確定文言のまま、en・zh-TW・ko は「5 boats racing」「5艇出賽」「5척 출주」と書いた（2026-10-17、BOA-822 wording-editor）
- 新しい表示面（SNS の共有文など）に注意度の割合・段を出すときは、カードが渡している件数（n）と免責（inCaution.disclaimer）も引き継ぐ。段の言葉が保証・射幸心に当たらない前提は免責の併記（2026-10-17、BOA-822 #1610 wording-editor P1）
- 全貌動画の字幕の文でも平均ST は「平均ST（直近30走）」と期間を付ける（図の軸の名前は画面と同じ短い「平均ST」でよい）。本文で1着率を出すときは件数（その順位のときの件数・全体の件数）を添える（2026-10-20、wording-editor、scene2-data.mjs の itemSentence・run.mjs の postText）
- 文の型は「項目＋値＋順位」を1文にまとめる（「〜の一番上は○○の4位 / 25.0%…」と値を別の行に分けると、短い表示時間で何の値か読み取れない）。優勝戦・準優勝戦の日の今節の着順点は、画面が今日の順位を出しつつ棒の今日の位置は出さないので、字幕も「1号艇は1位、準優勝戦の日は枠順に近く参考」と理由まで書く（2026-10-20、wording-editor・オーケストレーター、全貌動画 場面2）
