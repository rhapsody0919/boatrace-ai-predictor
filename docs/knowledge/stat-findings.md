## 選手・機力
- モーター2連率は単体の予測力が低い。展示タイムと並べて見せる（2026-10-11、データサイエンティスト役の回答。読み物なし）
- 「荒れ水面（風5m以上・波5cm以上）に強い／弱い」は選手の性質としてほぼ持続しない。1年→翌年の相関は1着率0.04・3連率0.04（約6,200組、荒れ約35走）で、残る差のSDは約1pt・1.6pt。印（±5〜15pt）の付いた選手が翌年も同じ向きなのは51〜57%で、印は付けない（2026-10-13、BOA-716、K・Bファイル2020-02〜2026-09の220万走、docs/reference/rough-water-trait-verification.md）
- 選手の荒れ水面での率を「全選手の平均」と比べると力量を測るだけになる（全国勝率との相関0.67〜0.95）。比べるなら本人の全体か静水と比べる（2026-10-13、BOA-716、docs/reference/rough-water-trait-verification.md）
- 風5m以上と波5cm以上はほぼ同じレースを指す（荒れの走の割合15.7%・9.4%、どちらか16.0%）。選手の風の差と波の差の相関は0.75〜0.85で、分けても別の性質は見えない（2026-10-13、BOA-716、docs/reference/rough-water-trait-verification.md）
- 選手の条件別の表で荒れの走が約35走のとき、1着率±11pt・3連率±15pt程度の差は偶然でよく出る（並べ替えのSD 5.7pt・7.6pt）。荒れ水面の情報は選手の印より、全国・会場のコース別の効き目（荒れで1コース1着率 55.9%→49.5%）のほうが根拠がある（2026-10-13、BOA-716、docs/reference/rough-water-trait-verification.md）

## 思考アシスト（軸・相手）
- 2〜6号艇が1着のレースを「その艇の級でそろえた範囲（VC/NC）」で見ると中央値69件、30件未満24%、6号艇は57%。会場の全レース（VA）なら中央値1,698件・最小342件（6号艇、10%点400件）（2026-10-12、10/8〜10/11 の600R×5艇、docs/design/thinking-assist/analysis/boa845-axis-place.md）
- 2〜6号艇が1着のときの2着は軸で変わる: 1号艇+11〜+22pt、2号艇−6〜−12pt、4が1着なら5が+6pt。無条件の値より2着の Brier が3.4%良い（区間 [2.8, 4.0]%、学習〜2026-03・検証2026-04〜09 の12,462R）（2026-10-12、同 boa845-axis-place.md）
- 1着だけを条件にした3着は、相手の無条件の3着率より良くならない（Brier −0.24%、区間は0をまたぐ）。3着の条件付きの表は出さず、3着以内の無条件の値で足りる（2026-10-12、同 boa845-axis-place.md、docs/design/thinking-assist/boa831/fan-panel-boa845.md）
- 級でそろえた範囲の条件付きの率は30件未満だと無条件より悪い（2着 Brier 0.8123 対 0.7856）。30件未満は割合を出さず、件数が足りる範囲へ広げる（2026-10-12、同 boa845-axis-place.md）
- 2〜6号艇の1着時の2着・3着は、1号艇の範囲・会場の全レース・全国の scenario（tri）からバッチの変更なしで出せる（src/utils/assistSummary.js の winFollowers の boat 引数、api/analogy/scenario の scope=VA）（2026-10-12、同 boa845-axis-place.md）
- 相手レンズの印（軸に合わせた2着率と基準の差が5pt以上）は件数の揺れでは点かない: 会場の全レースの600組で偶然の印の期待値は計0.91組、向きは後の期間で97.7〜99.4%同じ（2026-10-12、同 boa845-axis-place.md「相手レンズの印のルール（案C）の検証」、data/analysis/boa845-axis-place/mark-rule.json）
- 基準を「全レースの2着率を軸の艇を除いて割り直した値（q）」にすると、1号艇は120組すべてで ↑ になる（負けたレースだから2着が増えるだけ）。基準は「その艇が1着でなかったレースでの2着率を割り直した値（q_nw）」にする。2着の Brier も p 0.7448・q_nw 0.7541・q 0.7933（2026-10-12、同上）
- q_nw を基準にした印は600組で179組、1号艇 ↑ は34組。中身は 4→5 ↑ 24会場・4→2 ↓ 23・3→2 ↓ 20・5→6 ↑ 15 で、全国の効き目と同じ向きのスジ（2026-10-12、同上）
- 差が閾値ちょうどの組は約50%で印が点いたり消えたりする。判定は丸める前の値で行い、表示の整数で判定しない（例 徳山・4号艇軸の6号艇は基準 q との差が +4.5pt で、5pt の印は付かない）（2026-10-12、同上）

## イン崩れ（1号艇が1着を逃すか）
- 一番よく当てる1つの量は「1号艇の全国勝率 − 2〜6号艇の最高勝率」。AUC 0.681 で、今のイン崩れ指数（0.664〜0.679）を上回る（2026-10-11、検証 2025-06〜2026-10-10 の 75,295R、docs/design/in-collapse-caution/analysis/round1.md）
- 類似レース上位400件の1号艇の非1着率は、今のイン崩れ指数より AUC +0.020［+0.008, +0.032］、級の並びの率（思考アシスト「堅い？荒れる？」）より +0.016。小さい回帰には −0.011 届かない。長期では「指数から展開予測の値を抜き平均STを直近30走にしたもの」と区別できない（+0.008［−0.004, +0.019］）（2026-10-11、2026-09-22〜10-10 の 2,869R と 2025-06〜の抽出 3,975R、docs/design/in-collapse-caution/analysis/round2.md）
- 平均ST（直近30走・1コース）は、勝率と一緒に見ると1号艇の非1着にほぼ効かない（回帰から抜いて AUC −0.003）。今の指数の式で全期間の平均を直近30走に替えると −0.004（2026-10-11、同 round1.md）
- 会場の中での順位（0〜100）にすると、会場ごとの崩れやすさが消えて当てる力が下がる（AUC 0.679→0.670）（2026-10-11、同 round1.md）
- 級の並びの率はそのまま率として出しても較正のずれが最大 1.5pt。類似レースの層が400件未満のレース（4.2%）は当てる力が落ちる（AUC 0.651、167R、区間は未検証）（2026-10-11、同 round1.md・round2.md）
- 本番 predictions（unified）のイン崩れ指数は 2026-08-11〜09-21 の多くの日で夜に書き直されている（BOA-628）。過去の比較には朝に書いた 2026-09-22 以降を使う（2026-10-11、同 round1.md）
- 朝（類似レースのバッチより前）のイン崩れの代わりは、勝率差を0.5刻みの帯にした全国の前日までの非1着率。類似レースの割合との AUC の差 −0.007［−0.013, −0.001］、Spearman 0.917。切り替えで変わる幅は中央値 4pt、10pt超が12%、3段（35/55）で段が変わるのは20%（2026-10-12、2,869R、docs/design/in-collapse-caution/analysis/round3.md）
- 類似レースの層が400件未満のレースは4.0%で、優勝戦の68%・準優の40%が当たる。そこでは AUC 0.611、低い側の予測が12pt端に振れる。全国の率に m=25 で寄せると Brier −0.0028［−0.0054, −0.0004］（2026-10-12、同 round3.md）
- 展示後に並べ直した類似レースの割合は、展示前より AUC +0.0067［+0.0038, +0.0094］。下位10%の非1着率 23.6%→19.9%。本番で展示後の値が出ないのは約0.9%（大半は欠場）（2026-10-12、同 round3.md）
- 類似レースの割合の段は 35%・55% で切る3段なら、19日分（2,869R）でも段ごとの実際の非1着率 26.5%／42.0%／63.5% の区間が重ならない。10pt刻みの5段は中ほどが隣と重なる（2026-10-12、同 round3.md）
- イン崩れ注意度の値（勝率差を0.5刻みの帯にした全国の前日までの非1着率、案Y）は、今の指数より Brier −0.0050［−0.0085, −0.0013］（2026-09-22〜10-10 の 2,869R。AUC +0.013［−0.002, +0.028］）、長期では展開予測の値を抜いた指数より AUC +0.0069［+0.0040, +0.0097］（75,295R）（2026-10-12、docs/design/in-collapse-caution/analysis/round4.md）
- その値を 35%・55% で3段に切ると、長期・19日分とも段の区間が重ならない（実際の非1着率 26.7／42.6／65.5%、入る割合は約25／45／30%）。帯の率の期間は全期間・3年・2年・1年で Brier の差が 1/10,000 未満なので全期間（2026-10-12、同 round4.md）
- 準優・優勝戦は勝率差の帯の率の当てる力が AUC 0.56〜0.58 で、率が高く出る（準優は予測 36.4% 対 実際 27.6%）。ラウンドで分けた帯の率にすると準優の較正のずれが 17.0pt→4.6pt（2026-10-12、同 round4.md）
- 勝率差を浮動小数で0.5刻みの帯にすると 0.041% のレースが下の帯にずれる。1/100 の整数で計算する。1艇欠場のレースは残りの艇で勝率差を出しても AUC 0.667（3,983R）（2026-10-12、同 round4.md）
- 件数100未満の (ラウンド, 勝率差の帯) で注意度を出さないレースは、2025-06〜2026-10-10 の完全レース 75,295 のうち28（0.04%）で、準優24（0.77%）・優勝戦2・一般2・予選0。直近30日は2レース（1日 0.07）。100〜299件の「件数少なめ」は171（0.23%）で、優勝戦の8.05%に当たる。SG・G1 の準優・優勝戦で出さないレースは0（2026-10-13、docs/design/in-collapse-caution/analysis/sparse-cells.md）
