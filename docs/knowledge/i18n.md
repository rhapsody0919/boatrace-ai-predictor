# 多言語の実装と需要

多言語（en・ko・zh-TW）の実装の落とし穴と、言語ごとの検索の需要。用語の対訳は [glossary.md](glossary.md)「用語の対訳」と `docs/reference/i18n-glossary.md`、新しいページの区分は `.claude/rules/i18n-new-pages.md`。書き方は [README.md](README.md)。

## ルーティングと SEO
- 言語の正本は URL（/en/* 等）。言語設定によるリダイレクトは初回の読み込みとトップ（/）でだけ行う。描画のたびに行うと JA への切り替えとぶつかり、深い URL で行うと直接のアクセスが飛ばされる（2026-07-13、memory i18n_project、BOA-126）
- LANGUAGE_ONLY_PATHS はパス単位（/venues 全体）で言語対応を決める。一部の会場しか無い言語を足すと、無いページへの hreflang が出る。全ページがそろってから LANGUAGE_ONLY_PATHS と generate-sitemap.js の両方に足す（2026-08-10、memory feedback_venue_guide_quality_upgrade、src/config/languages.js）
- 一部の記事だけ翻訳したブログでは、ルーティングのガードに言語を見ない isPathTranslated を使わない（未対応の言語で lang を宣言したまま日本語を配る）。言語ごとに getAvailableLanguages で判定する（2026-08-11、memory foreign_audience_growth_strategy_2026_08、PR #274）
- 多言語のページは本文だけでなく JSON-LD 内の文字列も言語ごとに出し分ける（VenueRegionHub.jsx の BreadcrumbList が英語固定だった、PR #245）（2026-08-10、memory feedback_venue_guide_quality_upgrade）

## 画面の実装
- Recharts の dataKey は翻訳した文字列にしない（lodash の path として読まれ系列が壊れる）。dataKey は英語の識別子か DB の値のままにし、凡例は <Bar name={t(...)}> で訳す（2026-08-09、memory i18n_p1_analysis_tools_handoff、PR #193）
- 言語の判定は i18n.language ではなく i18n.resolvedLanguage を使う。i18n.language には正規化前の navigator.language が残ることがある（2026-08-09、memory i18n_p1_analysis_tools_handoff、PR #194）
- グラフ内の選手名に translate="no" を付けるときは ResponsiveContainer の外側の div に付ける（ResponsiveContainer は知らない属性を DOM に渡さない）。英語の件数の文言には i18next の _one も用意する（2026-08-09、memory i18n_p1_analysis_tools_handoff）
- formatDate() は和暦固定の ja 専用。翻訳対象のページでは formatDateLocalized（Intl.DateTimeFormat）を使う。/en/race/... に日本語の日付が混ざった（2026-08-29、memory venue_list_redesign_2026_08_28）
- 名称変更は locale の説明だけでなく、グラフの dataKey・凡例・軸単位と記事メタも照合する（2026-10-13、2026-10-13-plan-review-20261013-18.md）
- 4言語のキーとプレースホルダーが一致しても、訳語の整合は保証されない。新しい注記は既存の対訳に照合する（2026-10-13、2026-10-13-plan-review-20261013-26.md）

## 需要
- 英語圏で検索が多いのは「AI予想」ではなく観戦・賭け方を学ぶ内容（how to bet on boat race japan 等、競合は localbetjapan.com）。繁体字の「日本旅行で観戦する」内容には先行者がいる（WAmazing 等）。韓国は Naver が主流で、Google 側の観測だけでは需要を低く見積もる（2026-08-16、memory i18n_technical_and_demand_audit_2026_08_16、要確認）
- 多言語の流入はほとんど無い。GA4 の en は30日で7PV、Search Console の en・ko・zh-TW のクリックは14日で10件未満（2026-09-29、memory growth_pdca_2026_09_29）
- 言語別overrideを日本語baseへ重ねる方式では、新しいメタ専用キーも未翻訳ならbase値を継承する。適用前にメタ保有記事と翻訳登録の重なりを確認し、翻訳title等へのフォールバック契約と分ける。（2026-10-19、2026-10-19-review-20261019-12.md）
