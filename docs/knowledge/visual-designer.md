# 龍神レーダー SNS のデザインの知見ノート（デザイナー役が最初に読む）
1行1知見、出典つき。デザイナー役（.claude/agents/visual-designer.md）が最初に読み、答えの最後に出した「足す行」を依頼元が書き足す。古くなった行は消さずに「（廃止 日付 理由）」を付ける。初版は hq の knowledge/ryujin/designer.md（2026-10-11 時点）を写した

## オーナーの評価（2026-10-11、蒲郡12R の Shorts v3〜v5）
- 文字が多いのは不可。字幕は1場面2つまで・16字以内、動きに合わせて1つずつ出す。数値は図の中に大きく
- スタート隊形はサイトの部品（SlitShapeIcon・SlitHint）を使い、隊形の呼び名（イン凹み・カド一撃等、サイトの文言）を大きく見せる
- 動きが弱いのは不可。ただし点々の一斉点灯のような、何を表すか分からない動きは不可。並べ替え等は滑らかに（重なり・カクつき無し）
- 流れ図（サンキー）は1艇分だけだと何の図か分からない。見出し・列名・艇名を付ける
- 内部メモが画面に出る事故があった（v3「思考アシストは別投稿で」）。台本の注記と字幕を分けて書く
- 参考: uchita_success の「動くスライド」。動かすのは見る人が聞きたくなる所だけ（BOA-817）
- BGM は既存の note 動画の Pixabay 曲、尺は59秒以内（1分超は申し立てでブロック）

## オーナーの評価（2026-10-11、v6）とデザイナー役の点検
- 展示の場面は「何を見るか」だけでなく、判断の基準を数字で出す（例: 展示タイム上位1〜2位なら40%、下位なら22%）
- 展示STから作るスリット隊形は、展示の判断材料として描かない（本番STとの相関0.08と矛盾する）
- 同じ図（スリット図）の使い回しは1本で1回まで。何度も出すと中身が無く見える
- 図は画面幅100%・縦60%を使う。下40%が空く構成は質が低く見える。字は最小36px相当
- 展示タイムの棒はサイトと同じく「最も遅い艇との差」にし、差を秒で明示する（0.1秒差は素の値の棒では見えない）
- BGM はオーナーの好みで X/TikTok の縦型動画の曲（soundtrack.wav）。note 用の Calm Corporate Relax は不採用（10/11）

## サイトの UI/UX（龍神レーダーの画面）
- 押せる部品はスマホで高さ44px以上。見た目を小さくしたい「?」等は見た目16pxのまま押せる範囲を24×24に広げる（src/components/race/TermHintButton.css の ::before、e2e/race-tab-width.spec.js）
- 結論を先に出す。表・図より上に一言の結論、詳しい数字は下か深掘りへ（Orchestrate 2026-10-11 依頼、思考アシスト・龍神ソナーの共通方針）
- PC のタブの横幅は3段: 6艇を列に並べる表は全幅／図とリストは最大1200／文章と1行1項目は720。どの段も左端はタブの列（1440px で x=24、1920px で x=184）にそろえ、中央寄せにしない（BOA-820、PR #1382、e2e/race-tab-width.spec.js）
- 選んでいない項目が選ばれているように見える見た目にしない（塗り・太字・下線を選択中だけに使う）（Orchestrate 2026-10-11 依頼）
- 余白はモバイル(480px以下)で margin・padding 0.75〜1rem、gap 0.5〜0.75rem。デスクトップは margin 2〜2.5rem、padding 1.5〜2.5rem、gap 1〜1.5rem（.claude/rules/mobile-ui.md）
- ページ背景に直接乗る文字は意味トークン（--text-primary 等）を使い、ダークモードでも確かめる（.claude/rules/component-reuse.md、2026-08-25 の不可視見出し）
- 横あふれは表示項目を削らずデザインで解く（memory feedback_dont_remove_info_for_layout）
- 押せる1行を持つトーストは6秒・マウスを重ねている間は消さない・閉じるボタン付き。2秒では読んで押せない（BOA-832、src/components/Toast.jsx）
