# SNS 動画の検査・合格判定と計画の扱い

完成した SNS 動画を評価・検査するときと、動画の計画・承認を扱うときの落とし穴。構成・画面配置・動き・音は [video-composition.md](video-composition.md)、数字の言い方は [number-wording.md](number-wording.md)。書き方は [README.md](README.md)。

## 完成物の検査と合格判定
- 評価対象は厳密なパス・SHA256・尺で固定する。glob の先頭や素材 PNG を完成 MP4 の代用にしない。小さい一覧画像の数値は原寸で再確認する（2026-10-16、2026-10-16-full-picture-generator.md）
- 文字の欠け・重なり・接触が疑われたら、固定した完成 MP4 の同じ時刻を別名・原寸で新規に抽出して再確認してから重大度を決める。縮小表示・旧評価・原画の転記だけで確定指摘にしない（2026-10-13、2026-10-13-plan182452-shorts.md・2026-10-17-split-r13-r17.md）
- 内容評価の P0/P1 0件、旧版の目視、仮の秒割り、収録メタ（recorded・answerProblems=0）、DOM の表示・全 scene complete を、採用尺・音・完成映像の合格へ転用しない（2026-10-14、2026-10-14-script-review-gate.md・2026-10-16-full-picture-generator.md）
- 静止画・manifest の目視は生成元（コード・SHA）と対応させ、コードが更新されたら再確認する（2026-10-16、2026-10-16-split-scene-contract.md）
- 読速は本文だけでなく、画面に残す範囲・条件の行・CTA を含む全文字で測り、完成 MP4 の境界直前・直後と最終フレームの実尺で確認する（2026-10-16、2026-10-16-split-round9-render.md）
- 機械 QA の合否と人の実聴は別に記録する。実聴待ちは human_review に残し、機械 QA 不合格へ混ぜず、実聴済みとも書かない（2026-10-14、2026-10-14-sns-v1-bundle-trial.md）
- 時間換算は固定 30fps とせず完成 MP4 の fps とフレーム数に合わせる。fps フィルタで間引いた画像の配列番号は秒に直さず、実フレーム番号と符号化後の場面境界で換算する（2026-10-16、2026-10-16-split-full-rounds.md・2026-10-16-generator-structure-progress.md）
- 別レースへ書き出しを移すときは、素材台帳の raceId だけでなく撮影 URL・選手 ID・配置後の会場名・期間・締めの結論に前レースの固定値が残っていないか確認する。レース ID の強制書換えで関門を通さない（2026-10-16、2026-10-16-split-live-omura.md）
- 場面を廃止するときは、生成呼出しだけでなく素材の必須条件・場面順・受領検査・終端検査も同時に更新する（2026-10-16、2026-10-16-split-no-scene9.md）
- 台本の theoryRows と描画指定の capture.theoryRows は同一データから生成し、答えと表示方針の一致を検査する（2026-10-17、2026-10-17-split-6axis-text.md）
- 締めで案内する項目とリンク先の内部タブを照合する（類似レースの流れは sonar=similar、展開の形と結果は sonar=scenario）（2026-10-14、2026-10-14-script-review-gate.md）
- 問いの台帳は機能群を先頭 ID にまとめず、使用する個別 ID を列挙する（2026-10-14、2026-10-14-script-review-gate.md）
- オーナーが保存用の読み時間の例外を指定した末尾カードは、全行の即時読了と保存後の参照を区別して評価し、例外を通常の字幕へ広げない。免除しても、艇番札と本文の接触・欠け・最終文字サイズは完成実画面で別に検査する（2026-10-16、2026-10-16-split-no-scene9-text.md・2026-10-17-split-r13-text.md）
- 占有率の基準を足すときは、分母（全画面／素材区画）・含める要素・字幕が出る前後・重なりの扱いを決め、区画と必要面積が両立するか書き出し前に検算する。画像矩形だけの達成案と、実字幕を描画した安全域・最小文字・元情報の保持は別（2026-10-16、2026-10-16-split-progress-before-layout2.md・2026-10-17-split-r13-r17.md）
- 素材を横幅いっぱいに拡大しただけで小文字が解消したとしない。全 overlay 座標と描画換算の文字サイズを同時に更新し、下端超過も事前検査する（2026-10-16、2026-10-16-split-progress-before-layout2.md）
- 列・率を非表示にする修正は、条件名の折り返し終端と件数の断片（閉・開の両状態）、率の非表示後に結果名だけが残っていないか、結果の件数が読めるかを点検する（2026-10-16、2026-10-16-task-48-split-contract-repair.md）
- 短い重点答えの尺が通っても、前場面の問い・答えとの意味の接続は別に確認する。字幕の一部の静止画だけで欠落を断定せず全チャンクを読む（2026-10-17、2026-10-17-split-r13-r17.md）
- answerLines の上限から出した箱高の警告は保守的だが、実字幕が2行で安全領域を越えるなら完成フレームで残す。機械警告を一括で誤検知として外さない（2026-10-17、2026-10-17-split-wind.md）
- 契約に固定した数値でも、艇番と実進入コースの条件が出典と異なれば表示を合格にしない。契約の遵守と数値の定義の一致は別（2026-10-16、2026-10-16-split-scene-contract-text.md）
- 全数値表には本文のカードだけでなく、継続表示の上帯のレース番号・保存締切・凡例の場面番号も含める。艇印を部分集合へ変換する対応は受領台帳に結ぶ（2026-10-16、2026-10-16-split-scene8-card.md）
- 字幕の分割は、断片連結の原文一致・区間連続・ページ内収容に加え、数値と条件が別時点に分かれる実フレームを点検する。連結一致だけで実表示を認証しない（2026-10-16、2026-10-16-split-generalize.md）
- 字幕から件数を外す変更は、結論が同じ2指標の比較を回収していることと、図・値台帳に件数と同一分母が残ることを別々に確認する（2026-10-16、2026-10-16-split-wind-text.md）

## 計画と承認の扱い
- 試作は測る距離・変更する寸法・対象区間を1点に固定し、採否待ちの別差分や共通部品の一括変更を基準へ混ぜない（2026-10-13、2026-10-13-plan-1726.md・2026-10-13-plan-1826.md）
- 修正済みソースと保存済み全尺動画の反映状態が違うときは基準を明記し、旧動画との比較で既承認の変更を新案の改善に数えない。既存試作が別場面だけなら、他場面への効果は未確認とする（2026-10-13、2026-10-13-plan-1626.md・2026-10-13-plan-1826.md）
- 計画後の実行が重複制作を見つけたら、次の計画では出力先の完成・比較・評価記録を既存成果物として扱い、同じ変更を再起票しない（2026-10-13、2026-10-13-plan-1726.md）
- 最新の完成物・指示が出たら、直前計画の未制作案や旧型の改善枠を承認対象に残さず、判断を最新側へ一本化する。差し替え版を正とする指定は後続計画の採用対象リンクにも反映し、旧版の評価（視覚・実聴）を流用しない（2026-10-14、2026-10-14-plan-1236.md・2026-10-14-plan-1708.md）
- 後続の返答で解消した指摘は、元の時点の評価を履歴に残し、現在の停止理由には最新の返答を使う（2026-10-14、2026-10-14-plan-1109.md）
- 承認・判断は場面ごとの範囲に限って記録する。後続場面の仕様承認を先行場面の構成変更の承認にしない（2026-10-14、2026-10-14-scene2-r1.md）
- 場面単体の「P1 を残して提出」の承認を、日次型の採用・公開合格へ広げない。個別の修正範囲と型への反映を分けて記録する（2026-10-14、2026-10-14-plan-2343.md）

## 点検での見落としを防ぐ知見
- 専門家本人の振り返りで得る内心・操作感覚と、公開データで説明できる条件・過去結果を区別する。（2026-10-12、2026-10-12-jlc-video-study.md）
- 素材の文字サイズは横・縦の縮小後に検査し、元素材のpx値だけで最小文字サイズを満たしたとしない。（2026-10-12、2026-10-12-task-38-template-trial.md）
- 問いの台帳IDの存在だけで制作検査を合格にせず、元の問いと各場面の答えの対応を照合する。（2026-10-12、2026-10-12-task-38-template-trial.md）
- 字幕を長い語へ置き換えたら、範囲・母数を保持したうえで字数と読速を再確認する。（2026-10-12、2026-10-12-video-12R-v12c.md）
- 字幕の表示秒数は台本だけでなく描画コードのローカルフレーム補正と完成MP4の切替フレームで確認する。（2026-10-12、2026-10-12-video-12R-v12d.md）
- 短い加工済み音源を元曲の原本として扱わず、原本と加工版を区別する。（2026-10-12、2026-10-12-video-12R-v12f.md）
- 音の加工記録（連続区間・反復・フェード位置）、完成音の測定値、全尺の聴覚確認は別に記録する。（2026-10-12、2026-10-12-video-12R-v12f.md）
- 長い見出しは字を縮めて詰め込まず意味の区切りで改行し、説明・図・字幕の領域を別に確保する。（2026-10-12、2026-10-12-video-12R-v12f.md）
- 場面内で全国結果から本人指標へ切り替えるときは図・見出しを同じフレーム条件で切り替え、境界直前・直後の残留を照合する。（2026-10-13、2026-10-13-daily-shorts-scene4-heading.md）
- 固定条件の試作が仕様判断待ちで停止した場合、同じ差分を次の計画へ再投入して判断待ちを解除しない。（2026-10-13、2026-10-13-plan-1527.md）
- 定義を含む数値カードが単体で表示秒数内に読めない場合、段階表示を早めるだけで解消したとせず、定義の表示と読速を別に点検する。（2026-10-13、2026-10-13-plan142204-hook.md）
- 保存画面の抜粋の焼き込み文字は追加テキストのDOM検査と別に原寸・モバイル幅で点検する。（2026-10-13、2026-10-13-plan142204-ximage.md）
- 承認済み動画を別素材へ再編集するときも、元の数値検査がAPI対描画か公開画面対APIか確認し、承認を新依頼の出典確認へ読み替えない。（2026-10-13、2026-10-13-plan152328-ximage.md）
- 別の縦横比へ再配置したら文字領域の収まりに加え、タグラインの省略と札同士の接触を別々に検査する。（2026-10-13、2026-10-13-task-46-x-entry-video.md）
- 完成音をloudnormで測るとき、input_i/input_tpを入力した完成音の測定値として記録し、検査処理で仮変換したoutput_iを完成音の実測として報告しない。（2026-10-13、2026-10-13-task-46-x-entry-video.md）
