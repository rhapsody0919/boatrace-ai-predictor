# ADR 0018: 龍神レーダー ロゴタイプ用明朝体の配信方式

## ステータス
採用

## 背景
ロゴタイプ「龍神レーダー」の表示にNoto Serif JPを採用することが決まっている（UI本文はサンセリフに統一し、明朝体はロゴタイプのみに限定）。配信方式（CDN経由 or 自己ホスト）を決める必要がある。検討過程で、Google Fonts CDN経由の読み込みはプライバシー（ユーザーIPがGoogleに送信される）とパフォーマンス（外部リクエスト増加、既存のSEO/Core Web Vitals投資への影響）の懸念が指摘されていた。

## 決定
ビルド時にNoto Serif JPから「龍神レーダー」の表示に必要なグリフのみを`fonttools`（`pyftsubset`）でサブセット化し、WOFF2として`public/fonts/`に格納して自己ホストする。実行時の外部リクエストは発生しない。

## 却下した選択肢
- **Google Fonts CDN（`text=`パラメータでのランタイムサブセット取得）**: 実装は最も簡単だが、外部リクエストとプライバシー懸念が残る。ロゴタイプは数文字のみでファイル容量の上限を気にする必要がない（ユーザー確認済み）ため、自己ホストのコストに見合う
- **フルセットのNoto Serif JPをそのまま自己ホスト**: 数MB規模になりCore Web Vitalsへの悪影響が大きく、ロゴタイプ用途には過剰

## 影響
ビルドプロセスに`pyftsubset`実行ステップが加わり、開発環境にPython依存が必要になる（`docs/setup/`にセットアップ手順の追記が必要）。ロゴタイプの文言が将来変わった場合はサブセットの再生成が必要になる。
