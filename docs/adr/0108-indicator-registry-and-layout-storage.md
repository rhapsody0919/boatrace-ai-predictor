# ADR-0108: 指標の定義を1か所（登録簿）に置き、画面の並べ方はブラウザに保存する

## 状況

- 画面に出ている指標を洗い出すと約870行あり、119の族（同じ問いに答える指標）にまとまった。同じ名前で値が違う物（モーターの「2連率」の5定義、イン崩れ注意度の新旧など）が A 10件・B 22件あり、計算・期間・母数・最良の判定・書き方が画面ごとに別の所に書かれている（`docs/design/indicator-parts/catalog.md`・`catalog-2.md`）
- オーナーは「ボートレースで分析する上での一つ一つの観点・指標・要素を部品化する」「ユーザーが自分の画面を組めるように。保存はまずブラウザ、登録なし」と決めた（2026-11-23、設計 `docs/design/indicator-parts/plan.md`、§10 にオーナーの決定4点）
- 古い版が最大約12時間動く（ADR-0106 の定時の配備）。ブラウザの保存は新旧の版が同時に読む

## 決定

1. **指標の定義の正は登録簿**。1つの指標＝1つの定義（id・族・種類・主語・場面・値の形・出所・書き方・比べ方・値を選ぶ純関数・注記・詳しいタブ・札・見立ての材料）。置き場は `src/pure/indicator<大分類>.js` と `src/pure/indicatorRegistry.js`（`src/pure` は平ら、下の階層を作らない）。画面・AI 用コピー・一覧のカードは、行の計算・最良の判定・書き方を自前で持たず、登録簿の定義を通す
   - 期間・母数・主語が違う物は別の id・別の名前にする（同じ名前で値が違う物を作らない）。艇番と進入コースは別の主語
   - 見立て（龍神のモデル・判定）は材料の指標の id を持ち、見立てを含むカードは「結果を保証しない」を自動で出す
   - 置き換えた旧の定義は登録簿に残さない（例: イン崩れ注意度の旧、オーナー 2026-11-23「新を公開して旧を消す」）
   - 定義の値を選ぶ関数は値だけを返す。取得中・失敗は出所ごとの状態からカードが決める（ADR-0069: 失敗を「データなし」にしない）
2. **並べ方の保存はブラウザ**（登録なし）。キーは `boatai-user:layout:<場面>`、版は本文の `version` の1か所だけ
   - 読んだ時に書き戻さない。書くのはユーザーが操作した時だけ
   - 知らない id はその id だけを描かない（新しい版で足した id を古い版が消さないため）。カードが空になった時だけそのカードを既定で描く
   - 自分より新しい `version` の保存は既定で描き、編集させず、上書きしない。壊れた JSON も既定で描く
   - id を改名する時は登録簿の `aliases`（旧 id → 新 id）で読み替える。保存の中の id を消さない
   - 別のタブとの同期は storage イベント（`useFavorites.js` と同じ）
3. **URL と計測は変えない**: `?tab=`・`?boat=` の値（ADR-0084）は並べ方の保存で変えない。ボット向け HTML（ADR-0089）は既定の並びだけを使う（レースのボット向け HTML は表の値を出さない決定のまま）
4. **組む画面は ja だけ**。指標の名前は `/race` が翻訳の対象なので4言語

## 守り

- 登録簿の verify（tier ci）: id の重複、ja の文のキーの有無、書き方の種類が `src/pure/dataFormat.js` の関数と一致、見立ての材料の参照先があり輪にならない、見立てを含むカードの断り
- 並べ方の検査（段2）: 保存が無い・ある・壊れた JSON・知らない id・自分より新しい版の5つの状態の verify と E2E

## 戻し方

登録簿は今の行の定義（`src/components/race/raceIndicatorsRowDefs.jsx` 等）を移した物なので、画面ごとに移す PR を戻せば元に戻る。並べ方の保存は読むだけで書き戻さないので、組む画面を外しても保存が残るだけで害は無い（キーは `boatai-user:` の名前空間で、キャッシュの全削除では消えない）。

## 選ばなかった案

- 見た目の部品（表・棒・グラフ）だけを共通にする: 行の中身（計算・期間・母数・最良）が画面ごとに残り、同じ名前で値が違う問題が直らない
- `src/pure/indicators/` の下の階層: AGENTS の「src/pure は平ら」（オーナー 2026-11-10）に反する
- 読んだ時に保存を正規化して書き戻す: 古い版のタブが新しい版で足した指標を「消えた id」と読み、ユーザーの保存を消す
- 保存のキーに版を入れる（`:v1`）: 新しい版の読み手が古い保存を見つけられず、黙って既定に戻る
