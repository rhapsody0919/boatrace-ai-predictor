# ADR 0067: 公式サイトのコンテンツの再表示に関する方針（リスクを認識したうえで現状維持）

## ステータス
採用（2026-09-19、ユーザー判断）。本ADRは、ユーザーの判断の記録であり、法的見解・法的助言ではない。

## 背景

本サービスは、公式サイト（boatrace.jp）と会場公式サイトから取得したデータ（出走表・オッズ・結果・展示・気象など）を、集計・加工したうえで表示している。一部は、取得した値をそのまま画面に表示している（例: 出走表の選手情報、オッズ一覧、結果の着順・払戻）。

2026-09-19、Geminiによるスクレイピング設計案（[docs/proposal/gemini-scraping-design.md](../proposal/gemini-scraping-design.md)）が、次の趣旨を述べた。生データをそのまま公開・再配布すれば著作権法および利用規約に違反しうる。一方、機械学習等の情報解析を目的とした複製は、著作権法第30条の4により適法となる公算が高い。これはGeminiの一般論であり、専門家による確認を経ていない（Geminiが「規約上の禁止事項」として引用した「自動スクレイピング禁止」は、第三者サイトの規約であり、公式サイトの規約ではなかった）。

公式サイトポリシー（https://www.boatrace.jp/owpc/pc/extra/policy.html、2026-09-19に取得）の要点は次のとおり。

- **著作権等**: サイト上のコンテンツは、本財団および第三者が有する著作権により保護されている。著作権法が定める場合、または個々のコンテンツに個別の利用条件が示されている場合を除き、私的使用など法律によって認められる範囲を超えて、著作権者の許諾なく無断で使用（複製、改ざん、頒布などを含む）することはできない
- **禁止事項5**: 「不正アクセス、大量の情報送受信及び大量のアクセスなど、本サイトの運営に支障を与える行為」。自動取得そのものの禁止ではなく、運営に支障を与える負荷が対象
- 禁止行為を行ったと財団が判断した場合、事前の通知なく利用を停止でき、損害があれば賠償する旨の規定がある

これまでに、次の対応を行っている。

- 会場公式サイトのToS本文を24会場全件で確認し、明示的な著作権条項がある3会場（戸田・浜名湖・宮島）を、スクレイピング対象から除外した（[docs/issues/DATA_SCRAPING_GAPS.md](../issues/DATA_SCRAPING_GAPS.md)、[ADR-0055](0055-venue-site-scraper-template-strategy.md)）
- 第三者の商用予想サービス（日刊スポーツ系の「コンピ指数」。AI学習目的の収集を名指しで禁止）を、取得対象から除外した（BOA-294）

見つけられた範囲では、公式サイトポリシーに基づく「取得データの再表示の範囲」の検討は、これまで文書化されていなかった。

## 決定

**現状の取得・表示の方針を維持する。リスクとして認識したうえで進め、現時点では、専門家（弁護士等）への確認は行わない。**

あわせて、次を継続する。

- **取得負荷の抑制**（公式サイトポリシー禁止事項5への配慮）: リクエスト間隔、並列度の上限、429/503でのバックオフとサーキットブレーカー（[BOA-368](https://linear.app/boat-ai/issue/BOA-368)、ADR-0066の共通ラッパの要件）。取得量を増やす変更（新しい取得ジョブ、頻度の引き上げ）は、負荷の見積りを、specに書く
- **除外済みのソースの維持**: 明示的な制限のある会場（戸田・浜名湖・宮島）、AI学習目的の収集を禁止する第三者サービス
- **新規の取得元は、着手前に、利用規約・サイトポリシーの本文を確認する**（例: BOATCAST。[BOA-281](https://linear.app/boat-ai/issue/BOA-281)）

## 却下した選択肢

- **専門家（弁護士等）への確認を先に行う**: 判断の材料は増えるが、ユーザーが、現時点では見送りを選択した。見直しの契機（下記）が生じた場合に再検討する
- **取得データの表示を、加工結果（集計・予測）のみに縮小する**: 生データの再表示を減らせるが、機能の範囲・競合との差別化への影響が大きいため、現時点では採用しない

## 影響・見直しの契機

- 次のいずれかが生じた場合は、本ADRを見直し、専門家への確認を再検討する: 公式・会場から通知・要請を受けた場合、収益化・広告・有料化など事業形態が変わる場合、取得・表示の量や範囲が大きく変わる場合、規約・法令が変わった場合
- 「リスクを認識したうえでの現状維持」であり、リスクが解消されたことを意味しない

## 追記案（2026-09-21）: 選手コメント（ピットレポート）の画面表示

> ステータス: **案**。ユーザーが内容を確認して、マージ時に確定する。本追記は、ユーザーの判断の記録であり、法的見解・法的助言ではない。

### 決定（ユーザーの承認、2026-09-21）

公式サイトのピットレポート（`https://www.boatrace.jp/owpc/pc/race/pitreport`）の**選手コメントを、レース詳細の画面に、そのまま表示する**（[BOA-379](https://linear.app/boat-ai/issue/BOA-379)、[docs/design/pit-comments/](../design/pit-comments/spec.md)）。**出典表記を付けたうえで進めてよい**（現状維持の方針の範囲として扱う）。専門家（弁護士等）への確認は、引き続き行わない。

表示の要件（出典表記）:
- 「出典: BOAT RACE オフィシャルウェブサイト ピットレポート」を、コメントを読める位置に常に表示する
- 該当ページ（元のpitreportのURL）へのリンクを付ける（新しいタブ）
- 取得時刻を併記する
- コメントの改変・要約をしない（本文をそのまま表示する。AIによる言語化はしない）

### 背景（事実。2026-09-21の実測）

これまでの表示（本ADRの背景）は、出走表・オッズ・結果・展示などの**数値・事実データ**を、集計・加工して、または取得値のまま表示するものだった。選手コメントは、次の点で異なる。

- レポーター（第三者）が取材して書いた**自由記述の文章**（1レース最大6件、1件20〜115字）で、数値より著作物性が明確である
- **加工せず、そのまま**表示する（生の文章の複製になる）
- 公開する画面への表示に加えて、内部の保存（データベース）と、再解析用の生HTMLの保管（Storageの非公開バケット。再配布・公開しない）を行う
- 対象は、SG・G1・G2の一部のレース（1日約6〜18レース）。ピットレポートのページ本文・フッターには、個別の利用条件の記載は見つからなかった（フッターは「COPYRIGHT © BOAT RACE OFFICIAL WEB ALL RIGHTS RESERVED」と、サイトポリシーへのリンク）

### 影響・見直しの契機

- 本ADRの「見直しの契機」（取得・表示の量や範囲が大きく変わる場合）に該当しうる変更（数値・事実データから、第三者の自由記述の文章の、そのままの再表示へ）を、リスクを認識したうえで承認した記録である
- 公式・会場から通知・要請を受けた場合は、コメントの表示を止める（マイグレーション086のポリシーとGRANTの削除だけで、匿名の読み取りを止められる設計）。取得負荷の抑制（[BOA-368](https://linear.app/boat-ai/issue/BOA-368)）は、本機能の取得ジョブにも適用する（[plan.md §4.7](../design/pit-comments/plan.md)）
- 匿名への公開（マイグレーション086の適用）は、画面の実装・モック承認の後に、ユーザーの承認のもとで行う
