# ADR 0021: 六星占術の「運気リズム」実装範囲

## ステータス
採用

## 背景
spec.md（[[racer-fortune-telling]]要件2）は六星占術の計算方式を「運気リズム」（種子・緑生・立花・健弱・達成・乱気・再会・財成・安定・陰影・停止・減退の12段階を12年周期で巡る、大殺界を含む）と指定している。

実装にあたり、以下は複数の独立した検索結果で照合・確認できた:
- 運命星（土星人・金星人・火星人・天王星人・木星人・水星人）は日柱の干支の「空亡」（60干支を10日ずつ6つの「旬」に分けた際、その旬で使われない2支）で決まる
- 戌亥空亡→土星人、子丑空亡→水星人 の2組は独立した検索で複数回一致（他4組は同じ6分割から機械的に導出可能）
- 陰陽（+/-）は生まれ年の十二支（陽支/陰支）で決まる

一方、「ある対象年が12段階のどこに当たるか」を決める起点・オフセットの計算式は、検索した範囲では見つからなかった。複数のサイトが「万年暦から導き出した運命数表を使う」と説明するのみで、公開された計算式が無い（細木数子氏の書籍・有償サービスで商業的に守られている可能性が高い）。

## 決定
12段階の運気周期は実装せず、検証済みの構成要素（運命星6種×陰陽2種=12分類）のみを使う。12分類を西洋占星術の12星座と同型の「距離ベースのアスペクト」構造（[westernAstrology.js](../../scripts/lib/fortuneTelling/westernAstrology.js)と同じ`ASPECT_SCORES`配点）に載せ、出生日の分類と対象日の分類との距離でスコアを決定する（[rokuseiSenjutsu.js](../../scripts/lib/fortuneTelling/rokuseiSenjutsu.js)）。

ユーザーに選択肢（(A)運命星+陰陽で代用 / (B)12年周期を推定で実装 / (C)六星占術を今回のスコープから外す）を提示し、(A)を承認された（2026-08-24）。

## 却下した選択肢
- **12年周期を推定で実装する**: それらしい規則（干支の関係等）で組み立てることは可能だが、的中率の検証結果が実際の六星占術とズレる可能性があり、「検証した」と称して実は独自解釈を検証しているだけになるリスクが高い。spec.mdの受入基準「既存の占いツールでの検証サンプルと結果が一致する」を満たせない
- **六星占術を今回のスコープから外す**: 4占術中3占術（西洋占星術・四柱推命・九星気学）はいずれも公開されている古典的計算式があり検証済みだが、六星占術のみ商業的に非公開の部分がある。除外も選択肢として提示したが、ユーザーは「運命星+陰陽の関係で代用」する道を選んだ

## 影響
- 「運気リズム」という名称でspec.mdに書かれた本来の意味（12年周期のどの季節にいるか）とは異なる、簡略化された指標になる。相関検証レポートでは、この占術の結果が「六星占術の一般的な言説（大殺界等）」とは対応しない可能性がある点を明記する
- 12分類の並び順（土星人→金星人→火星人→天王星人→木星人→水星人、各+/-）はコード内で便宜的に決めたものであり、六星占術の公式な周期順序ではない。距離ベースのスコアリングは対称的な関係性の指標として機能するが、「循環する季節」という原義とは切り離れている
- 日柱の干支計算ロジック（[sexagenaryCycle.js](../../scripts/lib/fortuneTelling/sexagenaryCycle.js)）を四柱推命と共有する形にリファクタリングした
