# ADR 0015: レース荒れ度ムード演出のビジュアルコンセプト選定

## ステータス
採用

## 背景

BOA-195（レース荒れ度ムード演出アニメーション、`docs/design/race-open-animation/`）で、イン崩れ指数（`volatilityPercentile`）に応じて強弱が変わる装飾アニメーションを追加することになった。艇番・決まり手等の具体的な予測内容は一切表現しない制約（spec.md FR2）の下で、どんなビジュアル表現にするかは複数案があり、ユーザーの創作判断が必要だった。

3つのコンセプト（波紋エフェクト／スピードライン／パーティクル）を、それぞれ警戒/標準/堅いの3段階で実際に動くCSSプロトタイプとしてArtifact上に構築し、ユーザーに実物を見て選んでもらった。

## 決定

**波紋エフェクト（Ripple）**を採用する。中心から複数のリングが同心円状に拡大・フェードアウトする表現。警戒レベルは多重・高速（5リング、1.15秒周期）、標準は中程度（3リング、1.9秒周期）、堅いレベルは単一・緩やか（2リング、2.8秒周期）とする。

採用理由:
- ユーザー評価「波紋エフェクトがわかりやすい」（3案の実機比較後の直接評価）
- ボートレース（水上競技）・「イン崩れ」という水面由来の用語との意味的な親和性
- 実装は既存の`AiCopyBanner`（BOA-194）で確立済みの「複数のmotion.spanを時間差でscale+opacityアニメーションさせるping効果」パターンをそのまま流用でき、新規の実装パターンを増やさない

## 却下した選択肢

- **スピードライン**: 「速度感・勢い」を汎用的に表現できるが、水上競技としての文脈と直接結びつかず、ユーザー評価でも波紋に及ばなかった
- **パーティクル（きらめき）**: エンタメ性・華やかさは最も高いが、ランダム配置の粒がやや散漫な印象になりやすく、イン崩れ指数という「1つの連続値」を視覚的に表現する上では波紋の同心円（値が大きいほど輪が増える）の方が直感的だった

## 影響

- 実装は`framer-motion`のみで完結し、新規依存関係・動画アセットは不要
- `AiCopyBanner`のping効果パターンを一般化して再利用するため、実装コストは低い
- レベルごとのリング数・周期はArtifactプロトタイプで検証済みの数値をそのまま実装に引き継ぐ（`docs/design/race-open-animation/plan.md`参照）
