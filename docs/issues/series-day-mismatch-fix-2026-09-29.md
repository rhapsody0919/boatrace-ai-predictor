# race_conditions.series_day の是正（BOA-501、2026-09-29）

## 何が起きていたか

`race_conditions.series_day`（節の何日目か）が、公式の日目と食い違う行が **762行（64会場日）** ある。

- 公式は、中止・順延の日に日目を振らない（津 2026-09-21〜28 のタブは `順延, 中止, ２日目, …, ６日目, 最終日`）。暦日からの引き算（`race_date − start_date + 1`）とずれる
- 原因は2つ
  1. **#911 のバックフィル**（`race_series` からの導出）が、中止・順延を含む節で1日ぶん進んだ値を書いた: **306行（26会場日）**
  2. **出走表のページから書いた値**: 「最終日」をタブの総数にしていたため過大（津 9/28 は公式7日目なのに8）、および順延が決まる前に書かれた値のまま: **456行（38会場日）**
- コードは BOA-501 の PR で直した（最終日＝ラベルの日目の最大値＋1、順延・中止の日は日目なし、中止・順延のある節は導出で埋めない）

## 正解の出し方

公式の成績ファイル（Kファイル、`www1.mbrace.or.jp/od2/K/`）の会場見出しにある「第N日」を正とした（最終日も番号で載る）。2025-12〜2026-09-28 の **全712節・306日分** のKファイルを取得し、race_conditions の全 46,740 行と会場日ごとに照合した（2026-09-29）。

| 区分 | 会場日 | 行 |
|---|---:|---:|
| 一致 | 3,837 | 45,966 |
| ずれ（#911 のバックフィルで作成） | 26 | 306 |
| ずれ（ページから書いた値） | 38 | 456 |
| 丸一日中止の日に日目が入っている（尼崎 2026-05-16） | 1 | 12 |

- 中止・順延の無い節では、ずれは0（導出値と公式が一致）
- 一部のレースだけ中止になった節（26節）でも、ずれは0
- Kファイルが取れなかった日は0

### 3. 事後確認（読み取り）

1 の SQL を再実行する。期待値: `rows_to_fix = 0`

例として、津の節（公式: 順延・中止・２日目〜６日目・最終日＝7日目）:

```sql
select r.race_date, min(c.series_day) as series_day, max(c.series_day) as series_day_max
from races r join race_conditions c on c.race_id = r.race_id
where r.venue_code = 9 and r.race_date between '2026-09-21' and '2026-09-28'
group by r.race_date order by r.race_date;
```

期待値: 9/21=1、9/22=2、9/23=2、9/24=3、9/25=4、9/26=5、9/27=6、9/28=7（是正前は 9/28 だけ 8）。9/22 は丸一日中止だが、Kファイルは会場の見出しを「第2日」として載せ、翌日も「第2日」と振り直すため、Kファイルに合わせて 2 のままにしている

## 判断が要るもの（このSQLには含めていない）

**丸一日中止の日に日目が入っている行**: 尼崎(13) 2026-05-16 の12行（`series_day = 2`）。公式の成績ファイルに尼崎の見出しそのものが無い日（津 9/22 のような「中止でも見出しは載る」日とは違う。節 2026-05-15〜18 の 5/16〜18 に結果が無い）。BOA-501 の新しい規則では、中止・順延の日は日目なし（NULL）。揃えるなら:

```sql
update race_conditions c set series_day = null
from races r
where r.race_id = c.race_id and r.venue_code = 13 and r.race_date = '2026-05-16'
  and c.series_day is not null;
-- 期待: UPDATE 12
```

## バックフィルについて

`scripts/maintenance/backfill-series-day.js` は、BOA-501 の PR で、節の中に中止・順延（確定）があるレースを埋めないようにした（`series_has_cancellation`）。修正前の版は実行しないこと。
