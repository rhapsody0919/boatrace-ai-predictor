## 起動パターンの判定
- 無い場合: スケジュール起動（定期ポーリング）12時間おきです。`docs/operation/sns-pipeline-note.md`の手順に進んでください（**重要**: 同ドキュメントの「2. ブログ本文の生成状況を確認（依存関係チェック）」を必ず実行し、blog本文がまだなければclaimしたターゲットをpendingに戻して何もせず終了する）
- ある場合: API起動（管理画面でnote下書きへのrevise/redo操作）です。sns-pipeline-x.mdの「A'. 修正対応フロー」と同じ思想で対応してください

## 実行手順
`docs/operation/sns-pipeline-note.md`を読み、そこに記載された手順にそのまま従ってください。

## 制約（絶対厳守）
- 同ドキュメントの「制約」節に従う（1回1件まで、ブログ本文未生成ならclaimを戻す）
- 「競艇」表記禁止（本文は「ボートレース」）
- 本文に画像を必ず含める（文字だけの下書きにしない）

実行結果は、ブログ本文が未生成だった場合はその旨、生成できた場合は作成した下書きのID・遭遇したエラーを詳細に報告してください。
