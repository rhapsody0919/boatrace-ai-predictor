# SNSマーケティング戦略

X・YouTube・note での集客の方針。運用の手順は`docs/operation/sns-*.md`（下の「関連」）、知見は `docs/knowledge/`（`x.md`・`youtube.md`・`note.md`）にある。このファイルには今の方針だけを書き、判断の経緯は git の履歴と ADR に任せる。

## 全体方針

- **チャネル**: X（`@kyouteiboatai`）・YouTube（主に Shorts）・note・ブログ。TikTok はアカウントが停止されたので運用しない
- **X の位置づけ**: ブログ・SEO・ブランド認知の補完チャネル（`x-operations-playbook.md`）。KPI は X 単体の伸びより、サイトへの送客・ブランド想起への寄与を優先する
- **頻度**: X は毎日1本を安定して続けることを目標にし、1日の上限は4本（投稿どうしの共食いを避ける）
- **送信**: 全貌動画（X・YouTube 完全版・YouTube Shorts）と /today の X 投稿は、検査が通れば承認なしで自動で送る。ほかの投稿は1件ずつユーザーが承認する（`sns-posting-operations.md`、ADR-0094）。X への送信は X API（OAuth、`api/admin/sns-hub/x-oauth/`）で行う

## マネタイズとの関係

最終ゴールは、各ボートレース場を管理する自治体への営業で役所広告を受注すること。受注には PV・認知度の実績が前提で、SNS 施策はこの認知度づくりの一環。有料の AI 動画生成による CM は将来構想で、予算は広告収入の再投資が前提。当面は無料枠（Remotion＋ffmpeg＋Playwright）での PV・インプレッションの成長が現実的なルート。

## コンテンツの軸

- X・ボートレースのハッシュタグの実地調査では、**推し活（特定の選手への感情移入）・個人の観戦や遠征の体験談**が最も伸び、公式の告知や買い目の羅列は伸びない。AI 予想の精度の訴求だけでは伸びず、人間味が効く
- 動画の型・制作の規則は `sns-video-producer-prompt.md`、コピーは `sns-viral-copywriter-prompt.md`
- 動画のカバー（frame=0）は、会場攻略・データ一覧型の「案A」（非対称配置・実データの可視化・ベタ塗り帯・GOLD 統一）を基準にする。巨大な数字とフック帯はアニメーションさせず、frame=0 で必ず見えるようにする。巨大な数字のフォントサイズは文字数で変える（目安: 3〜4文字なら250〜300、小数点込みの5〜6文字なら180〜220。実測して決める）。数字だけでは的中系と未確定系が区別できないので、型は上部のバッジで示す
- プラットフォームによっては、賭けの結果に影響する統計そのものがギャンブル情報として扱われる。新しいプラットフォームに出す前に公式ポリシーを確かめる（`sns-video-producer-prompt.md` 絶対厳守10）

## 多言語の SNS アカウント

- **今のアカウントに英語などの投稿を混ぜない**。推薦のアルゴリズムは視聴者の地域・言語で配信先を決めるので、混ぜると日本のフォロワーの離脱とアカウントの評価の低下を同時に招く
- 言語別のアカウントに分けるのが正しい方向だが、今は作らない。英語の投稿は生成も止めている
- **英語のアカウントを作る条件**: (a) 日本語の X・YouTube の投稿が1か月以上安定して続いている、かつ (b) 英語版サイトの月間 PV などで英語の需要の兆しが確認できた。条件を満たしたら、英語の1アカウントだけを作る（zh-TW・ko を同時に広げない）
- 作るときは、プロフィール・カバー・投稿の文言・ハッシュタグの体系まで英語圏向けにそろえる（日本語アカウントの英訳のコピーでは刺さらない）

## SNS マーケティングハブの改善ループ（Phase 2）

設計は `docs/design/sns-hub-phase2-pdca-loop/`。PDCA のループ自体が、動画の質・戦略を継続的に改善する仕組み。

- **新しいビジュアル・コンポジションの自律生成を許可する**。送る前の承認か検査が最終の防波堤になる
- **試行数に上限は設けない**
- **改善案の反映は週次で評価する**（日次で変えると型の一貫性が失われる）
- **ブランドのガードレール**: `BOAT_COLORS`（艇番色）・金の龍ロゴ・GOLD 統一のトーン・`risk-rules.json` のテキストルール。新しいコンポジションを作るときは必ず参照する（`docs/reference/brand-kit.md`）
- **試作のコードも git で管理する**。採用・不採用にかかわらず Remotion の JSX をコミットする（動画のバイナリは Supabase Storage）
- **改善案は DB に構造化して残す**（`sns_strategy_insights`。scope・本文・根拠・status）。生成側は active な insight だけを読む。採用の前に `risk-rules.json` と照合し、禁止の規則に触れるものは採用しない
- 「戦略メモ」タブ（採用・却下の画面）は、直近30日の利用0件のため 2026-10-24 に撤去した（hq SH01 R2）。insight の status は `sns_strategy_insights` を読んで確かめる

### 外部調査の手段

- **無人のクラウド Routine は、X などの外部サイトを調べられない**。WebFetch・curl は許可リスト外のドメインに一律 `EGRESS_BLOCKED`、ヘッドレス Chromium も外部に接続できない。Chrome 拡張は接続先のブラウザが要るので、無人の Routine では使えない
- そのため、外部調査（競合・隣接ジャンルの観測）は対話セッションで `/x-growth-report`・`/note-growth-report` を定期的に実行し、結果を insight として DB に登録する。1週間以上実行していなければ、セッション開始時に提案する（`.claude/rules/content-ops.md` フローC-5）
- X API は従量課金になっており、読み取りの費用は小さい。競合の観測に使うかは、費用の判断としてオーナーに聞く

## やめた施策・やらないこと

`/x-growth-report` などで施策を提案する前に、ここと照合する。重複していたら、前と同じ理由で失敗しそうか、状況が変わって再挑戦する価値があるかを明示してから提案する。

| 施策 | 今の扱い | 理由 |
|---|---|---|
| TikTok での運用 | やめた | アカウントが停止された |
| マスコットキャラ3体の比較テスト・マスコット掛け合い型 | 終了。掛け合い型の部品は削除済み | 9本では勝者を判定できず（全投稿のエンゲージメントがほぼ0）、方向性も選手データの演出として合わなかった |
| リプライの定点の対象アカウントリスト | 使わない | 同じ相手への反復より、今まさに呟いている人に反応する方が自然で、新しい層に広がる |
| リプライの同時一括送信 | しない（承認はまとめてよい） | 同時に送ると bot 的に見える |
| リプライの対象から直接競合を外す | 撤回した（今は対象に含め、厳格なトーンで書く） | 候補が予想師・競合で埋まり、除外すると対象がほとんど残らない |
| 投稿本数をなし崩しに増やす | しない（上限は1日4本） | 1日7〜9本に膨らんだ時期があり、共食いでリーチが下がる |
| 過去のレースを「今日」「本日」と呼ぶ | しない | 事実に反する |
| 予想数値フック型で締切に余裕の無いレースを選ぶ | しない（目安は60分以上の余裕） | 作業中にレースが終わり、投稿直前に差し替えた |
| 6決まり手の確率分布の全面表示 | しない | 2つの表示が違う問いに答えて分かりにくい |
| 英語の投稿の生成 | 止めた | 英語のアカウントが無い（多言語の節の条件を満たしたら再開） |
| 無人の Routine で外部の SNS を調べる・ネットワークの許可リストに X を足す | できない | 外部への接続が遮断され、JS で描画するページは許可しても中身が取れない |
| 投稿時間帯（21時前後）を決め打ちする | しない（仮説として扱う） | 裏付けが無いまま決めていた |
| X API を使わない | 撤回した（今は OAuth で送信している） | 自動送信に必要になった。読み取りの費用は小さい |

## 効果測定

- `/x-growth-report`: X 自体のパフォーマンス（インプレッション・いいね・フォロワーの推移）と、サイトへの送客
- `/note-growth-report`: note 自体のパフォーマンス
- 48時間後・7日後の数字から次に変える1点を決めるのは `x-channel`・`youtube-channel`
- `/growth-pdca`: Search Console・GA4（検索流入・ブログ側）。SNS 自体のパフォーマンスは対象外
- 月1回、`/growth-monthly-summary` で横断して見る

## 今後の検討事項

- **投稿頻度の引き上げ**: いずれは1日5本を目指す意向がある。ただし X は1日4本を超えると共食いが起きるので、フォロワーが増えて共食いにならない規模になってから再検討する
- **リプライのパートナーシップ**: 近い規模・隣接ジャンルの5〜10アカウントと継続的にリプライし合うと、双方のリーチが上がるという業界分析がある。「固定の対象リストは使わない」というリプライの方針と部分的に食い違い、効果の測り方も決まっていないので、候補として残すだけにする
