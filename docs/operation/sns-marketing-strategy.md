# SNSマーケティング戦略（生きているドキュメント）

X/TikTokでの集客施策の意思決定・戦略を記録する。**このファイルは追記型**——新しい判断・方針転換が起きるたびに追記し、他セッションからも経緯を追えるようにする（2026-08-23〜）。

運用手順そのものは`docs/operation/sns-*.md`（下記参照、git管理下）に分離した。動画ファイル・キャプション下書き・レンダリング出力等の実作業用アセットは`scratch-tiktok-pilot/`配下（git管理外）に残している。このドキュメントは「何をどういう理由で決めたか」の意思決定ログに徹する。

## 全体方針

同時多発ではなくフェーズ分けで進める。

- **フェーズ1（現在）**: X（`@kyouteiboatai`）での検証。TikTokはアカウント未開設（ユーザー側の宿題、Claudeは代行不可）
- **フェーズ2**: TikTokアカウント準備でき次第解禁。フェーズ1の動画素材は使い回すが、フック・編集は作り直す（Xは「もう関心がある人」向け、TikTokは「関心の無い人を3秒で止める」設計が必要という前提の違いがあるため）
- **フェーズ3**: 投稿頻度の拡大は、型が実証されてから判断する（2025-12の同種の取り組みが下書き止まりで終わった教訓を踏まえ、量を先に決めない）

自動化の限界: SNS投稿は毎回ユーザーの明示的な承認が必須（Claude側の安全ルール、変更不可）。TikTokアカウント作成もClaudeは代行不可。

**X APIは使わない方針（コスト理由、確定済み）**: `scripts/daily/post-x-animation.js`という過去のX API連携スクリプトが実在し、2026-08-14のモデル改修でUI要素が変わり動作しなくなった際に定期実行を無効化した。この技術的な破損は副次的な理由であり、**本質的な理由はX APIが有料ティアでないと使えないため、そもそも継続利用しない判断を過去にしている**（ユーザー確認、2026-08-23）。したがって「動画添付を自動化したい」等の話が出た際も、X API導入は選択肢に含めない。Chrome in Claudeでの手動添付前提の運用（`sns-posting-operations.md`）を維持する。

## マネタイズとの関係

最終ゴールは各ボートレース場を管理する自治体への営業により役所広告を受注すること。受注にはPV・認知度の実績が前提。SNS施策はこの認知度づくりの一環。有料AI動画生成によるCM展開も将来構想としてあるが、予算はGoogleアドセンス収入の再投資が前提（2026-08-22時点で月約1,000円のみ）。したがって当面は無料枠（Remotion+ffmpeg+Playwright）でのPV/インプレッション成長が実質唯一の現実的なルート。

## マスコットキャラクター施策（2026-08-22〜）

企業告知調ではなく人間味のあるキャラ発信が有効という調査結果を受け、龍神をモチーフにしたマスコットキャラ3体（A'=元気系リュウくん、B'=冷静系レーダー、C'=気品系龍神さま、いずれもボートレース用ボートに乗った金銀のドラゴン）を作成。当初は同じ実データ（児島2R）で1体1本・3日連続の設計だったが、n=1では判断材料として少なすぎるという指摘を受け、キャラごとに3本ずつ・計9本を9日間ローテーション投稿する設計に一度拡張。その後**ユーザー指示で3日間・1日3本（1日目=キャラA、2日目=キャラB、3日目=キャラC）に再圧縮**、かつ**同じキャラでも3本とも同じ型（答え合わせ型）にせず型を変える**方針に修正（2026-08-23）。9本の動画・キャプション下書きは`X投稿用/`・`x-mascot-video-captions.md`に用意済みだが、既存の答え合わせ型6本（A2/A3/B2/B3/C2/C3）を新スケジュールにどう割り当てるかは未確定（次回セッションで相談）。

**動画内の時制表現の修正（2026-08-23）**: 全9本のフック文言・キャプションが「今日は危険」「本日、AIが」等と実際の日付を偽る表現になっていたと判明（ユーザー指摘）。過去のレース（2〜8日前）を「今日」と呼ぶのは事実に反するため、「これは危険」「先日、AIが」等の時制を明示しない表現に修正し、9本全て再レンダリング済み。

**今後の的中系動画の題材について**: 今回の9本は過去10日分から選定したが、**今後は当日開催・当日的中のレースに限定する**方針（2026-08-23、ユーザー指示）。1日1〜3本の投稿枠のうち1本を的中系、残りは分析ツール系等の別フォーマットにする構成を試験する想定。

**1日目・投稿ステータス（2026-08-23、3本すべて投稿完了）**:
1. **1本目**（A'・答え合わせ型・児島2R）: 修正後の文言で投稿完了
2. **2本目**（A'・本日のデータ一覧型・急上昇選手ランキング、`ToolCM_A`）: 投稿完了。当初は「一覧アピール型」（ツール紹介）で作ったが、ユーザーの提案で「本日の急上昇選手」という日替わりニュース的な見せ方に近い新フォーマット「本日のデータ一覧型」として`sns-video-producer-prompt.md`に記録（型はいくつあってもよい方針、2026-08-23合意）
3. **3本目**（A'・予想数値フック型、`LivePredictionCM_A`）: 投稿完了。**制作・投稿フローで実際にリスクが顕在化した実例**——当初は福岡5R（AI逃げ確率16%・イン崩れ指数96%）で制作したが、キャプションの誤字（「畦」という無関係な文字が`computer`のtype操作で混入）を修正している間にそのレースが終了（⏱️終了バッジで確認）。「本日開催中・結果未確定」という型の前提が崩れたため投稿直前に検知し、投稿を止めて別レース（若松2R、締切15:48時点で70分以上の余裕あり、AI逃げ確率37%・イン崩れ指数83パーセンタイル）の実データに丸ごと差し替えて動画を再レンダリング・再投稿した。**教訓: この型は結果未確定であることが前提のため、キャプション編集等で時間を要する場合は締切まで余裕のあるレースを選ぶこと**（`sns-video-producer-prompt.md`のフォーマットライブラリに追記済み）

2日目（キャラB）・3日目（キャラC）の具体的な型・題材は未着手。

## X実地調査（BOA-210対応、2026-08-23）

TikTok解禁時に実施した実地調査（複数キーワード横断検索・ハッシュタグ配下投稿の個別分析・隣接ジャンル先行事例分析）と同水準の調査をXでも実施し、比較できる状態にした。

**主な発見**:
- 「競艇 AI予想」等での検索で、直接競合「競艇AI PREDICTOR｜AI予想＆アプリ」(@KAIPREDICTOR、開設1ヶ月・71フォロワー)を発見。独自Androidアプリのパッケージ名が偶然`com.ktsoftworks.boataipredictor`と酷似。ピン留め投稿（アプリローンチ告知）でも880ビュー・いいね1件と低エンゲージメント
- #ボートレースハッシュタグ上位投稿を実見した結果、最もエンゲージメントが高いのは「推し活」（特定選手への感情移入・あるある共感、1164ビュー）と個人の観戦/遠征体験談（303〜335ビュー）。公式会場アカウントの投稿（290〜757ビュー）や買い目羅列型（1〜2いいね）はそれより弱い。自社の過去投稿（新機能告知）は13ビューと最弱水準
- 隣接ジャンル（競馬）で「競馬AI『鬼絞り』」(@keiba_pace、2021年開設・69.7Kフォロワー)を発見。ただし5年運用という交絡要因があり、「いいね・RT・フォローで無料」というエンゲージメント誘導の型を併用しているため、AIブランディング単体の効果とは分離できない

**結論**: TikTokと構造的に同じ（AI予想の精度訴求だけでは伸びない、選手個人への感情移入・人間味が効く）とXでも確認できた。既存のマスコット戦略・会場攻略型構想の方向性が2プラットフォームで裏付けられた。詳細は memory `sns_marketing_phased_strategy_2026_08_22` を参照。

## 効果測定

- `/x-growth-report`（新設、2026-08-23）: X自体のパフォーマンス（インプレッション・いいね数・フォロワー推移）の定点観測。X APIは未契約のためChrome in Claudeで画面を読み取る方式
