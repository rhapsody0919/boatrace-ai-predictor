# 龍神レーダー SNS投稿運用フロー（2026-08-23確定）

`sns-video-producer-prompt.md`（動画制作）・`sns-viral-copywriter-prompt.md`（コピー）とは別に、「作った後どう投稿・追跡するか」を扱う。

## 前提となる制約（変えられないもの）

- **投稿は毎回ユーザーの明示的な承認が必要**（Claude側の安全ルール。一度の許可を根拠に以降無許可で投稿し続けることはできない）
- **動画ファイルの添付は自動化不可**（2026-08-23確認済み）。Chrome拡張の`file_upload`ツールは、Claudeが生成したファイルをパス指定で渡す方式では通らない（「セッションに明示的に共有された添付ファイルのみ」という制約に阻まれる）。毎回ユーザーに手動添付を依頼する前提で設計する。同じ調査を毎回繰り返さない
- **Xの標準投稿UIには動画のカバー（サムネイル）編集機能が無い**（2026-08-25確認。X Media Studioというカバー差し替え機能自体は存在するが、Premium契約が前提でありboat-ai公式アカウントは非Premium。投稿後の差し替えも不可）。そのため**投稿前のレンダリング済みmp4のframe=0が、事実上そのままX上のプレビュー静止画になる**。動画制作段階（`sns-video-producer-prompt.md`のセルフレビューチェックリスト「frame=0（サムネイル）で主要テキスト・マスコットが完全に見えているか」）で必ず確認済みであることを、投稿準備（下記B）に進む前に再確認する
- TikTok関連は別フロー（アカウント開設後に着手、[[sns_marketing_phased_strategy_2026_08_22]]参照）

## A. コンテンツ制作（不定期、ネタが見つかったとき）

1. `sns-video-producer-prompt.md`の制作フローに従う（実データ確認→UI表示可能かPlaywrightで先に確認→台本→実装→セルフレビュー→レンダリング）
2. `sns-viral-copywriter-prompt.md`のチェックリストに従ってキャプションを作成
3. レンダリング済みファイルを、投稿しやすい名前・フォルダにコピーする（例: `sns-video-studio/published/x/{投稿予定日}_{内容がわかる名前}.mp4`）。`sns-video-studio/remotion/out/`直下は過去の試作が混在しているため、投稿用に整理したコピーを別途作る

## B. 投稿準備（Claude側で毎回実施）

1. X（またはTikTok）の投稿画面を開き、キャプションを入力（ここまでは自動化可能）
2. リンクカードが自動生成された場合、画像が最新ブランドと一致しているか確認する（Xのクローラーキャッシュが古いままのケースが実際にあった）。不一致なら本文中の裸URLを削除してカード生成自体を回避する
3. 「動画ファイルを`{パス}`から選んで添付してください」とユーザーに明確なパスを伝える（フォルダを探させない）
4. 添付完了の報告を受けたら、投稿前の最終状態をスクリーンショットで確認し、ユーザーに一言「この内容で投稿していいか」を確認してから投稿ボタンをクリックする
5. **この時点で動画のframe=0が空白・不完全でないか、添付後のプレビューでも目視確認する**（2026-08-25追加）。制作段階のセルフレビューで見落とされていた場合の最終防波堤。Xは投稿後の差し替えができないため、ここでの見落としはそのまま公開される

## C. 投稿後のトラッキング

1. 該当の下書き管理ファイル（動画は`x-mascot-video-captions.md`等、ブログ記事は`note-articles/tweet-drafts.md`）のチェックボックスを「投稿済み（日付・方法）」に更新する
2. 24時間後を目安に、インプレッション数・いいね数（可能ならプロフィールクリック数）をX Analyticsで確認し、memoryまたは下書きファイルに記録する

## D. 定点評価・意思決定

1. マスコット3体のテスト投稿が出揃ったら（3本投稿から24時間後）、指標を比較して勝者キャラを決定する
2. 勝者が決まったら、継続運用のペースを決める（次項E参照）
3. ブログ記事下書きの滞留状況（`note-articles/tweet-drafts.md`の未投稿数）も定期的に確認し、動画制作だけに偏らないようにする

## E. 継続運用のペース（勝者キャラ確定後の目安）

競合調査（[[sns_marketing_phased_strategy_2026_08_22]]）では同業アカウントが日次〜1日複数回の高頻度運用だった一方、本アカウントは1本ごとに実データ検証・自己レビューを挟む制作コストがあるため、**同じ頻度を目指さない**。目安は週2〜3本。過去に「下書きだけ溜まって投稿が続かない」実績（[[feedback_x_strategy_lapsed_2025_12]]）があるため、頻度は少なめでも「決めた頻度を実際に守れているか」を毎回のセッションで確認する方を優先する。
