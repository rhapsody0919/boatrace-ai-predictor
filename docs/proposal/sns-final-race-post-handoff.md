# 「今日の優勝戦・準優勝戦の特徴」SNS投稿の型 — 引き継ぎメモ

2026-10-05、調査の途中で中断した。ユーザー判断で、型づくりは BOA-271（アナロジー・ファインダー）と BOA-430（AI分析タブ）の UI/UX が完成してから始める。再開するときはこのメモから続ける。

## 依頼の要旨

各チャネル（sns-hub で運用中の X・YouTube・note 等）に、その日の優勝戦・準優勝戦の特徴を投稿する型を作る。将来は BOA-271・BOA-430 の分析・図を差し込む。設計1ファイル＋実データ1日分のサンプルを PR にし、オーケストレーター経由でユーザー承認を得る。投稿の最終送信はユーザー承認が必須。

## 調べたこと

### sns-hub の現状
- 生成 Routine `sns-hub-content-generation` は 2026-09-15 からユーザーが意図的に無効化している（週次上限を開発に回すため）。再開時は有効化の要否をユーザーに確認する
- 既存の型で一番近いのは「本日のデータ一覧」（`morning-digest`）。共通仕様 `docs/operation/sns-pipeline-morning-digest.md` が、材料の固定（ページと SNS が同じ行を読む）・書いてよいこと・チャネルごとの切り口・X テンプレート（280 weight 以内、画像1枚）をまとめている。新しい型も同じ構成で書くのが早い
- 新しいネタ種別は、全チャネル分の実データ生成物をユーザーが確認して OK を出すまで実運用にしない（`.claude/rules/content-ops.md` フローB-1）

### 使えるデータ
- 優勝戦・準優勝戦の判定: `race_conditions.race_stage`。会場固有の接頭（「ツッキー優勝戦」等）があるので `like '%優勝戦'` で粗く絞り、`isFinalStage` で「準優勝戦」「準々優勝戦」を除く（`src/services/supabaseDataService.js` 3050行付近、BOA-457）
- 2026-10-05 の実例: 優勝戦は2本（唐津12R 14:19「日刊スポーツ杯」、津12R 16:14「津インクル開設15周年記念レース」）、準優勝戦は4会場12本（住之江・尼崎・下関・福岡の各3本。`race_title` で節名が取れる）。モーニング開催の唐津は優勝戦が14時台なので、投稿時刻は会場ごとの締切から逆算する必要がある
- 出走表: `race_entries`（級・勝率・当地勝率・モーター/ボート2連率・F/L数・体重・支部）
- イン崩れ指数: `races.volatility_score` / `volatility_level`。画面のパーセンタイル表示との対応は未確認
- 今節の得点率・準優ボーダー: `supabaseDataService.js` 6530行付近（男女W優勝戦は2シリーズに分ける。BOA-511）
- SG/G1/G2 の節ページ（BOA-292、`/venue/{会場}/meet/{節の初日}`）は他レーンで作成中

## 守ること

- 本文・画像に「競艇」を書かない（ハッシュタグ `#競艇` のみ可）
- 的中率・回収率で煽らない。過去の実績数値を使うなら、予想なしの基準（例: 1号艇の1着率）と並べる
- 選手を揶揄しない。動画で誇張演出を足さず、事実を淡々と並べる
- 「勝率」を1着率の意味で使わない
