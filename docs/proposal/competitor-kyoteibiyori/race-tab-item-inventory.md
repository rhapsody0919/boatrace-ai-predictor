# ボートレース日和 出走表ページ 全タブの項目一覧（網羅確認の基準）

対応: [BOA-365](https://linear.app/boat-ai/issue/BOA-365)（網羅確認）/ [BOA-305](https://linear.app/boat-ai/issue/BOA-305)（レース詳細のUI/UX）

## この文書の役割

**プロジェクトのゴール「日和が提供している情報は全て取れるようにする」に対する、網羅の基準（物差し）。**
2026-09-28にユーザーが定義した。

> 日和が提供している情報は全て取れるようにしたい。出走表ページの各タブを見て
> 全て提供（出さないものは出さないと判断）できていたらOK。

各項目が次のどちらかになっていれば網羅を満たす。**達成条件は「未判断のまま残っている項目が0件」。**

| 状態 | 意味 |
|---|---|
| ✅ 提供済み | 龍神レーダーで同等の情報を出している |
| ⛔ 出さない | 出さないと**明示的に判断済み**（理由が要る） |
| ❓ 未判断 | まだどちらでもない。**これが0件になるまで網羅は未達** |

**本文書は日和側の「事実」（どんな項目があるか）を確定させることを主目的にする。**
龍神レーダー側の状態列は、タブ単位で埋めていく（一度に全部やると300項目超になり、
1セッション・1PRでは終わらないため）。

### 数え方

- 6艇分の列は1項目として数える（列軸なので）
- 同じ指標が期間別に行で分かれていれば、**期間ごとに別項目**として数える
  （自社が同じ切り口を持てているかの棚卸しに使うため）
- 別ページへのリンク・凡例・注記・UI機能はカウント外。ただし「ST履歴」「決り手履歴」のように
  艇ごとに列として並ぶ詳細リンクは、その位置に1項目分の枠を占めるためカウントに含める

### 全タブ共通のフレーム（項目とは別）

- 日程切替（初日〜最終日、日付併記）／レース切替（1R〜12R）
- レース見出し: 会場名・開催日・節名・レース種別・締切時刻
- 機能ボタン: 「展示進入変化」「お気入り登録」「< レース一覧」
- 凡例: 「1位」「2位」の順位色分け、「表の見方について」リンク
- 関連リンク群: レースライブ / 日刊予想 / TELEBOAT、会場情報（レース一覧 / 得点率 / モータ一覧 / 結果一覧 / 場情報）

## 6. この一覧の保守

日和は月2〜5回機能を追加するため、**この一覧は放置すれば必ず古くなる**（実際に
2026-09-15の8タブ調査が2週間で10タブに変わっていた）。タブが `?slider=N` で

HTMLの構造差分を検知するか）は未決。
