## 結論

1. **龍神の強み**は、予想の材料を過去の実例の件数で見せること。龍神ソナー・イン崩れ注意度の帯ごとの実績・節ページの必要点・ピットレポートの無改変の掲載がこれに当たる。無料・登録なし・外れも全件公開は、新しい AI 系の社も同じことをしていて差にならない。有料・ログインの中身は見ていないので、「他社に無い」とは言い切らない
2. **ファンが他社に一番欲しがったのは、機能の数でなく入口と再訪**。具体的には、全レース一覧の荒れ度のラベル・予想の更新時刻・締切前の通知。実際の画面でも、1MARK は「このレースは荒れそうか」を最初の画面で答えている。龍神は答えるための材料を、スクロールの先に置いている
3. **ドメインの力は、年齢だけの差ではない（推測）**。12社のうち10社は 2026年に登録され、龍神（2025-12）より新しい。確かめた差は次の3つ
   - 龍神の生の HTML は全ページ同じ title で、本文が無い。11社はページごとに入れている
   - トップの title に、頭の語の「予想」が無い
   - 老舗が並ぶ比べの記事に、龍神はほとんど載っていない
   - 生の HTML の title は [ADR-0114](../adr/0114-per-page-head-in-raw-html.md) で直す方向が決まり、実装が進んでいる。他社の順位は測っていない（検索結果の画面を機械で読まないため）
4. **SNS** は日和だけが大きい。新しい社の X はフォロワー数十〜数百人で、ふだんの投稿はほとんど見られていない。伸びたのは、出来事（艇国データバンクの閉鎖）に合わせた1本だけ。毎日の買い目・結果の自動の連投は、どの社でも見られていない
5. **旬の取り方**: 1MARK・BOATEC は、SG の特集を開幕の10〜20日前に骨組みで出している。龍神には SG の特集のページが無い

## 調べ方と限界

- 読んだのは公開のページ・sitemap・WHOIS・Wayback・X の公開のプロフィールだけ。ログイン・有料の中身は見ていない
- 実際の画面を見たのは、龍神・日和・1MARK・BOATEC の4社（スマホ幅）。ほかの8社は HTML から読んだ作りの比べ
- ファン4人は同じモデルの役で、結論は仮説
- 競合の数字はすべて自己申告か公開の表示で、第三者の検証は無い
