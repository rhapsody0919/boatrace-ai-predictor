# インバウンド需要・外国人向け機能・マーケティング戦略（2026年9月）

龍神レーダー(boat-ai.jp)の[競合ランドスケープ分析](./boatrace-competitor-landscape-2026-09.md)に続き、「外国人にボートレース観戦・賭博への需要が実際にあるか」「外国人が何を使っているか」「必要な機能・マーケティング施策」を4体のエージェントで並列調査した結果をまとめる。既存の[[i18n_technical_and_demand_audit_2026_08_16]]（多言語SEO監査）・[[foreign_audience_growth_strategy_2026_08]]（ブログi18n展開）の知見を土台に、今回は需要の実証・現地実務・マーケティングチャネルを深掘りした。

## 調査方法

- 4体のエージェントに分割し、WebSearch/WebFetch/ブラウザ実操作で一次情報を確認（推測記述は排除、確認できなかった項目は「未確認」と明記）
- 対象: ①需要の実証（TripAdvisor・Reddit・YouTube・JNTO）、②外国人が実際に使う情報源・ツール、③現地でのベッティング実務・多言語対応、④インバウンド向けマーケティングチャネル

## 総合結論（要約）

1. **需要**: 顕在化した強い需要ではないが、ゼロでもない。「弱い〜中程度の下限」。TripAdvisorレビュー絶対数は主要4会場合計約69件とニッチ以下の水準だが、**外国人向け有料ガイドツアーが京都・大阪の複数事業者から商品化され、実際に予約実績（完売しやすいバッジ表示）がある**点は、単なる検索需要より一段階強い実需要シグナル
2. **外国人が使っているもの**: 観戦文化理解は公式サイト(4言語対応だが基礎知識のみ)・旅行ブログが中心。賭け方の実務ガイドは`localbetjapan.com`がほぼ唯一の専業サイト（ただし概念説明のみで実データなし）。**実際に賭ける手段は現地対面投票のみが現実的**（オンライン投票TELEBOATは日本の銀行口座が必要で短期滞在の観光客は事実上利用不可）。**予想・データ分析を英語で提供するサイトは実質ゼロ**
3. **必要機能**: 「AI予想を英語化する」こと単体より、**「現地観戦サポート」（買い方ガイド・会場別多言語対応状況・当日の展開解説）を軸に、その上に英語データ分析を載せる**設計が実態に合う。TELEBOAT非対応という制約上、「予想を見て、現地の券売機で紙の投票券を買う」導線が前提になる
4. **マーケティング**: 個人開発規模でも着手可能な順に、①OTA経由の個人ツアーガイドとの提携、②Reddit上の自発的な言及への誠実な情報提供、③中規模YouTuberとのバーター、④既存英語メディアへの寄稿、の順で優先度をつける

## 1. 需要判定

### 実証データ
| 項目 | 結果 |
|---|---|
| TripAdvisorレビュー（平和島・住之江・江戸川・戸田の合計） | 約69件（浅草寺等の主要観光地は数万件規模、明確にニッチ以下） |
| 外国人向け有料ガイドツアーの商品化 | **複数事業者から実在**（京都発「Lake Biwa Boat Race Tour」¥20,000〜25,000/人、TripAdvisor/GetYourGuide 5.0/5。尼崎の「Amagasaki Retro Tour」はViatorで「完売しやすい」表示） |
| Reddit上の自発的言及 | r/TokyoTravel「なぜもっと勧められないのか」という投稿を確認（2026年1月頃、コメント10件以上）。組織的な議論ではないが自発的な口コミの実例あり |
| YouTube | 観光vlogは確認できず、AFP/TaiwanPlusの報道動画（「不正防止のため選手を軟禁」「八百長事件で信用失墜」という業界のイメージ課題を扱う文脈）のみ |
| JNTO（国レベル観光局） | ボートレースを推す紹介ページなし |
| 自治体（大田区・大阪観光局） | 最小限の紹介のみ、多言語対応の記述もほぼなし |
| 平和島・住之江での実証実験 | 2026年（平和島、在日台湾人対象モニターツアー）・2024年（住之江、JTB/南海電鉄との実証実験）と、自治体・観光企業側が商品化を模索中。恒常的なプログラムには未到達 |

### 需要が集中する層
訪日観光客（リピーター・日本通層）が中心で、目的は賭博でなく文化体験（「隠れた名物」「非日常体験」という文脈で語られる）。有料ツアー価格帯（¥20,000〜25,000）から見て、予算に余裕のある客層。在日外国人コミュニティ内での関心度は判断材料が不足（未確認）。

### 東京vs地方の非対称性（重要な追加発見）
平和島（東京）はTripAdvisorでの認知度が公営競技の中で最も低い（レビュー45件、ツアー商品0件）一方、**ボートレースまるがめ（香川）はGoogleマップで1,145件のレビューを獲得し、Trip.com（アジア圏最大級OTA）にチケット販売ページが存在しUGC投稿も確認できた**。これは「ボートレース自体への需要がゼロなのではなく、東京の施設がインバウンド動線に乗れていないだけ」という仮説を裏付ける。

## 2. 外国人が実際に使っている情報源・ツール

| 用途 | 主な手段 | 評価 |
|---|---|---|
| 観戦・文化理解 | 公式boatrace.jp英語版（4言語対応、会場・ルール解説）、japan-guide.com（**運営団体自身のスポンサード記事**）、汎用旅行ブログ | 最も厚いが、基礎知識どまり |
| 賭け方の実務ガイド | `localbetjapan.com`がほぼ唯一の専業サイト（出走表の読み方、賭式解説、投票用紙記入法等、最低6記事確認） | 概念説明のみ、実際のレースデータ・オッズ・出走表は一切提供せず |
| 実際に賭ける行為 | **現地会場での対面投票が唯一の現実的手段** | 国籍・在留資格・銀行口座を問わず20歳以上なら現金で投票可能。ただし現金必須、マークシート表記は会場差あり（福岡は多言語対応・英語デスクあり、宮島は外国語対応記載なし） |
| オンライン投票（TELEBOAT） | 日本の指定銀行の普通預金口座（居住者口座）が必須 | 短期滞在の観光客は口座を開設できず事実上利用不可。中長期在留資格を持つ在日外国人は条件を満たせば利用できる可能性 |
| **予想・データ分析** | **英語で提供するサイト/アプリは実質ゼロ** | localbetjapan.comを含め、どのサイトも「予想の考え方」を教えるだけで、実データに基づく予想値・出走表・統計を英語で提供するサイトは一件も確認できず |
| コミュニティの生の声 | 実質的な議論はほぼ見当たらず（Reddit/Quora） | SEO記事が疑問への回答を独占している状態 |
| オフショア賭博 | `sportsbet.io`等のクリプトブックメーカーがkyoteiを扱うが日本の規制外のグレー〜違法領域 | 参照すべき「健全な競合」ではない |

**龍神レーダーのポジション**: 「予想・データ分析」領域は英語圏で事実上の空白地帯。ここは既存の日本語版の中核機能（AIデータ予想・出走表分析）をそのまま活かせる、直接競合が存在しない領域。

## 3. 龍神レーダーが提供すべき機能（提言）

現地実務調査の結論（「短期滞在の観光客でも現地では現金で投票できるが、TELEBOATは使えない」）と、既存ツール調査の結論（「予想・データ分析は英語で空白地帯」）を組み合わせると、以下の機能設計が導かれる。

1. **買い方ガイドの多言語化・データ裏付け化**: `localbetjapan.com`が「概念」しか教えていない領域に、龍神レーダーは実データ（出走表・過去成績）を組み合わせた具体的な説明を提供できる。単なる翻訳でなく、実例ベースのガイドにする
2. **会場別・多言語対応状況の案内**: 「どの会場が外国語対応の券売機・スタッフを持つか」という情報は現状どこにも整理されていない（福岡は対応、宮島は非対応という会場差を確認済み）。既存の会場別ビジターガイド（24会場対応済み）にこの軸を追加する
3. **TELEBOATが観光客には使えないという正直な情報の明示**: 既存の英語リソースはこの制約を明確に説明していない。信頼性の差別化要因になる
4. **「予想を見て、現地の券売機で紙の投票券を買う」導線を前提にしたUX**: アプリ内で投票が完結しない構造的制約を前提に、印刷・スクリーンショットしやすい予想表示、オフラインでも参照しやすい形式を検討
5. **当日レースのリアルタイム展開解説**: テレボート不要で使える「観戦をより楽しむための補助」として、AI予想・超展開予測を英語で提供する。これが空白地帯の核心部分であり、最も差別化度が高い

**優先度メモ**: 1〜3は工数が小さく（既存の会場ガイド・ブログi18nインフラの延長）、4〜5は英語版分析ツール自体の拡充が前提になるため、まず1〜3から着手し、需要の反応（アクセス数・Search Console表示回数）を見てから4〜5に投資する、という段階的アプローチが個人開発規模に合う。

## 4. マーケティング施策（優先順位）

| 優先度 | 施策 | 根拠 | 個人開発規模での実行可能性 |
|---|---|---|---|
| 1 | OTA（GetYourGuide/Viator）向けの英語コンテンツ提供・個人ツアーガイドとの提携 | 大井競馬場に272件のツアー商品が紐付く一方、平和島は0件。京都の個人ガイド「Kenji from Kyoto」が複数OTAでボートレースツアーを実際に販売している実例あり | 高い。既存ツアーガイドに龍神レーダーのデータを英語資料として提供する提携から始められ、開発コストがほぼ不要 |
| 2 | Reddit（r/TokyoTravel、r/JapanTravelTips）への自然な情報提供 | 「なぜもっと勧められないのか」という自発的な口コミが既に確認できている | 高い。広告費ゼロ、既存スレッドへの誠実な回答や実用的な新規投稿から。宣伝色が強いと逆効果になる点に注意 |
| 3 | 登録者1万〜10万人規模の中規模Japan系YouTuberとのバーター交渉 | 競輪はJKA自身が中規模チャンネル（登録者5.79万人）への有償タイアップを実施済み。ボートレース側はこの枠が空いている | 中程度。「英語データ・予想を無料提供する代わりに動画内で紹介してもらう」という無償/低コストの交渉が現実的 |
| 4 | 既存英語メディア（Japan Guide、Tokyo Cheapo）への寄稿・情報提供 | 両メディアは既にボートレース記事を保有。運営団体自身がJapan Guideにスポンサード記事を出稿している実績もある | 中程度。記事化の意思決定権がメディア側にあるためコントロールしづらい |
| 5（中長期・要検証） | Trip.com経由の中華圏インバウンド接点 | まるがめが既にTrip.comでチケット商品化・UGC投稿を獲得済み。龍神レーダーは繁體中文対応済み | 低い。個人開発規模での出店・提携は難易度が高く、優先度1〜3で型を確立してから検討 |

### 経営判断としての注記
- 運営団体自身（BOAT RACE公式）が既にjapan-guide.comへ広告出稿を始めており、「公式がこの土俵で動き始めている」ことは事実として認識しておくべき。龍神レーダーが取るべきは公式と競合する位置取りではなく、**公式が提供しない「実データに基づく英語予想」という空白**を埋める位置取り
- 大規模な広告予算・専業スタッフを前提にした施策（優先度5、専業代行業者との提携等）は個人開発規模とは相性が悪く、後回しにするのが妥当
