# 月100万PV の見込みと戦略（2026年11月）

- 日付・依頼: 2026-11-27。オーナーの問い「100万PV を目指して龍神が競合に勝つ見込みはあるか、どう戦略を立てるか」
- 材料（非公開）: `~/.config/ryujin/private/seo/pv-1m-strategy-2026-11/`（GA4・GSC・Keyword Planner の実数、独立の検証の全文）。repo は公開なので、実数はここに書かない
- 関連: [boatrace-competitor-landscape-2026-11.md](boatrace-competitor-landscape-2026-11.md)（競合12社）、[core-update-recovery-2026-11.md](../design/seo-data-loop/core-update-recovery-2026-11.md)（コアアップデートの回復の案）
- 検証: second-opinion-reviewer が「直して推す」。この文書は直した後の物

## オーナーの決定（2026-11-27）
- 100万PV は GA4 の PV（screenPageViews、Cookie に同意した人の分）で測る。GSC のクリックの一部しか映らないことは承知の上
- ページの本数は、回復の案の判定（12/8 以降）を先にする。それまで URL の本数を増やす打ち手は保留する（新しい日別ページ・長期データの過去ページ）
- 通知の手段は未定

## 見込み（推測）
- 新しい AI 系10社には勝てる見込みがある。どれも開業から1〜8か月で SNS も小さく、データの深さは龍神が上。負けているのは最初の画面の結論と、ページごとの title（ADR-0114 で直し中）。相手の流入の実数は無い
- 日和を1年で抜く見込みは低い。名前の検索に桁違いの差があり、毎日開く道具としての習慣がある
- 100万PV は今の PV から桁で離れている（基準と倍率は非公開の材料）。他社の名前を除く検索の需要は、言い換えを畳んで帯の幅を入れると、全部の語で上位3という非現実の仮定でやっと届く程度（試算は非公開の材料）。検索だけでは届かない。本体は毎日戻る人と名前の検索で、名前の検索は伸びている

## 戦略（順）
1. 検索の基本を終わらせる: ADR-0114 の生の head、トップの title、回復の案。検索のクリックの大半がトップ1枚に集まっている
2. グランプリ（期限 12/20）: `/grandprix` は 11/27 に入った。開催中の毎日の更新と、終わった後の優勝戦の結果・優勝者の積み上げ
3. 「今日・結果・配当」の群（龍神はほぼ取れていない）を、URL を増やさずに取る: `/races/:date` の title・中身を全場の結果・配当の一覧に向ける（今は「AI予想データ」）。日付の無い「今日・昨日」の入口は seo-marketer の審査を経る
4. 毎日戻る理由（100万PV の本体）: 先に今の再訪の基準値（visit_day の分布、重複を除いた人数）を取る。その上で、最初の画面の結論（イン崩れ注意度は 11/27 公開）、お気に入りの選手・会場の通知、朝一の「今日見る所」
5. URL を増やす打ち手（長期データ BOA-1719 の過去ページ等）は、回復の判定の後
6. SNS の再開は質の仕組みから（名前を育てる手段として）

やらない: 他社の名前の語を狙う、SNS の量産、薄いページの増産。

## 限界
- Keyword Planner の値は桁の帯で、選手名・会場名の単独の語が種に少ない。需要を小さく見ている可能性があり、大きさは未検証
- 「今日・結果」の語の検索結果の上位の顔ぶれは見ていない（検索結果の画面を機械で読まない）
- 新しい流入の1訪問あたりの PV は目安（根拠なし）
