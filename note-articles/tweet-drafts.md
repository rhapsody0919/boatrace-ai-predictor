# Xツイート下書き（新規ブログ記事公開時に自動追記）

`scripts/generate-tweet-draft.js`で新規ブログ記事公開のたびに自動生成・追記される。実際の投稿はユーザーが内容を確認の上、手動でXに投稿する。

**投稿したら`- [ ] 投稿済み`を`- [x] 投稿済み`に変更する**（2026-08-22運用開始）。投稿状況が追えず滞留に気づけなかった実績があるため、`/growth-report`実行時に未消化件数（`- [ ] 投稿済み`の数）を機械的にカウントして報告する。過去分（2026-08-22時点で39件）は実際の投稿有無が不明なため一律未チェックにしてある。実際に投稿済みのものがあれば手動でチェックを入れる。

**2026-08-23、廃止済み機能の下書き2件を削除**: 「今日のおすすめ」機能紹介の下書き（picks-guide, picks-performance-report）は、同機能がその後の統合モデル(unified)化で廃止済み（記事本文には免責注記済みだが下書き本文は無警戒に現在形で紹介していた）だったため削除した。今後もツイート下書きが滞留した場合、投稿前に廃止済み機能・古いモデル体系（本命狙い/スタンダード/穴狙いの3モデル）への言及が無いか確認すること。
