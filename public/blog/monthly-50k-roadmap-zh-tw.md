## 前提：為什麼是每月5萬日圓？

### 每月5萬日圓的價值

```
年間60萬日圓的副業收入
= 能自由花用飲酒、興趣費用
= 每年能去2次家族旅行
= 每月能存一筆退休金
```

**重要的是「再現性」：**
- 一次賺100萬日圓 < 每月賺5萬日圓持續12個月
- 穩定收入更能豐富人生

### 為什麼選賽艇？

**賽艇適合當副業的理由：**

1. **小額即可開始**
   - 最低100日圓即可購買
   - 不需要像股票或外匯那樣的大額資金

2. **結果立即揭曉**
   - 一場比賽約2分鐘見真章
   - 當天即可確定收支

3. **數據豐富**
   - 選手、馬達、過去比賽數據皆公開
   - 可用AI分析

4. **每天都有比賽**
   - 平日、假日皆有舉辦
   - 能配合自己的時間參與

## 步驟1：打好基礎（第1個月）

### 目標：每月±0日圓

首先以**不虧損**為目標。

### 該做的事

**1. 每天在BoatAI確認預測**

👉 [boat-ai.jp](https://boat-ai.jp/)

養成每天早上花5分鐘確認今日比賽的習慣。

**2. 只買複勝**

首先累積命中體驗很重要。

**購買規則：**
```
每場比賽：100日圓
每日：10場（1,000日圓）
每月：30天（30,000日圓）
```

**選擇的比賽：**
- AI分數3500以上
- 靜水面的賽艇場（大村、蘆屋、津、德山）
- 風速3m以下

**3. 做記錄**

用Excel或記事應用程式記錄：
```
日期 | 比賽 | 購買額 | 派彩額 | 收支
12/18 | 大村第3場 | 100日圓 | 130日圓 | +30日圓
12/18 | 蘆屋第7場 | 100日圓 | 0日圓 | -100日圓
...
```

### 第1個月的期望成績

**複勝命中率：52.1%（BoatAI實績）**

```
投注：30,000日圓（100日圓×10場×30天）
派彩：29,400日圓（130日圓×52.1%×300場）

**若結果接近±0日圓，就算是大成功了。**

### 第1個月要學習的事

- 馬達2連率的重要性
- 各賽艇場的特性

- 排除感情的購買方法

## 步驟2：穩定化（第2-3個月）

### 目標：每月+1萬〜2萬日圓

熟悉複勝後，導入3連複。

### 該做的事

**1. 改變投注組合種類的分配**

**第2個月的購買分配：**
```
複勝：7場 × 100日圓 = 700日圓/天
3連複：3場 × 100日圓 = 300日圓/天
合計：1,000日圓/天
```

**購買3連複的比賽條件：**
- AI分數3800以上
- 排名前3的艇馬達2連率皆40%以上
- 靜水面的賽艇場
- 風速3m以下

**2. 鎖定賽艇場**

集中在擅長的賽艇場，能提升命中率。

**建議賽艇場（內道有利）：**
- 大村（1號艇勝率63%）
- 蘆屋（1號艇勝率58%）
- 德山（1號艇勝率58%）
- 津（1號艇勝率57%）

**應避開的賽艇場（初學者）：**
- 戶田（1號艇勝率45%）
- 江戶川（1號艇勝率47%）
- 平和島（1號艇勝率48%）

### 第2個月的期望成績

```
【複勝】

派彩：23,940日圓（130日圓×52.1%×210場）

【3連複】

**達成每月+1萬日圓！**

### 第2-3個月要學習的事

## 步驟3：收益化（第4個月以後）

### 目標：每月+5萬日圓

從這裡開始正式邁向收益化。

### 該做的事

**1. 增加投注額（謹慎進行）**

**第4個月的購買分配：**
```
複勝：5場 × 200日圓 = 1,000日圓/天
3連複：3場 × 300日圓 = 900日圓/天
3連單：2場 × 100日圓 = 200日圓/天
合計：2,100日圓/天
```

**重要：**
不要突然增加投注額，而是**在資金範圍內逐步**增加。

**2. 小額加入3連單**

3連單命中率雖低（5.6%），但命中時報酬大。

**購買3連單的比賽條件：**
- AI分數第一、第二名皆3900以上
- 1號艇A1級 × 馬達2連率45%以上
- 靜水面 × 風速2m以下
- 第12場優勝戰級的比賽

**3. 分辨高派彩比賽**

**高派彩的特徵：**
```
【值得鎖定】
- 2-4號艇為A級選手 × 優良馬達
- 1號艇為B級 或 馬達狀況不佳
- 順風3m以上（外道有利）

【應避開】
- 1號艇A1級 × 馬達2連率超過50%
→ 過於穩健導致賠率過低
```

### 第4個月的期望成績

```
【複勝】
投注：30,000日圓（200日圓×5場×30天）
派彩：33,930日圓（260日圓×52.1%×150場×平均派彩修正）
收支：+3,930日圓

【3連複】
投注：27,000日圓（300日圓×3場×30天）
派彩：56,187日圓（平均派彩2,080日圓×15.3%×90場×3倍投注）
收支：+29,187日圓

【3連單】
投注：6,000日圓（100日圓×2場×30天）
派彩：26,982日圓（平均派彩24,188日圓×5.6%×60場）
收支：+20,982日圓

合計：+54,099日圓
```

**達成每月+5萬日圓！**

遵守**複勝7成、3連複2成、3連單1成**的平衡
