# 夜間賽攻略法——與白天比賽不同的5個特徵與數據分析

## 前言

「用白天比賽的感覺投注夜間賽，結果完全不準...」

您是否有過這樣的經驗？

夜間賽和白天比賽有著**截然不同的特徵**。氣溫、水面、照明、選手狀況等，影響預測的要素大幅不同。

本文將徹底解說夜間賽的**5個特徵**與**依據數據的攻略法**。

---

## 什麼是夜間賽

夜間賽主要在**下午15時左右〜20時30分左右**舉行。由於下班後也能觀賽，近年來人氣急速上升。

### 夜間賽舉行會場（全國7處）

| 會場 | 特徵 |
|------|------|
| **桐生**（群馬） | 內陸型，日夜溫差大。冬季夜間特別寒冷 |
| **蒲郡**（愛知） | 靜水面，內道有利。夜間賽歷史悠久 |
| **丸龜**（香川） | 海水，受潮汐影響。逆風較多 |
| **下關**（山口） | 海水・小型水池。水面穩定 |
| **若松**（福岡） | 海水，潮位變化大。易受風勢影響 |
| **德山**（山口） | 全國頂級的內道勝率。靜水面 |
| **大村**（長崎） | 全國最高水準的內道第一名率。夜間賽的代表會場 |

## 與白天的5個差異

### 1. 氣溫下降造成馬達出力變化

夜間賽最大的特徵是**氣溫下降**。

**原理：**
- 氣溫下降，空氣密度上升
- 空氣密度上升，馬達吸入的氧氣量增加
- 結果**馬達出力提升**

**對預測的影響：**
- 相較於白天前段的比賽，夜間後段比賽的馬達性能差異更容易顯現
- 保養能力強的選手更為有利
- 氣溫下降10度以上的冬季夜間賽尤需注意

**要點：** 由於展示時間多在白天測量，實際比賽時往往**比展示時間更快**。

---

### 2. 水面較易穩定

夜間相較於白天，**風勢較弱**的傾向。

**理由：**
- 日落後地表溫差縮小，對流減弱
- 內陸的桐生尤其明顯，即使是臨海的蒲郡、德山、大村等灣內會場也有此傾向

**對預測的影響：**
- 水面穩定，內道逃走更容易成功
- 起跑時機更容易掌握
- 較不容易發生爆冷

---

### 3. 選手狀況變化

夜間賽由於是接近一天的後段，選手的**疲勞**會影響預測。

**檢查要點：**
- 當日第2、第3場出賽的選手可能已累積疲勞
- 反之，夜間賽首場出賽的選手集中力較高
- 資深選手夜間賽經驗豐富，應變能力較強

**重要：** 常參加夜間賽的選手與不熟悉夜間賽的選手，表現可能有所差異。也請確認出賽次數。

---

### 4. 照明對視野的影響

夜間賽中，**照明的反射**映照在水面上，視野與白天不同。

**受影響的要點：**
- 其他艇的引波較難看清
- 難以掌握與轉彎標的距離感
- 不熟悉的選手轉彎時容易大幅偏出

**運用於預測：**
- 重視在夜間會場出賽經驗豐富的選手
- 尤其是中央、外道的外攻容易受照明影響
- **結果內道會更加有利**

---

### 5. 越後段比賽內道勝率越高

這是夜間賽中最重要的一項數據。

**傾向：**
- 前段比賽（15時左右）的內道第一名率與平常差異不大
- 越到後段比賽（18時以後），內道第一名率越高
- 最終比賽附近，某些會場**內道第一名率甚至超過60%**

**複合原因：**
- 氣溫下降 → 馬達出力提升 → 起跑力提升
- 風勢減弱 → 水面穩定 → 起跑精準度提升
- 照明影響 → 外道進攻變得困難

| 比賽時段 | 內道第一名率（參考值） | 特徵 |
|-------------|------------------|------|
| 15:00〜17:00 | 50〜55% | 與白天差異不大 |
| 17:00〜19:00 | 55〜60% | 逐漸轉為內道有利 |
| 19:00〜20:30 | 60〜65% | 內道逃走的黃金時段 |

## 夜間賽獨有的3個策略

### 策略1：後段比賽以內道逃走為主軸

18時以後的比賽，只要1號艇選手不是特別弱勢，**以內道逃走為本命**組合投注組合是基本原則。

**投注範例：**
- 3連單第一名固定為1號艇
- 第二名鎖定2、3號艇，第三名廣泛佈局
- 由於容易出現穩健的結局，需注意與賠率的平衡

---

### 策略2：善用氣溫差異評估馬達

僅憑白天的展示時間判斷馬達性能是有風險的。

**應確認的事項：**
- 當日氣溫變化（白天與夜間相差幾度）
- 馬達2連率高的選手，夜間更為有利
- 保養能力強的A1級選手的馬達，夜間更能發揮實力

---

### 策略3：掌握各夜間會場的特性

並非所有夜間賽會場都相同。請理解各會場的特性。

| 會場 | 內道有利度 | 爆冷易度 | 攻略要點 |

| 蒲郡 | ★★★★☆ | ★★☆☆☆ | 靜水面，內道有利。以穩健投注為主 |
| 丸龜 | ★★★☆☆ | ★★★☆☆ | 確認潮汐漲退。滿潮時內道有利 |
| 下關 | ★★★★☆ | ★★☆☆☆ | 小型水池水面穩定。內道逃走率偏高 |
| 若松 | ★★★☆☆ | ★★★☆☆ | 水面隨風與潮位變化，應重視數據 |
