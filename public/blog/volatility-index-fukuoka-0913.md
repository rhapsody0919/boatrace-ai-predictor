# イン崩れ指数100%は当たるのか？9/13福岡3Rの実例で検証

![福岡3Rのイン崩れ指数バッジ表示例。イン崩れ指数100%と1号艇全国勝率4.00を示すカバー画像](/images/blog/volatility-index-fukuoka-0913.jpg)

「イン崩れ指数100%」——龍神レーダーのレース詳細ページでこの表示を見たとき、「本当にそんなに崩れるの？」と疑問に思ったことはないでしょうか。

今回は2026年9月13日・福岡3Rを実例に、発走前に表示されていた「イン崩れ指数100%」という予測が、実際の結果とどう対応したのかをそのまま検証します。都合の良い結果だけを選んでいないか確認できるよう、発走前のデータと結果を数値でそのまま並べます。

---

## イン崩れ指数とは何か

イン崩れ指数は、そのレースで1号艇が崩れる（3着以内に入れない）可能性を、会場内の他レースと比較した相対的な位置づけ（パーセンタイル）で0〜100%に示す指標です。主に以下の実データから総合的に算出しています。

- 1号艇選手の全国勝率
- 1号艇のスタートタイミング（今節平均ST）の傾向
- AIが予測する「逃げ」決まり手の確率
- モーター調子や枠なり別の決まり手傾向

数値が高いほど「セオリー通りの1号艇イン逃げにならず、まくり・差しなど外枠の決まり手が有力」というAIの見立てを意味します。

## 9/13福岡3R：発走前に表示されていたデータ

12:48発走の福岡3Rには、次の実データが表示されていました。

| 項目 | 数値 |
|------|------|
| イン崩れ指数（会場内パーセンタイル） | **100%** |
| 1号艇（山下奈緒選手・B1）全国勝率 | **4.00** |
| AI逃げ確率 | **29%** |
| 1号艇の今節平均ST | 0.214秒 |

AIが挙げていた判定根拠は次の3点でした。

- AI逃げ確率が非常に低い（29%）→ まくり・差しが有力
- 1号艇の今節STが遅い（平均0.214秒）→ イン崩れリスク
- 1号艇の全国勝率がやや低い（4.00）→ 崩れやすい

対して3号艇（吉田裕平選手・A1）は全国勝率7.43、4号艇（藤丸光一選手・B1）は全国勝率4.67と、特に3号艇とは実力差が数字上はっきり出ていました。

## レース結果：実際にどうなったか

同レースの結果は以下の通りです。

| 着順 | 艇番 |
|------|------|
| 1着 | 3号艇 |
| 2着 | 4号艇 |
| 3着 | 1号艇 |
| 4着 | 5号艇 |
| 5着 | 2号艇 |
| 6着 | 6号艇 |

決まり手は**「まくり」**。全国勝率で1号艇を上回っていた3号艇（吉田選手）が優勝し、AIが判定根拠に挙げていた「まくり・差し有力」という見立ては、実際の決まり手と一致しました。

一方で1号艇（山下選手）は、1着こそ逃したものの3着に粘り、「イン崩れ指数100%」が示唆していたほどの完全な崩れには至りませんでした。イン崩れ指数はあくまで確率的な指標であり、100%という表示でも1号艇が3着以内を確保するケースは実際に起こります。1レースの結果だけで「当たった」「外れた」と単純に判定できない、指数の限界がそのまま出た実例です。

## 全国平均、指数の"効きやすさ"は会場でも違う

イン崩れ指数が「警戒」レベル（会場内パーセンタイル70%以上）のレースについて、龍神レーダーが蓄積した実測データを見ると、全国平均では次のようになっています（2026年10月時点、8,854レース中）。

| 区分 | レース数 | 実測イン崩れ率（1号艇が1着を逃す割合） | 全体平均との差 |
|------|---------|------------------------------------|--------------|
| 警戒レベル（70%以上） | 2,644件 | **63.8%** | +19.0pt |
| 標準レベル | 3,578件 | 42.9% | -1.9pt |
| 安定レベル（30%以下） | 2,632件 | 28.3% | -16.5pt |

全国平均では「警戒」レベルは全体平均（44.8%）より+19.0ポイントも1号艇が1着を逃しやすいという、はっきりした傾向が出ています。この「1着を逃す率」は、今回の福岡3Rのように3着には残るケースも含むため、本文冒頭で説明した「3着以内に入れない」こととは別の指標です。1号艇が3着以内を確保できるかどうかは、この数値よりもさらに高い確率で起きています。

今回のレースの会場である福岡は、「警戒」レベルが141件・実測63.8%相当の全国水準に対し、実測イン崩れ率56.7%・会場全体平均39.3%との差は+17.4ポイントで、全国平均に近い水準です。同じ「イン崩れ指数100%」でも会場ごとにサンプル数・効きやすさが異なる点は、[`/winning-technique`](/winning-technique?tab=volatility)の「会場ランキング」タブで誰でも確認できます。

## この指数の使い方

レース詳細ページを開くと、イン崩れ指数はバッジ形式で表示されます。

1. [福岡3R（9/13）のレース詳細ページ](/race/2026-09-13-22-03)のように、気になるレースの詳細ページを開く
2. 「⚖️ イン崩れ注意度」バッジで会場内パーセンタイルと判定根拠を確認する
3. [`/winning-technique?tab=volatility`](/winning-technique?tab=volatility)で、レベル別・会場別の実測イン崩れ率を確認する

バッジには判定根拠（全国勝率・AI逃げ確率・平均ST等）がリスト表示されるため、「なぜこの数値になっているか」を自分の目で確認したうえで舟券戦略を組み立てられます。

## 活用のポイント

### 100%でも「3着以内を確保する」ことはある

今回のケースのように、イン崩れ指数100%でも1号艇が3着以内に粘ることはあります。指数はあくまで確率的な指標であり、「必ず崩れる」ことを保証するものではありません。

### 対抗艇の実力差と合わせて確認する

イン崩れ指数だけで判断せず、1号艇と対抗艇の全国勝率差、モーター調子、AI逃げ確率を合わせて確認すると、より根拠のある判断がしやすくなります。今回のケースでも、1号艇（4.00）と優勝した3号艇（7.43）との勝率差3.43ポイントが、AIの判定根拠を裏付ける材料になっていました。

### 会場ごとの傾向差も参考にする

イン崩れの起きやすさは会場によって差があります。[`/winning-technique`](/winning-technique?tab=volatility)の「会場ランキング」タブでは、会場ごとの実測データを比較できるので、遠征観戦や複数会場を跨いだ検討をする際の参考にしてください。関連する分析は[勝ちパターン分析ガイド](/blog/winning-technique-analysis-guide)でも詳しく解説しています。

## よくある質問

### イン崩れ指数100%なら、必ず1号艇が負けるのですか？

いいえ。イン崩れ指数は過去データに基づく確率的な指標であり、100%という数値も「会場内で最も1号艇が崩れやすい水準にある」ことを意味するもので、結果を保証するものではありません。今回の福岡3Rでも、1号艇は1着を逃したものの3着に残っています。

### イン崩れ指数はどこで確認できますか？

各レースの詳細ページに「⚖️ イン崩れ注意度」バッジとして表示されます。また[`/winning-technique?tab=volatility`](/winning-technique?tab=volatility)では、レベル別・会場別の実測イン崩れ率を会場横断でまとめて確認できます。

### 「1着を逃す」ことと「3着以内に入れない」ことは同じ意味ですか？

同じではありません。イン崩れ指数が示す「1号艇が崩れる可能性」は3着以内に入れない可能性を指しますが、実測データの「イン崩れ率」は1号艇が1着を逃した割合を集計したものです。今回の福岡3Rのように、1着は逃しても3着に残るケースはどちらの集計でも区別して考える必要があります。
