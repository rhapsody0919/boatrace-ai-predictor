# 枠なりとは？全国の81.0%は枠なり進入｜崩れる会場と進入の読み方

枠なりは全艇が艇番と同じコースから進入する形で、全国24場の直近1年（2025年10月20日〜2026年10月19日）では55,414レース中44,867回（81.0%）が枠なりでした。
全国の残る55,414レース中10,547回（19.0%）は枠なりにならない進入で、1艇以上が艇番と違うコースに入りました。会場別では蒲郡の2,478レース中663回（26.8%）から江戸川の2,068レース中34回（1.6%）まで開きがあります。

今日のレースで各艇が本番に何コースへ入りそうかは、[今日のレース一覧](/races)からレースを開き、直前情報の「この枠からの進入コース」で見られます（手順は最後から2つ目の節）。

## 枠なりとは、全艇が艇番と同じコースに入る進入

枠番（艇番）は出走表で決まる1〜6の番号で、コースは本番のスタートで内から何番目に並んだかです。1号艇が1コース、2号艇が2コースというように、6艇とも番号どおりに並べば枠なりです。1艇でも番号と違うコースに入れば、枠なりではありません。コースは公式の結果にある本番の進入コースで、展示の進入ではありません。

| 範囲と期間 | 枠なりのレース | 枠なりにならなかったレース |
|---|---|---|
| 全国・直近3か月（2026年7月20日〜2026年10月19日） | 14,301レース中11,693回（81.8%） | 14,301レース中2,608回（18.2%） |
| 全国・直近6か月（2026年4月20日〜2026年10月19日） | 28,606レース中23,261回（81.3%） | 28,606レース中5,345回（18.7%） |
| 全国・直近1年（2025年10月20日〜2026年10月19日） | 55,414レース中44,867回（81.0%） | 55,414レース中10,547回（19.0%） |

3つの期間とも、枠なりは81.0〜81.8%でした。全国で見ると、5レースのうちおよそ4レースは艇番どおりの並びで始まります。

## 枠なりが崩れる形：前付け・深イン・スローとダッシュ

ピットを出てからスタートまでの待機行動の間に、選手は入るコースを選べます。外の艇番の選手が内のコースへ入るのが前付けです（龍神レーダーの画面では「前づけ」と表記しています）。たとえば4号艇が2コースへ入ると、進入は1-4-2-3-5-6になり、2号艇と3号艇は1つずつ外へ出ます。

前付けで内の艇がスタートラインに近い位置まで押し込まれ、助走が短くなる形を深インと呼びます。1コースの艇が深くなると加速の距離が取れず、スタートで後れを取りやすくなります。

スタートの位置には、助走の短い内側のスロー勢と、助走を長くとる外側のダッシュ勢があります。ダッシュ勢の一番内がカドで、枠なりなら4コースです。前付けが入ると、誰がカドになるかも変わります。

## 枠なりが崩れやすい会場・崩れにくい会場

直近1年（2025年10月20日〜2026年10月19日）で、枠なりにならなかったレースの割合が高い3場と低い3場です。

| 会場 | 枠なりにならなかったレース |
|---|---|
| 蒲郡 | 2,478レース中663回（26.8%） |
| 常滑 | 2,546レース中674回（26.5%） |
| 唐津 | 2,070レース中529回（25.6%） |
| 大村 | 2,377レース中316回（13.3%） |
| びわこ | 2,193レース中194回（8.8%） |
| 江戸川 | 2,068レース中34回（1.6%） |
| 全国（24場） | 55,414レース中10,547回（19.0%） |

6場とも全国の19.0%との差は、24場をそれぞれ全国と比べるときの統計の線（|z|が約3.08以上）を超えます。蒲郡・常滑・唐津の3場の間の順は、差を確認できない大きさです。江戸川の2,068レース中34回（1.6%）は24場で最も少なく、ほとんどのレースが艇番どおりの並びで始まる会場です。

24場すべての割合と、直近3か月・6か月の値は[全24場の進入の動きやすさ](/blog/venue-waku-nari-entry-rate)にまとめています。

## 艇番の1着とコースの1着はどれだけずれるか

1着の艇を出走表の艇番で分けるか、本番で入ったコースで分けるかで、回数が変わります。全国24場・直近1年の55,414レースです。

| 番号 | 艇番で分けた1着（55,414レース中） | コースで分けた1着（55,414レース中） |
|---|---|---|
| 1 | 30,480回（55.0%） | 30,732回（55.5%） |
| 2 | 7,522回（13.6%） | 7,373回（13.3%） |
| 3 | 7,022回（12.7%） | 7,127回（12.9%） |
| 4 | 5,465回（9.9%） | 5,726回（10.3%） |
| 5 | 3,275回（5.9%） | 3,406回（6.1%） |
| 6 | 1,650回（3.0%） | 1,050回（1.9%） |

開きが大きいのは6の行です。6号艇の1着は55,414レース中1,650回（3.0%）、6コースの1着は55,414レース中1,050回（1.9%）でした。前付けで内へ入って勝った6号艇は「6号艇の1着」に入り、「6コースの1着」には入りません。逆に、外へ出されて6コースから勝ったほかの艇番の艇は「6コースの1着」に入ります。2つの回数の差は、内から勝った6号艇の回数そのものではありません。艇番とコースの分け方の違いは[6号艇の1着率と6コース](/blog/six-boat-first-place-rate)で詳しく扱っています。

もう1つ深い点は分母です。全国の直近1年には欠場で6艇に満たないレースが568あり、6コースに艇がいたのは54,846レースでした。6コースの1着率を「6コースに艇がいたレース」で割ると、54,846レース中1,050回（1.9%）になります。枠なりかどうかも、欠場した艇を除き、残った艇が艇番どおりのコースに入ったかで分けています。

## 今日のレースで進入を読む手順

1. [今日のレース一覧](/races)からレースを開き、直前情報の「この枠からの進入コース」を見ます。各艇が今回と同じ枠番で出たとき、本番で何コースに入ったかが、枠なり・前づけの割合と走数で1本の棒に出ます（2025年12月以降の集計。6走未満の艇は棒が薄く出ます）。前づけの割合が高い艇がいるレースは、進入が動く前提で読みます。
2. 展示のあと、直前情報の「展示進入」の行でスタート展示のコースを見ます（2026年9月21日以降のレースに表示）。展示の見方は[展示航走の見方](/blog/exhibition-run-guide)にまとめています。
3. 会場の1コースの1着率などコース別の数字は、艇番でなく入ったコースの行に当てます。6号艇が展示で3コースに入ったら、6コースの行ではなく3コースの行を見ます。
4. 蒲郡・常滑・唐津のように枠なりにならないレースが4レースに1回を超える会場では、2と3の手順を重く見ます。江戸川は2,068レース中34回（1.6%）しか崩れていないので、出走表の艇番のままコース別の数字を読めます。会場ごとの1コースの1着率は[会場別の1コースの1着率](/blog/venue-course1-win-rate-ranking)にあります。

## 数字の範囲と注意

母数は結果のあるレースで、中止・順延と不成立のレースは入りません。1着は返還艇を除き、1着の同着は艇番の小さい艇を採っています。直前情報の「この枠からの進入コース」は選手ごとの2025年12月以降の集計で、この記事の全国・会場の値とは期間と範囲が違います。展示の進入は本番で変わることがあります。会場によって進入が動く理由は、この数字からは言えません。過去の割合は、今日のレースの結果を約束する数字ではありません。
