# 什麼是「筋投注」？依會場分類的鎖定模式速查表【大村1號艇勝率約60%等】

## 前言

看到「1-2-3」「4-5-6」這樣的投注組合，您能說明**為什麼是這個組合**嗎？

賽艇有一種稱為「筋」的**比賽走勢理論**。理解筋，就能不只是單純的數字組合，而是**一邊想像比賽走勢一邊組合投注組合**。

本文將徹底解說筋投注的基礎到實戰活用法。

---

## 什麼是筋投注？

### 定義

**筋投注**是依據賽艇走勢理論所組成的投注組合。

賽艇的勝負幾乎在第一圈第一轉彎標（1轉彎）的攻防中決定。此時，有一個法則是**依哪艘艇率先領先，後續的名次模式容易隨之決定**。

### 為什麼會形成筋？

賽艇的航道是逆時針方向。轉過1轉彎時：

- **內側的艇**：迴旋距離短，能較早轉彎
- **外側的艇**：迴旋距離長，容易落後

因此，**依獲勝艇的航道，容易決定第二・第三名容易出現的艇**。

---

## 基本筋模式

### 內道逃走筋（1號艇獲勝時）

**最基本的模式。1號艇成功起跑並逃走到底的情況。**

| 走勢 | 筋目 | 理由 |
|------|--------|------|
| 1號艇逃走 | 1-2、1-3 | 內側的2,3號艇直接跟進 |
| 1號艇逃走（切入） | 1-4、1-2-4 | 4號艇切入內道進入第二名 |

**代表性投注組合：**
```
1-2-3（本命中的本命）
1-2-4（涉及切入的模式）
1-3-2（3號艇領先於2號艇的模式）
1-3-4
```

**要點：**
- 1號艇逃走時，外側的5,6號艇基本上不會進榜
- 「1-2-6」「1-5-6」是**逆筋（不太可能的組合）**

---

### 外攻筋（外道獲勝時）

**3〜6號艇從外側一舉進攻，搶下1轉彎的情況。**

#### 3號艇外攻
| 走勢 | 筋目 | 理由 |
|------|--------|------|
| 3號艇外攻 | 3-4、3-5 | 外側的艇隨外攻氣勢跟進 |
| 3號艇外攻切入 | 3-1、3-4-1 | 切入內道使3號艇出線 |

**代表性投注組合：**
```
3-4-5（外攻走勢）
3-4-1（外攻＋內道苦守）
3-1-4（切入走勢）
```

#### 4號艇外攻
| 走勢 | 筋目 | 理由 |
|------|--------|------|
| 4號艇外攻 | 4-5、4-6 | 一同外繞的艇跟進 |
| 4號艇外攻 | 4-5-6 | 完全的外攻走勢 |

**代表性投注組合：**
```
4-5-6（大外攻）
4-5-1（外攻＋內道苦守）
4-3-5（3號艇苦守第二名）
```

---

### 切入筋

**內道的艇先轉彎，但被內側切入的情況。**

| 走勢 | 筋目 | 理由 |
|------|--------|------|
| 2號艇切入 | 2-1、2-3 | 切入1號艇內側 |
| 4號艇切入 | 4-1、4-2 | 看似外攻卻切入內側 |

**要點：**
- 切入是**擅長轉彎的選手**的拿手好戲
- 切入成功時，**內道容易保住第二名**

## 筋速查表

值得記住的**筋速查表**。

| 第一名 | 第二名候選（筋） | 第三名候選 |
|-----|----------------|---------|
| 1號艇 | 2, 3, 4 | 2, 3, 4, 5 |
| 2號艇 | 1, 3 | 1, 3, 4 |
| 3號艇 | 1, 4, 5 | 1, 2, 4, 5 |
| 4號艇 | 3, 5, 6 | 1, 3, 5, 6 |
| 5號艇 | 4, 6 | 1, 4, 6 |
| 6號艇 | 4, 5 | 1, 4, 5 |

![以官方艇番顏色呈現的筋速查表，從1號艇(白)到6號艇(綠)，以彩色圓圈顯示各艇奪冠時的第二名・第三名候選](/images/blog/suji-funaken-chart-zh-tw.jpg)

**法則：**
- 內道獲勝 → **內側的艇容易跟進**
- 外道獲勝 → **外側的艇容易跟進**

## 逆筋（不易出現的組合）

理解筋之後，也能了解**不易出現的組合**。

### 內道逃走卻外道進榜的組合（逆筋）
```
❌ 1-5-6（1號艇逃走時5,6進第2、3名的情況罕見）
❌ 1-6-5
❌ 1-6-2
```

### 外攻卻內道進榜的組合（逆筋）
```
❌ 4-1-2（4號艇外攻時1,2跟進的情況罕見）
❌ 5-1-2
❌ 6-1-2
```

**逆筋出現的時候：**
- 大爆冷的比賽
- 發生翻覆・落水
- 起跑大幅參差不齊

逆筋**派彩較高**，但要瞄準命中並不容易。

---

## 運用筋的投注方式

### 策略1：用筋縮減投注組合

**縮減投注組合時運用筋**

範例：1號艇看似會獲勝的比賽
```
全組合：1-234-234 = 6點
用筋縮減：1-2-3, 1-2-4, 1-3-2, 1-3-4 = 4點
```

只要減少2點，回收率就會提升。

---

### 策略2：從走勢預測選擇筋

**觀看起跑展示預測走勢，決定筋**

```
【走勢預測】
・1號艇起跑較慢
・4號艇起跑快，似乎會外攻
→ 採用4號艇外攻筋

【投注組合】
4-5-6（外攻走勢）
4-5-1（內道苦守）
4-3-5（3號艇保住）
```

---

### 策略3：分開本線與保守

**筋目作為本線，逆筋作為保守**

```
【本線（筋目）】80%資金
1-2-3：1,000日圓
1-2-4：800日圓
1-3-2：600日圓

【保守（逆筋）】20%資金
1-5-4：300日圓
1-6-4：300日圓
```

## 依會場分類的筋傾向

筋的傾向依會場而異。

### 內道逃走筋容易成功的會場
| 會場 | 1號艇勝率 | 特徵 |
|------|----------|------|
| 大村 | 約60% | 日本第一內道強度 |
| 蘆屋 | 約58% | 靜水面內道有利 |
| 德山 | 約57% | 平穩的水面 |

→ **1-2-3、1-2-4的筋容易成功**

### 外攻筋容易成功的會場
| 會場 | 特徵 |
|------|------|
| 戶田 | 水面狹窄外攻有利 |
| 平和島 | 受潮汐影響內道不利 |
| 江戶川 | 難水面內道受苦 |

→ **3-4-5、4-5-6的筋容易出現**

## AI與筋的組合

將BoatAI的預測與筋組合，能進一步提升準確度。

### 使用方法

1. **確認AI的預測**
   - 第一名預測：4號艇
   - 第二名預測：5號艇
   - 第三名預測：1號艇

2. **套用筋**
   - 4號艇第一名 → 4號艇外攻筋
   - 4-5 符合筋 ✓
   - 4-5-1 是「外攻＋內道苦守」，很自然 ✓

3. **符合筋則提升信心度**
   - AI的預測符合筋 → 信心度高
   - AI的預測是逆筋 → 需要謹慎

## 常見問題

### Q. 依筋投注就能贏嗎？

**A. 光靠筋無法獲勝。**

筋終究只是「容易出現的模式」，並非100%。重要的是：
- 從起跑展示預測走勢
- 選手實力與馬達性能
- 風與浪的影響

請將筋當作**縮減投注組合的工具**來使用。

### Q. 逆筋不買比較好嗎？

**A. 視情況而定。**

- 平時**優先選擇筋目**
- 容易爆冷的比賽**逆筋也可小額保守佈局**
- 逆筋出現時派彩較高，作為保險相當有效

### Q. 該如何記住筋？

**A. 請記住「獲勝艇附近的艇容易進榜」。**

- 1號艇獲勝 → 2,3號艇跟進（相近）
- 4號艇獲勝 → 5,6號艇跟進（相近）
- 例外是「切入」造成內道保住名次的模式

## 總結

### 筋投注的要點

1. **筋是走勢理論**
   - 內道獲勝則內道跟進
   - 外道獲勝則外道跟進

2. **用筋縮減投注組合**
   - 全組合購買資金效率差
   - 用筋能縮減2〜3點

3. **逆筋不易出現**
   - 「1-5-6」「4-1-2」罕見
   - 出現時派彩高但難以瞄準

4. **考量會場特性**
   - 內道強的會場 → 內道逃走筋
   - 外攻多的會場 → 外攻筋

5. **搭配AI效果佳**
   - AI預測符合筋 → 信心度提升
   - 預測偏離筋 → 需謹慎判斷
