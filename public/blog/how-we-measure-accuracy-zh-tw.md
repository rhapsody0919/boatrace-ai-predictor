## 實績計測方法

### 1. 對象比賽

以龍神雷達公開預測的**所有比賽**為對象。

- 不會只挑選特定比賽計測
- 不做「只計測信心度高的比賽」這種恣意篩選
- 只要公開預測，該比賽就必定納入統計對象

### 2. 命中判定基準

#### 複勝命中率
AI預測的「本命」艇若進入**前2名**，即計入命中。

```
複勝命中率 = 本命進入前2名的比賽數 ÷ 全部比賽數 × 100
```

#### 3連複命中率
若AI預測的投注組合中，包含**實際前3名的3艘艇組合**，即為命中。

```
3連複命中率 = 3連複命中的比賽數 ÷ 全部比賽數 × 100
```

#### 3連單命中率
若AI預測的投注組合中，包含**實際第一名-第二名-第三名依順序的組合**，即為命中。

```
3連單命中率 = 3連單命中的比賽數 ÷ 全部比賽數 × 100
```

### 3. 回收率計算方法

回收率是顯示「相對於投注金額，回收了多少」的指標。

```
回收率 = 派彩合計 ÷ 投注金額合計 × 100
```

#### 具體範例

| 比賽 | 投注額 | 結果 | 派彩 |
|--------|--------|------|--------|
| 第1場 | 1,000日圓 | 命中 | 3,500日圓 |
| 第2場 | 1,000日圓 | 未命中 | 0日圓 |
| 第3場 | 1,000日圓 | 未命中 | 0日圓 |
| 第4場 | 1,000日圓 | 命中 | 2,200日圓 |
| 第5場 | 1,000日圓 | 未命中 | 0日圓 |
| **合計** | **5,000日圓** | - | **5,700日圓** |

此情況下的回收率：
```
5,700日圓 ÷ 5,000日圓 × 100 = 114%
```

**回收率100%以上**代表回收金額超過投注金額（＝正收支）。

### 4. 投注額的前提

龍神雷達的回收率計算，是以**每點100日圓**為前提。

例如，若3連單的推薦投注組合為10點：
- 投注額：100日圓 × 10點 = 1,000日圓
- 派彩：命中時的賠率 × 100日圓

統一這個前提，才能進行比賽之間的比較。

## 各指標的意義與參考標準

### 命中率與回收率，哪個比較重要？

**結論：回收率比較重要。**

即使命中率高，若回收率低就毫無意義。

| 模式 | 命中率 | 回收率 | 結果 |
|----------|--------|--------|------|
| A | 50% | 80% | 虧損 |
| B | 30% | 120% | **獲利** |
| C | 10% | 150% | **獲利** |

模式A雖然一半會命中，但賠率過低導致回收率80%。也就是說，即使投注1萬日圓，也只回收8,000日圓。

另一方面，模式C命中率10%，但回收率150%。投注1萬日圓即成為15,000日圓。

### 龍神雷達鎖定的目標數值

| 指標 | 目標 | 目前實績 |
|------|------|-----------|
| 複勝命中率 | 45%以上 | 49.5% |
| 複勝回收率 | 80%以上 | 85.3% |
| 3連複命中率 | 10%以上 | 12.8% |
| 3連單回收率 | 100%以上 | 134.3% |

尤其將**維持3連單回收率100%以上**視為最重要目標。

## 為什麼可以信賴龍神雷達的數字

### 1. 公開所有比賽的數據

在龍神雷達的「成績」頁面，可以確認所有依日期分類的命中率・回收率。

- 表現好的日子、表現差的日子都毫不隱瞞地公開
- 各會場的成績也一併公開
- 過去的預測與結果也能在「過去的預測」頁面確認

### 2. 預測事先公開

龍神雷達的預測，是在**比賽開始前**就公開的。

- 不可能事後聲稱「其實已經命中了」
- 公開時刻也有記錄
- 任何人都能即時確認預測

### 3. 結果自動統計

比賽結果出爐後，系統會自動進行命中判定與統計。

- 沒有人為操縱數字的空間
- 賠率也使用官方數據
- 防止計算失誤或蓄意竄改

### 4. 程式碼開放（預定）

未來預定將統計邏輯的程式碼在GitHub上公開。

「真的是用這種計算方式統計的嗎？」這樣的疑問，只要看程式碼就能得到答案。
