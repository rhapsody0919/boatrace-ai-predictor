## 為什麼AI預測獲勝？

### 理由1：不受感情左右

**人類預測A的失敗案例：**

**12/7 大村第8場：**
```
人類預測A：「因為喜歡峰竜太選手，本命2號艇」
→ 馬達2連率28%（需警戒等級）
→ 結果：第5名（未命中）

AI預測：「1號艇A1級×馬達2連率48%」
→ 結果：第1名（命中）
```

**分析：**
人類容易憑「喜歡的選手」「上次命中的選手」等感情判斷。

AI則完全依據數據判斷。

---

### 理由2：瞬間處理龐大數據

**人類能做到的分析：**
```
選手級別
馬達2連率
展示時間
→ 約5-10項
```

**AI能做到的分析：**
```
選手級別、勝率、2連率、3連率
當地勝率、全國勝率
馬達2連率、近期成績
艇體2連率
展示時間、轉彎、起步、伸展
風向、風速、水面、氣溫
過去相同條件比賽的數據
→ 45項以上
```

**差距顯而易見。**

---

### 理由3：學習各賽艇場的特性

**人類預測B的失敗案例：**

**12/10 江戶川第5場：**
```
人類預測B：「1號艇是A1級，所以1-2-3很穩」
→ 江戶川1號艇勝率47%（全國最低等級）
→ 結果：1號艇第4名（未命中）

AI預測：「江戶川容易爆冷，重視2-4號艇」
→ 結果：2-4-5命中
```

**分析：**
江戶川是受潮汐影響、水面容易爆冷、理論難以套用的賽艇場。

AI從過去數據學習到「江戶川不能過度信賴1號艇」。

---

### 理由4：多角度分析展示航行

**人類預測C的失敗案例：**

**12/12 戶田第3場：**
```
人類預測C：「展示時間第一名的4號艇為本命」
→ 展示時間雖佳，但馬達2連率僅32%
→ 結果：第6名（未命中）

AI預測：「比起展示時間，優先馬達性能」
→ 1號艇（馬達2連率46%）本命
→ 結果：第1名（命中）
```

**分析：**
展示時間僅供參考。

正式比賽中馬達性能最為重要，AI將此列為最優先。

## AI預測有弱點嗎？

### 弱點1：不擅長應對突發意外

**12/8 琵琶湖第11場：**
```
AI預測：本命1號艇（A1級×馬達2連率52%）
→ 起跑時搶跑失格
→ 未命中
```

**分析：**
搶跑或引擎熄火都是無法預測的。

不過，這一點人類也一樣。

---

### 弱點2：颱風等極端惡劣天候

**假設颱風直撲的情況：**
```
風速15m以上
浪高2m以上
→ 理論完全失效
```

在這種極端狀況下，AI的預測準確度也會下降。

**對策：**
BoatAI在惡劣天候時會顯示「警示」，不建議購買。

---

### 弱點3：並非完美

即使是AI預測，也不可能達成100%命中率。

**現實數字：**
- 複勝：約50%

**重要的是：**
