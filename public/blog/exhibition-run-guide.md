# ボートレースの展示は何分前？展示タイムは締切16.4分前に出る｜展示の見方

展示タイムが公式の直前情報に出るのは、締切予定の時刻の16.4分前が中央値でした（2026年10月19日〜25日の1,088レース）。最も遅いレースでも締切の8.43分前には出ていて、オリジナル展示の一周・まわり足は展示タイムより遅く、中央値で11.4分前に出ています。

今日の展示を見る入口は[開催場一覧](/)です。開催場からレースを開くと、「直前情報」で展示タイム・展示進入・一周・まわり足を6艇並べて見られます。

## 展示タイムは締切の16.4分前に出る（中央値）

展示タイムは展示航走の後に出る値なので、展示航走そのものはこの時刻より前に終わっています。直前情報の項目ごとに、出た時刻を締切予定の時刻から数えると次のとおりでした。

| 直前情報の項目 | 出た時刻（締切予定の時刻から） | 期間・件数 |
|---|---|---|
| 当日体重・調整重量 | 60分前には全レースで出ていた | 2026年10月12日〜25日の2,184レース |
| 展示タイム | 中央値16.4分前、最も遅いレースで8.43分前 | 2026年10月19日〜25日の1,088レース |
| 展示タイム（12Rだけ） | 中央値20.4分前 | 2026年10月12日〜25日の182レース |
| 一周・半周ラップ・まわり足・直線（オリジナル展示） | 中央値11.4分前（早いレースで25.2分前、遅いレースで2.3分前） | 2026年10月25日時点の直近30日 |

2026年10月12日〜25日の14日間では、締切15分前までに展示タイムが出ていたのはレースの77.7%で、9分前にはほぼ全レース（99.95%）で出そろっていました。12Rは早めに出ます。一周・まわり足まで見てから決めるなら、締切の11.4分前（中央値）まで待つことになります。

## 展示航走で出る値と、それぞれの中身

展示航走にはスタート展示と周回展示の2つがあります（[BOAT RACE公式：周回展示とは？](https://www.boatrace.jp/owpc/pc/extra/enjoy/guide/level2/l2_01_02_06.html)）。スタート展示では本番と同じようにスタートし、そこで入ったコースが直前情報の「展示進入」、スタートのタイミングが展示STです。展示進入は本番の進入と変わることがあります。

展示タイムは、周回展示の2周目に、バックストレッチのスタートライン延長線から第2ターンマークまでの150mを通過した時間です（福岡は計測地点が異なります。[BOAT RACE公式：周回展示／展示タイム](https://www.boatrace.jp/owpc/pc/extra/enjoy/guide/level2/l2_01_02_07.html)）。

龍神レーダーの直前情報では、展示タイムの下に、会場が計測するオリジナル展示の「一周」「半周ラップ」「まわり足」「直線」が並びます。どれも秒数が小さいほど速い値です。計測する区間は会場ごとに違うので、別の会場の秒数とは比べず、同じレースの6艇の中の順位で読みます。

## 展示タイム1位の艇の1着は、コースでどれだけ違うか

2026年9月22日〜10月11日の全国2,844レースで、本番の進入コースごとに、展示タイムが6艇中1位だった艇とそれ以外の艇の1着を数えました。

| 本番の進入コース | 展示タイム1位の艇の1着 | 1位でない艇の1着 |
|---|---|---|
| 1コース | 887艇中573回（64.6%） | 1,957艇中1,055回（53.9%） |
| 2コース | 543艇中94回（17.3%） | 2,301艇中281回（12.2%） |
| 3コース | 482艇中97回（20.1%） | 2,362艇中265回（11.2%） |
| 4コース | 449艇中78回（17.4%） | 2,395艇中202回（8.4%） |
| 5コース | 409艇中50回（12.2%） | 2,435艇中106回（4.4%） |
| 6コース | 496艇中11回（2.2%） | 2,348艇中32回（1.4%） |
| 2〜6コースの計 | 2,379艇中330回（13.9%） | 11,841艇中886回（7.5%） |

1〜5コースと2〜6コースの計では、展示タイム1位の艇の1着が1位でない艇より多く、7つの比べを合わせた統計の線（|z|が約2.69以上）を超えました。2〜6コースの計は13.9%と7.5%で、6.4ポイントの開きです。6コースは496艇中11回と2,348艇中32回で、差を確認できない大きさでした。

1コースの1位は割り引いて読みます。同じ選手でも1号艇のときは展示タイムが約0.017秒速く出る、という検証があります。1コースの艇は展示タイムが5・6位でも494艇中245回（49.6%）1着で、1・2位のときは1,490艇中942回（63.2%）でした。

## 一周・まわり足・直線、展示STのどれを見るか

同じ期間に、2〜6コースの艇を項目ごとに「6艇中1位」と「それ以外」に分けた1着です。項目ごとに6艇分の値がそろったレースだけを使っています。

| 項目（2〜6コースの艇） | 1位の艇の1着 | 1位でない艇の1着 |
|---|---|---|
| 一周・半周ラップ | 1,321艇中213回（16.1%） | 11,459艇中875回（7.6%） |
| 展示タイム | 2,379艇中330回（13.9%） | 11,841艇中886回（7.5%） |
| まわり足 | 1,660艇中214回（12.9%） | 11,185艇中880回（7.9%） |
| 直線 | 1,924艇中190回（9.9%） | 9,086艇中773回（8.5%） |

一周・展示タイム・まわり足は、1位の艇の1着が1位でない艇より多く、4つの比べを合わせた統計の線（|z|が約2.50以上）を超えました。直線は1,924艇中190回と9,086艇中773回で、線に届きません。

上級者向けに1つ深い点を足すと、一周とまわり足は、進入コース・展示タイム・選手の勝率・モーター2連率をそろえても1着との関係が残りました。直線は展示タイムをそろえると関係がほぼ0になります。直線の速さは展示タイムと重なる情報で、展示タイムを見た後に足しても材料は増えません。展示STは本番STとの相関が艇ごとに0.08と弱く、着順の材料としての上積みも出ていません。

## 今日のレースで展示を読む手順

1. 締切の16.4分前（中央値）を目安に、[開催場一覧](/)からレースを開き、「直前情報」の展示タイムを6艇で比べます。まだ出ていなくても、締切9分前にはほぼ全レースで出そろいます。
2. 展示タイム1位の艇が本番で何コースに入りそうかを、「展示進入」の行で見ます。2〜5コースの1位なら上の表の行が使えます。1コースの1位は、1号艇が速く出やすい分を割り引きます。
3. 締切の11.4分前（中央値）には一周・まわり足が出ます。展示タイムと一周・まわり足の1位が同じ艇か別の艇かを見て、別なら両方の艇を材料に残します。直線と展示STは補助にとどめます。
4. 会場・枠番ごとの展示タイム最速の1着は[展示タイム最速艇の1着転換率](/winning-technique?tab=extime)で見られます。スタート展示の読み方は[スタート展示の見方](/blog/start-exhibition-guide)、進入が崩れる形は[枠なりとは](/blog/course-prediction-tips)にあります。

## 数字の範囲と注意

出た時刻は、公式の直前情報を2分おきに見に行って取れた時刻で、実際の公開はそれより少し早いことがあります。展示航走そのものが始まる時刻は、この記録からは言えません。1着の集計は2026年9月22日〜10月11日の20日間で、結果があり、返還・フライング・出遅れがなく、6艇とも着順と進入コースが分かる2,844レースです。1位は同じ秒数で並んだ艇を全部1位に数えています。[展示タイム最速艇の1着転換率](/winning-technique?tab=extime)の画面は過去90日・枠番で数え、最速が並んだレースを除いているので、この記事の数字とは一致しません。秋の20日間の集計で、会場ごとの違いや別の季節の値は示していません。過去の割合は今日の着順を約束する数字ではありません。
