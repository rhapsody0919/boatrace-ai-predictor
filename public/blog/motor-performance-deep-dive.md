# モーター2連率の落とし穴4つ｜節の途中は変わらない・選手の実力が混ざる・部品交換の見方

出走表のモーター2連率は節の初日に決まり、節の途中のレースの着順では変わりません。2026年9月27日の若松12Rでは、6基のモーター2連率は39.01%から34.18%までで、一番高いモーターと低いモーターの差は4.83ポイントでした。

今日のレースの6基は[モーター調子](/winning-technique?tab=motor)で並べて見られます。行を押すと、そのモーターの使用履歴と部品交換・プロペラ交換の履歴が出ます。

## 落とし穴1: 出走表のモーター2連率は節の初日に決まり、節の途中は変わらない

モーター2連率は、そのモーターが2着以内に入った回数を出走回数で割った割合です。出走表に載る公式の値は節の開始時点で決まり、今節のレースで1着を取っても、同じ節の間は同じ値のままです。

| 場面 | 出走表のモーター2連率 | 龍神レーダーの画面 |
|---|---|---|
| 節の途中 | 節の初日の値のまま | 「公式2連率（節時点）」に同じ値。今節の走りは使用履歴に出る |
| 新しいモーターの最初の節 | 全艇0% | この場での走りから出した2連率に「※」を付けて出す |
| まだ1回も走っていないモーター | 0% | 「まだ走っていません」 |
| 最初の節が終わった後 | 次の節の初日から公式の累計が入る | 推移のグラフは累計が付いた日から始まる |

新しいモーターの0%は、2着以内に1回も入っていないという意味ではなく、公式の累計がまだ付いていないだけです。モーターは会場ごとにおおむね年1回入れ替わり、番号は新しいモーターに引き継がれます。同じ番号でも、入れ替え前の成績は別のモーターの成績です。

## 落とし穴2: 6基の差は数ポイントで、2連率の順位と展示タイムの順位は並ばない

2026年9月27日の若松12Rの6艇です。モーター2連率は出走表の値、展示タイムは直前情報の値で、順位は6艇の中の順です。

| 艇番 | モーター2連率 | モーターの順位 | 展示タイム | 展示タイムの順位 |
|---|---:|---:|---:|---:|
| 1号艇 | 34.18% | 6位 | 6.79秒 | 1位 |
| 2号艇 | 37.24% | 2位 | 6.85秒 | 4位 |
| 3号艇 | 39.01% | 1位 | 6.81秒 | 2位 |
| 4号艇 | 35.75% | 4位 | 6.96秒 | 6位 |
| 5号艇 | 35.87% | 3位 | 6.86秒 | 5位 |
| 6号艇 | 35.63% | 5位 | 6.82秒 | 3位 |

モーター2連率が6位の1号艇は、展示タイムが6艇で最も速い6.79秒でした。3位の35.87%と5位の35.63%の差は0.24ポイントで、モーターの順位が2つ違っても値はほとんど離れていません。結果は4-1-5で、1着は展示タイム6位の4号艇の差しでした。1レースの着順は、どちらの順位が効くかの答えになりません。答えは次の見出しの集計で見ます。

## 落とし穴3: モーター2連率の順位より、展示タイムの順位で1着率が大きく開く

龍神レーダーの集計では、全国の枠なりのレース313,938レース（2019年4月1日〜2026年9月26日）で、4カドなど攻める艇の1着率を、その艇のモーター2連率が6艇中1〜2位のときと5〜6位のときで比べると、差は4〜8ポイントでした。同じ比べを展示タイムの順位でしたときは10〜18ポイントでした。攻める艇がいるスタートの形5つ（カド一撃・カド受け凹み・イン凹み・2コース凹み・ダッシュ勢先行）のすべてで、攻める艇の1着率の開きは展示タイムの順位のほうが大きく出ています。

上級者向けにもう1つ深い点です。同じレースの6艇の中で、モーター2連率はその日の足の値とほとんど連動していません（2026年9月22日〜10月11日の全国2,844レース）。

| 同じレースの6艇の中での組み合わせ | 相関（1に近いほど連動） |
|---|---:|
| モーター2連率と展示タイム | 0.115 |
| モーター2連率とオリジナル展示の一周 | 0.051 |
| モーター2連率とオリジナル展示の直線 | 0.053 |
| モーター2連率とまわり足 | 0.007 |
| 選手の勝率と一周 | 0.297 |
| 選手の勝率とまわり足 | 0.266 |

モーター2連率は節の初日までの過去の値で、展示タイムと一周は今日の足の値です。2連率の高い艇が今日も速いとは決まっていないので、展示の後は展示タイムの順位を先に見ます。展示の見方は[展示は何分前？展示タイムの見方](/blog/exhibition-run-guide)にあります。

## 落とし穴4: 2連率には乗った選手の実力が混ざる

モーター2連率は、これまでそのモーターに乗った選手たちの着順から出た値です。上手な選手が続けて乗ったモーターは2連率が上がりやすく、今日乗る選手の成績でもありません。

この分を差し引いた値が、[モーター調子](/winning-technique?tab=motor)の機力指数です。「このモーターで2着以内だったか」から「その時乗っていた選手の全国2連率」を引いた差を、全レースで平均した値で、プラスが大きいほど、乗った選手の実力を超えて走ってきたモーターです。6走未満の機力指数はオレンジ色で、参考値として出ます。モーター2連率・全国2連率・ボート2連率の違いは[モーター2連率とは](/blog/motor-condition-guide)にまとめています。

## 部品交換は、悪い兆しにも良い兆しにもなる

部品交換・プロペラ交換は、それだけでは機力が落ちたサインにも、整備した直後の好転のサインにもなります。交換した部品の数だけで良し悪しは決まりません。龍神レーダーは、交換の前と後の展示タイムの平均を比べた目安を履歴に添えています。

| 履歴の目安 | 出る条件 |
|---|---|
| 交換後に展示タイム改善 | 交換した日より後の3日分の平均が、前の3日分の平均より0.02秒以上速い |
| 交換後に展示タイム悪化 | 交換した日より後の3日分の平均が、前の3日分の平均より0.02秒以上遅い |
| 交換前後で大きな変化なし | 前後の差が0.02秒未満 |

日はそのモーターが走った日で、交換した日は前にも後にも入りません。0.02秒未満の差は、展示タイムの日ごとのぶれの範囲として扱っています。前と後のどちらかに展示タイムが無いときは、目安は付きません。

## 今日のレースでモーターを見る手順

1. [モーター調子](/winning-technique?tab=motor)で今日のレースを選び、6基の公式2連率（節時点）を並べます。値が0%なら、新しいモーターの最初の節かを「※」の印で見ます。
2. 6基の値の差が数ポイントなら、モーターの順位だけで艇の上下を決めず、機力指数で乗った選手の実力を差し引いた値を見ます。
3. 行を押して使用履歴と部品交換・プロペラ交換の履歴を開き、今節の走りと交換の前後の展示タイムを見ます。
4. 展示タイムが出たら、モーター2連率の順位より展示タイムの順位を先に見ます。
5. 会場の全モーターの並びは[モーターランキング](/winning-technique?tab=motorranking)で見られます。

## 数字の範囲と注意

若松12Rの表は出走表と直前情報の値で、順位は6艇の中の順です。この日は下の集計の期間の外です。順位と1着率の集計は、全艇が艇番どおりのコースに入った枠なりのレースだけで、モーター2連率は出走表の時点の値です。相関は2026年9月22日〜10月11日の2,844レースの値で、展示タイムと一周などは速いほど大きい向きにそろえています。部品交換の目安は展示タイムの前後の比べで、着順の比べではありません。部品交換・プロペラ交換が着順にどれだけ効くかは、まだ分析していません。過去の割合は今日の着順を約束する数字ではありません。
