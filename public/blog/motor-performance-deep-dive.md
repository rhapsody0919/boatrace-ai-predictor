# モーター2連率だけで決めない理由｜平均33.98%・展示タイムとの差・部品交換の見方

出走表のモーター2連率は節の初日に決まる累計の値で、モーター2連率が0%でない297,188件の平均は33.98%でした。ただし攻める艇の1着率は、モーター2連率の順位より展示タイムの順位で大きく開きます。全国の枠なりのレースで、カド受け凹みから攻める4号艇の1着率は、展示タイムが6艇中1〜2位で28,627レース中8,157回（28.5%）、5〜6位で26,087レース中3,708回（14.2%）でした。

今日のレースの6基は[モーター調子](/winning-technique?tab=motor)で並べて見られます。行を押すと、そのモーターの使用履歴と部品交換・プロペラ交換の履歴が出ます。

## モーター2連率は節の初日の累計で、平均は33.98%

モーター2連率は、そのモーターが2着以内に入った回数を出走回数で割った割合です。2連率・3連率の違いや龍神レーダーでの見方は[モーター2連率の解説記事](/blog/motor-condition-guide)にまとめています。ここでは、値が変わる時点と平均だけを押さえます。

| 場面 | 出走表のモーター2連率 | 龍神レーダーの画面 |
|---|---|---|
| 節の途中 | 節の初日の値のまま。今節のレースで1着を取っても変わらない | 「公式2連率（節時点）」に同じ値。今節の走りは使用履歴に出る |
| 新しいモーターの最初の節 | 全艇0%。値が入るのは2節目の初日から | この場での走りから出した2連率に「※」を付けて出す |
| まだ1回も走っていないモーター | 0% | 「まだ走っていません」 |
| 年1回のモーター入れ替え | 累計は新しいモーターで始まり直す | 推移のグラフは公式の累計が付いた日から始まる |

新しいモーターの0%は、2着以内に1回も入っていないという意味ではなく、公式の累計がまだ付いていないだけです。モーターは会場ごとにおおむね年1回入れ替わり、番号は新しいモーターに引き継がれます。同じ番号でも、入れ替え前の成績は別のモーターの成績です。入れ替え直後は出走回数が少なく、出走10回のモーターなら、2着以内が3回で30%、4回で40%で、1回の違いで10ポイント変わります。

6艇で走るボートレースでは、1レースで2着以内に入るのは6艇中2艇です。そのため全モーターをならした2連率は、理屈の上では**約33.3%**になります。

龍神レーダーに保存している公式の出走表（2025年12月2日〜2026年10月31日、モーター2連率が0%でない297,188件）では、平均33.98%、中央値33.8%で、理屈の値に近い結果でした。2連率の帯ごとの割合は次のとおりです。

| 2連率 | この帯に入る件数の割合 | 位置づけ |
|-------|----------------------|---------|
| **40%以上** | 21.6% | 上位およそ2割 |
| **35%以上40%未満** | 22.0% | 平均より上 |
| **30%以上35%未満** | 26.3% | 平均前後。他の要素で判断 |
| **25%以上30%未満** | 17.2% | 平均より下 |
| **25%未満** | 13.0% | 下位およそ1割強。割引いて評価 |

※ 件数は出走表の1行（1艇×1レース）を1件としています。同じモーターが何レースも出れば、その分が件数に入ります。

40%以上は出走の上位およそ2割に入る値です。ただ、この値は節の初日までの過去の累計で、今日の足ではありません。2連率だけで艇の上下を決めない理由は、次の3つです。

## 理由1: 6基の差は数ポイントで、2連率の順位と展示タイムの順位は並ばない

2026年9月27日の若松12Rの6艇です。モーター2連率は出走表の値、展示タイムは直前情報の値で、順位は6艇の中の順です。

| 艇番 | モーター2連率 | モーターの順位 | 展示タイム | 展示タイムの順位 |
|---|---:|---:|---:|---:|
| 1号艇 | 34.18% | 6位 | 6.79秒 | 1位 |
| 2号艇 | 37.24% | 2位 | 6.85秒 | 4位 |
| 3号艇 | 39.01% | 1位 | 6.81秒 | 2位 |
| 4号艇 | 35.75% | 4位 | 6.96秒 | 6位 |
| 5号艇 | 35.87% | 3位 | 6.86秒 | 5位 |
| 6号艇 | 35.63% | 5位 | 6.82秒 | 3位 |

一番高い3号艇の39.01%と一番低い1号艇の34.18%の差は4.83ポイントで、6基とも上の帯の表の「35%以上40%未満」か「30%以上35%未満」に入ります。3位の35.87%と5位の35.63%の差は0.24ポイントで、モーターの順位が2つ違っても値はほとんど離れていません。モーター2連率が6位の1号艇は、展示タイムが6艇で最も速い6.79秒でした。結果は4-1-5で、1着は展示タイム6位の4号艇の差しです。1レースの着順は、どちらの順位が効くかの答えになりません。答えは次の見出しの集計で見ます。

## 理由2: 攻める艇の1着率は、展示タイムの順位のほうが大きく開く

龍神レーダーの集計で、全国の枠なりのレース（2019年4月1日〜2026年9月26日、313,938レース）のうち、4号艇がカドから攻めるカド受け凹みの形（83,143レース）を、4号艇のモーター2連率の順位と展示タイムの順位で分けた4号艇の1着です。

| 4号艇の6艇の中の順位 | モーター2連率の順位で分けたとき | 展示タイムの順位で分けたとき |
|---|---:|---:|
| 1〜2位 | 30,080レース中7,067回（23.5%） | 28,627レース中8,157回（28.5%） |
| 3〜4位 | 27,206レース中5,449回（20.0%） | 28,429レース中5,412回（19.0%） |
| 5〜6位 | 25,764レース中4,738回（18.4%） | 26,087レース中3,708回（14.2%） |

モーター2連率の1〜2位と5〜6位の1着率は23.5%と18.4%で、差は5.1ポイントでした。展示タイムの1〜2位と5〜6位は28.5%と14.2%で、差は14.3ポイントでした。どちらも上位と下位の差ははっきり出ていますが、開きは展示タイムの順位のほうが大きく出ています。攻める艇がいるスタートの形5つ（カド一撃・カド受け凹み・イン凹み・2コース凹み・ダッシュ勢先行）のすべてで、攻める艇の1着率の開きは展示タイムの順位のほうが大きく出ました。

上級者向けにもう1つ深い点です。同じレースの6艇の中で、モーター2連率はその日の足の値とほとんど連動していません（2026年9月22日〜10月11日の全国2,844レース）。

| 同じレースの6艇の中での組み合わせ | 相関（1に近いほど連動） |
|---|---:|
| モーター2連率と展示タイム | 0.115 |
| モーター2連率とオリジナル展示の一周 | 0.051 |
| モーター2連率とオリジナル展示の直線 | 0.053 |
| モーター2連率とまわり足 | 0.007 |
| 選手の勝率と一周 | 0.297 |
| 選手の勝率とまわり足 | 0.266 |

モーター2連率は節の初日までの過去の値で、展示タイムと一周は今日の足の値です。2連率の高い艇が今日も速いとは決まっていないので、展示の後は展示タイムの順位を先に見ます。展示の見方は[展示航走の見方](/blog/exhibition-run-guide)にあります。

## 理由3: 2連率には乗った選手の実力が混ざる

モーター2連率は、これまでそのモーターに乗った選手たちの着順から出た値です。上手な選手が続けて乗ったモーターは2連率が上がりやすく、今日乗る選手の成績でもありません。

この分を差し引いた値が、[モーター調子](/winning-technique?tab=motor)の機力指数です。「このモーターに乗った過去のレースで2着以内だったか」から「その時乗っていた選手自身の全国2連率」を引いた差を、全レース分平均した値で、プラスが大きいほど、乗った選手の実力を超えて走ってきたモーターです。6走未満の機力指数はオレンジ色で、参考値として出ます。

## 部品交換・プロペラ交換は、悪い兆しにも良い兆しにもなる

部品交換・プロペラ交換は、それだけでは機力が落ちたサインにも、整備した直後の好転のサインにもなります。交換した部品の数だけで良し悪しは決まりません。龍神レーダーは、交換の前と後の展示タイムの平均を比べた目安を履歴に添えています。

| 履歴の目安 | 出る条件 |
|---|---|
| 交換後に展示タイム改善 | 交換した日より後の3日分の平均が、前の3日分の平均より0.02秒以上速い |
| 交換後に展示タイム悪化 | 交換した日より後の3日分の平均が、前の3日分の平均より0.02秒以上遅い |
| 交換前後で大きな変化なし | 前後の差が0.02秒未満 |

日はそのモーターが走った日で、交換した日は前にも後にも入りません。0.02秒未満の差は、展示タイムの日ごとのぶれの範囲として扱っています。前と後のどちらかに展示タイムが無いときは、目安は付きません。2連率が平均より下の帯のモーターでも、交換後に展示タイムが改善していれば、理由2の展示タイムの順位とあわせて見ます。

## 今日のレースでモーターを見る手順

1. [モーター調子](/winning-technique?tab=motor)で今日のレースを選び、6基の公式2連率（節時点）を並べます。値が0%なら、新しいモーターの最初の節かを「※」の印で見ます。
2. 6基の値を上の帯の表に当てます。差が数ポイントで同じ帯に収まるなら、モーターの順位だけで艇の上下を決めず、機力指数で乗った選手の実力を差し引いた値を見ます。
3. 行を押して使用履歴と部品交換・プロペラ交換の履歴を開き、今節の走りと交換の前後の展示タイムを見ます。
4. 展示タイムが出たら、モーター2連率の順位より展示タイムの順位を先に見ます。
5. 会場の全モーターの並びは[モーターランキング](/winning-technique?tab=motorranking)で見られます。

## 数字の範囲と注意

平均と帯の割合は、龍神レーダーに保存している公式の出走表（2025年12月2日〜2026年10月31日）で、モーター2連率が0%の行を除いた値です。若松12Rの表は出走表と直前情報の値で、この日は順位と1着率の集計の期間の外です。順位と1着率の集計は、全艇が艇番どおりのコースに入った枠なりのレースだけで、モーター2連率は出走表の時点の値です。相関は2026年9月22日〜10月11日の2,844レースの値で、展示タイムと一周などは速いほど大きい向きにそろえています。部品交換の目安は展示タイムの前後の比べで、着順の比べではありません。部品交換・プロペラ交換が着順にどれだけ効くかは、まだ分析していません。過去の割合は今日の着順を約束する数字ではありません。舟券の購入は20歳からです。[責任あるギャンブル](/responsible-gambling)のページもあわせてご覧ください。
