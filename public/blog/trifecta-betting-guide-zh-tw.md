## 什麼是3連單？——理解派彩機制

### 基本規則

**3連單（3連勝單式）**是**依照名次順序**命中第一名・第二名・第三名的投注組合。

| 投注組合種類 | 組合數 | 平均派彩 |
|---------|------------|---------|
| 3連複 | 20種 | 約2,000日圓 |
| 3連單 | **120種** | **約7,000日圓** |
| 2連單 | 30種 | 約2,000日圓 |

與3連複相比，組合數多達6倍，**派彩也容易變高**是最大的優點。

### 為什麼3連單有利？

- 命中時報酬大，**即使命中次數少也能達成正收支**
- 由於連名次都要預測，**自己的分析能力能直接反映**在結果上
- 由於人氣容易集中偏頗，**存在期望值高的冷門投注組合**的比賽

## 縮減投注組合——主軸選擇佔9成

### 步驟1：決定第一名的主軸

3連單中最重要的是**第一名的主軸選擇**。只要固定第一名，投注組合就能從120種減少到20種。

**第一名主軸的選擇方法：**
- A1級選手在內道的比賽
- 馬達2連率40%以上的選手
- 展示航行中領先的艇
- BoatAI預測中第一名信心度高的選手

### 步驟2：將第二名候選縮減至3〜4艘

決定第一名主軸後，縮減第二名候選。從剩下5艘艇中縮減至**3〜4艘**是理想的做法。

### 步驟3：決定第三名候選

包含未選為第二名候選的艇在內，選擇第三名候選。

## 排列式投注 vs 全組合投注——哪個有利？

### 排列式投注 ✅

**分別指定第一名・第二名・第三名的投注方式。最大優點是能縮減點數。**

```
【範例】第一名：1號艇／第二名：2,3,4／第三名：2,3,4,5
→ 1-2-3, 1-2-4, 1-2-5, 1-3-2, 1-3-4, 1-3-5,
  1-4-2, 1-4-3, 1-4-5 = 9點
```

### 全組合投注 ⚠️

**投注所選艇的所有排列方式。點數容易變多。**

```
【範例】1,2,3,4號艇的4艇全組合
→ 4×3×2 = 24點
```

| 投注方式 | 優點 | 缺點 |
|-------|---------|----------|
| 排列式 | 能縮減點數 | 需要走勢預測 |
| 全組合 | 思考量少 | 點數多，容易變成投注虧損 |

**結論：以排列式為基本方式。** 全組合容易導致點數過多，吃掉派彩。

## 依點數分類的回收率——投注幾點最好？

投注組合的點數直接影響回收率。

| 點數 | 命中率參考值 | 所需賠率 | 回收率傾向 |
|-----|----------|----------|------------|
| 6點 | 15〜20% | 30倍以上 | ⭐ 可鎖定高回收率 |
| 12點 | 25〜35% | 35倍以上 | ✅ 平衡型 |
| 24點 | 40〜50% | 50倍以上 | ⚠️ 需注意投注虧損 |
| 36點以上 | 超過50% | 70倍以上 | ❌ 幾乎都是投注虧損 |

**建議6〜12點。** 超過這個範圍，即使命中也難以獲利。

## 1號艇主軸 vs 外道主軸——策略運用

### 1號艇主軸（鎖定內道逃走）

賽艇1號艇的勝率全國平均約55%。**最穩定的主軸**。

```
【穩健模式】
1-2-3：出現率最高
1-2-4：涉及4號艇切入的模式
1-3-2：3號艇領先的模式
```

**適合的比賽：**
- 內道勝率高的會場（大村・蘆屋・德山）
- 1號艇為A1級選手＋優良馬達
- 風勢弱、水面平穩

### 外道主軸（鎖定外攻・切入）

以外道為主軸可鎖定**高派彩**。

```
【外道主軸模式】
4-5-6：外道外攻走勢
3-4-1：外攻＋內道苦守
4-1-5：切入走勢
```

**適合的比賽：**
- 1號艇起跑較慢（展示時機0.20以上）
- 外道有A1級選手＋馬達狀況良好
- 容易外攻成功的會場（戶田・平和島・江戶川）

## 資金分配的思考方式

### 均等投注會吃虧

所有投注組合都投注相同金額，是**效率最差**的方法。

### 建議：階梯式分配

**本命目投注較多，保守目投注較少。**

```
【12點投注的資金分配範例（合計2,000日圓）】
本命（4點）：各300日圓 = 1,200日圓
對抗（4點）：各100日圓 = 400日圓
保守（4點）：各100日圓 = 400日圓
```

### 分配鐵則

1. **單場比賽上限為資金的5〜10%**
2. **確認本命目命中後是否仍能獲利的賠率**
3. **刪除容易變成投注虧損的投注組合**
