# ボートレース日和の使い方・見方｜アプリ・有料の有無と龍神レーダーとの違い

ボートレース日和は、日和自身の「はじめての方」のページに「ずっと無料」と書かれたデータのサイトで、App Store・Google Play の専用アプリの案内はなく、ブラウザで開いて使います。会員登録とログインもありますが、MyData やメモなど自分用の機能に使う物です。この記事は、日和の使い方・見方・登録の要点を日和の公開ページから整理し、その後に、同じく無料で使える龍神レーダーで見られる物を、6艇の差を棒・折れ線・多角形の図で見せる画面とあわせて並べます。

日和の内容は、下の「出典」に挙げた日和のページを2026年11月26日に読んで書いています。日和はよく機能を足しているため、今の画面と違う所があれば日和のページが正です。

## ボートレース日和とは

ボートレースのデータを集めて出走表の形で見せるサイトです。2021年6月6日に、それまでの名前から「ボートレース日和」に変えました（トップページのお知らせ）。運営は株式会社GAIN（山口県周南市）です。

| 問い | 日和の公開ページに書かれていること（2026-11-26） |
|---|---|
| 料金 | 「はじめての方」に「ずっと無料」。有料プランの案内はトップ・はじめての方・よくある質問・出走表の見方のページに無い |
| アプリ | ストアの専用アプリの案内は無い。利用規約の動作環境は Google Chrome と Safari の最新版 |
| 会員登録 | マイページ・ログインがある。MyData（自分用の出走表）やメモはマイページの機能 |
| 通知 | まくり・チルト跳ね・前付けのアラートを Discord の通知サーバーで受け取れる（2026年4月28日の更新） |
| 予想 | 「予想カードメーカー」（2026年10月13日）で、自分の予想印と買い目をカードにして保存・共有できる |

「アプリ」で探している人は、スマホのブラウザで kyoteibiyori.com を開いて使います。

## 日和の使い方：出走表を開くまで

日和の「逃がし2着率」と「出走表とデータの見方」のページ（2020年の版）による流れは次のとおりです。

1. トップから見たい場を選ぶ
2. 出走一覧からレースを選ぶと、出走表が開く
3. 出走表の上の「データ変更タブ」を左右に動かして、見たいデータに切り替える
4. 選手名を押すと、その選手の過去の成績が開く

画面の下にはレース一覧・前のレース・次のレースへ動くメニューがあり、「その他」から得点率一覧やモータ一覧などの場ごとのデータへ移れます。トップには、1号艇の逃げ率と2号艇の逃し率の条件で探す「ガチガチレース検索」、1号艇の逃げ率と2〜6号艇の差し・まくり率で探す「穴レース検索」、展示タイムの差で探す「まくりアラート」もあります。

## 日和の見方：出走表のタブ

今のレース一覧（2026年11月26日の住之江）では、各レースに「出走表・枠別勝率・今節成績・モータ比較・直前情報・結果・オッズ・出目ランク・MyData」の入口が、ログインしていない状態で並びます。タブの中身は「出走表とデータの見方」（2020年9月30日の版）に次のように書かれています。名前は今と少し違う所があります。

| タブ | 中身 |
|---|---|
| 基本情報 | すべてのコースを合わせた総合の成績 |
| 枠別情報 | 進入したコース別の成績（艇番別ではない）。進入が変わるときは「コース変更」で切り替える。下に逃げシミュレーション |
| モータ情報 | モーターの通算と直近1か月の成績、過去に使った選手 |
| 今節成績 | 今節の連対率や平均 ST |
| 直前情報 | 展示の後に更新。進入・スタート・展示タイム・コメント・場別のオリジナル展示タイム |
| オッズ検索 | 人気順やフォーメーションでオッズを探す。合成オッズの計算。予想カードメーカーもここから開く |
| オッズ一覧 | オッズの一覧 |
| 出目ランク | 直近1年のその場・そのレースの出目 |
| MyData | 自分で選んだデータだけを並べた出走表 |
| 結果（後の更新で追加） | 確定後の結果。1マークの展開の切り抜き動画（2024年4月）、スロー・ダッシュと起こしの「深」の表示（2026年6月） |

日和で名前の付いたデータのうち、よく探される物の意味は次のとおりです。

- **逃がし2着率**: 1コースが逃げたときに2着になった割合を、選手ごとに集計した物。直近1年が対象で、総合・一般戦・SG/G1・女子戦で切り替えられる。枠別情報の下の「逃げシミュレーション」にある
- **超展開データ**: 各選手が1マークでどう攻めてどれだけ勝ち、どう攻められてどれだけ負けたかのデータ（日和のオリジナル）
- **MyData**: マイページで項目を足し、「登録」ボタンを押して初めて保存される。よくある質問では、押し忘れると消えたように見えるとしている

### 日和の登録・ログインと設定

お気に入り選手の「★」と前付けしそうな選手の「前」の簡易表示は、「ユーザー情報」の「ユーザー設定」で固定できます（2022年6月の更新）。アラートは2021年12月の更新でメールでも受け取れるようになりました。X での自動の通知は、2026年4月から Discord の通知サーバーで受け取る形に替わっています。よくある質問（2021年6月の版）には、パスワードの再発行と退会は問い合わせで受けると書かれています。

## 日和に予想の機能はある？

日和自身が全レースの予想を出す機能の案内は、はじめての方と更新履歴（2020年2月〜2026年10月の分）に見当たりませんでした。オッズ検索の「期待値分析」（2022年8月）は、過去6か月の人気別の的中率などから買い目ごとの期待値を出す分析です。予想は、データを見た人が自分で組み立て、予想カードメーカーや「展開予想ボード」（艇を動かして1マークを考える道具、2026年8月）で形にする作りです。どのサイトのデータでも、結果を保証する読み方はありません。

## 龍神レーダーで無料で見られる物

龍神レーダーも無料のサイトで、会員登録・ログインの仕組みがありません。出走表・AI予想・分析のページは登録なしでそのまま開けます（2026年11月26日に本番の画面とコードで確かめた内容）。レース詳細の「出走表とタブ」には、発走前は8つ、レースが確定すると「結果」が加わって9つのタブが並びます。

| タブ | 中身 |
|---|---|
| 基本情報 | 勝率・2連対率・3連対率・平均 ST を、全国/当地・グレード・期間で切り替え。走数も出す |
| 龍神ソナー | 類似レース（条件が近い過去のレース）の結果と、進入・スタートの形ごとの過去の割合 |
| AI予想 | 1マークの展開予測と、イン崩れ注意度 |
| 今節 | 6選手の今節の得点率・節内順位・準優の目安までの必要得点 |
| 直前情報 | 展示タイム・気象・ピットレポート |
| 枠別情報 | 想定コースの成績、ST 考察、「1コースが逃げたとき」のカード（その場で1コースが逃げたときの2着のコースの割合と2連単。使い方ガイドでは逃げシミュレーションと呼ぶ）、「逃がし率（2号艇の選手）」のカード |
| モータ情報 | その場のモーターの成績・調子 |
| オッズ一覧 | 発売中のオッズ |
| 結果 | 確定後の着順と配当（確定するまで出ない） |

枠別情報・モータ情報のタブは、日和と同じ名前です。日和の逃げシミュレーションに近い物は、龍神レーダーでは枠別情報の「1コースが逃げたとき」のカードで、その場の1コースが逃げたレースを2着のコース別に集めた物です。日和の逃がし2着率のような選手ごとの数字ではありません。選手ごとの数字では、同じタブの「逃がし率（2号艇の選手）」が、今日の2号艇の選手が2コースで走ったときに1コースの艇に逃げで1着を取られた割合を出します。2着に残った割合ではないので、日和の逃がし2着率とは別の物です。龍神レーダーの逃げシミュレーションの読み方は[逃げシミュレーションの使い方](/blog/nige-simulation-guide)にまとめています。

## 龍神レーダーの強み：6艇の差を図で読む

龍神レーダーは、出走表の数字の多くを棒・折れ線・多角形の図にして、6艇の差や今節の流れを目で比べられるようにしています。数字を1つずつ読み比べる前に、6艇の並びを形でつかめます。下の画像は、2026年11月27日の常滑12R（チャレンジカップ）を本番の画面で開いた物です。

### 枠別情報：全国の平均との差を棒で見る

![常滑12Rの枠別情報。6艇の想定コースでの1着率を、全国の同じコースの平均からの差の棒で並べている](/images/blog/hiyori-how-to-use-guide-waku.jpg)

6艇それぞれが、枠なりで進入したときに入るコースで、直近3期（2025年5月〜2026年10月）にどれだけ1着になってきたかを、全国の同じコースの1着率（中央の線）からの差の棒で並べます。1号艇の1コースの69.1%（進入68走）と4号艇の4コースの28.6%（進入49走）のように、コースで大きさが違う数字も、平均との差にすると並べて見られます。この例では、4号艇が4コースの平均10.6%に対して+18.0ptと、1号艇の+14.1ptより大きな差でした。棒は「そのコースの平均よりどれだけ上か」で、どの艇が1着になりやすかったかではありません。それは上の過去の1着率の数字（1号艇69.1%と4号艇28.6%）で見ます。基準は全選手の平均なので、この例のようにA1がそろうレースでは多くの艇がプラスになり、6艇どうしはコースの平均との差を棒の長さで比べます。▲緑・▼赤の印は、走数から見て偶然のぶれだけでは説明しにくい差のときだけ付き、偶然のぶれと区別できない差の棒は灰色になります（この例の3号艇の+2.0pt）。進入の走数がコースごとの線より少ない艇は、棒を点線の枠にして差を出しません（この例の6号艇の「—」。6コースは67走未満が線）。前付けで進入が変わるレースでは、想定のコースとずれます。

### 龍神ソナー：6艇の中の順位を多角形で見る

![常滑12Rの龍神ソナー。全国勝率・当地勝率・平均ST・モーター2連率などの項目ごとに、6艇の中の順位を多角形で重ねた図](/images/blog/hiyori-how-to-use-guide-sonar-radar.jpg)

全国勝率・当地勝率・直近30走の1着率・モーター2連率・平均ST・今節の着順点などの項目ごとに、6艇の中の順位を多角形の図に重ねます。外側ほど6艇の中で上位で、頂点に白い丸が付いた白い太線が1号艇です（外側を囲む灰色がかった太い線は、白い縁取りの付いた2号艇の線）。頂点の外の丸の数字は、その項目で1位の艇です。点線は、同じ条件で1号艇が1着になったレースでの1号艇の平均の順位で、1号艇の線が点線より内側にある項目ほど、勝ったときの形より弱い項目と読めます。この例の1号艇は、全国勝率で点線とほぼ重なり、ほかの5項目で点線より内側、とくに当地勝率・直近30走の1着率・モーター2連率で大きく内側でした。ただし、内側の項目が過去に1着率を分けてきたかは別です。この日の画面では、内側の5項目はどれも、1号艇がその項目で一番高いときと一番低いときの1着率の差が6〜12ポイントで「ぶれ幅が重なる」と出ていて（当地勝率9・モーター2連率7・直近30走の1着率6・今節の着順点12・平均ST10ポイント）、はっきりした差は確認できませんでした（数字は撮影した11月27日の時点の物）。「差が大きい」と出たのは全国勝率だけでした。項目ごとの差は、次の棒で確かめます。どれも過去のレースの形との比べで、このレースの結果を示す物ではありません。詳しい使い方は[龍神ソナーと思考アシストの紹介](/blog/sonar-assist-intro)にあります。

![全国勝率の項目を開いた所。1号艇が6艇中1位〜6位だったときの過去の1着率を棒で並べ、今日の3位を枠で囲んでいる](/images/blog/hiyori-how-to-use-guide-sonar-bars.jpg)

項目名（▼の付いた所）を押すと、1号艇がその項目で6艇中1位〜6位だったときの過去の1号艇の1着率を棒で並べ、今日の順位を枠で囲みます。この例の全国勝率では、1位のとき288件中218件で76%、6位のとき162件中82件で51%、今日の3位は224件中149件で67%でした。点線は同じ条件（常滑・6艇ともA1、2019年4月〜2026年11月）の全レース1,255件中853件の68.0%です。画像の「差が大きい」は、この項目で一番高いときと一番低いとき（76%と51%）のぶれ幅が重ならず、開きが10ポイント以上あることを示します。今日の1号艇は上から3位で、点線の68.0%に近く、この項目だけでは全体より高いとも低いとも読みにくい、ということになります。どれも過去のレースの割合で、このレースの確率ではありません。

### 今節：6艇の流れを折れ線で見る

![常滑12Rの今節タブ。6艇の今節のSTを日ごとの折れ線で重ね、右端に前走の値を並べた図](/images/blog/hiyori-how-to-use-guide-meet-trend.jpg)

今節の各走のSTか展示タイムを、6艇の折れ線で重ねます（上の「ST」「展示」で切り替え）。縦の軸は上ほど速く、選んだ艇（ここでは1号艇）の点の中の数字はその走の着順、右端の札は各艇の前走の値です（今日まだ走っていない艇は、最後に走った日から点線で札につなぎます）。節の初日から今日までの各艇の流れを並べて見られます。走数が少ないうちは、走ごとのぶれも大きく出ます。

このほかにも、基本情報の6艇の成績の横棒と推移の折れ線、直前情報の展示タイムの棒、モータ情報の6基の推移の折れ線などがあり、多くのタブで数字と図を並べて見られます。

## 日和と並べたときの違い

どちらも無料です。それぞれが前に出している物を並べると次のとおりです。

| 項目 | ボートレース日和 | 龍神レーダー |
|---|---|---|
| 登録 | 出走表は見るだけなら不要。MyData・メモ・お気に入り（選手・モーター・レース）はマイページの機能 | ログインの仕組みが無い。選手と会場のお気に入りはブラウザに保存でき、出走・開催がトップに出る。MyData のように項目を選んだ出走表やメモは無い |
| 図 | 更新履歴に載る物では、たとえば（かっこ内は追加された時期）枠別情報の着順分析グラフ（2023年2月）、本日の場状況のグラフ（2023年2月）、モーターの節ごとのグラフ（2022年3月） | 基本情報・龍神ソナー・今節・直前情報・枠別情報・モータ情報などのタブに、6艇を並べた棒・折れ線・多角形の図 |
| 独自のデータ | 超展開データ、オリジナル展示タイムの解析（2024年9月）、級別審査（β版、2026年10月） | 龍神ソナーの類似レースと、進入・スタートの形ごとの過去の割合 |
| レースの探し方 | ガチガチ・穴レース検索、まくり・前付け・チルト跳ねのアラート | 「思考アシスト」で、軸・展開・機力・相手の問いから選手の成績と過去の傾向を開く |
| 予想 | オッズ検索の期待値分析と、自分の予想をカードやボードで形にする道具 | AI予想タブで、1マークの展開予測とイン崩れ注意度を出す |

AI予想の展開予測は「どの艇がどの決まり手で1着になりそうか」を確率つきの上位3つで出します。イン崩れ注意度は、1号艇が崩れやすいかどうかの目安で、そのレースで1号艇が負ける確率ではありません。どちらも予想の材料で、予想を実際の結果と照らした記録は外れを含めて[成績ページ](/accuracy)にあります。

龍神ソナーと思考アシストの順番は[龍神ソナーと思考アシストの紹介](/blog/sonar-assist-intro)、思考アシストの部品ごとの使い方は[思考アシストの使い方](/blog/assist-guide)にあります。

### アプリのように使うには

龍神レーダーもストアのアプリはありません。スマホのブラウザで www.boat-ai.jp を開き、「ホーム画面に追加」（iPhone の Safari は共有ボタン、Android の Chrome は右上のメニューにある）を選ぶと、アイコンからアドレスバーなしで開けます。日和も同じくブラウザで開くサイトなので、両方をホーム画面に置いて使い分けられます。

## よくある質問

### ボートレース日和は有料ですか？

2026年11月26日の時点で、日和の「はじめての方」には「ずっと無料」とあり、有料プランの案内は見当たりません。

### ボートレース日和のアプリはありますか？

App Store・Google Play の専用アプリの案内は、日和のページにありません。スマホのブラウザで開いて使います。

### ボートレース日和は登録が必要ですか？

出走表を見るだけなら登録は要りません（2026年11月26日、ログインせずに住之江の出走表を開けた）。MyData（自分用の出走表）やメモは、マイページで登録・ログインして使います。

### 名前が変わる前の日和と、今のボートレース日和は同じですか？

同じサイトです。2021年6月6日に名前だけが変わり、サイトのアドレス（URL）は kyoteibiyori.com のままです。

### 龍神レーダーは登録が要りますか？

要りません。会員登録・ログインの仕組みが無く、AI予想・龍神ソナー・思考アシストを含め、そのまま見られます。舟券を買う前の準備は[ボートレースの始め方](/blog/beginners-start-guide)にまとめています。
