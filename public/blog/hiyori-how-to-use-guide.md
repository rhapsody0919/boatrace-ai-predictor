# ボートレース日和の使い方・見方｜アプリ・有料の有無と龍神レーダーとの違い

ボートレース日和は、日和自身の「はじめての方」のページに「ずっと無料」と書かれたデータのサイトで、App Store・Google Play の専用アプリの案内はなく、ブラウザで開いて使います。この記事は、日和の使い方・見方・登録の要点を日和の公開ページから整理し、その後に、同じく無料で使える龍神レーダーで見られる物を並べます。

日和の内容は、下の「出典」に挙げた日和のページを2026年11月26日に読んで書いています。日和は月に数回機能を足しているため、今の画面と違う所があれば日和のページが正です。

---

## ボートレース日和とは

ボートレースのデータを集めて出走表の形で見せるサイトです。2021年6月6日に、それまでの名前から「ボートレース日和」に変えました（トップページのお知らせ）。運営は株式会社GAIN（山口県周南市）です。

| 問い | 日和の公開ページに書かれていること（2026-11-26） |
|---|---|
| 料金 | 「はじめての方」に「ずっと無料」。有料プランの案内はトップ・はじめての方・よくある質問・出走表の見方のページに無い |
| アプリ | ストアの専用アプリの案内は無い。利用規約の動作環境は Google Chrome と Safari の最新版 |
| 会員登録 | マイページ・ログインがある。MyData（自分用の出走表）やメモはマイページの機能 |
| 通知 | まくり・チルト跳ね・前付けのアラートを Discord の通知サーバーで受け取れる（2026年4月28日の更新） |
| 予想 | 「予想カードメーカー」（2026年10月13日）で、自分の予想印と買い目をカードにして保存・共有できる |

「アプリ」で探している人は、スマホのブラウザで kyoteibiyori.com を開けば同じ画面が使えます。

## 日和の使い方：出走表を開くまで

日和の「出走表とデータの見方」のページ（2020年9月30日の版）による流れは次のとおりです。

1. トップから開催中の場を選ぶ
2. 出走一覧からレースを選ぶと、出走表が開く
3. 出走表の上の「データ変更タブ」を左右に動かして、見たいデータに切り替える
4. 選手名を押すと、その選手の過去の成績が開く

画面の下にはレース一覧・前のレース・次のレースへ動くメニューがあり、「その他」から得点率一覧やモータ一覧などの場ごとのデータへ移れます。

## 日和の見方：出走表のタブ

同じページに載っているタブは次の9つです。後の更新で「結果」など足されたタブもあります。

| タブ | 中身 |
|---|---|
| 基本情報 | すべてのコースを合わせた総合の成績 |
| 枠別情報 | 進入したコース別の成績（艇番別ではない）。下に逃げシミュレーション |
| モータ情報 | モーターの通算と直近1か月の成績、過去に使った選手 |
| 今節成績 | 今節の連対率や平均 ST |
| 直前情報 | 展示の後に更新。進入・スタート・展示タイム・コメント |
| オッズ検索 | 人気順やフォーメーションでオッズを探す。合成オッズの計算 |
| オッズ一覧 | オッズの一覧 |
| 出目ランク | 直近1年のその場・そのレースの出目 |
| MyData | 自分で選んだデータだけを並べた出走表 |

日和で名前の付いたデータのうち、よく探される物の意味は次のとおりです。

- **逃がし2着率**: 1コースが逃げたとき、各コースの選手が2着に入った割合。直近1年が対象で、総合・一般戦・SG/G1・女子戦で切り替えられる。枠別情報の下の「逃げシミュレーション」にある
- **超展開データ**: 各選手が1マークでどう攻めてどれだけ勝ち、どう攻められてどれだけ負けたかのデータ（日和のオリジナル）
- **MyData**: マイページで項目を足し、「登録」ボタンを押して初めて保存される。よくある質問では、押し忘れると消えたように見えるとしている

### 設定とログイン

お気に入り選手の印の固定やアラートのメール通知は、「ユーザー情報」の「ユーザー設定」で切り替えます（更新履歴の2021年12月・2022年6月の記事）。よくある質問（2021年6月の版）には、パスワードの再発行と退会は問い合わせで受けると書かれています。

## 日和に予想や必勝法はある？

日和はデータを見せるサイトで、日和自身が全レースの予想を出す機能の案内は、はじめての方・更新履歴のページに見当たりませんでした。予想は、データを見た人が自分で組み立て、予想カードメーカーや「展開予想ボード」（艇を動かして1マークを考える道具、2026年8月）で形にする作りです。どのサイトのデータでも、結果を保証する読み方はありません。

## 龍神レーダーで無料で見られる物

龍神レーダーも無料のサイトで、会員登録・ログインの仕組みがありません。出走表・AI予想・分析のページは登録なしでそのまま開けます（2026年11月26日に本番の画面とコードで確かめた内容）。レース詳細の「出走表とタブ」には、次の9つのタブが並びます。

| タブ | 中身 |
|---|---|
| 基本情報 | 勝率・2連対率・3連対率・平均 ST を、全国/当地・グレード・期間で切り替え。走数も出す |
| 龍神ソナー | 条件が近い過去のレースの結果と、進入・スタートの形ごとの過去の割合 |
| AI予想 | 1マークの展開予測と、イン崩れ注意度 |
| 今節 | 6選手の今節の得点率・節内順位・準優の目安までの必要得点 |
| 直前情報 | 展示タイム・気象・ピットレポート |
| 枠別情報 | 想定コースの成績、ST 考察、逃げシミュレーション |
| モータ情報 | その場のモーターの成績・調子 |
| オッズ一覧 | 発売中のオッズ |
| 結果 | 確定後の着順と配当（確定するまで出ない） |

枠別情報・モータ情報・逃げシミュレーションのように、日和に慣れた人が探しやすい名前と並びにそろえています。逃げシミュレーションの読み方は[逃げシミュレーションの使い方](/blog/nige-simulation-guide)にまとめています。

## 日和と並べたときの違い

どちらも無料です。並べると次のとおりです。

| 項目 | ボートレース日和 | 龍神レーダー |
|---|---|---|
| AI の予想 | 日和自身の予想の案内は無い（はじめての方・更新履歴） | 全24場の全レースで、1マークの展開予測とイン崩れ注意度を出す |
| 予想の成績 | — | 予想を実際の結果と照らした記録を、外れを含めて[成績ページ](/accuracy)に出す |
| 自分の出走表・メモ | MyData・メモはマイページ（ログイン）で使う | ログインの仕組みが無い。登録なしで開ける |
| 問いからデータを引く | 条件検索・アラート | 「思考アシスト」で、軸・展開・機力・相手の問いから選手の成績と過去の傾向を開く |

AI予想の展開予測は「どの艇がどの決まり手で1着になりそうか」を確率つきの上位3つで出します。イン崩れ注意度は、過去90日の同じ場のレースと比べて1号艇が崩れやすいかを0〜100で出します。どちらも予想の材料で、結果を約束する数字ではありません。

龍神ソナーと思考アシストの順番は[龍神ソナーと思考アシストの紹介](/blog/sonar-assist-intro)、思考アシストの部品ごとの使い方は[思考アシストの使い方](/blog/assist-guide)にあります。

### アプリのように使うには

龍神レーダーもストアのアプリはありません。スマホのブラウザで www.boat-ai.jp を開き、共有メニューの「ホーム画面に追加」を選ぶと、アイコンから全画面で開けます。日和も同じくブラウザで開くサイトなので、両方をホーム画面に置いて使い分けられます。

## よくある質問

### 名前が変わる前の日和とボートレース日和は同じサイトですか？

同じサイトです。2021年6月6日に名前だけが変わりました。住所は kyoteibiyori.com のままです。

### ボートレース日和は有料ですか？

2026年11月26日の時点で、日和の「はじめての方」には「ずっと無料」とあり、有料プランの案内は見当たりません。

### ボートレース日和のアプリはありますか？

App Store・Google Play の専用アプリの案内は、日和のページにありません。スマホのブラウザで開いて使います。

### 龍神レーダーは登録が要りますか？

要りません。会員登録・ログインの仕組みが無く、AI予想・龍神ソナー・思考アシストを含め、全部そのまま見られます。初めての方は[龍神レーダーの始め方](/blog/beginners-start-guide)から読めます。
