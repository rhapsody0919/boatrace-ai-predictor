# イン崩れ指数100%は当たるのか？9/3住之江6Rの実例で検証

「イン崩れ指数100%」——龍神レーダーのレース詳細ページでこの表示を見たとき、「本当にそんなに崩れるの？」と疑問に思ったことはないでしょうか。

今回は2026年9月3日・住之江6Rを実例に、レース前に表示されていた「イン崩れ指数100%」という予測が、実際の結果とどう対応したのかをそのまま検証します。都合の良い結果だけを選んでいないか確認できるよう、レース前のデータと結果を数値でそのまま並べます。

---

## イン崩れ指数とは何か

イン崩れ指数は、そのレースで1号艇が崩れる（3着以内に入れない）可能性を0〜100%のパーセンタイルで示す指標です。会場内の他レースと比較した相対的な位置づけで算出しており、以下のような要素から総合的に判定します。

- 1号艇選手の全国勝率
- 1号艇のスタートタイミング（平均ST）の傾向
- AIが予測する「逃げ」決まり手の確率
- モーター調子や枠なり別の決まり手傾向

数値が高いほど「セオリー通りの1号艇イン逃げにならず、まくり・差しなど外枠の決まり手が有力」というAIの見立てを意味します。

## 9/3住之江6R：レース前に表示されていたデータ

発走前、このレースには以下の実データが表示されていました。

| 項目 | 数値 |
|------|------|
| イン崩れ指数（会場内パーセンタイル） | **100%** |
| 1号艇（久保原選手・B1）全国勝率 | **2.61** |
| AI逃げ確率 | **33%** |
| 1号艇の今節平均ST | 0.190秒 |

AIが挙げていた根拠は次の3点でした。

- 1号艇の全国勝率が非常に低い（2.61）→ イン崩れリスク高
- AI逃げ確率が低い（33%）→ まくり・差し有力
- 1号艇の今節STが遅い（平均0.190秒）→ イン崩れリスク

対して4号艇（高倉選手・A1）は全国勝率7.13、全国複勝率56.41%と、1号艇との実力差が数字上はっきり出ていました。

## レース結果：実際にどうなったか

同日のレース結果は以下の通りです。

| 着順 | 艇番 |
|------|------|
| 1着 | 4号艇 |
| 2着 | 5号艇 |
| 3着 | 3号艇 |

決まり手は**「まくり」**。1号艇（久保原選手）は3着以内に入れず、全国勝率で1号艇を大きく上回っていた4号艇（高倉選手）が、AIが予測していた通り「まくり」で優勝しました。

イン崩れ指数100%・AI逃げ確率33%という発走前の数字が示していた「1号艇のイン逃げは苦しく、外枠のまくり・差しが有力」という見立ては、結果と一致した形です。

## この指数の使い方

レース詳細ページを開くと、イン崩れ指数はバッジ形式で表示されます。

1. レース詳細ページを開く
2. 「⚖️ イン崩れ注意度」バッジで会場内パーセンタイルと判定根拠を確認する
3. [`/winning-technique?tab=volatility`](/winning-technique?tab=volatility) では、レベル別（警戒・標準・堅い）の実測イン崩れ率を会場横断で確認できる

バッジには判定根拠（全国勝率・AI逃げ確率・平均ST等）がリスト表示されるため、「なぜこの数値になっているか」を自分の目で確認したうえで舟券戦略を組み立てられます。

## 活用のポイント

### 1回の結果だけで判断しない

今回は指数通りの結果になりましたが、イン崩れ指数はあくまで確率的な指標です。「警戒」レベル（パーセンタイル70%以上）のレースにおける実測イン崩れ率は、龍神レーダーが蓄積した2,928レースの実績で**64.6%**（790件中）。全体平均の45.5%と比べると+19.1ポイント高い水準ですが、裏を返せば約3割強は1号艇がそのまま押し切っています。「必ず崩れる」という意味ではない点に注意してください。

### 他の指標と組み合わせる

イン崩れ指数だけで判断せず、1号艇と対抗艇の全国勝率差、モーター調子、AI逃げ確率を合わせて確認すると、より根拠のある判断がしやすくなります。今回のケースでも、全国勝率の差（2.61 vs 7.13）という裏付けが伴っていたことが、結果との一致につながった要因の一つと考えられます。

### 会場ごとの傾向差も参考にする

イン崩れの起きやすさは会場によって差があります。`/winning-technique`の「会場ランキング」タブでは、会場ごとの実測データを比較できるので、遠征観戦や複数会場を跨いだ検討をする際の参考にしてください。

## よくある質問

### イン崩れ指数100%なら、必ず1号艇が負けるのですか？

いいえ。イン崩れ指数は過去データに基づく確率的な指標であり、100%という数値も「会場内で最も1号艇が崩れやすい水準にある」ことを意味するもので、結果を保証するものではありません。実測でも「警戒」レベルの的中率は64.6%にとどまり、約35%はそのまま1号艇が3着以内に入っています。

### イン崩れ指数はどこで確認できますか？

各レースの詳細ページに「⚖️ イン崩れ注意度」バッジとして表示されます。また[`/winning-technique?tab=volatility`](/winning-technique?tab=volatility)では、レベル別の実測イン崩れ率を会場横断でまとめて確認できます。

### 今回のように毎回的中するのですか？

毎回ではありません。今回のケースは全国勝率差（2.61 vs 7.13）やAI逃げ確率の低さなど複数の根拠が重なっていたため結果と一致しましたが、「警戒」レベル全体で見ると実測イン崩れ率は64.6%です。1回の結果だけでなく、こうした実測値と合わせて参考にすることをおすすめします。
