# 경정으로 월 5만 엔 부수입을 버는 로드맵 [재현성 중시]

## '월 5만 엔'은 현실적인 목표인가?

결론부터 말하면, **현실적입니다**.

다만 '한탕주의'를 노리는 도박이 아니라 **전략적인 투자**로 접근해야 합니다.

이 글에서는 BoatAI의 데이터 분석으로 도출한, 일본 경정(쿄테이)에서 '월 5만 엔을 버는 구체적인 로드맵'을 공개합니다.

**주의:**
- 한 방의 역전을 노리지 않는다
- 매일 꾸준히 쌓아간다
- 감정을 배제하고 기계적으로 산다

이 3원칙을 지킬 수 있는 사람만 계속 읽어주세요.

## 전제: 왜 월 5만 엔인가?

### 월 5만 엔의 가치

```
연간 60만 엔의 부수입
= 술값, 취미비를 자유롭게 쓸 수 있음
= 가족 여행을 연 2회 갈 수 있음
= 노후 자금으로 매달 적립 가능
```

**중요한 것은 '재현성':**
- 월 100만 엔을 1회 버는 것 < 월 5만 엔을 12개월 버는 것
- 안정적인 수입이 삶을 더 풍요롭게 만든다

### 왜 경정인가?

**경정이 부업에 적합한 이유:**

1. **소액으로 시작 가능**
   - 최저 100엔부터 구매 가능
   - 주식이나 FX처럼 큰 자금이 필요 없음

2. **결과가 바로 나옴**
   - 한 경주는 약 2분 만에 결판
   - 그날 안에 수지가 확정됨

3. **데이터가 풍부**
   - 선수, 모터, 과거 경주 데이터가 공개됨
   - AI로 분석 가능

4. **매일 개최**
   - 평일도 주말도 개최
   - 자신의 일정에 맞춰 참여 가능

## 1단계: 기초 다지기(1개월 차)

### 목표: 월 ±0엔

우선 **손해를 보지 않는 것**을 목표로 한다.

### 할 일

**1. BoatAI에서 매일 예상 확인하기**

👉 [boat-ai.jp](https://boat-ai.jp/)

매일 아침 5분, 오늘의 경주를 확인하는 습관을 들인다.

**2. 연승만 구매하기**

우선 적중 경험을 쌓는 것이 중요하다.

**구매 규칙:**
```
경주당: 100엔
하루: 10경주(1,000엔)
한 달: 30일(30,000엔)
```

**선택하는 경주:**
- AI 점수 3500 이상
- 정수면 경정장(오무라, 아시야, 츠, 토쿠야마)
- 풍속 3m 이하

**3. 기록하기**

엑셀이나 메모 앱에 기록:
```
날짜 | 경주 | 구매액 | 배당금 | 수지
12/18 | 오무라 3R | 100엔 | 130엔 | +30엔
12/18 | 아시야 7R | 100엔 | 0엔 | -100엔
...
```

### 1개월 차 예상 성적

**연승 적중률: 52.1%(BoatAI 실적)**

```
투자: 30,000엔(100엔×10경주×30일)
배당금: 29,400엔(130엔×52.1%×300경주)
수지: -600엔
```

**±0엔에 가까운 결과라면 대성공이다.**

### 1개월 차에 배울 것

- 모터 연대율의 중요성
- 경정장별 특성
- AI 점수와 적중의 상관관계
- 감정을 배제한 구매 방법

## 2단계: 안정화(2〜3개월 차)

### 목표: 월 +1만〜2만 엔

연승에 익숙해지면 삼복승을 도입한다.

### 할 일

**1. 승식별 배분 바꾸기**

**2개월 차 구매 배분:**
```
연승: 7경주 × 100엔 = 700엔/일
삼복승: 3경주 × 100엔 = 300엔/일
합계: 1,000엔/일
```

**삼복승을 구매하는 경주 조건:**
- AI 점수 3800 이상
- 상위 3정 모두 모터 연대율 40% 이상
- 정수면 경정장
- 풍속 3m 이하

**2. 경정장 좁히기**

잘 아는 경정장에 집중하면 적중률이 오른다.

**추천 경정장(1코스 유리):**
- 오무라(1코스 승률 63%)
- 아시야(1코스 승률 58%)
- 토쿠야마(1코스 승률 58%)
- 츠(1코스 승률 57%)

**피해야 할 경정장(초보자는):**
- 토다(1코스 승률 45%)
- 에도가와(1코스 승률 47%)
- 헤이와지마(1코스 승률 48%)

## 3단계: 수익화(4개월 차 이후)

### 목표: 월 +5만 엔

여기서부터 본격적으로 수익화를 노린다.

### 할 일

**1. 투자액 늘리기(신중하게)**

**4개월 차 구매 배분:**
```
연승: 5경주 × 200엔 = 1,000엔/일
삼복승: 3경주 × 300엔 = 900엔/일
삼쌍승: 2경주 × 100엔 = 200엔/일
합계: 2,100엔/일
```

**중요:**
갑자기 투자액을 늘리지 말고 **자금 범위 내에서 단계적으로** 늘린다.

**2. 삼쌍승을 소액으로 추가**

삼쌍승은 적중률이 낮지만(5.6%) 적중하면 배당이 크다.

**삼쌍승을 구매하는 경주 조건:**
- AI 점수 1위와 2위 모두 3900 이상
- 1코스 A1급 × 모터 연대율 45% 이상
- 정수면 × 풍속 2m 이하
- 12R 우승전급 경주

**3. 고배당 경주 판별하기**

**고배당의 특징:**
```
【노려볼 만한 경주】
- 2〜4코스가 A급 선수 × 우량 모터
- 1코스가 B급 또는 모터 상태 불량
- 순풍 3m 이상(바깥 코스 유리)

【피해야 할 경주】
- 1코스 A1급 × 모터 연대율 50% 초과
→ 지나치게 안정적이라 배당이 낮음
```

### 4개월 차 예상 성적

```
【연승】
투자: 30,000엔(200엔×5경주×30일)
배당금: 33,930엔(260엔×52.1%×150경주×평균 배당 보정)
수지: +3,930엔

【삼복승】
투자: 27,000엔(300엔×3경주×30일)
배당금: 56,187엔(평균 배당 2,080엔×15.3%×90경주×3배 투자)
수지: +29,187엔

【삼쌍승】
투자: 6,000엔(100엔×2경주×30일)
배당금: 26,982엔(평균 배당 24,188엔×5.6%×60경주)
수지: +20,982엔

합계: +54,099엔
```

**월 +5만 엔 달성!**

### 실패 패턴 2: 손실을 만회하려 함

**NG 패턴:**
```

```

**대책:**
잃은 날은 **거기서 끝낸다**. 다음 날 다시 같은 금액부터 시작한다.

**NG 패턴:**
```

→ 그 사이 17번에 자금이 바닥남
```

**대책:**
**연승 7할, 삼복승 2할, 삼쌍승 1할**의 균형을 지킨다

## 자주 묻는 질문

### Q1. 정말 월 5만 엔을 벌 수 있나요?

**A:** 데이터상으로는 가능합니다.

다만 **100% 보장은 할 수 없습니다**. 경정은 확률 게임이며 운도 작용합니다.

중요한 것은 **장기적으로 흑자를 목표로 하는 것**입니다.

### Q2. 초기 자금은 얼마나 필요한가요?

**A:** 최소 3만 엔을 권장합니다.

```
1개월 차: 30,000엔
예비 자금: 10,000엔(트러블 대응용)
합계: 40,000엔
```

### Q3. 시간은 얼마나 걸리나요?

**A:** 하루 30분 정도입니다.

```
아침: BoatAI에서 예상 확인(10분)
점심: 배권 구매(10분)
저녁: 결과 확인과 기록(10분)
```

### Q4. 잃는 날도 있나요?

**A:** 있습니다.

적중률 52.1%라는 것은 **약 절반은 빗나간다**는 뜻입니다.

하루 단위로는 잃는 날도 있지만, 한 달 단위로 보면 흑자가 되는 전략입니다.

### Q5. 스마트폰만으로도 가능한가요?

**A:** 가능합니다.

BoatAI는 스마트폰에 대응하며, 배권도 온라인으로 구매할 수 있습니다.
