## 共通點1：「因為是1號艇所以買」的思考停滯

### ❌ 輸家模式

「1號艇勝率高，先買1號艇比較安心」

這乍看之下似乎正確，但實際上是**賽艇輸家的典型模式**。

**為什麼會輸：**
- 1號艇全國平均勝率：約55%
- 也就是說有45%會輸
- 而且賠率低，即使命中回收率也差

**實際案例：**
```
江戶川第3場：1號艇單勝賠率1.2倍
→ 買100日圓即使命中也只有120日圓（+20日圓）
→ 未命中2次就是-80日圓
→ 整體是-60日圓
```

### ✅ AI預測的解決方案

BoatAI不是「因為是1號艇」，而是**從45項數據綜合判斷**。

**分析項目：**
- 選手級別、勝率、當地勝率
- 馬達2連率（最重要）
- 展示航行時間
- 風向・風速・水面狀況
- 過去相同條件比賽的傾向

**結果：**
在像江戶川這種「1號艇勝率低的賽艇場」，AI常會推薦2-4號艇，提升命中率。

## 共通點2：不看馬達性能

### ❌ 輸家模式

只憑選手判斷「因為是A1級選手所以會贏」。

**現實：**
無論選手多優秀，**若馬達差就無法獲勝**。

賽艇有句話說「選手3成、馬達7成」，馬達性能大幅左右勝負。

**實際案例：**
```
A1級選手搭乘馬達2連率25%的艇時
→ 第一名率：約15%（不到平常的一半）

B1級選手搭乘馬達2連率50%的艇時
→ 第一名率：約25%（有時甚至超過A1級）
```

### ✅ AI預測的解決方案

BoatAI**優先評估馬達2連率**。

**判斷基準：**
- 馬達2連率45%以上：超優良（積極鎖定）
- 馬達2連率35-45%：標準（視選手而定）
- 馬達2連率未滿35%：需警戒（排除主軸）

**12/10的成功案例：**
以馬達2連率46.7%的5號艇（B1級選手）為主軸推薦
→ 命中，達成回收率208.1%

## 共通點3：不看展示航行（或不知道怎麼看）

### ❌ 輸家模式

「展示航行是什麼？不看也沒關係吧」

或是

「因為展示時間第一名所以買了卻輸了！」

**問題點：**
- 不看展示航行是說不過去的
- 只看展示時間也不夠
- 轉彎、起步、伸展也需要觀察

**但是：**
初學者要精準分析展示航行**幾乎是不可能的**。

### ✅ AI預測的解決方案

BoatAI**多角度分析**展示航行。

**分析內容：**
- 展示時間
- 轉彎的迴旋腳程
- 起跑展示的起步
- 各賽艇場的展示可信度

**依賽艇場分類的展示可信度：**
- 大村、蘆屋：多與展示相符的走勢 → 重視展示
- 戶田、江戶川：展示與正式比賽容易落差 → 較不重視展示

透過這個調整，命中率能大幅提升。

## 共通點4：憑感情購買（追加投注・上頭）

### ❌ 輸家模式

**模式A：追加投注**
```
第1場未命中 → 想在第2場扳回加倍購買
第2場未命中 → 在第3場再加倍購買
第3場未命中 → 回過神來資金已見底
```

**模式B：命中後過度自信**
```
第1場命中 → 「狀況好像不錯！」大額購買
第2場未命中 → 失去所有命中的獲利
```

**問題點：**
感情用事的判斷，統計上**必定會輸**。

### ✅ AI預測的解決方案

AI**總是保持冷靜**。

**優點：**
- 不受前一場比賽結果影響
- 每場比賽都以相同邏輯判斷
- 零感情判斷失誤

**建議的資金管理：**
1. 決定每日預算（例：3,000日圓）
2. 每場固定100日圓
3. 即使命中也不改變購買額
4. 未命中也不追加投注

依照BoatAI的預測**機械式購買**，能以長期正收支為目標。

## 共通點5：忽視回收率只追求命中率

### ❌ 輸家模式

「今天10場中命中7場！命中率70%！」

但收支卻是……

```
投注：1,000日圓（100日圓×10場）
派彩：840日圓（120日圓×7場）
收支：-160日圓
```

**即使命中率70%仍是虧損**的現實。

**問題點：**
即使命中率高，若回收率低於100%就是虧損。

### ✅ AI預測的解決方案

BoatAI**優先考量回收率**。

**依投注組合種類的策略：**

**複勝：**
- 命中率：52.1%
- 回收率：114.2%
- 策略：穩健累積獲利

**3連複：**
- 命中率：15.3%
- 回收率：208.1%
- 策略：鎖定中派彩有效率地賺取獲利

**3連單：**
- 命中率：5.6%
- 回收率：1343.8%（12/10實績）
- 策略：以高派彩一舉獲利

**重要的思考方式：**
即使命中率30%，只要回收率150%就是大成功。
