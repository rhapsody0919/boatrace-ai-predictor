# ボートレースのモーター2連率とは？何の割合で、いつ変わるか｜選手の2連率との違い

モーター2連率は、そのモーターが過去のレースで2着以内に入った割合です。2026年1月8日の戸田1Rでは、6基のうち1号艇のモーターが46.85%で最も高く、6号艇のモーターが30.23%で最も低い値でした。

今日のレースの6基は[モーター調子](/winning-technique?tab=motor)で並べて見られます。レースを選ぶと、6基の公式2連率（節時点）が棒で並び、会場内で何位のモーターかが添えられます。

## モーター2連率は2着以内の回数÷出走回数、出走表の値は節の初日に決まる

モーター2連率は「1着と2着の回数の合計÷そのモーターの出走回数」で、3連率は3着までを数えた割合です。出走表に載る公式の値は、モーターの使用開始からの通算で、今節の着順は入りません（[BOAT RACE公式の出走表の集計説明](https://www.boatrace.jp/owpc/pc/extra/about.html)）。

| 項目 | 公式のモーター2連率（出走表の値） |
|---|---|
| 何の割合か | そのモーターが2着以内に入った回数÷出走回数 |
| 集計の範囲 | 使用開始からの通算。今節の着順は入らない |
| 値が変わる時 | 節の初日。節の途中では同じ値が続く |
| 新しいモーター | 最初の節は全艇0%。2節目の初日から値が入る |
| 小数 | 2桁（例 46.85%） |

新しいモーターの最初の節で0%と出るのは、2着以内に1回も入っていないからではなく、まだ公式の累計が付いていないからです。この間、龍神レーダーはその会場での走りから出した2連率を「2連率（節時点）」の欄に出し、値に「※」を付けます。

## 実例: 戸田1Rの6艇で、選手の2連率とモーター2連率を並べる

2026年1月8日の戸田1R（公開出走表の値）です。全国2連率は乗る選手の成績、モーター2連率とボート2連率は機材の成績です。

| 艇番 | 級別 | 全国2連率（選手） | モーター2連率 | 6基の中の順位 | ボート2連率 |
|---|---|---:|---:|---:|---:|
| 1号艇 | A1 | 48.53% | 46.85% | 1位 | 30.34% |
| 2号艇 | A1 | 52.87% | 32.32% | 4位 | 36.56% |
| 3号艇 | A2 | 44.33% | 31.18% | 5位 | 52.63% |
| 4号艇 | B1 | 37.66% | 38.89% | 2位 | 36.67% |
| 5号艇 | A2 | 33.64% | 35.51% | 3位 | 34.02% |
| 6号艇 | B2 | 2.04% | 30.23% | 6位 | 28.89% |

6号艇は選手の全国2連率が2.04%なのに、モーター2連率は30.23%です。モーター2連率は、これまでそのモーターに乗った選手たちの着順から出た値で、今日乗る選手の成績ではありません。2号艇は選手の全国2連率が6艇で最も高い52.87%で、モーターは4位の32.32%でした。選手の欄と機材の欄で並びが変わるときは、両方を別々に置いて読みます。

公式の出走表は割合だけを出し、何走で出した値かは載せていません。

## 全国2連率・当地2連率・モーター2連率・ボート2連率の違い

| 欄 | 誰の・何の成績か | 範囲 |
|---|---|---|
| 全国2連率 | 選手の全国での2着以内の割合 | 開催初日の月を含む過去6か月 |
| 当地2連率 | 選手のその会場での2着以内の割合 | その会場での成績（範囲は公式の集計説明による） |
| モーター2連率 | モーター（エンジン）の2着以内の割合 | 使用開始からの通算 |
| ボート2連率 | ボート（船体）の2着以内の割合 | そのボートの過去のレース |

モーターとボートは節ごとに抽選で選手に割り当てられます。モーターはエンジン、ボートはエンジンを載せる船体で、別々の抽選です。全国2連率の範囲は、上の公式の集計説明によります。

## モーター調子の画面の見方: 一覧の欄と、行を押すと出るもの

[モーター調子](/winning-technique?tab=motor)の一覧は、左から次の欄が並びます。出どころが3つに分かれるので、欄ごとに「誰が出した値で、いつ変わるか」を押さえます。

| 欄 | 中身 | 出どころ・変わる時 |
|---|---|---|
| 枠番・選手名・機番 | 6艇と、それぞれのモーターの番号 | 出走表 |
| 公式2連率（節時点） | 出走表のモーター2連率。棒は6基の最大を全長にした長さ | BOAT RACE公式。節の初日に決まり、節の途中は変わらない |
| 会場内順位 | 会場の全モーターの中の順位（「何位／全体の機数」の形） | 各会場の公式サイトのモーター成績。節の終わりに更新。戸田・平和島・浜名湖・宮島は出さない |
| 2連率・3連率（過去90日など） | 選んだ期間（過去90日・直近1ヶ月）の、このモーター自体の2連率・3連率 | 龍神レーダーの集計。モーター入れ替えより前の分は入れない |
| 前検 | 前検のタイム | BOAT RACE公式。節の途中は変わらない |
| 1着率・優出数・優勝数 | このモーターの1着の割合と、優勝戦に乗った数・勝った数 | 各会場の公式サイト。節の終わりに更新。会場の公式サイトに値が無い会場は欄ごと出さない |
| 機力指数 | 「このモーターで2着以内だったか」−「その時乗っていた選手の全国2連率」の差の平均 | 龍神レーダーの集計。選んだ期間 |

一覧の印は3つです。金枠の値は、このレースで公式2連率が最も高いモーターです。ベージュの地は、その列で一番の値です。「※」は公式の2連率がまだ出ていないモーターで、押すと何走から出した値かが出ます。

選手の全国2連率と同じように、モーター2連率には乗った選手の実力も混ざります。上手な選手が続けて乗ったモーターは2連率が上がりやすく、機力指数はその分を差し引いた値です。プラスが大きいほど、乗った選手の実力を超えて走ってきたモーターです。会場内順位は会場の公式サイトの値で、棒は出走表の公式2連率なので、出どころが違い、棒の長さと順位が逆になるレースがあります。

行を押すと、そのモーター1基の中身が開きます。

| 開くもの | 何が分かるか |
|---|---|
| モーター鮮度 | このモーターが何走目・何節目か（会場の公式サイトの値） |
| 2連率・3連率の推移（公式の累計） | 節ごとの公式の値の動き。節の途中で変わらないので階段の形になる |
| 展示タイムの推移 | このモーターの展示タイムの動き。グラフは上ほど速い |
| コース別成績 | このモーターが実際に進入したコースごとの1着率・2連率・3連率 |
| 使用履歴 | 直近90日にこのモーターに乗った選手と、節ごとの着順・2連率 |
| 部品交換・プロペラ交換履歴 | 交換した日と、交換の前後の展示タイムの平均の比べ |

部品交換の履歴の読み方は[モーター2連率だけで決めない理由](/blog/motor-performance-deep-dive)にまとめています。

## 1着率の比べ方: モーター2連率の順位と展示タイムの順位で分ける

モーターの値で1着を比べるときは、2連率の数字そのものより「6基の中で何位か」で分けて見ます。下の集計も6艇の中の順位で分けているので、画面でも6基の中の順位で見ると同じ物差しで読めます。

龍神レーダーの集計で、全国の枠なりのレース（2019年4月1日〜2026年9月26日）のうち、6艇のスタートがそろった横一線の形（47,320レース）を、1号艇のモーター2連率の順位と展示タイムの順位で分けた1号艇の1着です。

| 1号艇の6艇の中の順位 | モーター2連率の順位で分けたとき | 展示タイムの順位で分けたとき |
|---|---:|---:|
| 1〜2位 | 17,185レース中11,773回（68.5%） | 25,445レース中18,088回（71.1%） |
| 3〜4位 | 15,313レース中10,154回（66.3%） | 13,873レース中8,671回（62.5%） |
| 5〜6位 | 14,762レース中9,407回（63.7%） | 8,002レース中4,615回（57.7%） |

横一線の1号艇の1着率は、モーター2連率の1〜2位と5〜6位で68.5%と63.7%、展示タイムの1〜2位と5〜6位で71.1%と57.7%でした。どちらも上位のほうが1着が多く、開きは展示タイムの順位のほうが大きく出ています。攻める艇がいる形（4号艇がカドから攻める形など）でも、攻める艇の1着率の上位と下位の差は、モーター2連率の順位で4〜8ポイント、展示タイムの順位で9〜18ポイントで、スタートの形7つのすべてで展示タイムの順位のほうが大きく出ました。

画面の「1着率」の欄は会場の公式サイトの値で、コースを分けない1着の割合なので、どのコースで乗ったかが混ざります。コースの違いを外して比べるには、行を押して「コース別成績」で、同じコースの1着率どうしを並べます。

上級者向けに1つ深い点を足すと、同じレースの6艇の中で、モーター2連率と展示タイムの相関は0.115と弱く、オリジナル展示の一周とは0.051、まわり足とは0.007でほぼ無関係でした（2026年9月22日〜10月11日の全国2,844レース）。モーター2連率は節の初日に決まる過去の値で、展示タイムは今日の足の値なので、別の材料として並べます。展示タイムの読み方は[展示は何分前？展示タイムの見方](/blog/exhibition-run-guide)にあります。

## 今日のレースでモーター2連率を見る手順

1. [モーター調子](/winning-technique?tab=motor)で今日のレースを選び、6基の公式2連率（節時点）と会場内順位を見ます。新しいモーターの最初の節は、見出しが「2連率（節時点）」に替わり、龍神レーダーが出した値に「※」が付きます。
2. 出走表の全国2連率と並べ、選手とモーターの並びが分かれた艇に印を付けます。実例の6号艇のように、モーター2連率は今日乗る選手の成績とは別に決まっています。
3. 機力指数を見て、乗った選手の実力を差し引いてもプラスのモーターかを分けます。
4. 展示タイムが出たら、モーター2連率の順位より展示タイムの順位を先に見ます。上の表のとおり、1着率の開きは展示タイムの順位のほうが大きく出ています。
5. 会場の全モーターの並びは[モーターランキング](/winning-technique?tab=motorranking)で見られます。勝率・2連率の使い分けは[AI指数とは？勝率・2連率の比べ方](/blog/ai-index-reading-guide)にあります。

## よくある質問

### 2連率とは？3連率との違いは？

2連率は2着以内に入った割合、3連率は3着以内に入った割合です。2連単・2連複のように2着までを当てる券種では2連率、3連単・3連複のように3着までを当てる券種では3連率を並べると、券種と同じ着順の範囲で比べられます。

### ボート2連率とは？モーター2連率とどう違う？

ボート2連率は、エンジンを載せる船体（ボート）が2着以内に入った割合です。モーターとは別の抽選で割り当てられます。龍神レーダーの集計では、全国・6艇ともA1のレースで、ボート2連率が一番高いときと低いときの2着以内・3着以内の差は0〜3ポイントでした。

### 会場内順位に添えた2連率が、一覧の2連率と0.1違うのはなぜ？

会場内順位に添えた2連率は会場の公式サイトの値で、小数2桁目を切り捨てて出しているためです。

### 過去のレースを開くと、期間を選べないのはなぜ？

過去のレースでは、モーターの成績を出走表の時点の公式の値で出すためです。機力指数は、一覧では当日のレースだけに出ます。行を押すと、そのレースの直前までの値が見られます。

### 同じ番号のモーターなのに、推移が出ないのはなぜ？

モーターは会場ごとにおおむね年1回入れ替わり、番号は新しいモーターに引き継がれます。入れ替え前のレースのモーターは、今の同じ番号のモーターとは別のモーターなので、推移・機力指数・使用履歴は出しません。

## 数字の範囲と注意

実例の表は2026年1月8日の戸田1Rの公開出走表の値で、6基の中の順位は表の値から数えました。順位と1着の集計は、全艇が艇番どおりのコースに入った枠なりのレースだけで、モーター2連率は出走表の時点の値です。モーター2連率の順位で分けた件数は6艇の値がそろうレースだけなので、合計が横一線の47,320レースより少なくなります。順位は同じ値なら小さいほうの順位に入れるため、展示タイムの1〜2位は件数が多くなります。ボート2連率の0〜3ポイントは全国・6艇ともA1のレースの2着以内・3着以内の差で、モーターの1着の集計とは範囲と着順が違います。相関の0.115などは2026年9月22日〜10月11日の2,844レースの値です。過去の割合は今日の着順を約束する数字ではありません。
