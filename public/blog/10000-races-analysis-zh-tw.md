# BoatAI突破1萬場比賽——數據回顧AI預測的實力與極限

## 前言

BoatAI的累計分析比賽數已**突破1萬場**。

雖然坊間有許多AI預測服務，但**公開超過1萬場所有實績**的服務極為罕見。本文將誠實傳達從1萬場比賽的數據中看到的「AI預測的實力」與「極限」。

---

## 累計實績摘要

截至累計突破1萬場比賽時（2025年12月），根據**合計32,364件預測數據**，單勝命中率25.2%〜47.4%、單勝回收率81.4%〜85.9%、3連複命中率9.5%〜18.0%、3連複回收率69.2%〜73.5%，皆落在此區間內。

※當時是以標準・本命導向・冷門導向3種類型運作，現在已統一為單一的統合模型。最新實績請見[成績頁面](/accuracy)。

## AI預測的「實力」——好的一面

### 1. 單勝命中率47.4%的意義

賽艇由6艘艇競賽。隨機選擇的命中率約為16.7%（1/6）。

BoatAI的預測為**47.4%**。這代表：

- 相較隨機**約2.8倍**的準確度
- **約每2場中有1場**命中第一名
- 由於這是12,324場的大量數據得出的數字，並非偶然

### 2. 複勝命中率約70%

BoatAI的預測複勝（前2名）命中率約70%。計算結果**10場比賽中有7場本命進入前2名**。

這是「AI的預測並非離譜」的證據。即使未命中第一名，多數情況仍會進入前2名。

### 3. 3連複命中率18.0%與3連單的準確度

3連複是命中前3艘艇組合（不論順序）的投注組合。機率為1/20（5%）。

BoatAI的預測為**18.0%**（約5.5場中1場）。以**約3.6倍**於隨機的準確度命中3連複。當時3種類型整體落在9.5%〜18.0%（相較隨機約1.9〜3.6倍）的區間。

此外，即使是需要完全命中順序的**3連單**（機率1/120），也達成**5.9%**（約隨機的7.1倍）。

### 4. 依會場來看，回收率超過100%的情況眾多

雖然月度・整體平均低於100%，但依**會場×模型×投注組合**的組合來看，找到多個回收率超過100%的條件。

2025年12月的實績：
- 蘆屋×標準×3連單 = **1,258.9%**
- 濱名湖×冷門導向×3連單 = **515.0%**
- 丸龜×冷門導向×3連單 = **382.4%**

**不是均一購買全24會場，而是鎖定擅長的會場**這一點很重要。

## AI預測的「極限」——誠實傳達

### 1. 整體回收率低於100%

當時3種類型整體，單勝回收率介於81.4%〜85.9%，3連複回收率介於69.2%〜73.5%的區間。

**無論哪種類型，若所有比賽均一持續投注，回收率都是69〜86%**。

這代表什麼？**若對所有比賽持續投注100日圓，長期來看約會損失15%**。

### 2. 為什麼回收率會低於100%

賽艇的抽成率約為25%。也就是說，投注100日圓平均只會回收75日圓。

BoatAI的回收率85.9%，已「部分」跨越這道抽成率的牆，但尚未能完全突破。

```
隨機（期望值）：約75%
BoatAI 標準：85.9%  ← 改善+10.9%
BoatAI 本命導向：84.8%  ← 改善+9.8%
損益平衡點：100%
```

### 3. 「絕對能贏的AI」並不存在

這一點可以斷言。**無論多優秀的AI，若以所有比賽為對象，都極難穩定維持回收率超過100%**。

理由：
- 賽艇存在起跑時機、風向、浪況等**大量即時變數**
- AI能分析的僅限於出賽前的數據
- 賠率反映了所有市場參與者的知識

## 那麼，該如何活用？

### 策略1：鎖定會場

不是買全24個會場，而是**集中在AI擅長的會場**。

BoatAI在7個會場實裝了獨自的分析規則，這些會場的準確度有較高的傾向。

### 策略2：篩選條件

BoatAI的預測附有「信心度」分數。**鎖定信心度高的預測**，能改善命中率・回收率。

### 策略3：靈活運用投注組合種類

- **穩健導向**：複勝（命中率約70%的實績）
- **重視回收率**：單勝（截至2026年1月，曾有回收率超過90%的實績）
- **一擊逆轉**：3連複（命中率18.0%的實績）或3連單（依會場而定，超過100%的情況眾多）

最新的命中率・回收率請見[成績頁面](/accuracy)。

### 策略4：徹底做好資金管理

AI預測終究只是**參考資訊**。請務必遵守以下事項：

- 事先決定每日預算
- 不因想扳回輸的部分而追加投資
- 不動用生活費
- 請一併確認[責任博彩](/responsible-gambling)頁面
