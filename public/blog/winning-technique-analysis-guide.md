# 決まり手データの見方｜江戸川の1号艇逃げ194回と分母の読み分け

ボートレースの決まり手データは「勝ったときの内訳」を示し、江戸川の1号艇の逃げは216レース中194回（89.8%）でした（2026年7月11日〜2026年9月28日、1号艇が1着だった保存記録）。「どれだけ勝ったか」と「どう勝ったか」を分けると、インを軸に考えた後の展開まで読み進められます。

会場・枠番ごとの内訳を見る入口は、[龍神レーダーの決まり手データ分析](/winning-technique?tab=technique)です。会場を選ぶと枠番別のグラフがあり、その下の表で決まり手・回数・出現割合を読めます。

## 江戸川の1号艇は、216勝のうち逃げ194回

2026年7月11日〜2026年9月28日の江戸川の保存記録では、1号艇が1着だったのは216レース。その勝ち方は、逃げ194回、抜き21回、恵まれ1回でした。ここでの1号艇は号艇、つまり枠番です。

| 江戸川・1号艇が勝った決まり手 | 同期間に1号艇が1着だった216レースの内訳 |
|---|---|
| 逃げ | 216レース中194回（89.8%） |
| 抜き | 216レース中21回 |
| 恵まれ | 216レース中1回 |

この表が答えるのは、「1号艇が勝ったとき、どんな決まり手だったか」です。1号艇の勝ち方を考えるなら、この期間の江戸川では、まず逃げを起点に読み、道中で逆転した抜きも別の勝ち方として捉えられます。

抜き21回と恵まれ1回は、同じ「逃げ以外の1着」でも意味が違います。抜きは道中で前の艇を抜いて勝った結果、恵まれは先行艇の事故などによって勝った結果です。逃げ以外をまとめて「外から攻めた勝ち方」と扱うより、この内訳を残した方がレースの姿に近づきます。

## 1着率と決まり手構成比は、分母が違う

1着率は、その枠番が出走したレース全体のうち、1着になった割合です。決まり手構成比は、その枠番が1着になったレースだけを集め、勝ち方を分けた割合です。「1号艇の逃げ」の文字があっても、分母によって答えている問いが変わります。

| 知りたい問い | 分母に置くレース | 分子に置く結果 |
|---|---|---|
| 1号艇はどれだけ勝ったか | 1号艇が出走したレース全体 | 1号艇が1着になったレース |
| 1号艇が勝つとき、逃げはどれだけあったか | 1号艇が1着になったレース | そのうち決まり手が逃げのレース |
| 全体の中で1号艇の逃げはどれだけあったか | 1号艇が出走したレース全体 | 1号艇が逃げで1着になったレース |

同期間の江戸川で1号艇が勝った216レース中194回（89.8%）という逃げの割合は、真ん中の問いへの答えです。1号艇の1着を考える段階では、出走全体に対する成績を読み、その次に決まり手の内訳へ進むと、数字の役割がつながります。

上級者向けには、集める範囲の順序も大切です。**全出走から1着のレースへ、さらにその決まり手へ**と絞っています。同じ期間・同じ出走記録を使うなら、全出走に対する「逃げでの1着」の割合は、「1着率」と「勝った中での逃げ構成比」を掛けたものになります。決まり手の表で逃げの部分だけを見るより、先に1着へ残る頻度を押さえることに意味があります。

## 逃げ・差し・まくり・まくり差しを分ける

決まり手は、1着艇がどう勝ったかを表します。レースを見るときは、次のように攻めた場所と勝ち方を分けると、実況や結果欄と結び付きます。

| 決まり手 | 勝ち方の読み方 |
|---|---|
| 逃げ | インから先に回り、そのまま先頭を守って勝つ |
| 差し | 内の艇が回った後の空いた内側を通って勝つ |
| まくり | 内の艇を外側から回って勝つ |
| まくり差し | 外からまくりつつ、艇の間を内へ差して勝つ |
| 抜き | 道中で前を走る艇を抜いて勝つ |
| 恵まれ | 先行艇の事故などによって勝つ |

差しとまくりは、内側を通るか外側を回るかで分かれます。まくり差しは、その両方の動きを含む勝ち方です。内の艇が先に回る形を考えるときと、外の艇が攻めて出る形を考えるときでは、着目する決まり手も変わります。

勝つ艇の候補を決めた後、後続の相手まで考えるなら、[スジ舟券の意味と決まり手別の読み方](/blog/suji-funaken-guide)へ進めます。決まり手は勝者の攻め方を読む入口で、後続については、その攻め方の後にどの艇が残ったかという別の結果を使います。

## 今日のレースでは、進入から決まり手の順に読む

今日の江戸川を見るなら、[江戸川の会場別レース一覧](/venue/3)から対象レースの出走表へ進めます。まず枠番と進入の見立てを結び付け、次に選手のコース別成績や展示を読み、最後に会場の決まり手の内訳を重ねる順序です。

たとえば、1号艇がインから走る形を考えたら、先に回れる材料を出走表と展示から探します。外の艇が攻める形を考えたら、外を回るまくりなのか、内へ切り込むまくり差しなのかまで分けます。こうすると、「外の艇が強そう」という印象を、どこを通って先頭へ出る展開なのかという問いへ具体化できます。

展示進入は、枠番と実際に入る位置を結び付ける材料です。決まり手のグラフの枠番を起点にしつつ、今日どの位置から走るかを出走表や直前情報と合わせて読むと、会場の過去の勝ち方を今日の組み合わせに重ねられます。

## データを使うときの注意

本文の江戸川の数字は、2026年7月11日〜2026年9月28日の保存記録に限った例です。決まり手データ分析の画面は過去90日間の集計なので、更新後の表示とは期間が異なります。本番の進入コース別、欠場・返還の有無別の内訳は、この例の範囲外です。

抜き21回・恵まれ1回のように30回未満の結果は、件数で捉えます。この記録だけで会場の順位や季節差、個々の選手の得意不得意までは言えません。過去の内訳は今後の結果を保証するものではなく、今日の進入・選手・展示と合わせる判断材料です。
