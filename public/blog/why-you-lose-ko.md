# 경정에서 이기지 못하는 사람들의 5가지 공통점과 AI예측의 해결책

## 왜 당신은 경정에서 이기지 못하는가?

「오늘이야말로 적중시키겠다」는 마음으로 마권을 사지만, 또 빗나간다.

정신을 차려보면 이번 달도 적자... 이런 경험 있지 않으신가요?

사실 경정에서 이기지 못하는 사람에게는 **명확한 공통점**이 있습니다. 이 글에서는 1,899경기 데이터 분석으로 밝혀진 「패배 패턴」과, AI예측을 활용한 해결책을 전달합니다.

---

## 공통점1: 「1번정이니까 산다」는 사고 정지

### ❌ 패배 패턴

「1번정은 승률이 높으니까, 일단 1번정을 사두면 안심」

이는 언뜻 맞는 말처럼 보이지만, 사실은 **경정에서 지는 사람의 전형적인 패턴**입니다.

**왜 지는가:**
- 1번정의 전국 평균 승률: 약 55%
- 즉 45%는 진다
- 게다가 배당률이 낮아, 적중해도 회수율이 나쁘다

**실제 사례:**
```
에도가와 3R: 1번정 단승 배당률 1.2배
→ 100엔을 사서 적중해도 120엔(+20엔)
→ 2번 빗나가면 -80엔
→ 합계 -60엔
```

### ✅ AI예측의 해결책

BoatAI는 「1번정이니까」가 아니라, **45개 항목의 데이터로 종합 판단**합니다.

**분석 항목:**
- 선수의 등급, 승률, 현지 승률
- 모터 연대율(가장 중요)
- 전시 항주 타임
- 풍향・풍속・수면 상황
- 과거 동일 조건 레이스에서의 경향

**결과:**
에도가와처럼 「1번정 승률이 낮은 경기장」에서는 2~4번정을 추천하는 경우도 많아, 적중률이 향상됩니다.

## 공통점2: 모터 성능을 보지 않는다

### ❌ 패배 패턴

「A1급 선수니까 이기겠지」라고 선수만 보고 판단한다.

**현실:**
아무리 우수한 선수라도, **모터가 나쁘면 이길 수 없습니다**.

경정은 「선수 3할, 모터 7할」이라고 할 만큼, 모터 성능이 승패를 좌우합니다.

**실제 사례:**
```
A1급 선수가 모터 연대율 25%의 정에 탑승했을 경우
→ 1착률: 약 15%(평소의 절반 이하)

B1급 선수가 모터 연대율 50%의 정에 탑승했을 경우
→ 1착률: 약 25%(A1급을 웃도는 경우도 있음)
```

### ✅ AI예측의 해결책

BoatAI는 **모터 연대율을 최우선으로 평가**합니다.

**판단 기준:**
- 모터 연대율 45% 이상: 초우량(적극적으로 노림)
- 모터 연대율 35~45%: 표준(선수에 따라 다름)
- 모터 연대율 35% 미만: 주의 필요(축에서 제외)

**12/10의 성공 사례:**
모터 연대율 46.7%의 5번정(B1급 선수)을 축으로 추천
→ 적중, 회수율 208.1% 달성

## 공통점3: 전시 항주를 보지 않는다(또는 보는 법을 모른다)

### ❌ 패배 패턴

「전시 항주가 뭐야? 안 봐도 되지 않아?」

또는

「전시 타임이 1위라서 샀는데 졌다!」

**문제점:**
- 전시 항주를 안 보는 것은 논외
- 전시 타임만 보는 것도 불충분
- 턴 회전, 가속력, 신장력도 봐야 한다

**하지만:**
초보자가 전시 항주를 정확하게 분석하는 것은 **거의 불가능**합니다.

### ✅ AI예측의 해결책

BoatAI는 전시 항주를 **다각도로 분석**합니다.

**분석 내용:**
- 전시 타임
- 턴의 회전 속도
- 스타트 전시의 가속력
- 경기장별 전시 신뢰도

**경기장별 전시 신뢰도:**
- 오무라, 아시야: 전시대로 전개되는 경우가 많음 → 전시 중시
- 토다, 에도가와: 전시와 본선이 괴리되기 쉬움 → 전시 경시

이 조정을 통해 적중률이 크게 향상됩니다.

## 공통점4: 감정으로 산다(추가 베팅・흥분)

### ❌ 패배 패턴

**패턴A: 추가 베팅**
```
1R 빗나감 → 2R에서 만회하려고 배액 구매
2R 빗나감 → 3R에서 다시 배액 구매
3R 빗나감 → 정신을 차려보니 자금이 바닥
```

**패턴B: 적중 후 과신**
```
1R 적중 → 「오늘 컨디션 좋은데!」라며 고액 구매
2R 빗나감 → 적중분을 전부 잃음
```

**문제점:**
감정적인 판단은 통계적으로 **반드시 진다**.

### ✅ AI예측의 해결책

AI는 **항상 냉정**합니다.

**장점:**
- 이전 레이스 결과에 영향받지 않음
- 매 레이스, 같은 로직으로 판단
- 감정에 의한 판단 실수가 제로

**추천하는 자금 관리:**
1. 하루 예산을 정한다(예: 3,000엔)
2. 1레이스 100엔으로 고정한다
3. 적중해도 구매액을 바꾸지 않는다
4. 빗나가도 추가 베팅하지 않는다

BoatAI의 예측대로 **기계적으로 구매**함으로써, 장기적인 흑자 수지를 노릴 수 있습니다.

## 공통점5: 회수율을 무시하고 적중률만 쫓는다

### ❌ 패배 패턴

「오늘은 10레이스 중 7레이스 적중! 적중률 70%!」

하지만 수지는...

```
투자: 1,000엔(100엔×10레이스)
환급: 840엔(120엔×7레이스)
수지: -160엔
```

**적중률 70%여도 적자**라는 현실.

**문제점:**
적중률이 높아도, 회수율이 100%를 밑돌면 적자입니다.

### ✅ AI예측의 해결책

BoatAI는 **회수율을 최우선**으로 합니다.

**마권 종류별 전략:**

**연승:**
- 적중률: 52.1%
- 회수율: 114.2%
- 전략: 꾸준히 이익을 쌓는다

**삼복승:**
- 적중률: 15.3%
- 회수율: 208.1%
- 전략: 중배당을 노려 효율적으로 번다

**삼쌍승:**
- 적중률: 5.6%
- 회수율: 1343.8%(12/10 실적)
- 전략: 고배당으로 단숨에 이익을 낸다

**중요한 사고방식:**
적중률 30%여도, 회수율 150%라면 대성공입니다.

## 정리: 이기지 못하는 이유는 「정보 부족」

경정에서 이기지 못하는 사람의 공통점은 **압도적인 정보 부족**입니다.

**필요한 정보:**
1. 모터 성능(연대율)
2. 선수의 강한 경기장(현지 승률)
3. 전시 항주의 다각도 분석
4. 풍향・풍속・수면 상황
5. 과거 동일 조건 레이스 데이터

이것들을 사람이 매 레이스마다 분석하는 것은 **불가능**합니다.

그렇기 때문에 AI의 힘을 빌리는 것입니다.
