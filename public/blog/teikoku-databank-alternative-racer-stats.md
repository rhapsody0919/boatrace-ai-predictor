# 艇国データバンクの代わりは？選手成績を最大15期と進入コース別で調べる

艇国データバンクの代わりに選手成績を調べるなら、龍神レーダーの選手ページで最大15期分（2018年11月1日〜2026年4月30日）の期別成績と、進入コース別成績を見られます。たとえば2026年後期の成績でA1に決まった331人の6コース進入数は、同じ期の中央値で16走です。

調べる入口は[龍神レーダーの選手一覧](/racers)です。まず選手を開き、知りたいことが「長期の成績」か「今日入るコースでの残り方」かで、読む表を選びます。

## 艇国データバンクの代わりに選手成績を探す入口

艇国データバンクは2026年10月23日に閉鎖したと報じられています。[閉鎖を伝えた記事](https://kyotei-mania.com/teikoku-closed)では、選手の過去成績やコース別データを調べる先が必要になったことも取り上げられています。

龍神レーダーで選手成績へ進む経路は、次のとおりです。

1. 選手一覧で支部や級別などを絞り、調べたい選手名を開く。名前が分かっていれば、ヘッダーの「選手名で検索」から漢字・ひらがなで探す。
2. 選手ページの「公式成績（期別・進入コース別）」で、期ごとの集計期間と出走数を読む。
3. 今日の進入位置に合わせて「進入コース別成績（公式）」の行を読む。今日の号艇から調べるときは「枠番別成績」を使う。

登録番号が分かる場合は、[選手ページの例（登録番号4320）](/racer/4320)のように個人ページを直接開けます。プロフィールや節目の記録も調べたい人は、[選手個人ページのプロフィール・記録の読み方](/blog/racer-profile-page-guide)へ進めます。

## 期別成績は「級の適用」と「集計期間」を分けて読む

「2026年後期」の成績が集めるのは、2025年11月1日〜2026年4月30日の走りです。その成績で決まった級が使われるのは、2026年7月〜12月。表の期名は、走った半年と級が使われる半年を結び付けています。

直近の期を並べると、対応は次のようになります。

| 期の名前 | 成績の集計期間 | その成績で決まった級の適用期間 |
|---|---|---|
| 2026年後期 | 2025年11月1日〜2026年4月30日 | 2026年7月〜12月 |
| 2026年前期 | 2025年5月1日〜2025年10月31日 | 2026年1月〜6月 |
| 2025年後期 | 2024年11月1日〜2025年4月30日 | 2025年7月〜12月 |

たとえば、過去の成績を級別に読みたいときは、「この期で決まった級」と「適用」の列を合わせます。今の級だけで過去の表を読み進めるより、各期にどの成績を残し、その後どの級で走ることになったかをたどれます。

長期の歩みを調べるときは、勝率の推移に加えて出走数を追います。勝率は着順点の平均、2連対率は2着以内、3連対率は3着以内に入った割合です。安定して上位に残ったかという問いには、勝率の線だけでなく連対率の列も使えます。

## コース別は進入数とセットで読む｜A1の6コースは中央値16走

2026年後期の成績でA1に決まった331人について、2025年11月1日〜2026年4月30日の進入数を見ると、1コースの中央値は26走、6コースは16走でした。ここでの中央値は、選手ごとの進入数を並べた中央の値です。

| 進入コース | A1選手331人の進入数の中央値（2025年11月1日〜2026年4月30日） |
|---|---:|
| 1コース | 26走 |
| 2コース | 20走 |
| 3コース | 20走 |
| 4コース | 20走 |
| 5コース | 19走 |
| 6コース | 16走 |

これは全選手を足したレース数でも、勝った回数でもなく、選手ごとにそのコースで走った回数の中央の値です。「外からどれだけ残ったか」を読む前に、その選手には外から走った記録が何走あるかを見る理由が、この表から分かります。

選手ページの進入コース別成績は、出走とコース別データのある直近3期をまとめた表です。期間を広げた成績を起点にし、今日入ると考えたコースの進入数と、1着率・2連対率・3連対率を一緒に読みます。

## インの残り方は進入コース別、今日の枠は枠番別で読む

インから勝ち切る実績を知りたいなら、進入コース別の1コースの1着率へ進みます。1コースから上位に残った実績まで見たいなら、2連対率・3連対率も読む対象です。今日の先マイ（最初のターンマークを先に回ること）を想定するときにも、勝ち切る実績と上位に残る実績を分けて材料にできます。

一方、枠番別成績が答えるのは「何号艇で出たときの成績か」です。1号艇で出て実際には別のコースに入ったレースも、枠番では1号艇として扱います。前付けなどで進入が変わるレースを考えるときは、実際の進入位置に沿った表と、出走表の号艇に沿った表を使い分けると、問いと数字がつながります。

複数期の進入コース別2連対率は、各期の率を単純に平均するのではなく、そのコースの1着回数と2着回数を期をまたいで足し、進入数の合計で割った値です。出走数の違う期をまとめるときも、各走が同じ重みになります。

今日使うなら、[本日の開催を探せるレース一覧](/races)で対象レースを開き、「この艇は何コースに入りそうか」を先に考えます。そのうえで選手ページの該当コースの進入数と成績を読み、展示進入を見て、読む行を合わせます。インの1着を問うのか、外の艇の2着以内を問うのかまで言葉にすると、使う列も決まります。

## データを読むときの注意

2026年10月29日時点で期別成績が扱う範囲は、2018年11月〜2026年4月の最大15期です。選手ごとに記録のある期数は異なり、デビューからの生涯通算や、1月〜12月の暦年別成績とは異なります。進入コース別の合算期間は表の見出しにあり、出走のない期を飛ばしている場合も、その期間に沿って読みます。

期別成績の最新は2026年4月30日までで、出走表の全国勝率とは集計期間が異なります。期ごとの勝率の上下だけで、今日の好調・不調を決めることは避けます。

コースの進入が30走未満なら、割合の大小より出走数と着順の記録を中心に読みます。展示進入と本番の進入が変わる場合もあります。過去の成績は今日の着順を保証するものではありません。
