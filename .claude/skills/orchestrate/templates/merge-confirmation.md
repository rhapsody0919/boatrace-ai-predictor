# ユーザーへのマージ確認の雛形

- 確認は1件ずつ出さず、溜まった分をまとめて1回で出す
- ユーザーが他のセッションや PR を見に行かなくても判断できる形にする。中身はレーンの報告から転記する
- 「確認するなら」のような任意の書き方をしない。「確認すること: ○○／不要」と言い切る
- 本番で実行する SQL がある場合は、全文を1ファイルにまとめて SendUserFile で渡し、ここにはそのファイル名を書く

---

マージの確認が {n} 件ある。マージ順: #{a} → #{b} → #{c}

### PR #{番号}: {タイトル}（{PR の URL}）

**あなたが確認すること**
- {開く URL}
- {押すタブ・操作の手順}
- {見るポイント（新旧の違い、期待される表示）}
- （画面が変わらない PR なら「確認不要」。判断が要る点があればそれだけを書く）

**私が確認済みのこと**
- CI: 全部緑／CLEAN
- レビュー: {PR コメントの URL}。指摘 {n} 件、うち修正 {n} 件・理由付きで見送り {n} 件
- 実データ・本番での確認: {結果／該当なし}
- ファイルの重なり: {#番号 と {ファイル}／なし}
- マージ順: {#番号 の後／制約なし}

**判断材料**
- 変更内容: {1〜3行}
- 残るリスク: {あれば／なし}
- squash: {必要／不要}
- 本番で実行する SQL: {SendUserFile で渡したファイル名／なし}
