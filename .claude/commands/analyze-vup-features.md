# ボートレース日和 バージョンアップ機能一覧

kyoteibiyori.com/vup/ から全バージョンアップ機能をスクレイピングして表示します。

## 実行手順

1. **機能スクレイピング**
   ```bash
   node scripts/analysis/scrape-kyotei-vup.js
   ```

2. **結果から興味のある機能を選ぶ**
   - 日付（最新順）
   - 機能名
   - 説明

3. **精査対象機能を指定**
   - 以下のコマンドで詳細分析を実行してください
   ```
   /analyze-vup-feature {機能名}
   ```

## boataiへの適用判断ポイント

各機能について以下の視点から親和性を評価します：

✅ **既存デザイン・UX向上** — スマホ対応？既存UIと調和？
✅ **買い目予想・根拠提示** — 予想精度向上？信頼度向上？
✅ **分析に役立つ** — データ分析、統計情報の活用度
✅ **「この舟は来ない根拠」になるか** — 除外判断の根拠として機能するか？（最重視）

---

**実行例：**
```
/analyze-vup-feature スロー／ダッシュ表示
```

このコマンドで、指定機能の詳細分析と実装案、Linearチケット化を行います。
