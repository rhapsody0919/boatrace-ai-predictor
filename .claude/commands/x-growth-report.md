# X集客状況レポート（自アカウント投稿実績＋競合定点観測）

X（Twitter）自体のパフォーマンス（インプレッション・いいね数・フォロワー推移）と競合アカウントの動向を定点観測し、次の投稿・運用施策につなげます。

`/growth-report`・`/growth-pdca`がSearch Console/GA4（検索流入・ブログ側）を扱うのに対し、このスキルは**Xというプラットフォーム自体のパフォーマンス**を扱う。X APIは契約していないため、Chrome in Claudeで実際の画面を開いて数値を読み取る方式を取る。

## 実行手順

### 0. 前回提案した施策の実施・効果検証（必須、最初に行う）

PDCAの「C→A」を閉じるための最重要ステップ。**新しいデータを集める前に**、直近の`data/analysis/x-growth/report-*.json`（またはmemory）に残っている「前回の提案」を確認し、以下を明示する。

- 前回提案した施策（投稿時間帯変更、フォーマット変更等）は実際に実行されたか
- 実行された場合、その後の投稿実績に変化が見えるか（今回集めるデータと突き合わせる）
- 実行されていない場合、なぜか（判断が保留された/優先度が下がった等）を記録する

過去レポートが無い初回実行時はこのステップをスキップし、その旨を明記する。

### 1. 自アカウント（@kyouteiboatai）の投稿実績を確認

Chrome in Claudeで`https://x.com/kyouteiboatai`を開き、直近の投稿（目安5〜10件）について、**各投稿を個別に開いて「アナリティクスを表示」（インプレッション数・エンゲージメント率・プロフィールクリック数・リンククリック数が出る詳細画面）まで確認する**。フィード上のいいね・リポスト数だけを見て終わらせない（それだけでは精度不足）。

記録する項目:
- 投稿日時・内容の概要（動画/テキストのみ/ブログ告知等の種別、A/Bテストがあればどのバリエーションか）
- インプレッション数・エンゲージメント率・いいね数・リポスト数・返信数
- プロフィールクリック数・リンククリック数（詳細アナリティクスで見える場合）
- フォロワー数の現在値（プロフィール画面）

結果を`data/analysis/x-growth/report-{日付}.json`に保存する（構造: `{generatedAt, followerCount, previousActionsReview: [...], posts: [{postedAt, type, summary, impressions, engagementRate, likes, reposts, replies, profileClicks, linkClicks}]}`）。専用スクリプトは無い（X APIが無いため）。Writeツールで直接書き込む。

### 2. 判断基準（しきい値）— 分析を「なんとなく」で終わらせないために

数値を見て終わりにせず、以下を基準に「注目に値する差か、ただのばらつきか」を判定する。

- **母数が少ない段階（投稿10件未満）の警告**: この段階での「動画とテキストどちらが強いか」等の比較は、統計的に意味のある結論を出すには早すぎる。傾向として言及してよいが、断定はしない
- **外部基準（2026-08-22調査より）**: 同ジャンルの類似アカウント（ボートレース日和、フォロワー2.9万人）の通常投稿は表示回数3,000〜4,300件、価値提供型の突出投稿は49万件。フォロワー規模が近づいてきたらこの水準と比較する。フォロワーが少ない段階では絶対数の比較よりも「自アカウント内での相対的な伸び」を見る
- **内部基準（自アカウントの推移が十分に貯まってから）**: 直近5〜10投稿の中央値をベースラインとし、そこから明確に外れた投稿（2倍以上／半分以下）を「なぜそうなったか」の分析対象にする

### 3. 過去レポートとの比較（Claudeが実施）

`data/analysis/x-growth/report-*.json`の過去分と比較し、以下を算出する。

- フォロワー数の増減
- 投稿タイプ別（動画 / テキストのみ / ブログ告知）の平均インプレッション・エンゲージメント率の比較（ステップ2の母数警告を踏まえて解釈する）
- マスコットキャラ3体（A'/B'/C'）のようなA/Bテスト企画がある場合、各バリエーションの数値を横並びで比較する

### 4. 競合アカウントの定点観測（頻度: 月1回目安、毎回はしない）

競合アカウントの投稿傾向は短期間で大きくは変わらないため、**毎回リサーチし直さない**。前回調査から1ヶ月以上経っている場合のみ、以下を実施する。

- 前回調査対象アカウント（`sns_marketing_phased_strategy_2026_08_22`memory参照）のプロフィールを再訪問し、フォロワー数・投稿頻度・フォーマットに変化が無いか確認する
- 新規に伸びているアカウントが無いかWebSearchで軽く確認する
- X公式のベストプラクティス・アルゴリズムに関する新しい発表が無いか確認する（`business.x.com/en/basics/organic-best-practices`、X公式ブログ等）

前回調査から1ヶ月未満の場合は「前回調査済み、変化なしと仮定」と明記してこのステップを省略してよい。

### 5. 下書き・投稿キューの消化状況

```bash
grep -c "^- \[ \] 投稿済み" note-articles/tweet-drafts.md
```

加えて、動画投稿用のキャプション下書きファイル（`scratch-tiktok-pilot/x-*-video-captions.md`等、プロジェクトによってファイル名は変わる）があれば同様に未消化件数を確認する。未消化が多い場合は他の施策より優先度を上げて報告する（`/growth-pdca`と同じ方針）。

### 6. 統合分析・次の施策

上記を踏まえ、次の投稿・運用施策を提案する。判断基準は`/growth-pdca`と同じ「インパクト×工数」マッピングを使う。**次回このスキルを実行する際にステップ0で検証できるよう、提案した施策は具体的に（「投稿時間を21時→20時に変更」等、後から実行有無を判定できる粒度で）書く**。

- 小施策（即実行）の例: 投稿時間帯の見直し、キャプションのハッシュタグ調整、反応の良かった投稿フォーマットの横展開
- 大施策（提案のみ）の例: 新しい動画フォーマットの開発、TikTok解禁の判断、マスコットキャラの勝者確定・統一

## 解釈の注意点

- Xのインプレッション数は投稿後24〜48時間で大きく伸びが止まる傾向があるため、投稿直後（数時間以内）の数値だけで判断しない
- フォロワー数が少ない段階（1万人未満目安）は母数が小さく、数件のバズ投稿で平均値が大きく歪むため、中央値や個別投稿の傾向も併記する
- 「インプレッションが低い」原因が投稿内容なのか投稿頻度なのかタイミングなのかを切り分ける（`docs/operation/sns-posting-operations.md`の運用フローと照らし合わせる）
- Xの投稿詳細アナリティクス画面が何らかの理由で開けない場合（権限・UI変更等）は、フィード上のいいね・リポスト数のみで代替した旨を明記し、精度が落ちることを報告に含める
