# コーディング規約

## 用語・表記
- 「競艇」は使用禁止 →「ボートレース」を使用する（コード・ドキュメント・ブログ本文・見出し・UI表示テキストすべて）。理由: 「競艇」という表記を使うと役所（自治体・公的機関）の広告出稿対象から外れるため
- **例外1（2026-09-29 範囲を明確化）**: Webアプリの画面内に描画されないメタ情報は「競艇」使用可。対象は `<title>`・`meta description`・`meta keywords`・OGP/Twitterカード（`og:title`/`og:description`等）。ブラウザのタブ名・検索結果の見出しと説明文・SNS共有カードに出ることは許容する。ページ本文・見出し（h1等）・UIに表示されるテキストは例外対象外（本文は引き続き「ボートレース」で統一）
- **例外1・2は暫定措置**: 認知度が上がり役所へ広告営業に行くまでの措置。営業前に例外1・2の「競艇」表記をすべて外す。外せるよう、メタ情報に「競艇」を入れる変更はコミットメッセージかPR本文に明記する
- **例外2（2026-09-25 ユーザー判断）**: **SNS投稿のハッシュタグ**（`#競艇` 等）は使用可。検索・発見のための語であり、広告出稿の審査で見られる本文とは別物という判断。**投稿の本文・ナレーション・画像や動画に焼き込む文字は例外対象外**（引き続き「ボートレース」で統一する）

デザイン統一・CSS・Reactのルールは`.claude/rules/component-reuse.md`（`src/**`編集時のみ自動読み込み）を参照。

## JavaScript/Node.js
- ES Modules（import/export）を使用
- async/awaitを使用（コールバック地獄を避ける）
- エラーハンドリングは適切に行う
